## 概要

MapFan API は、ジオテクノロジーズの日本地図データを使い、Web システムや Web サイトに地図表示、住所・スポット検索、ルート検索などを組み込むための法人向けクラウドサービスである。地図はラスタ (WMTS 形式のタイル、サイズ指定の静止画像) とベクタータイルで提供する。道路単位の通行量 (人流データから推計) や VICS 渋滞考慮ルートなどの有償オプションがある (出典: 公式サイト)。契約はジオテクノロジーズとの直接契約と、API マーケットプレイス RapidAPI 経由の 2 通りがある。

## 地図データ

- データの出どころ (自社調査 / OSM / 他社からのライセンス): 自社調査。公式サイトは「自社による独自調査」「車が通行できる全国の道路をくまなく走行調査」と説明し、走行距離は延べ 720 万 km、撮影画像などは 40 億枚超としている (出典: ジオテクノロジーズの強み)。ベクタ地図 API の仕様は「GeoTechnologies 製日本地図データ」と書く (出典: ベクター地図 API v2 仕様)。
- 国内の詳しさ (建物の形状、住所・番地、POI、道路の属性、注記): 住所逆引き検索は町丁目と番地・号まで返す。道路情報は道路種別、道路名称、最高速度、レーン数、幅員、交差点名称、信号、一時停止、通行規制などを取得できる。スポット検索は営業時間や付帯設備、トラック向け設備情報 (オプション) を返す (出典: 公式サイトの機能一覧)。地図データの元になる MapFan DB は「詳細な建物を表現する大縮尺地図」を含むとしている (出典: MapFan DB)。道路ネットワークの規模は API ページで「全国約 190 万 km」(2026 年 3 月現在)、MapFan DB ページで「約 130 万 km」とあり、数え方の違いと思われるが説明はない。
- 全球の対応: 日本のみと読める (ベクタ地図は「GeoTechnologies 製日本地図データ」)。地名や施設名の表示言語は 13 か国 (14 言語) に対応する (出典: 公式サイト)。海外の地図データの提供有無は明記がない。
- 更新頻度: 年 12 回 (毎月) (出典: 公式サイトのよくある質問)。

## 提供形式と機能

| 機能 | 有無 | 備考 |
|---|---|---|
| ラスタタイル | あり | JavaScript 向けの WMTS 形式の地図タイル画像と、サイズ指定の静止地図画像。印刷向けのモノクロデザインを含む複数スタイル (出典: 公式サイト) |
| ベクトルタイル (形式、スキーマ) | あり (別途申込) | MVT。v2 は PMTiles で配信し、スタイルは Mapbox Style Specification 準拠。スタイルは `mapfan`、`mapfan_light` とそれぞれのロゴ非表示版の 4 種。レイヤ定義 (スキーマ) は公開ページで確認できなかった (出典: ベクター地図 API v2 仕様) |
| スタイルの編集・カスタマイズ | あり | ベクタ地図は利用者側で色やフォントを変更できる。Maputnik 向けのスタイル取得 API がある (出典: 公式サイト、ベクター地図 API v2 仕様) |
| 衛星・航空写真 | 記載なし | 機能一覧に航空写真・衛星画像の配信はない |
| 地形・3D 建物 | 記載なし | 機能一覧に地形や 3D 建物の表示はない。ルート形状点に標高値を付ける「標高値付きルート検索」(有償オプション) はある |
| ジオコーディング / 逆ジオコーディング | あり | 住所検索、住所逆引き (番地・号まで)、住所階層検索、郵便番号検索、駅検索、スポット検索。保存には「複製オプション」が必要 |
| ルート検索 | あり | 自動車、歩行者、車種別規制考慮、巡回 (経由地最大 30)、経路マトリクス (最大 50 地点・2,500 ルート)、マップマッチング。VICS 渋滞考慮は有償オプション |
| オフライン利用 | なし | 配信型のサービスで、データの複製は原則禁止。「複製オプション」契約中に限り社内ネットワーク内で API 出力を保存できる (出典: 利用規約第 4 条) |

## 対応ライブラリ

- 公式 SDK (Web / Android / iOS): Web 向けに MapFan API JavaScript ライブラリがある。動作確認環境は Windows 11 の Chrome / Edge、iOS 18・26 の Safari、Android 16〜17 の Chrome (出典: 公式サイト)。Android / iOS のネイティブ SDK は公式サイトに記載がない。
- 公式以外のライブラリから使えるか (MapLibre GL JS, Leaflet, OpenLayers など): ベクター地図 API v2 は MapLibre GL JS などの PMTiles 対応ライブラリで使うと明記している。MapLibre GL JS では PMTiles ライブラリが必要。v2 は Mapbox GL JS では使えない (出典: ベクター地図 API v2 仕様)。ラスタタイルを Leaflet や OpenLayers から使えるかは公開資料で確かめられなかった。
- 組み合わせの制約 (特定の SDK でしか表示してはならない等): 利用規約第 4 条第 5 項で、仕様書に定める方法以外でのデータ利用は保証・損害賠償の対象外とされる。特定 SDK に限る禁止条項は見つからなかった。
- API キー・アカウントの要否: 必要。直接契約では申込後に技術仕様書の開示とアクセス許可登録が行われる。RapidAPI ではアカウント作成後すぐに API キーを発行できる (出典: 公式サイトの導入フロー)。

## 料金

- 課金単位 (地図ロード、タイルリクエスト、MAU など): RapidAPI のプランは「地図」「検索」「経路」の機能単位で、月間アクセス数で上限と超過料金が決まる。地図は「地図タイル」と「サイズ指定地図」を別に数える (出典: 公式サイトの料金プラン)。ベクター地図 API では、z/x/y で表す地図タイル領域 15 エリア分のアクセスで 1 PV と数え、style、glyph、sprite へのアクセスは数えない (出典: ベクター地図 API v2 仕様)。
- 無料枠: RapidAPI の Basic プランは無料で、地図タイル月 10,000 アクセス、サイズ指定地図・検索・経路は各月 1,500 アクセスまで。上限到達後は使えない (2026-11-10 確認)。利用規約には別に「無料プラン」(月 5,000 PV まで、移動体管理には使えない、印刷不可) と「体験プラン」(月 10,000 PV まで、開始から 3 か月、商用利用不可) の条件がある (出典: 利用規約の別紙 1、別紙 4)。直接契約向けに無料体験版の申込窓口がある。
- 従量単価 (主な API ごとに、通貨と確かめた日つき): 問い合わせ・見積もり制で、本ファイルには金額を載せない。有償プランの条件は申込者に開示される (2026-11-10 確認)。
- 月 10 万 / 100 万 / 1,000 万 地図ロードの概算 (計算式も書く。単位の換算に仮定を置いたら仮定も書く): 算出しない。単価が問い合わせ制のため、規模を伝えて見積もりを取る。見積もりを比べるときは課金単位に注意する (ベクター地図 API は 15 タイル領域で 1 PV と数えるので、1 地図ロードで 15 タイル前後を取ると仮定すれば、1 地図ロードがおよそ 1 PV になる。2026-11-10 にベクター地図 API v2 仕様で確認)。
- 契約形態 (セルフサーブ / 要見積もり / 年間契約): 無料の Basic プランは RapidAPI 経由でセルフサーブ。有償プランは問い合わせ・申込のうえで契約する。直接契約は見積もりと申込書による契約で、初年度の利用期間は 1 年が最小単位、以後 1 年単位で自動更新 (出典: 公式サイト、利用規約第 6 条)。

## 利用規約上の制約

- 商用利用: 直接契約と RapidAPI の有料プランは商用利用を前提とする。体験プランは商用利用不可、無料プランは移動体管理 (アセットトラッキング) 機能を持つサービスでは使えない (出典: 利用規約の別紙 1、別紙 4)。利用できるのは利用契約で定めた社内システムとインターネット上のサービスに限られ、別のサービスに使うには新たな契約が要る (第 3 条)。
- アクセス量の上限・公正利用の条件: 配信サーバに過大な負荷を与える行為 (バッチ処理を含む) をしないよう配慮する義務があり、過大な負荷を与えるリクエストは遮断されうる (第 4 条第 6 項、第 11 条第 5 項)。
- キャッシュ・オフライン保存: データの複製、抽出、加工、改変、二次利用は禁止 (第 4 条第 2 項)。「複製オプション」として指定された API を有償契約と複製オプションの契約期間中に使う場合に限り、社内ネットワーク内で複製・利用でき、契約終了後は消去する (第 4 条第 8 項)。一度使ったアクセスキーの保管・再使用も禁止 (第 4 条第 4 項)。閲覧者が自ら閲覧するための印刷は認められる (第 4 条第 3 項)。
- 帰属表示の要件: 表示するデータに「地図閲覧利用規約」(別紙 2) と著作権表記『© GeoTechnologies, Inc.』を表示する (第 4 条第 1 項)。
- 他社の地図との併用、データの持ち出しの制限: 他社の地図との併用を禁じる条項は見つからなかった。データの持ち出しは上記の複製禁止に従う。

## 安定性と運用

- SLA: 公開資料に SLA は見つからなかった。利用規約は、サービスが中断なく動作することを保証しないとし (第 11 条第 1 項)、保守や障害時に事前通知なく中断できるとする (同第 4 項)。損害賠償の上限は受領済み利用料または年間利用料の少ないほう (第 16 条)。サービスの一部または全部を予告なく変更・終了しうるが、全部を終了する場合は事前に通知する (第 7 条)。契約者向けのサポートは平日 9:30〜12:00 / 13:00〜17:30 (出典: 公式サイト)。
- 運営の継続性 (運営主体、資金源): ジオテクノロジーズ株式会社。社員数 583 名 (2026 年 4 月 1 日現在)。カーナビ向け地図データの提供実績を公式サイトで挙げている (出典: 会社概要、MapFan DB)。
- 障害情報の公開先: 未確認。利用規約は、中断後に書面または「本サービス案内サイト」で報告するとしている (第 11 条第 4 項)。

## 向いている場面

- 日本国内で、番地・号までの住所逆引き、車種別規制を考慮したルート検索、マップマッチングなど、カーナビ由来の道路データを使う業務システムを作る場合。
- 配送計画や動態管理など、地図表示とルート・検索 API を同じ提供元でそろえたい場合。
- 業務での地図の印刷利用が必要な場合 (公式サイトは「業務での印刷利用は即時可能」としている)。

## 向いていない場面

- 海外の地図が必要な場合。
- API の結果を自社データベースに自由に保存したい場合。複製オプションの契約が必要で、範囲も社内ネットワーク内に限られる。
- 契約前に公開単価だけで費用を見積もりたい場合 (料金は問い合わせ制)。
- 航空写真や 3D 表示を同じ提供元で使いたい場合。
