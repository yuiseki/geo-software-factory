# e-Stat の統計データと境界データ

対象: 政府統計の総合窓口 e-Stat の統計地理情報システム (国勢調査の小地域境界、地域メッシュ統計)

## 概要

e-Stat の統計地理情報システムは、国勢調査や経済センサスなどの小地域の統計と地域メッシュ統計、その集計単位の境界データを無償で配る。統計データは CSV で、境界データと結合するための KEY_CODE が付いている。境界データは統計の集計のために作られたもので、行政上の町丁界とは必ずしも一致しない。人口や事業所数などを町丁・字や 250m〜1km のメッシュで塗り分ける主題図の素材になる。

## 形式と取得方法

- 配布形式 (Shapefile、GeoJSON、GeoParquet、PMTiles、CSV など): 境界データは、世界測地系の緯度経度で Shapefile、GML、KML、平面直角座標系で Shapefile と GML。GeoJSON の配布は案内にない。統計データは CSV (カンマ区切り) だが拡張子は .txt で、比率の項目はダウンロードできない。ダウンロードファイルは圧縮されている。出典: https://www.e-stat.go.jp/help/data-definition-information/download
- 取得方法 (一括ダウンロード、API、範囲を絞った取得): 境界データダウンロードと統計データダウンロードの画面で、調査、年、地域を選んでファイルを取る。統計データは e-Stat API (バージョン 3.0 で小地域・地域メッシュのデータに対応、2019-10-18 告知) でも取れる。API はユーザー登録と、アプリケーションごとのアプリケーション ID が要る。API で境界データを取れるかは案内に書かれていない。出典: https://www.e-stat.go.jp/gis 、 https://www.e-stat.go.jp/api/ 、 https://www.e-stat.go.jp/api/api-info/api-guide
- 座標参照系: 境界データは世界測地系の緯度経度か平面直角座標系を選ぶ。地域メッシュ統計は、2020 年と 2021 年の調査が JGD2000 と JGD2011 の両方、それより前の調査は JGD2000 のみ。境界データの測地系の版 (JGD2000 か JGD2011 か) を調査ごとに確かめる必要がある。出典: https://www.e-stat.go.jp/help/data-definition-information/download

## 品質の限界

- 境界は統計の集計のために作られたもので、一般的な行政区域や地域の境界とは「必ずしも一致していません」と明記されている。目的に合うかは利用者が判断する。出典: https://www.e-stat.go.jp/help/data-definition-information/download
- 国勢調査の境界の町丁名が、住居表示上の町名と一致しないことがある。出典: 同上
- 都道府県境が接合されておらず、県をまたぐ市区町村合併などで境界がずれて見えることがある。他県の飛び地や水面調査区を含むことがある。同じコードの区域が複数ある市区町村があり、重複フラグで区別する。出典: 同上
- 経済センサスの境界では、名前のない区域が「その他」とされ、事業所数に誤記入が含まれることがある。出典: 同上
- 統計地理情報システムの面積按分による集計値は、小地域の値を面積で按分した推計で、実際の値と違うことがある。出典: https://www.e-stat.go.jp/gis-terms
- 国勢調査の境界は 5 年ごとで、町丁の新設や区画整理を次の調査まで反映しない (推測)。

## 地図プロダクトでの使いどころ

- 人口、世帯、年齢構成、事業所数などを町丁・字やメッシュで塗り分ける主題図。KEY_CODE で境界と統計を結合できる。
- 地域メッシュ (1km、500m、250m) で全国をそろえて比べる分析や、施設の商圏、空白地域の把握。
- 商用利用を含めて CC BY 4.0 互換の条件で使える統計の面データが欲しいとき。

## 向いていない場面

- 行政上の正確な町丁界や住所の境界が必要な場面 (住居表示の町界と一致しないことがある)。
- 毎年や毎月の新しさが要る場面。国勢調査は 5 年ごとで、境界も調査年のもの。
- GeoJSON や API での境界の取得を前提にした自動処理。境界は画面からの Shapefile、GML、KML の取得になる。
- 統計の秘匿 (小さい区域で数値が伏せられること) が問題になる細かい分析 (推測、本ファイルでは秘匿の扱いを確かめていない)。
