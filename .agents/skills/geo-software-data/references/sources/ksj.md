## 概要

国土数値情報は、地形、土地利用、行政区域、公共施設、交通、災害リスク、都市計画、地価などを国土交通省が GIS データとして整備し、無償で配布しているものである。全国を同じ仕様でそろえた主題データが多く、背景地図ではなく主題レイヤーの素材として使える。ただしデータ項目ごとに整備年度と更新の間隔がばらばらで、利用条件も項目と版ごとに違う。同じ項目でも古い版だけ非商用ということがあるので、使う版の条件を個別に確かめる必要がある。

## 形式と取得方法

- 配布形式 (Shapefile、GeoJSON、GeoParquet、PMTiles、CSV など): 現行の JPGIS 2.1 準拠のデータは GML (サイトの表記は xml)、Shapefile、GeoJSON で配られる。ただし GeoJSON が付かない項目もあり、避難施設 2012 年度版は GML と Shapefile のみである。旧形式として JPGIS 1.0 の XML、旧統一フォーマットの TXT と CSV もある。GeoParquet と PMTiles の配布は一覧ページに見当たらない。出典: https://nlftp.mlit.go.jp/ksj/index.html 、 https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P20.html
- 取得方法 (一括ダウンロード、API、範囲を絞った取得): データ項目ごとの詳細ページから、年度と地域 (全国、都道府県など) を選んで zip を一括ダウンロードする。一覧ページには API の案内がなく、閲覧用のウェブマッピングシステムの案内がある。出典: https://nlftp.mlit.go.jp/ksj/index.html
- 座標参照系: 新しい版は JGD2011 の緯度経度 (行政区域 2026 年版、学校 2023 年度版、医療機関 2020 年度版で確認)。古い版は JGD2000 のものがある (避難施設 2012 年度版は JGD2000)。出典: 各データの詳細ページ

- 出典表示の書き方 (公式の例): 「出典：国土交通省国土数値情報ダウンロードサイト（当該ページのURL）」、または「「国土数値情報（○○データ）」（国土交通省）（当該ページのURL）（○年○月○日取得）」。出典: https://nlftp.mlit.go.jp/ksj/other/agreement_01.html

## 品質の限界

- 項目ごとに時点が大きく違う。避難施設は 2012 年度版、公共施設は 2006 年版が最新のままで、自治体の最新の指定とずれている可能性がある。避難施設の詳細ページは、自治体が公表する最新の情報を確かめるよう注意している。出典: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P20.html 、 https://nlftp.mlit.go.jp/ksj/index.html
- 避難施設は自治体の地域防災計画などを原典としており、データの基準が市町村ごとに違うと書かれている。出典: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P20.html
- 行政区域は境界が未確定の市区町村があり、その部分の境界線は暫定的に引かれている。出典: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html
- 医療機関データには廃止された施設や院内の施設も含まれ、往診のみの施設は含まれない。出典: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P04-2020.html
- 古い版は JGD2000 で作られているものがあり、新しい版 (JGD2011) と重ねるときに測地系の違いに注意がいる。

## 地図プロダクトでの使いどころ

- 全国を同じ仕様でそろえた行政区域、鉄道、学校、医療機関、地価公示、将来推計人口メッシュなどを主題レイヤーにするとき。最新版が CC BY 4.0 の項目は商用プロダクトでも出典表示で使える。
- 洪水浸水想定区域 (2025 年版、CC BY 4.0) など災害リスクの面データを全国規模で重ねるとき。
- 行政区域に全国地方公共団体コードが入っているので、統計データを市区町村単位で結合するとき。

## 向いていない場面

- 避難所、市区町村役場 (P34、P05 は CC BY 4.0)、郵便局、警察署、消防署など、最新版でも非商用の項目を商用プロダクトや再配布するタイルで使う場面。
- 施設の開設や廃止をすぐに反映したい場面。更新は項目ごとに数年おきのものが多く、自治体のオープンデータや施設管理者の情報のほうが新しいことがある。
- 避難場所のように、自治体が指定を変えると安全に関わる情報。最新の指定は自治体や国土地理院の「指定緊急避難場所・指定避難所データ」(CSV と GeoJSON、市町村が登録し公開に同意したもの) で確かめる必要がある (https://www.gsi.go.jp/bousaichiri/hinanbasho.html)。
