# 中国本土 (高德 / 百度 / 天地図、GCJ-02 と BD-09)

## メタ情報

| 項目 | 値 |
|---|---|
| 確かめた日 | 2026-11-10 |

## 概要

中国本土では、測絵 (測量と地図作成) が法律で許可制になっており、外国の組織や個人は国の承認と中国側の機関との協力なしに測絵できない ([测绘法 第八条](https://www.liyang.gov.cn/html/czly/2017/AQQLAICH_0503/7964.html))。外商投資のネガティブリストでも、地形図や導航電子地図の編制などへの外資の投資が禁止されている ([负面清单 2024年版 第19項](https://fgw.yinchuan.gov.cn/fgzc/bmgz/202409/W020240924356564454107.pdf))。公開する地図には審査 (审图号) が要り、インターネット地図サービスのサーバーは国内に置くよう求められる ([地图管理条例 第十五条・第三十四条](https://zh.wikisource.org/wiki/%E5%9C%B0%E5%9B%BE%E7%AE%A1%E7%90%86%E6%9D%A1%E4%BE%8B))。さらに国内の地図は GCJ-02 という WGS84 からずらした座標系で提供されるため、実際の選択肢は審査と資質を持つ国内事業者 (高德、百度、腾讯など) と国の天地図にほぼ限られる。

## 法規制

- 地図データの作成・提供・国外持ち出しに関わる法令と所管 (条文や公的文書の出典つき):
  - 《中华人民共和国测绘法》(2017 年改正、2017-07-01 施行)。所管は国務院の測絵地理信息主管部門 (現在は自然資源部)。第八条で外国の組織・個人の測絵に承認と中国側との協力を求め、第三十四条で国家秘密に当たる測絵成果の対外提供に国務院と中央軍事委員会が定める審批手続を求め、第三十八条でインターネット地図サービス提供者に審査済みの地図の使用と地図データの安全管理制度を求める ([条文の転載: 溧阳市政府サイト](https://www.liyang.gov.cn/html/czly/2017/AQQLAICH_0503/7964.html))。全国人大の公式サイトの原文は取得できなかった。
  - 《地图管理条例》(2016-01-01 施行)。第十五条で地図審査制度 (社会に公開する地図は審査を受ける。景区図や地下鉄路線図など内容が単純な地図は除く)、第三十三条で位置情報・地理情報の投稿標注・地図データベース開発などを行うインターネット地図サービス事業者に測絵資質を求め、第三十四条でサーバーを国内に置くことを求める ([wikisource の条文](https://zh.wikisource.org/wiki/%E5%9C%B0%E5%9B%BE%E7%AE%A1%E7%90%86%E6%9D%A1%E4%BE%8B))。
  - 自然資源部の地図審査に関する規章では、インターネット地図サービスは地図ページの左下に审图号を表示し、その有効期間は 2 年とされる (検索結果の抜粋による。規章名と条番号は未確認)。
  - 強制性国家標準 GB 20263-2006《导航电子地图安全处理技术基本要求》は、導航電子地図を公開・販売・再配布・使用する前に空間位置の技術処理を施すことを求める ([Wikipedia による引用](https://en.wikipedia.org/wiki/Restrictions_on_geographic_data_in_China))。自然資源部は改訂版の意見募集を 2025-04-15 締切で行った (検索結果の抜粋による。改訂版の公布は未確認)。
- 外国企業・外国人がサービスを提供・利用するときの制約:
  - 外国の組織・個人が中国の領域で測絵するには、国務院の測絵地理信息主管部門が軍の測絵部門と共同で承認し、かつ中国の関係部門・単位と協力して行う必要があり、国家秘密や国家安全に関わってはならない (测绘法 第八条)。無承認または協力なしの測絵には、違法所得・測絵成果・測絵工具の没収と 10 万元以上 50 万元以下の罰金が科され、情状が重い場合は出国命令などもありうる (同 第五十一条) ([条文の転載](https://www.liyang.gov.cn/html/czly/2017/AQQLAICH_0503/7964.html))。
  - 《外商投资准入特别管理措施（负面清单）（2024年版）》(2024-11-01 施行) の第19項は、外資による大地測量、海洋測絵、測絵航空撮影、地面移動測量、行政区域界線測絵、地形図・世界政区地図・全国政区地図・省級以下政区地図・教学地図・真三次元地図・導航電子地図の編制などへの投資を禁止する ([银川市发改委が転載した全文 PDF](https://fgw.yinchuan.gov.cn/fgzc/bmgz/202409/W020240924356564454107.pdf)、[発改委の解説](https://www.ndrc.gov.cn/xxgk/jd/jd/202409/t20240907_1392878_ext.html))。
  - 以上から、外国企業が自ら中国の地図データを作って配信する道は閉じており、国内の資質を持つ事業者のサービスを利用する形になる。外国企業が高德・百度の開発者登録や企業認証をどの書類で通せるかは公式文書で確かめられなかった (未確認)。
- 国境・領土表示の規制と罰則:
  - 地図管理条例 第八条は国家の統一・主権・領土保全を損なう内容の表示を禁じ、第十条は中華人民共和国の国界を「中国国界线画法标准样图」に従って描くよう求める ([wikisource](https://zh.wikisource.org/wiki/%E5%9C%B0%E5%9B%BE%E7%AE%A1%E7%90%86%E6%9D%A1%E4%BE%8B))。
  - 罰則は、送審すべき地図を送審しなかった場合に 10 万元以下の罰金と地図の没収 (第四十九条)、インターネット地図サービス事業者が審査を経ていない地図を使った場合や新規内容の点検を怠った場合に 20 万元以下の罰金 (第五十四条)、表示してはならない内容をインターネットで投稿標注した場合に 10 万元以下の罰金 (第五十五条) ([wikisource](https://zh.wikisource.org/wiki/%E5%9C%B0%E5%9B%BE%E7%AE%A1%E7%90%86%E6%9D%A1%E4%BE%8B))。条文の適用範囲 (中国国外のサーバーから中国国外の利用者向けに配信する地図が対象になるか) は条文からは読み取れず、ここでは判断しない。

## 座標系

- 使われる座標系と WGS84 との違い:
  - GCJ-02: 国内の公開 Web 地図 (高德、腾讯など) が使う座標系。WGS84 に非線形のずれを加えたもので、WGS84 の GPS 座標を GCJ-02 の地図にそのまま載せると 100〜700 m ずれる ([Wikipedia](https://en.wikipedia.org/wiki/Restrictions_on_geographic_data_in_China))。
  - BD-09: 百度が GCJ-02 にさらに独自の変換を加えた座標系。百度の座標変換 API は入力に GPS 座標 (WGS84)、amap/tencent 座標 (GCJ-02)、bd09ll、bd09mc を受け付け、BD-09 系か GCJ-02 へ変換する ([百度 坐标转换](https://lbs.baidu.com/faq/api?title=webapi/guide/changeposition-base))。
  - 天地図: WMTS で経緯度投影 (`vec_c` など) と球面メルカトル投影 (`vec_w` など) の 2 系統を提供する ([天地图 地图服务](http://lbs.tianditu.gov.cn/server/MapService.html)、検索結果の抜粋による)。基準の測地系が CGCS2000 であることは第三者の技術記事による (公式ページは取得できず未確認)。GCJ-02 のような意図的なずれを加えていないかは公式文書で確かめられなかった (未確認)。
- 座標変換の扱い (公開されたアルゴリズムの有無、法的な制約):
  - GCJ-02 の変換アルゴリズムは公式には公開されていない。流出したコードに基づくとされる実装が多くの言語で出回っており、WGS84 から GCJ-02 への変換は精度が高く、逆変換は反復計算でセンチメートル程度まで詰められるとされる ([Wikipedia](https://en.wikipedia.org/wiki/Restrictions_on_geographic_data_in_China))。こうした非公式実装を商用で使うことの法的な位置づけは、公式文書で確かめられなかった (未確認)。
  - 国内事業者の公式 API は「他の座標系から自社座標系へ」の一方向だけを提供する。百度の座標変換 API は、GPS 座標への変換は必ず失敗するとし、その理由を「根据法律规定，不支持将任何类型的坐标转换为GPS坐标」と書いている ([百度 坐标转换 错误码 4](https://lbs.baidu.com/faq/api?title=webapi/guide/changeposition-base))。高德の座標変換 API も GPS、mapbar、baidu の座標を高德座標へ変換するものとして説明されている ([高德 坐标转换](https://lbs.amap.com/api/webservice/guide/api/convert))。
- 技術選定への影響 (GPS 座標や他の地図との重ね合わせ):
  - 端末の GPS 座標 (WGS84) は、表示する地図の座標系 (GCJ-02 か BD-09) に合わせて変換してから載せる必要がある。保存は WGS84 のまま持ち、表示の直前に変換するか、事業者の API で変換するかを決めておく。
  - GCJ-02 の地図、BD-09 の地図、WGS84 の衛星画像や OSM を 1 枚の地図に重ねると互いにずれる。複数の提供元を混ぜる設計は避ける。
  - 自社が保持する POI を国外へ出す、国外の地図に載せるといった処理が「測絵成果の対外提供」や地図審査に当たるかは条文から断定できない。データの持ち方は現地の法律専門家に確かめる前提にする。

## 国外のサービスを使う場合

- Google Maps, Mapbox, OSM などをこの地域で使ったときの制約と表示の質:
  - Google Maps Platform: 利用契約の「Prohibited Territories」に China が含まれ (2022-03-21 更新版)、契約は Google Maps Core Services を使う顧客アプリを Prohibited Territory で配布・販売することを禁じている ([Prohibited Territories](https://cloud.google.com/maps-platform/terms/maps-prohibited-territories)、[Google Maps Platform Terms](https://cloud.google.com/maps-platform/terms))。中国国内向けの製品には使えないと考えてよい。中国国外の利用者が中国の地域を見る場合も、Google の道路地図は GCJ-02 でずらされ、衛星画像は WGS84 のままなので、道路と衛星画像が 50〜500 m ずれる ([Wikipedia](https://en.wikipedia.org/wiki/Restrictions_on_geographic_data_in_China))。
  - Mapbox: 2017 年ごろに中国国内に配信基盤を置く mapbox.cn を発表した ([Mapbox blog](https://blog.mapbox.com/announcing-mapbox-cn-369a1a484676))。現在も提供されているかは公式に確かめられなかった (未確認)。第三者の記事は終了したとしている。
  - OSM: OSM の wiki は、無許可の私的な測絵は中国本土で違法であり、それは OSM の参加そのものを違法にしうると書き、GCJ-02 に変換したデータや画像を OSM に入れないよう求めている ([OSM wiki China](https://wiki.openstreetmap.org/wiki/China))。OSM のデータは WGS84 なので GPS と一致するが、GCJ-02 の国内地図とは重ならない。中国国内向けに OSM ベースの地図を公開する場合、地図審査やサーバーの国内設置 (地图管理条例 第十五条・第三十四条) を満たせるかが問題になる。
  - 表示の質: 国外のサービスは中国国内の道路・POI の詳しさで国内事業者に及ばないとされるが、定量的な比較は確かめていない (未確認)。中国国内からの接続では国外サービスの読み込みが遅い・不安定だとする第三者の報告がある ([Chinafy](https://www.chinafy.com/blog/does-mapbox-work-in-china))。

## 技術選定への影響

- この地域を対象に含むプロダクトで、ライブラリとタイルの選び方がどう変わるか:
  - 中国国内の利用者に地図を見せるなら、タイルと API は高德・百度・腾讯などの国内事業者か天地図から選ぶことになる。描画ライブラリも各事業者の JS API や SDK を使うのが基本で、MapLibre や Leaflet で国内事業者のタイルを直接読む使い方が規約で許されるかは事業者ごとに確かめる必要がある (未確認)。
  - 世界向けプロダクトでは、中国本土だけ別の地図プロバイダと別の座標系を使う「出し分け」の設計になる。地図 SDK の抽象化層を挟み、座標変換 (WGS84 と GCJ-02 / BD-09) を表示直前に行う構成にする。
  - 商用なら高德は年額 50,000 元からの技術服務許可が前提になる (2026-11-10 確認)。無料の個人・企業認証枠は「非商用と評価された場合」に限られる ([高德 服务套餐](https://lbs.amap.com/upgrade))。
  - データの保管場所 (国内サーバー) と地図審査は事業者側が満たしているが、自社の POI やユーザー投稿を地図に重ねる場合は、表示してはならない内容の投稿標注の禁止 (地图管理条例 第三十七条) を自社の運用でも守る必要がある。
- 情勢で変わりうる点 (日付つきで書き、見直す前提にする):
  - 高德の料金体系は 2025-05-20 から新体系に移行した (2026-11-10 確認)。年額と配額は改定されうる。
  - GB 20263 の改訂版は 2025-04-15 締切で意見募集が行われた。公布されると「安全処理」の要件が変わる可能性がある (2026-11-10 時点で公布は未確認)。
  - 外商投資ネガティブリストは数年ごとに改訂される。2026-11-10 時点で確認したのは 2024 年版 (2024-11-01 施行)。
  - Google Maps Platform の Prohibited Territories の最終更新は 2022-03-21 (2026-11-10 確認)。
