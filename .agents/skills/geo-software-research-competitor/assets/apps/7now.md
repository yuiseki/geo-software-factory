## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | セブン-イレブンの店頭商品を最短 20 分程度で指定の住所や外出先へ届ける即時配送アプリ |
| 提供する価値 | 配達先周辺の対応店舗のリアルタイム在庫から注文でき、配達員の現在地・移動経路・到着予定時刻を地図上で確認できる |
| 想定する利用者 | コンビニ商品の即時配達を自宅・職場・外出先で受け取りたい日本の消費者 |
| 商用か非商用か | 商用 (商品代金、配送料、配送パートナーとの連携による小売売上) |
| 推定の売上 | 推測: 年数十億〜数百億円規模 (App Store 評価約 9.7 万件、Google Play 100 万ダウンロード以上。全国のセブン-イレブン店舗網を活用) |
| 運営 | 企業 (株式会社セブン-イレブン・ジャパン / Seven-Eleven Japan Co., Ltd) |
| 推定の運用費 | 推測: 月数千万円〜億円規模 (配送網手配、店舗在庫リアルタイム連携、地図・モビリティ API 費用) |
