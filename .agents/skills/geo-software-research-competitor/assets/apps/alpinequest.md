# AlpineQuest

- URL: https://alpinequest.net/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: オフライン地図、アウトドア、登山、GPS、GeoTIFF、MBTiles、GeoPackage、Android

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 多様なオンライン地形図の保存と GeoTIFF / MBTiles 等のオフライン地図ファイル読み込みに対応した高機能 Android GPS ナビゲーションアプリ |
| 提供する価値 | 電波のない山岳・荒野・海外でも、保存した地形図や手持ちのラスター地図上でリアルタイム測位、ウェイポイント管理、詳細なトラック統計を利用できる |
| 想定する利用者 | 登山、トレイルランニング、狩猟、セーリング、オフロードナビゲーション等を行う海外・国内のアウトドアユーザー |
| 商用か非商用か | 商用 (無料版「Explorer Lite」と有料買い切り版「Off-Road Explorer」2,499円、アプリ内購入あり) |
| 推定の売上 | 推測: 年数千万円規模。有料版 10万+ ダウンロード (2,499円前後)、無料版 500万+ ダウンロード。売上は公開されていない |
| 運営 | 個人 / 小規模開発元 (Psyberia、開発者 Ambrosi Camille Francois。Google Play 登録地はスペイン Puçol) |
| 推定の運用費 | 推測: 月数万円以下。地図データは端末ローカル保存や外部タイルサーバーを参照する設計 |
