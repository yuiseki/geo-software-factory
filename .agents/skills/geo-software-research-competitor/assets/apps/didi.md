## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本や中南米、豪州などでタクシー・ライドシェアの配車を提供するグローバルモビリティアプリ |
| 提供する価値 | 地図上で乗車地と目的地を指定し、近くの提携車両を呼んで到着予定時刻や料金目安を確認しながら移動できる |
| 想定する利用者 | 日本国内および対応国の都市部でタクシーや配車サービスを利用する人 |
| 商用か非商用か | 商用 (配車手数料、アプリ決済、法人向けサービス等) |
| 推定の売上 | 公開 (DiDi Global 全体の売上は年間数百億ドル規模。日本法人は DiDi モビリティジャパン株式会社) |
| 運営 | 企業 (DIDI MOBILITY INFORMATION TECHNOLOGY PTE. LTD. / 日本は DiDi モビリティジャパン株式会社) |
| 推定の運用費 | 推測: 月数千万円〜億円規模 (配車マッチング、地図・ルート計算基盤、加盟タクシー事業者サポート) |
