## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 表示した地図を自動キャッシュして携帯圏外でも現在地確認やトラックログ記録ができる個人開発の登山用 GPS アプリ |
| 提供する価値 | 事前に画面へ表示した国土地理院の地形図や OSM を端末に自動保存し、電波の届かない山奥や海上でも正確な現在地確認とルート案内が行える |
| 想定する利用者 | 登山者、ハイカー、トレッキングやバックカントリー、海外トレッキングを行うアウトドア愛好家 |
| 商用か非商用か | 商用 (基本無料、機能制限解除の買い切り型アプリ内課金あり。一部機能で動画広告の視聴による制限緩和あり) |
| 推定の売上 | 推測: 年数百万円規模。App Store の評価約 2,400 件、Google Play 10万+ ダウンロード。売上は公開されていない |
| 運営 | 個人 (作者は松本圭司 / Keiziweb) |
| 推定の運用費 | 推測: 月数万円以下。地図タイルは国土地理院や OSM 等の公開サービスを参照し、端末キャッシュ中心でサーバー負荷が小さい |
