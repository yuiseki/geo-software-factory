## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国でタクシーを呼べる日本最大級のタクシー配車アプリ (旧 JapanTaxi と MOV が統合) |
| 提供する価値 | 地図上で乗降地を指定して近くのタクシーを即座に配車でき、AI 予約や事前確定運賃、アプリ決済にも対応する |
| 想定する利用者 | 日本国内の通勤者、ビジネス客、旅行者、高齢者などタクシーを利用する人 |
| 商用か非商用か | 商用 (アプリ手配料、決済手数料、法人契約 GO BUSINESS、車載サイネージ等) |
| 推定の売上 | 推測: 年数十億〜数百億円規模 (App Store 評価約 90.7 万件、Google Play 1,000 万ダウンロード以上) |
| 運営 | 企業 (GO株式会社 / GO Inc.) |
| 推定の運用費 | 推測: 月数千万円〜億円規模 (全国タクシー事業者との連携基盤、地図・ルート計算、広告・開発費) |
