| 項目 | 内容 |
|---|---|
| 一行で | 東南アジア 8 か国で配車、フード・日用品配達、決済・金融を提供するスーパーアプリ |
| 提供する価値 | 東南アジア特有の細い路地やバイク専用ルート、建物の正確な乗降ポイントを捉えた地図上で、配車や配達を正確に行える |

| 商用か非商用か | 商用 (配車・配達手数料、GrabUnlimited サブスクリプション、金融サービス、GrabMaps の B2B 外販) |
| 推定の売上 | 公開 (米国上場企業 Grab Holdings の年間売上は数十億ドル規模) |
| 運営 | 企業 (Grab Holdings / GRABTAXI HOLDINGS PTE. LTD.) |
| 推定の運用費 | 推測: 年間数億ドル規模 (スーパーアプリ基盤、ドライバー網から地図を収集・更新する GrabMaps 運用費等) |
