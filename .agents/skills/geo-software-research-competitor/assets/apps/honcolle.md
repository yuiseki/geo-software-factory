## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 本と本屋をつなぐアプリで、近くの書店を探し、新刊とランキングを調べ、店からのクーポンと在庫 (連携した店) を確かめられる |
| 提供する価値 | 出版業界が共同で運営し、書店が自分で店の情報と在庫を載せるので、近くの店で欲しい本があるかを確かめられる |
| 想定する利用者 | 本を買う人、近くの本屋を探す人 |
| 商用か非商用か | 商用 (アプリは無料。書店の登録は無料で、出版業界 8 社が出資する会社が運営。店への送客と販促の事業と見られる (推測)) |
| 推定の売上 | 未確認 |
| 運営 | 企業 (株式会社 Catalyst・Data・Partners) |
| 推定の運用費 | 推測: 月数百万円以上 (店と在庫のデータの連携、アプリの運用)。App Store の初出は 2010-09-25、評価 14.2 万件、Android のパッケージ名は jp.co.tsutaya.android.ranking で、以前の TSUTAYA のアプリを引き継いだと見られる (推測) |
