## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 近隣のスーパーマーケットや小売店の食料品・日用品を注文し、パーソナルショッパーが買物代行して当日配達するアプリ |
| 提供する価値 | 配送先に対応した近隣店舗を選び、ショッパーの買物・配達状況と到着予定時刻をリアルタイムに確認できる |
| 想定する利用者 | 北米で食料品や日用品の当日配達・店頭受取を利用する一般消費者 |
| 商用か非商用か | 商用 (配達料、サービス料、Instacart+ サブスクリプション、小売広告) |
| 推定の売上 | 公開 (上場企業 Maplebear Inc. / Instacart の年間売上は数十億ドル規模) |
| 運営 | 企業 (Maplebear Inc.) |
| 推定の運用費 | 推測: 年間十億ドル規模 (ショッパー報酬、地図・ルート計算基盤、クラウド、決済・サポート) |
