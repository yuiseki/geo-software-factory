## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 検索キーワードの代わりに「今の気分」「誰と行くか」「距離」から AI とユーザー投稿で穴場のおでかけ先を提案する個人開発アプリ |
| 提供する価値 | 「なんとなく出かけたいが行き先が浮かばない」ときに、気分ベースでカフェや自然、穴場スポットを見つけ、訪れた思い出を写真付きで残せる |
| 想定する利用者 | 休日のおでかけ先やデートスポットを探したい若年層、穴場スポットを共有したいユーザー |
| 商用か非商用か | 商用 (アプリは無料ダウンロード。公式サイトに店舗アカウント・広告・スポンサー掲載の案内あり。CAMPFIRE でクラウドファンディングも実施) |
| 推定の売上 | 推測: 初期段階。App Store の評価 16 件、2026年8月リリース |
| 運営 | 個人 (Kensuke Sakamoto、大学生による個人開発) |
| 推定の運用費 | 推測: 月数千円〜数万円。スポット投稿のデータベース、AI レコメンド API、地図・画像ストレージ費用 |
