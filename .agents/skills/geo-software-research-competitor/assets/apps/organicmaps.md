- 探すときの語: オフライン地図、ナビ、OpenStreetMap、プライバシー、登山、自転車、OSS

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | OpenStreetMap をもとにした、広告も追跡もない無料のオフラインの地図とナビのアプリ |
| 提供する価値 | 旅行、ハイキング、自転車で、ネットにつながらずに速く地図と検索とナビを使え、プライバシーが守られる |
| 想定する利用者 | 旅行者、ハイカー、サイクリスト、プライバシーを気にする人 |
| 商用か非商用か | 商用 (寄付。サイトに寄付のページ。Open Collective の表示で年約 2,800 USD (2026-11-12)。広告とアプリ内課金は無い) |
| 推定の売上 | 推測: 年数百万円規模の寄付 (Open Collective のほかの寄付の経路の額は未確認) |
| 運営 | 企業 (Organic Maps OÜ、エストニア)。開発はボランティアと明記 |
| 推定の運用費 | 推測: 月数十万円。全世界の地図を月 2 回作り直して配る計算とサーバー |

## 技術 (2026-11-12 の観測)

| 項目 | 観測したもの |
|---|---|
| 種類 | iOS と Android のアプリ |
| 描画 | 自前の C++ の地図エンジン (MAPS.ME の omim から分かれた) |
| フレームワーク | C++ (共通)、Android と iOS の画面はそれぞれ |
| 背景の地図とタイル | OSM から作った自前のオフラインの地図 (月 2 回の更新) |
| 投稿やデータの保存先 | 端末の中 (アカウント無し) |
| 配信 | App Store、Google Play、Obtainium (GitHub のリリース) |
