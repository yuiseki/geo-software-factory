# スーパー地形

- URL: https://www.kashmir3d.com/superdem/
- 観測した日: 2026-11-12
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 地形、登山、オフライン地図、GPS、古地図、3D、カシミール3D

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地形にこだわった 100 種類以上の地図 (古地図を含む) を、オフラインで使い、GPS で記録し、3D やパノラマで見る登山と地形のアプリ |
| 提供する価値 | 圏外の山でも地図と GPS が使え、地形と古地図を重ね、山の名前の分かる展望図まで見られる |
| 想定する利用者 | 登山者、まち歩きや城巡りをする人、地形や地図の愛好家 (テレビ番組『ブラタモリ』でも使用とストアの説明) |
| 商用か非商用か | 商用 (機能制限の解除 1,300 円のアプリ内課金。作者のサイトに Google の広告) |
| 推定の売上 | 推測: 年数百万円。App Store の評価 1.4 万件、Google Play 10 万ダウンロード以上。売上は公開されていない |
| 運営 | 個人 (作者は杉本智彦。PC 用のフリーソフト「カシミール3D」の作者) |
| 推定の運用費 | 推測: 月数万円。地図の配信 (地理院タイルなど公的なものが多いと見られる) とアプリの開発 |
