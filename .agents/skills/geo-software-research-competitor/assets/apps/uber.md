## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 現在地と目的地を指定して自動車やタクシーを配車し、事前確定運賃や到着予定時刻の共有・決済まで完結するグローバルな配車アプリ |
| 提供する価値 | 地図上で配車位置と周辺車両を視覚的に確認し、呼んだ車の現在地と到着予定時刻をリアルタイムに追える |
| 想定する利用者 | 都市部や旅行先で移動手段を手配したい個人・ビジネス利用者 |
| 商用か非商用か | 商用 (配車ごとの仲介手数料、サブスクリプション Uber One など) |
| 推定の売上 | 公開 (上場企業 Uber Technologies の売上は年間数百億ドル規模。モビリティ・デリバリー等を含む) |
| 運営 | 企業 (Uber Technologies, Inc.) |
| 推定の運用費 | 推測: 年間数億〜数十億ドル規模 (グローバルなインフラ、地図・ルーティング基盤、サポート、決済を含む) |
