## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | エンドツーエンド暗号化されたメッセージ・音声・ビデオ通話に加え、現在地ピンやリアルタイムのライブ位置情報を共有できる世界最大級のメッセンジャーアプリ |
| 提供する価値 | チャット画面から現在地や時間指定 (15分・1時間・8時間) のライブ位置情報を手軽に送信し、待ち合わせや安全確認に使える |
| 想定する利用者 | 世界中の個人・ビジネス利用者 (特に欧州・中南米・インド・東南アジア等) |
| 商用か非商用か | 商用 (Meta Platforms 傘下。個人向け無料、WhatsApp Business Platform の企業向け課金や広告連携等で収益化) |
| 推定の売上 | 公開 (親会社 Meta Platforms の年次報告に含まれ、WhatsApp Business 関連の売上は年間十数億ドル規模) |
| 運営 | 企業 (WhatsApp Inc. / WhatsApp LLC、親会社 Meta Platforms, Inc.) |
| 推定の運用費 | 推測: 年間数億ドル規模 (数十億ユーザー向けのメッセージ配信・暗号化基盤、地図 SDK 利用料等) |
