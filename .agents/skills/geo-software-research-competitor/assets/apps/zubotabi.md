## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 写真の位置情報取り込みとバックグラウンド自動記録だけで、行った国や都道府県を世界地図に塗りつぶせる個人開発の旅日記アプリ |
| 提供する価値 | 日記を書いたりチェックインしたりする手間なしに、過去の旅も含めて訪問済みの国・街・年表・国別スタンプが自動で地図上にまとまる |
| 想定する利用者 | 旅行や出張の記録を手間なく残したい人、行った国や都道府県を地図で可視化したい人 |
| 商用か非商用か | 商用 (無料ダウンロード、買い切り 800円・サブスクなしのアプリ内課金と公式サイトに明記) |
| 推定の売上 | 推測: 数十万円規模。App Store の評価 22 件、公式サイトで 1,000ダウンロード超と記載 |
| 運営 | 個人 (高島彬 / Shiori Studio) |
| 推定の運用費 | 推測: 月数千円以下。移動履歴を開発者サーバーに送らず端末内で完結させる設計のため、バックエンド運用費が極めて小さい |
