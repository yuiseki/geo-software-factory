# 2GIS

- URL: https://2gis.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 2GIS、ロシア地図、UAE、ドバイ、オフライン地図、屋内地図、ディレクトリ、Sberbank、Fiji GIS

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ロシア・CIS・中東 (UAE 等) を中心に、建物の階層・入口・店舗ディレクトリまで網羅したオフライン対応の都市地図・ナビゲーションサービス |
| 提供する価値 | 都市部の詳細な建物・屋内フロア図 (Floors) や入口の位置、営業時間付きの企業・店舗情報、車・徒歩・公共交通の経路案内をオフラインでも利用できる |
| 想定する利用者 | 都市の住民や旅行者、ドライバー、配達員、2GIS Platform API/SDK を利用する法人開発者 |
| 商用か非商用か | 商用 (一般利用者向けは無料。B2B 広告・検索優先表示・企業プロフィール掲載および開発者向け 2GIS Platform API/SDK のリクエスト課金パッケージを提供) |
| 推定の売上 | 推測: 年数十億〜数百億円規模。Sberbank (Sber) 傘下の大手地域情報・地図プラットフォームで広告と法人 API で収益化しているが、最新単体売上は未確認 |
| 運営 | 企業 (2GIS、ロシア・ノボシビルスク発祥、現在は Sberbank が 100% 所有) |
| 推定の運用費 | 推測: 月数千万円規模。独自 GIS「Fiji」による地図生成、現地調査員と車載カメラ解析による高精度データ維持、世界各都市のタイル・API 配信を運用している |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 独自描画エンジン (応答 HTML から `https://d-assets.2gis.ru/museum/museum.js` 等の独自アセットを読み込む構成を確認。モバイル向けに自社 iOS/Android/Flutter SDK も提供) |
| フレームワーク | 未確認 (リダイレクト先の `2gis.ae/museum` で `/_/polyfills.min.js` と `museum.js` を確認) |
| 背景の地図とタイル | 自前の都市地図・屋内地図タイル (独自 GIS システム Fiji で構築) |
| 投稿やデータの保存先 | 未確認 (ユーザーレビューや写真、企業ディレクトリを扱うが保存先インフラの詳細は非公開) |
| 配信 | nginx (`server: nginx` を応答ヘッダーで確認。`2gis.com` から `2gis.ae/museum` へリダイレクト) |
