# 無料の商圏分析・統計データマッピング|47maps

- URL: https://47maps.com/
- 観測した日: 2026-11-12
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 商圏分析、エリアマーケティング、統計地図、階級区分図、コロプレス、出店計画、到達圏、アイソクロン、国勢調査、経済センサス、昼間人口、あさひる統計、GIS、trade area analysis、choropleth map、area marketing

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 国勢調査や経済センサスなどの統計を、都道府県、市区町村、町丁の単位で地図に色分けし、円の商圏や到達圏を登録して集計できるブラウザの統計地図 |
| 提供する価値 | 専用の GIS を入れなくても、出店候補地や販促エリアの人口、世帯、年齢構成、曜日と時間帯ごとの人口を地図とグラフで比べられる |
| 想定する利用者 | 出店計画や販促を考える企業のマーケティング担当、自治体、研究者や教育の現場、都市計画や不動産の担当 (「47mapsについて」のページ) |
| 商用か非商用か | 商用 (本業への集客。統計調査とデータ提供を本業とする企業が無料で提供し、問い合わせへ誘う。旧 47maps では商品を販売していた (利用規約の経過措置の条)。新 47maps に有料プランや広告は見えなかった) |
| 推定の売上 | 推測: 47maps そのものの売上は 0 円に近い。会員登録は無料で、価値は運営会社の調査とデータ提供の仕事への集客。はてなブックマークは 2 件 (2026-11-12) |
| 運営 | 企業 (株式会社日本統計センター、本社は北九州市。1961 年設立。「あさひる統計」のデータは株式会社楽しいチリビジの提供) |
| 推定の運用費 | 推測: 月数万円。CloudFront と S3 の静的配信は小さく、Mapbox GL JS は月 5 万ロード、Mapbox の Isochrone API は月 10 万回まで無料。会員の認証 (Amazon Cognito と見られる) と統計の API (自社の 47stats) のサーバーが主な費用 |

## 技術 (2026-11-12 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Mapbox GL JS (JavaScript の中に版の文字列 3.30.0 が見えた。地図の画面はサインインが必要で、開いていない) |
| フレームワーク | React 18.3.1、React Router、Vite と見られる (`assets/index-<hash>.js` の分割)、Tailwind 系の UI (Flowbite と見られる) |
| 背景の地図とタイル | Mapbox のスタイル (`mapbox://styles/mapbox/standard`、streets-v12、light-v11、dark-v11、satellite-streets-v12 など 10 種を切り替え)。3D の建物は Mapbox の `building` レイヤー。JavaScript の中の文字列で判定し、タイルの通信は観測していない |
| 投稿やデータの保存先 | 統計と境界の GeoJSON は自社の統計の API (`api-stats.47stats.com/api/stats/v1`、`/map/datamap/polygon/geojson` など)。会員の認証は AWS Amplify (Cognito の設定項目の文字列が見えた)。退会は API Gateway (`execute-api.ap-northeast-1.amazonaws.com`)。地図の表示状態は手元に自動で保存し、ファイルで書き出せる (「47mapsについて」のページ) |
| 配信 | Amazon S3 + CloudFront |

メモ:

- トップページ、「47mapsを使う」、「47mapsについて」、利用規約は紹介と文書のページで、地図は出ていない。「47mapsを使う」(`/services`) はサインインの画面で、地図の画面はサインインした後にある。そのため地図の帰属表示は読めていない
- 機能は、階級区分図 (凡例の区切りを編集できる)、グラフ、円の商圏 (足元 400 m、一次 1 km、二次 3 km、三次 5 km)、Mapbox の Isochrone API による徒歩などの到達圏、3D の建物、住所検索 (Mapbox の Geocoder と見られる)
- 統計の種類は「都道府県の統計」「市区町村の統計」「町丁の統計」「あさひる統計」。あさひる統計の階級図は、先に商圏を登録すると出る
- 利用規約は 2021-06-22 制定、2026-09-14 改定。提供する情報の利用は本人か所属する組織の中だけで、第三者への提供は有料、無料を問わず禁止 (第 2 条)。旧 47maps から新 47maps へ移った経過措置がある
- ページの解析に Zoho PageSense、問い合わせに Zoho Forms を使う。PageSense はヘッドレスのブラウザを検出すると DOM の関数を止めるので、観測ではその通信を止めて開いた
- 統計の API の学習サイト (`developers.47stats.com`) へのリンクがある。JavaScript に `github.com/47stats/47maps-react` と `47maps-dashboard` の文字列が見えた (公開か非公開かは未確認)

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 背景の地図、3D の建物 | Mapbox のスタイル (帰属表示は地図の画面で読めず未確認) | JavaScript の中のスタイルの URL |
| 人口、世帯、年齢構成、産業別就業者数 | 国勢調査 (町丁・字の単位まで) | 「47mapsについて」の「利用可能なデータ」の表、トップページの説明 |
| 事業所数、従業者数、売上高 | 経済センサス | 「47mapsについて」の「利用可能なデータ」の表 |
| 小売業、卸売業の店舗数、販売額 | 商業統計 | 「47mapsについて」の「利用可能なデータ」の表 |
| 最新の人口動向 | 推計人口 | 「47mapsについて」の「利用可能なデータ」の表 |
| 曜日と時間帯ごとの推計人口 | あさひる統計 (株式会社楽しいチリビジ) | トップページの説明とリンク、JavaScript の中の統計の説明 |
| 境界 (都道府県、市区町村、町丁) | 自社の統計の API から GeoJSON で配る。元の境界の出典は未確認 | JavaScript の中の API の経路 |
| 到達圏 | Mapbox Isochrone API | JavaScript の中の API の URL |

統計の年次と、境界の元データ (e-Stat の小地域など) の出典は、外から見えるページには書かれていなかった。利用規約では情報の権利が運営会社と「原資料提供者」に帰属するとだけある (2026-11-12)
