# エイブル 店舗検索

- URL: https://www.able.co.jp/shop/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、不動産仲介、賃貸、エイブル、ABLE、直営店、ネットワーク店、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のエイブル直営店・ネットワーク店舗を地域や路線から検索し、店舗情報や Google マップへの導線を確認できる公式店舗検索ページ |
| 提供する価値 | 希望エリアの最寄り店舗の営業時間・連絡先・取扱物件を調べ、外部の Google マップリンクから場所を確認して来店予約できる |
| 想定する利用者 | 賃貸物件の部屋探しでエイブル実店舗への相談・内見を希望する一般顧客 |
| 商用か非商用か | 商用 (自社店舗・ネットワーク店への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。株式会社エイブル単体の売上高は 443 億 2,300 万円 (2025 年 10 月期) |
| 運営 | 企業 (株式会社エイブル) |
| 推定の運用費 | 推測: 月数万円。Web サーバー (Apache) の運用費のみで、ページ内への地図 API 埋め込みによる従量課金は発生していない |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 埋め込み地図なし (店舗詳細ページ `https://shop.able.co.jp/000000337/` では `https://maps.google.com/maps?cid=...` への外部リンクのみを提供) |
| フレームワーク | jQuery 1.2.6 / 1.7.2 + Prototype.js (`prototype.chintai.js`、`.do` 拡張子の Java ベースサーバー描画) |
| 背景の地図とタイル | ページ内埋め込みなし (外部リンク先として Google マップを使用) |
| 投稿やデータの保存先 | エイブル自社店舗基盤 (`shop.able.co.jp` 配下の `.do` エンドポイントでサーバー側 HTML 生成) |
| 配信 | Apache 2.2.15 (`server: Apache/2.2.15 (Red Hat)`) |

メモ:

- `https://www.able.co.jp/shop/` は都道府県別の店舗サイトマップ (`https://shop.able.co.jp/<pref>/sitemap-List.do`) 等へ誘導しており、個別店舗ページ (`https://shop.able.co.jp/000000337/`) でも地図タイル API の埋め込みはなく Google マップへの外部リンク (`maps.google.com/maps?cid=...`) を掲載している。

データの出どころ (2026-11-17):

- 店舗検索・技術構成: `https://www.able.co.jp/shop/` および `https://shop.able.co.jp/000000337/` の HTTP 応答ヘッダ・HTML/JS (2026-11-17 観測)
- 店舗データ: 株式会社エイブル自社管理の店舗情報
- 外部地図リンク先: Google (Google マップ)
- 運営・業績情報: 株式会社エイブル 公開会社概要・決算情報 (2025 年 10 月期)
