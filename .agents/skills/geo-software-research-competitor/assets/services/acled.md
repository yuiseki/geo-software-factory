# ACLED

- URL: https://acleddata.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ACLED、紛争データ、政治的暴力、抗議活動、危機マッピング、非営利、501(c)(3)、ACLED Explorer

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界 200 以上の国・地域における武力紛争・政治的暴力・抗議活動をリアルタイムで収集・構造化し、地図とデータで公開する独立非営利モニター |
| 提供する価値 | 発生日時・関与勢力・緯度経度・死者数などを統一基準でコード化した紛争イベントデータを無料で閲覧・分析・エクスポートでき、紛争の傾向や民間人への影響評価に使える |
| 想定する利用者 | 国際機関 (国連等)、人道支援 NGO、政府機関、研究者、報道機関、企業の地政学リスク担当者 |
| 商用か非商用か | 非商用 (米国の 501(c)(3) 非営利団体。データは一般・研究・人道支援向けに原則無料で公開、国連 CRAF'd 等の助成金・寄付で運営) |
| 推定の売上 | 年間収入約 1,470 万米ドル (米国 IRS Form 990 の公開財務報告による。商業売上ではなく政府・国連・財団等からの助成金・寄付) |
| 運営 | 非営利団体 (ACLED / Armed Conflict Location & Event Data Project、米国登記の 501(c)(3) 非営利法人) |
| 推定の運用費 | 年間支出約 1,580 万米ドル (IRS Form 990 による。世界各地の調査アナリストによる毎日のコーディング人件費と分析ダッシュボード・API 基盤の維持費) |

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 紛争・抗議活動イベント | 世界各国の現地報道、NGO 報告、国際機関、信頼できる SNS 等を ACLED のアナリストが精査・コーディング | 公式サイトおよびメソドロジー文書 |
| 人口曝露計算データ | WorldPop 等の人口分布データ | Conflict Exposure Calculator 説明 |
