## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のイオンシネマ劇場をエリアや設備から検索し、各劇場の上映情報やアクセス案内を確認できる公式劇場検索ページ |
| 提供する価値 | 都道府県別のイオンシネマ劇場一覧から目的の映画館を探し、チケット予約「ワタシアター」や各劇場の駐車場・最寄駅案内へアクセスできる |
| 想定する利用者 | イオンモール等に併設されたイオンシネマでの映画鑑賞を予定している一般客・ファミリー層 |
| 商用か非商用か | 商用 (イオンシネマ各劇場への集客およびオンラインチケット販売への送客のために提供。利用料は無料) |
| 推定の売上 | 推測: 劇場検索単体の売上は 0 円。映画チケット売上および併設イオンモール等への集客に貢献 |
| 運営 | 企業 (イオンエンターテイメント株式会社) |
| 推定の運用費 | 推測: 月数万〜数十万円。Cloudflare を介した Web 配信費および劇場管理システムの運用費がかかる |
