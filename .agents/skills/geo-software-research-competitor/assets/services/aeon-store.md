# イオングループ 店舗一覧・店舗検索

- URL: https://www.aeon.com/store/list/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ストアロケーター、店舗検索、イオン、イオンスタイル、マックスバリュ、まいばすけっと、ショッピングモール、スーパー、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | イオングループ各業態の店舗を地域・業態・キーワードから検索し、各店舗の営業時間やアクセスマップを確認できる公式店舗検索サイト |
| 提供する価値 | イオン、イオンスタイル、マックスバリュ、まいばすけっとなどグループ横断で店舗を探し、詳細ページの地図や最寄駅・車でのアクセスを確認できる |
| 想定する利用者 | イオングループ各店舗への来店を予定している一般客、地域のスーパーやショッピングモールを探している利用者 |
| 商用か非商用か | 商用 (イオングループ各店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。グループ各店舗の売上およびチラシ・ネットスーパー等への送客に貢献 |
| 運営 | 企業 (イオン株式会社 / イオングループ) |
| 推定の運用費 | 推測: 月数十万円。Web サーバーおよび監視 (New Relic) の運用費に加え、NAVITIME 法人向け地図 API の利用料がかかる |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | NAVITIME 地図 API (`https://dp.navitime.biz/v1/10350520/mapscript?host=www.aeon.com&signature=...`、店舗詳細ページの `shop_detail_navitime.js`) |
| フレームワーク | jQuery 3.6.0 (New Relic Browser Agent を組み込み) |
| 背景の地図とタイル | NAVITIME の地図タイル (店舗詳細ページで `mapscript` 経由で読み込み) |
| 投稿やデータの保存先 | 店舗一覧・詳細の HTML はサーバー側で描画 (`www.aeon.com/store/list/...`)。周辺駅や車ルート案内は NAVITIME 連携 (`#navitime_station`、`#navitime_drive`) |
| 配信 | nginx (`server: nginx`) |

メモ:

- トップの検索一覧 (`/store/list/`) には地図は埋め込まれておらず、地域・業態から遷移する個別の店舗詳細ページ内に地図 (`#mapBox`) と NAVITIME の周辺駅・車アクセス欄が埋め込まれている

データの出どころ (2026-11-16):

- 店舗データ: イオングループ管理の店舗情報
- 背景地図・最寄駅・ルート案内: 株式会社ナビタイムジャパン (NAVITIME 地図 API)
