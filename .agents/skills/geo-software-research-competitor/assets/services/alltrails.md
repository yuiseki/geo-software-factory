# AllTrails

- URL: https://www.alltrails.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: AllTrails、ハイキング、トレイル、登山、アウトドア、オフライン地図、ルート検索、トレイルガイド

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中の 50 万件以上のトレイルガイド、地図、口コミ、GPS ナビゲーションを提供するアウトドア向け地図プラットフォーム |
| 提供する価値 | 難易度や距離、レビュー、写真から目的に合うコースを探し、オフライン地図やルート逸脱アラートで安全に行動できる |
| 想定する利用者 | ハイカー、トレイルランナー、サイクリスト、キャンプや公園の散策を楽しむ一般層 |
| 商用か非商用か | 商用 (基本無料。有料の AllTrails Plus は年額 35.99 米ドル、AllTrails Peak は年額 79.99 米ドル) |
| 推定の売上 | 推測: 年間 5,000 万から 1 億米ドル超規模 (登録会員 1 億人超、アプリストアの推定課金売上は月 100 万から 600 万米ドル規模と報じられるが、非公開企業のため公式売上は未確認) |
| 運営 | 企業 (AllTrails, LLC、米国サンフランシスコ拠点、Permira などが資本参加) |
| 推定の運用費 | 未確認 (全世界のトレイルと写真データの保管、Mapbox 等のエンタープライズ地図利用料、CloudFront 配信費、開発運用人件費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 種類 | ウェブ、iOS と Android のアプリ |
| 描画 | Mapbox (Mapbox の公式導入事例でアウトドア地図とカスタムスタイルの利用が紹介されている。トップページの HTML のみでは描画ライブラリ名は直接観測できず) |
| フレームワーク | Next.js (`x-powered-by: Next.js`、`_next/`)、React、Ruby on Rails (HTML 内に `rails` 関連の参照あり) |
| 背景の地図とタイル | Mapbox ベクトルタイルをベースにしたカスタムアウトドア地図、衛星画像、地形陰影、天気・大気質オーバーレイ |
| 投稿やデータの保存先 | 未確認 (自社クラウド基盤上と推測されるが公開情報からは特定できず) |
| 配信 | nginx + Amazon CloudFront (`server: nginx`、`via: CloudFront`) |

メモ:

- 2025 年 5 月に上位プラン「AllTrails Peak」を導入し、AI によるスマートルート作成やカスタムルート作成機能を提供している。
