## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のオートバックスおよびスーパーオートバックス等の店舗を、現在地・エリア・サービス内容から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 近くの店舗の位置や営業時間に加え、車検・ピット作業の対応状況や作業予約・店舗イベント情報を確認でき、来店予約につなげられる |
| 想定する利用者 | カー用品の購入やオイル・タイヤ交換、車検などのメンテナンスを希望するドライバー・自動車保有者 |
| 商用か非商用か | 商用 (フランチャイズを含む実店舗への来店・ピット作業予約への送客基盤として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の商品販売およびピット作業・車検サービスの受注に貢献する集客基盤 |
| 運営 | 企業 (株式会社オートバックスセブン) |
| 推定の運用費 | 推測: 月数十万円。Google Maps Platform の利用料および Cloudflare を含む Web 配信費がかかる |
