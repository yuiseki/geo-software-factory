## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 百度 (Baidu) が提供する中国最大級のデジタル地図・ナビゲーション・地域検索プラットフォーム |
| 提供する価値 | 中国全土の膨大な POI、リアルタイム交通、車線レベルナビ、公共交通案内、3D 建物表示を無料で利用でき、開発者向けの WebGL 可視化 API も備える |
| 想定する利用者 | 中国国内で移動や店舗検索をする一般の利用者、地図 API やデジタルツイン可視化を導入したい企業・開発者 |
| 商用か非商用か | 商用 (一般向けアプリ・ウェブは無料で、位置連動広告・店舗プロモーション・法人向け API パッケージで収益化。開発者向け API は無料枠超過後に従量・トラフィックパック課金や年間技術ライセンスを提供) |
| 推定の売上 | 未公表 (Baidu 社の決算では検索・AI 関連セグメント等に含まれ、百度地図単体の売上は分けて公表されていない) |
| 運営 | 企業 (Baidu, Inc. / 百度) |
| 推定の運用費 | 未確認 (中国全土の測量・POI 更新・ストリートビュー収集、BeiDou 等を含む測位処理、大規模クラウド配信基盤の運用費がかかる) |
