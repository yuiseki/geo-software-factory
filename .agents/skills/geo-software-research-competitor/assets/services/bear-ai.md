## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の地域ごとに、クマに遭遇する危険を AI で予測して地図に塗った研究室のページ |
| 提供する価値 | クマの出没が増えるなかで、どこが危ないかを地域ごとに見られる |
| 想定する利用者 | クマの出る地域の住民、登山や山菜採りに行く人、自治体の担当者 |
| 商用か非商用か | 非商用 (大学の研究室の公開。広告、寄付、有料プランは見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 大学の研究室 (上智大学大学院 深澤研究室) |
| 推定の運用費 | 推測: ほぼ 0 円。GitHub Pages の静的配信で、予測の計算は研究室の手元で行っていると見られる |
