# Bikemap

- URL: https://www.bikemap.net/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Bikemap、サイクリングルート、自転車ナビ、サイクルコンピュータ、GPX、OpenStreetMap、MapLibre、ウィーン

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中のサイクリストが投稿した自転車ルートを検索・計画し、音声ナビやサイクルコンピュータ機能で走れるサイクリング地図サービス |
| 提供する価値 | 舗装路・グラベル・自転車専用道などの路面情報や高低差を考慮した自転車向けルート探索と、オフライン地図でのターンバイターン音声案内を利用できる |
| 想定する利用者 | ロードバイク・グラベルバイク愛好家、自転車通勤者、サイクルツーリスト |
| 商用か非商用か | 商用 (基本のルート検索・記録は無料。Bikemap Premium は月額・年額サブスクリプションまたは 3 年間買い切りプランがあり、オフライン地図・音声ナビ・路面別レイヤー等を提供) |
| 推定の売上 | 推測: 年数百万ユーロ (数億円) 規模 (アプリ市場分析でストア売上月数万〜10 万ドル超、全体で年商数百万ドル規模と推計。Speedinvest 等から VC 調達、非上場のため非公開) |
| 運営 | 企業 (Bikemap GmbH、オーストリア・ウィーン) |
| 推定の運用費 | 推測: 月数百万円規模 (自転車特化の独自ルーティングエンジン、全世界のルート・写真・OSM タイルの AWS / CloudFront 配信を維持) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (2026-11-16 のトップページ観測では Next.js チャンクのみ検出。地図描画には MapLibre 等が利用されているとの技術事例がある) |
| フレームワーク | Next.js + Turbopack (応答ヘッダーの `x-powered-by: Next.js` および `/_next/static/chunks/turbopack-*.js` を確認) |
| 背景の地図とタイル | OpenStreetMap ベースの独自サイクリング地図、OpenCycleMap、地形図等。CSP の `connect-src` に `api.tomtom.com` への参照を確認 |
| 投稿やデータの保存先 | 自社のルート・メディア基盤 (`media.bikemap.net` を CSP ヘッダーで確認) |
| 配信 | nginx + Amazon CloudFront (`server: nginx`、`via: ... cloudfront.net`、`x-cache: Hit from cloudfront` を応答ヘッダーで確認) |
