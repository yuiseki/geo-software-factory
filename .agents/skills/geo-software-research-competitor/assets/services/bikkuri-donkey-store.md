## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のびっくりドンキー店舗を、エリア・キーワード・条件から検索し、店舗詳細で地図を確認できる公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の営業時間、駐車場、モーニングやテイクアウト対応の有無と店舗位置を地図で確認し、来店予約などへ進める |
| 想定する利用者 | びっくりドンキーを利用したい一般客、家族連れやドライバーなど |
| 商用か非商用か | 商用 (実店舗への来店送客およびテイクアウト・来店予約の導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社アレフ) |
| 推定の運用費 | 推測: 月数万円。Amazon S3 + CloudFront の配信費および店舗詳細 iframe 地図の利用範囲に応じた運用費 |
