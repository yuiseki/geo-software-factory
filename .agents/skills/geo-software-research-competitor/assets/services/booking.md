## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中のホテル、アパートメント、民泊などの宿泊施設や航空券、レンタカーを取り扱う世界最大級のオンライン旅行予約プラットフォーム |
| 提供する価値 | 膨大な宿泊施設を地図上の位置や価格ピン、周辺スポットとの距離、多言語の口コミから比較し、即座に予約・キャンセル管理できる |
| 想定する利用者 | 世界中の個人旅行者、ビジネス出張者、および宿泊施設を掲載するパートナー事業者 |
| 商用か非商用か | 商用 (宿泊・旅行予約の手数料、広告、決済関連収益など) |
| 推定の売上 | 約 269.2 億米ドル (親会社 Booking Holdings 全体の 2025 年通期売上高。2024 年は約 237.4 億米ドル) |
| 運営 | 企業 (Booking.com B.V.、オランダ・アムステルダム拠点、米国 Booking Holdings 傘下) |
| 推定の運用費 | 未確認 (グローバル規模の検索・予約基盤、多言語対応、地図 API・データ利用料、マーケティングおよび運用人件費) |
