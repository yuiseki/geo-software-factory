# CalTopo

- URL: https://caltopo.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: CalTopo、SARTopo、地形図、捜索救助、SAR、斜度解析、GPS、印刷用地図、バックカントリー

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | バックカントリーの計画や捜索救助 (SAR) 向けに、高精度な地形図、斜度や日照の解析、印刷用 PDF 出力、リアルタイム共有を提供する地図プラットフォーム |
| 提供する価値 | 複数の地形図や衛星画像を自在に重ねて斜度・方位・積雪状況などを解析し、大判印刷用地図の作成や現場チームでのリアルタイム位置共有ができる |
| 想定する利用者 | バックカントリー登山者、スキーヤー、山岳ガイド、捜索救助隊 (SAR)、消防・防災関係者 |
| 商用か非商用か | 商用 (Free は無料、Mobile は年 20 米ドル、Pro は年 50 米ドル、Desktop は年 100 米ドル、Team は年 2,000 米ドル前後・ボランティア SAR 向け割引あり) |
| 推定の売上 | 未確認 (非公開企業のため売上は公表されていない。個人向け有料プランと救助隊・機関向けチーム契約が収益源) |
| 運営 | 企業 (CalTopo、創業者 Matt Jacobs 氏が 2010 から 2011 年頃に SAR 向けツールとして開始し事業化) |
| 推定の運用費 | 未確認 (高解像度ラスター・ベクトルタイルおよび週次衛星画像の処理と配信基盤のサーバー費、データライセンス費) |

| 項目 | 観測したもの |
|---|---|
| 種類 | ウェブ、デスクトップアプリ (Desktop プラン)、iOS と Android のアプリ |

| 背景の地図とタイル | 自社 MapBuilder 地図、USGS 地形図、USFS 地図、Sentinel 週次衛星画像、斜度・標高陰影レイヤー、WMS/WMTS 外部レイヤー対応 |
| 投稿やデータの保存先 | 未確認 (クラウド同期およびオフライン端末・デスクトップローカル保存に対応) |

メモ:

- 捜索救助 (Search and Rescue) 向けの構成は「SARTopo」としても広く知られ、北米の山岳救助現場で標準的に使われている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 地形図・森林局地図 | USGS (米国地質調査所)、USFS (米国森林局) 等 | CalTopo 公式サイト |
| 衛星画像・標高データ | Sentinel 衛星データ、各種 DEM データ | CalTopo 公式サイト |
| 道路・トレイル等の基盤 | OpenStreetMap 等 (MapBuilder レイヤー) | CalTopo 公式サイト |
