# CellMapper

- URL: https://www.cellmapper.net
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: CellMapper、基地局マップ、携帯電話基地局、4G、5G、LTE、電波強度、RSRP、クラウドソーシング、OpenLayers

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中の携帯電話基地局 (2G/3G/4G/5G) の位置やセクター範囲、電波強度をユーザーの計測投稿で構築・可視化するクラウドソーシング地図 |
| 提供する価値 | 携帯キャリアが公式に公開しない基地局の設置場所、周波数帯 (バンド)、セル ID、実測カバレッジエリアを地図上で詳細に調べられる |
| 想定する利用者 | 通信マニア・無線愛好家、携帯回線の電波状況を確認したい一般利用者、通信エンジニア・研究者 |
| 商用か非商用か | 商用 (基本機能は無料で広告表示あり。有料の Premium Membership は月額 3 カナダドル (CAD) 程度で広告非表示・処理優先度向上を提供) |
| 推定の売上 | 推測: 年数百万円〜数千万円規模 (有料会員と広告収入による運営。個人・有志ベースの運営で売上数値は非公開) |
| 運営 | 個人・コミュニティ運営 (CellMapper) |
| 推定の運用費 | 推測: 月数十万円〜百万円規模 (世界中の膨大な基地局・トレイルデータの処理サーバー、DB、タイル・マップ API 利用料) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | OpenLayers 10.9.0 + ol-mapbox-style 13.5.1 (`ol@v10.9.0/dist/ol.js`、`ol-mapbox-style@13.5.1/dist/olms.js` の読み込みを確認) |
| フレームワーク | jQuery + Bootstrap 4 (`jquery/3.7.1`、`jqueryui/1.14.1`、`bootstrap/4.3.1`、`tom-select` を確認) |
| 背景の地図とタイル | Mapbox、Google Maps、ArcGIS 等の複数背景切り替え (`mapbox`、`maps.googleapis.com`、`arcgis` の記述を HTML 内で確認) |
| 投稿やデータの保存先 | CellMapper 独自サーバー (Android アプリからアップロードされた無線計測データ) |
| 配信 | Apache (`server: Apache` を応答ヘッダーで確認) |

メモ:

- ウェブ版のほか、電波・セル ID の自動計測とアップロードを行う公式 Android アプリ「CellMapper」を提供している (iOS は OS の無線 API 制限のため公式アプリなし)。
