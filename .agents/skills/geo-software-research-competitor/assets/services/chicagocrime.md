## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | シカゴ市警察の公開犯罪データを Google Maps 上にマッピングし、シビックテックとデータジャーナリズムの先駆けとなった初期マッシュアップ（2005〜2008年、現在は終了） |
| 提供する価値 | 犯罪の種類・日時・場所、さらには任意の歩行ルート沿いの犯罪発生状況を地図上でインタラクティブに検索・閲覧でき、公的オープンデータの可視化の可能性を示した |
| 想定する利用者 | シカゴの住民や引っ越し検討者、ジャーナリスト、シビックテック・オープンデータに関心のある開発者 |
| 商用か非商用か | 非商用 (Adrian Holovaty が 2005年5月に公開し、2008年1月31日に終了。後に Knight Foundation の助成を受けた EveryBlock へと発展) |
| 推定の売上 | なし (非商用プロジェクト。現在サービス終了) |
| 運営 | 個人 (Adrian Holovaty、2005年5月〜2008年1月31日。現在終了) |
| 推定の運用費 | 0円 (現在は終了・停止中) |

メモ:

- **現在はサービス終了している。** 2005年5月に公開され、2008年1月31日に公式に終了した。2026-11-16 時点のアクセスでもタイムアウトとなり応答しない。
- HousingMaps と並ぶ 2005年の最初期 Google Maps マッシュアップであり、Google Maps API の公式リリースにも影響を与えたほか、ニューヨーク近代美術館 (MoMA) の展示でもスクリーンショットが取り上げられた。
- Web フレームワーク **Django** の初期の代表的事例でもあり、同プロジェクトの発展形として 2007〜2008年に街区単位の地域情報サイト **EveryBlock** が立ち上げられた。
- iOS / Android の公式アプリは提供されていない。
