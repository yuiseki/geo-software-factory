## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の賃貸マンション・アパート・一戸建て情報をエリアや路線・地図から探せる日本の老舗賃貸不動産ポータルサイト |
| 提供する価値 | 全国の賃貸物件の空室情報を、地図上の現在地周辺や希望エリア・周辺施設 (スーパー・コンビニ等) との位置関係と合わせて比較し、LINE やアプリで手軽に問い合わせできる |
| 想定する利用者 | 日本国内で賃貸住宅を探す一般消費者 (一人暮らし・カップル・ファミリー)、および反響を獲得したい賃貸仲介会社・管理会社 |
| 商用か非商用か | 商用 (利用者は無料。不動産仲介会社・管理会社からの物件掲載料、反響課金、仲介会社向け業務支援システム等で収益化) |
| 推定の売上 | 未確認 (非上場企業のため売上高は非公開。第34期決算公告等で当期純利益約7億5,200万円を計上) |
| 運営 | 企業 (株式会社CHINTAI、東京都港区、エイブル＆パートナーズグループ) |
| 推定の運用費 | 推測: 月数百万〜数千万円規模。全国規模の賃貸物件データベース、画像・間取り図配信、検索・地図機能・LINE 連携基盤の運用 |
