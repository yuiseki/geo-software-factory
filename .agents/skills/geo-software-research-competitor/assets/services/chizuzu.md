# ChizuZu - 地図比較アプリ

- URL: https://chizuzu.highwide.net/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 地図の比較、距離感、縮尺、2 画面、並べて比べる、旅行

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 身近な場所と旅行先を、同じ縮尺の 2 枚の地図に並べて比べるアプリ |
| 提供する価値 | 知らない土地の距離感を、自宅から学校までのような身近な距離に置き換えて分かる |
| 想定する利用者 | 旅行の計画を立てる人、物件探しで駅からの距離を見る人、移動の企画をする動画の作り手 |
| 商用か非商用か | 非商用 (広告、寄付、有料プランは見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 個人と見られる (highwide.net のサブドメイン。運営者の表示は見つからなかった) |
| 推定の運用費 | 推測: 月 0〜数百円 (ドメイン代)。Cloudflare の静的配信。背景は OSM 財団の公開タイルで費用はかからないが、タイル利用方針の条件がある |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | OSM 財団の公開タイル |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | Cloudflare |

読み込んだタイルとスタイルの URL (一部):

- `https://a.tile.openstreetmap.org/{z}/{x}/{y}.png`
- `https://b.tile.openstreetmap.org/{z}/{x}/{y}.png`
- `https://c.tile.openstreetmap.org/{z}/{x}/{y}.png`

データの出どころ (地図の帰属表示と画面の最下部 500 字、2026-11-12):

- 地図の帰属表示: 「© OpenStreetMap contributors」
