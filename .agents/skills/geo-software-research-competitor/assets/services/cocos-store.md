## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のファミリーレストラン「ココス」店舗を、都道府県・エリア・条件から検索できる公式店舗検索サイト |
| 提供する価値 | 朝食バイキング実施店舗などの条件や住所・営業時間・店舗詳細を確認でき、Google マップへのリンクから場所を辿れる |
| 想定する利用者 | ココスを利用したい一般客、朝食バイキングや深夜営業などの条件で店舗を探す利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ココスジャパン) |
| 推定の運用費 | 推測: 月数万円。静的・Web サーバー (Apache) の運用費程度 (埋め込み地図 API の利用有無は未確認) |
