## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 関東・東海地方を中心に展開するドラッグストア クリエイト エス・ディーの店舗を検索し、各店舗の地図・営業時間・調剤受付等を確認できる公式店舗検索サイト |
| 提供する価値 | エリアや条件から最寄りのクリエイト店舗を探し、個別店舗ページで地図や営業時間・調剤薬局の対応状況を確認できる |
| 想定する利用者 | クリエイト エス・ディーを利用する一般客、処方箋調剤や日用品購入のため最寄り店舗を探している生活者 |
| 商用か非商用か | 商用 (実店舗への来店送客およびネットショップへの導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗および EC (`netshop.create-sd.co.jp`) の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社クリエイトエス・ディー) |
| 推定の運用費 | 推測: 月数万〜数十万円。店舗情報管理 SaaS (Canly) の利用料および CloudFront + Next.js の運用費がかかる |
