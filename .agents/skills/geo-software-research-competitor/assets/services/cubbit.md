# 方位図法世界地図作成ツール

- URL: https://maps.cubbit.app/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 正距方位図法、方位図法、地図投影、世界地図、図法、SVG

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 正距方位図法などの方位図法で、好きな点を中心にした世界地図を作り SVG と PNG で書き出すツール |
| 提供する価値 | 中心からの距離と方位が正しい世界地図を、印刷や編集に使える形で手に入れられる |
| 想定する利用者 | 地理の教材を作る人、デザイナー、地図の図法に関心がある人 |
| 商用か非商用か | 非商用 (広告、寄付、有料プランは見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 個人 (作者として X のアカウントへのリンク) |
| 推定の運用費 | 推測: 月 0〜数千円。Cloudflare の静的配信。Google Maps JavaScript API の地図ロードが月 1 万回を超えると 1,000 回あたり 7 USD かかる (はてなブックマーク 228 件で話題になった月は超えうる) |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps JavaScript API |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | 見つからなかった |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | Cloudflare |

データの出どころ (地図の帰属表示と画面の最下部 500 字、2026-11-12):

- 地図の帰属表示にも画面の最下部にも、データの出典は見えなかった。地図の画面の中に描かれている、別のボタンやページにある、の可能性はある
