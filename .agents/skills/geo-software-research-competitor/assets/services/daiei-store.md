## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ダイエーおよびイオンフードスタイル等の店舗を地域や条件から検索し、個別店舗ページの地図やチラシ・店舗情報を確認できる公式店舗検索サイト |
| 提供する価値 | エリア別に店舗を探し、各店舗ページで Google マップの地図、クラシルチラシ連携のチラシ情報、営業時間・設備を確認できる |
| 想定する利用者 | ダイエー各店舗への来店を予定している一般客、近隣のスーパーやチラシを探している生活者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ダイエー / イオングループ) |
| 推定の運用費 | 推測: 月数万円。Cloudflare + WordPress の運用費のみで、Google マップは簡易 iframe 埋め込みのため地図 API 従量課金は抑えられている |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google マップ iframe 埋め込み (個別店舗ページ `/stores/0004/` に `https://www.google.com/maps?q=34.718949,135.484178&hl=ja&z=16&output=embed` の iframe を確認) |
| フレームワーク | WordPress (`/kywp/wp-content/themes/kohyo/...`) + jQuery 3.7.1 (GA4 / GTM、Cloudflare Web Analytics) |
| 背景の地図とタイル | Google マップ (iframe 埋め込み) |
| 投稿やデータの保存先 | WordPress 側で店舗ページ (`/stores/<店舗コード>/`) を生成。チラシは外部ウィジェット (`chirashi.kurashiru.com`) を埋め込み |
| 配信 | Cloudflare (`server: cloudflare`、`cf-ray: ...-NRT`) |

メモ:

- 一覧ページ (`/stores/`) には地図は埋め込まれておらず、個別店舗ページ (`/stores/0004/`) に Google マップの `output=embed` 形式の iframe が埋め込まれている
- テーマパスに `kohyo`（同じイオングループの光洋系テーマ基盤）が使われていることを HTML から確認した
