## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のデイリーヤマザキ・ニューヤマザキデイリーストア店舗を、地図上での探索やエリア・条件から検索できる公式店舗検索サイト (AreaMarker) |
| 提供する価値 | 周辺のデイリーヤマザキ店舗の位置や、店内調理パン (デイリーホット)・ATM・酒・たばこなどの取扱条件を地図上で確認できる |
| 想定する利用者 | デイリーヤマザキを探している一般客、焼きたてパンや特定設備のある店舗を探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (山崎製パン株式会社。店舗検索システムはゼンリンデータコム等の AreaMarker を利用) |
| 推定の運用費 | 推測: 月数万〜数十万円。AreaMarker (ゼンリンデータコム) の ASP 利用料と S3 + CloudFront 配信費がかかる |
