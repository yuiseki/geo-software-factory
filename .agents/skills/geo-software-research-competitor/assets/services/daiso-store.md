## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の DAISO、Standard Products、THREEPPY などの店舗を、エリア・店舗規模・条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 近くのダイソー店舗や大型店・標準店の位置、営業時間、駐車場有無、取り扱いブランドなどを確認し、来店前の店舗選びができる |
| 想定する利用者 | 100 円ショップや生活雑貨を探している一般客、品揃えの多い大型店を探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客および公式ネットストア・DAISO アプリ連携の導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗での購買を促進する集客基盤 |
| 運営 | 企業 (株式会社大創産業) |
| 推定の運用費 | 推測: 月数十万円。Google Maps Platform の利用料と Web サーバー・CDN の運用費がかかる |
