# Datawrapper

- URL: https://www.datawrapper.de/
- ソース: https://github.com/datawrapper/datawrapper (コアの一部をオープンソース公開)
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Datawrapper、データ可視化、コロプレス地図、シンボル地図、ロケーター地図、報道、ジャーナリズム、D3、Svelte

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 報道機関や調査団体向けに、コーディング不要でレスポンシブなグラフ・表・地図を作成して記事へ埋め込めるデータ可視化ツール |
| 提供する価値 | コロプレス地図 (階級区分図)、シンボル地図、ロケーター地図を数分で作成でき、色覚多様性への配慮やモバイル対応、クレジット表記、SVG/PDF 出力まで一貫して整う |
| 想定する利用者 | 新聞社・テレビ局・Web メディアの記者や編集者、研究機関、自治体・企業の広報およびレポート担当者 |
| 商用か非商用か | 商用 (クレジット表示ありの個人・小規模向け Free プランと、ロゴ除去・チーム共有・高機能出力・API 自動化を備えた有料の Pro / Business / Enterprise プラン) |
| 推定の売上 | 推測: 年間 ARR 約 320 万ドル規模 (調査機関 GetLatka による推定値。VC 調達に頼らない自己資金経営の非上場企業のため公式非公開) |
| 運営 | 企業 (Datawrapper GmbH、ドイツ・ベルリン拠点、従業員約 25〜30 名) |
| 推定の運用費 | 未確認 (Cloudflare CDN 経由での埋め込みチャート・地図の大量配信およびバックエンド API 基盤の運用費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | D3.js + 自前の SVG/Canvas 地図レンダリングエンジン (地図種別に応じてランベルト正積方位図法やウェブメルカトル等を使い分け) |
| フレームワーク | Svelte (トップページ HTML では `svelte`、`react`、`next`、`d3` の文字列を確認) |
| 背景の地図とタイル | 内蔵の行政界・国境ベクターデータ (数千種類の地域地図テンプレート)、およびロケーター地図用のベースマップタイル |
| 投稿やデータの保存先 | Datawrapper クラウド (CSV/TSV 貼り付け、Google Sheets 連携、REST API による自動更新) |
| 配信 | Cloudflare (`server: cloudflare`) |

メモ:

- 汎用的な WebGIS ではなく「記事に埋め込んで読者に伝えること」に特化しており、地図の投影法や注釈の配置が非常に洗練されている。
- 外部からの自動生成向けの API も提供されている。
