# DeFlock Maps | ALPR Camera Map & Privacy Routes

- URL: https://maps.deflock.org/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: ナンバー読み取り、ALPR、監視カメラ、プライバシー、ルート、米国

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 米国の自動ナンバー読み取り装置 (ALPR) の位置を地図に示し、避けて通るルートを引くサービス |
| 提供する価値 | 誰が車を記録しているかを知り、監視カメラを避けた移動の計画ができる |
| 想定する利用者 | 米国でプライバシーを気にする運転者、監視の広がりを調べる市民や記者 |
| 商用か非商用か | 非商用と見られる (ボランティアの OSS。地図のページに広告、有料プランは見えなかった。寄付の受け付けは未確認) |
| 推定の売上 | なし (非商用と見られる) |
| 運営 | 団体 (ボランティアのオープンソースのプロジェクト。カメラの位置は OSM の貢献者が載せる) |
| 推定の運用費 | 推測: 月数千〜数万円。Cloudflare の後ろの配信と自前のタイル、ルート検索のサーバー |
