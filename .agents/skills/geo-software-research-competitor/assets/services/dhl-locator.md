## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | DHL Express の世界共通拠点検索システム上で、日本国内を含むサービスポイントや取扱店を地図で探せる公式ロケーター |
| 提供する価値 | 国際宅急便の発送持ち込み・受け取りに対応した最寄りの DHL サービスポイントや提携窓口の位置・営業時間・対応サービスを確認できる |
| 想定する利用者 | 国際郵便・国際宅配便を発送または受け取りたい個人・法人顧客 |
| 商用か非商用か | 商用 (DHL Express の国際輸送サービスの拠点案内・送客として提供。利用料は無料) |
| 推定の売上 | 推測: 拠点検索単体の売上は 0 円。国際輸送サービスの利用促進に貢献 |
| 運営 | 企業 (DHLジャパン株式会社 / DHL Express グローバル共通基盤) |
| 推定の運用費 | 推測: 月数十万〜数百万円（グローバル全体）。Google Maps Platform の地図表示・検索課金と拠点検索基盤の運用費がかかる |
