## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のドコモショップを、現在地・エリア・駅名・対応サービス条件から検索して地図上に表示し、来店予約へつなぐ公式店舗検索サイト |
| 提供する価値 | 最寄りのドコモショップの位置、営業時間、定休日、駐車場やバリアフリー設備、スマホ教室・修理受付の有無を確認し、そのまま Web 来店予約ができる |
| 想定する利用者 | 新規契約・機種変更・プラン相談・故障修理などでドコモショップへの来店を予定している利用者 |
| 商用か非商用か | 商用 (実店舗への来店予約・窓口業務の効率化および端末・回線契約への送客基盤として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗での通信契約・端末販売・サポート業務への送客に貢献する基盤 |
| 運営 | 企業 (株式会社NTTドコモ) |
| 推定の運用費 | 推測: 月数十万円。Google Maps Platform の利用料および自社ホスティング環境の運用費がかかる |
