## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のドン・キホーテや MEGA ドン・キホーテ等の店舗・駐車場を、現在地・エリア・条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 深夜・24 時間営業店舗や大型駐車場、免税対応、取り扱いサービスなどの条件で最寄り店舗を探し、チラシや店舗情報へアクセスできる |
| 想定する利用者 | ドン・キホーテを利用したい一般客、深夜帯に買い物できる店舗や駐車場付き店舗を探している利用者、訪日観光客 |
| 商用か非商用か | 商用 (実店舗への来店送客および WEB チラシ・電子マネー majica への導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗での購買および majica 会員基盤への送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社ドン・キホーテ / 持株会社: 株式会社パン・パシフィック・インターナショナルホールディングス) |
| 推定の運用費 | 推測: 月数十万円。Google Maps Platform の利用料と Web サーバー・CDN 等の運用費がかかる |
