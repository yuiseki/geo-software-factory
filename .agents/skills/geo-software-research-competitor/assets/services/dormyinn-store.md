## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | トップおよび一覧 (`/dormyinn/hotels/list/`) には埋め込み地図なし。個別ホテルページ (例: `/dormyinn/hotels/chitose`) 内で Google マップの iframe 埋め込み (`https://www.google.com/maps/embed?pb=...`) を使用 |
| フレームワーク | jQuery + jQuery UI + Slick (`jquery.js`、`jquery-ui.min.js`、`slick.js`) |
| 背景の地図とタイル | Google マップ (Maps Embed iframe) |
| 投稿やデータの保存先 | サーバー側で生成された HTML (`/dormyinn/hotels/...`)、静的アセットは `img.dormy-hotels.com` から配信 |
| 配信 | nginx (`server: nginx`、`x-cache: BYPASS`) |

メモ:

- `/dormyinn/` および `/dormyinn/hotels/list/` は地域・施設一覧の構成で、各ホテルの個別ページ内に Google マップの iframe が埋め込まれている
