# ドトールコーヒー 店舗検索

- URL: https://shop.doutor.co.jp/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ストアロケーター、店舗検索、カフェ、ドトールコーヒー、エクセルシオール、Wi-Fi、喫煙、営業時間、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のドトールコーヒーショップ等の店舗を、現在地・駅名・エリア・設備条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 近くの店舗の位置や営業時間、Wi-Fi・電源・喫煙設備などの条件を素早く確認し、目的に合った店舗を選べる |
| 想定する利用者 | ドトールコーヒーの店舗を探している一般客、外出先で休憩・作業できるカフェを探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびブランド送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社ドトールコーヒー) |
| 推定の運用費 | 推測: 月数万〜数十万円。NAVITIME Location Cloud (ゼンリン地図データ含む) の法人向け利用料とサーバー運用費がかかる |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | NAVITIME Location Cloud (ブラウザ観測および一次 HTTP 取得で NAVITIME の利用を確認) |

メモ:

- 2026-11-16 のブラウザ観測で NAVITIME Location Cloud の利用と、背景地図がゼンリンであることを確認した
- 一次 HTTP 取得 (`https://shop.doutor.co.jp/` → `https://shop.doutor.co.jp/doutor/`) ではステータス 200 (タイトル `トップ | 店舗検索｜株式会社ドトールコーヒー`)、HTML 内に `has_navitime: true`、配信ヘッダは `Apache` であった

データの出どころ (2026-11-16):
