# EarthCam

- URL: https://www.earthcam.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: EarthCam、アースカム、ライブカメラ、4Kストリーミング、タイムズスクエア、建設現場カメラ、タイムラプス、Leaflet

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中の観光地・都市の 4K ライブカメラネットワークを地図から探して視聴でき、法人向け建設現場カメラ事業も展開する老舗ライブカメラサービス |
| 提供する価値 | ニューヨークのタイムズスクエアや自由の女神像など世界中の有名スポットのライブ映像を地図上で探して無料で楽しめ、法人向けには建設・インフラ現場の監視・タイムラプス技術を提供する |
| 想定する利用者 | 一般の視聴者・旅行者、報道機関、建設会社・自治体・政府機関 (B2B 監視・記録用途) |
| 商用か非商用か | 商用 (コンシューマー向け EarthCam.com の視聴は無料・広告および映像ライセンス収益モデル。法人向けの建設現場監視・タイムラプス・ハードウェア提供 EarthCam.net は有料見積もり制) |
| 推定の売上 | 非公開 (米国の非公開企業 EarthCam, Inc. のため売上高非公開。1996年創業の業界大手で、B2C 広告・ライセンスと B2B 建設現場カメラ事業の両輪で展開) |
| 運営 | 企業 (EarthCam, Inc.、米国ニュージャージー州・1996年創業) |
| 推定の運用費 | 推測: 年間数億円規模 (世界各地の 4K ライブストリーミング配信・映像アーカイブ・Cloudflare CDN 等のインフラ維持費) |
