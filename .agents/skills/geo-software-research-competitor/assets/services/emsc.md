- 探すときの語: EMSC、CSEM、欧州地中海地震学センター、LastQuake、地震マップ、クラウドソーシング地震検知、地震速報

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 欧州・地中海地域を中心に世界の地震情報と、市民からの体感報告 (LastQuake) を組み合わせたリアルタイム地震情報サービス |
| 提供する価値 | 地震観測網のデータだけでなく、スマホアプリのアクセス急増や市民の体感アンケート・写真投稿を即座に集計し、地震発生を極めて迅速に検知・通知する |
| 想定する利用者 | 欧州・地中海および世界の一般市民、地震研究者、防災関係者 |
| 商用か非商用か | 非商用 (国際非政府・非営利の科学組織。Web・LastQuake アプリともに無料で広告なし) |
| 推定の売上 | 0 円 (商業売上はなく、加盟地震研究機関の会費、EU Horizon 2020 等の研究助成金、防災関連の公的・財団助成により運営) |
| 運営 | 非営利団体 (欧州地中海地震学センター EMSC / CSEM、フランス登記の国際 NGO・科学協会) |
| 推定の運用費 | 推測: 年数千万円〜数億円規模。加盟機関からのデータ集約サーバー、リアルタイム地震検知基盤、および全世界の LastQuake アプリへのプッシュ通知配信を維持している |
