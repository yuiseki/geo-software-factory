# Expedia

- URL: https://www.expedia.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Expedia、エクスペディア、旅行予約、OTA、ホテル、航空券、レンタカー、地図検索、One Key

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 航空券、ホテル、レンタカー、現地アクティビティなどを一括で比較・予約でき、地図上から宿泊施設の立地や価格帯を探せる世界大手の総合オンライン旅行会社 (OTA) |
| 提供する価値 | 宿泊施設の料金ピンを地図上に表示して観光地や駅からの距離感・周辺環境を比較しながら予約でき、航空券とのセット割引や One Key リワードも利用できる |
| 想定する利用者 | 国内外の個人・ビジネス旅行者、航空券やホテルをまとめて手配したいユーザー |
| 商用か非商用か | 商用 (旅行者の検索・利用は無料。宿泊予約・航空券・パッケージ等の販売手数料および広告収入で運営) |
| 推定の売上 | 親会社 Expedia Group 全体の 2024 年通期売上は 136.9 億ドル (総予約額約 1,100 億ドル) |
| 運営 | 企業 (Expedia Group, Inc.、米国上場企業) |
| 推定の運用費 | 推測: 月数億円以上。世界中の宿泊・航空在庫とのリアルタイム連携、膨大な検索トラフィック処理、グローバル CDN と地図 API の利用料が掛かる |

メモ:

- 2026-11-16 時点の HTTP 一次観測では `HTTP 429` が返却されたため、フロントエンドの地図ライブラリやレスポンスヘッダーの直接観測はできていない。
