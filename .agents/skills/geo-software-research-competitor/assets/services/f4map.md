# F4map

- URL: https://www.f4map.com/ (デモ: https://demo.f4map.com/)
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: F4map、F4、3D 地図、3D マップ、OpenStreetMap、OSM 3D、建物 3D、WebGL、立体地図、3D map、3D buildings

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | OpenStreetMap の建物や地形データを WebGL でリアルタイムに 3D 描画するインタラクティブな 2D/3D 地図および法人向けカスタム地図サービス |
| 提供する価値 | プラグイン不要のブラウザ上で、OSM の建物高さ・屋根形状の自動 3D 化、太陽光や天候エフェクト、ランドマークの精細な 3D モデルを閲覧・利用できる |
| 想定する利用者 | OSM の 3D マッピングを確認したいマッパー、観光・イベント・商業施設向けにカスタム 3D 地図を導入したい企業 |
| 商用か非商用か | 商用 (一般向けのデモは非商用 CC-BY-NC 扱いだが、法人向けのカスタム地図制作・埋め込み・プロモーション用途は個別見積もりで提供) |
| 推定の売上 | 未確認 (公開の料金表や売上数値は公表されていない。B2B の受託・カスタムソリューションが収益源と見られる) |
| 運営 | 企業 (F4 Group、フランス本社のインタラクティブメディア・ゲーム・ソフトウェア開発会社) |
| 推定の運用費 | 未確認 (OSM データの取り込み・3D タイル生成と Varnish/nginx を用いた配信基盤を自前で運用していると見られる) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 自前の WebGL 3D エンジン (プロプライエタリ・ソースコード非公開) |
| フレームワーク | 未確認 (応答ヘッダーでは `x-powered-by: Express` を確認) |
| 背景の地図とタイル | OpenStreetMap データを基にした自前の 3D/2D タイル、および一部ランドマークのカスタム 3D モデル |
| 投稿やデータの保存先 | OpenStreetMap (OSM 側の編集が F4map へ同期される) |
| 配信 | nginx + Express + Varnish/6.6 (配信先のインフラ事業者は未確認) |

メモ:

- 公開のセルフサーブ API や料金プランは提供されていない。
- ソースコードおよびカスタム 3D アセットはクローズドソース。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 建物・道路・土地利用等の地図データ | OpenStreetMap contributors | デモサイトおよび OpenStreetMap Wiki の F4 Map の解説 |
| 一部ランドマークの精細な 3D モデル | F4 Group 自社制作 | OpenStreetMap Wiki の F4 Map の解説 |
