## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のファミリーマート店舗を、現在地・エリア・駅名・設備条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 周辺のファミマ店舗の位置や、ATM・イートイン・マルチコピー機・駐車場などの取扱設備・サービスを素早く確認できる |
| 想定する利用者 | 近くのファミリーマートを探している一般客、特定の設備やサービスに対応した店舗を探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ファミリーマート) |
| 推定の運用費 | 推測: 月数十万円以上。GOGA 店舗検索サービスの利用料と Google Maps Platform の利用料、Google Cloud 側の配信費がかかる |
