# FedEx ジャパン 拠点検索

- URL: https://local.fedex.com/ja/search
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 拠点検索、営業所検索、FedEx、フェデックス、国際宅配便、ドロップオフ、クーリエ、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本国内のフェデックス営業所やドロップオフ拠点を、住所・現在地から地図上で検索できる公式ロケーター |
| 提供する価値 | 国際貨物の持ち込み発送や受け取りに対応した最寄りのフェデックス拠点の位置・営業時間・対応サービスを日本語で確認できる |
| 想定する利用者 | フェデックスで国際荷物を発送・受け取りしたい法人・個人顧客 |
| 商用か非商用か | 商用 (フェデックスの国際輸送サービスの拠点案内として提供。利用料は無料) |
| 推定の売上 | 推測: 拠点検索単体の売上は 0 円。国際宅配便サービスの利用促進に貢献 |
| 運営 | 企業 (フェデラルエクスプレスジャパン合同会社 / FedEx グローバル基盤) |
| 推定の運用費 | 推測: 月数十万〜数百万円（グローバル全体）。Cloudflare CDN と Google Maps Platform の利用料がかかる |
