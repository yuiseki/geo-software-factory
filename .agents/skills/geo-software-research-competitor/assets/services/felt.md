# Felt

- URL: https://felt.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Felt、クラウド GIS、コラボレーティブ地図、WebGIS、AI GIS、MapLibre、BigQuery、Snowflake、地図共有

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ブラウザ上でリアルタイム共同編集、空間データ可視化、クラウド DB 連携、AI 分析ができるクラウドネイティブ GIS プラットフォーム |
| 提供する価値 | 従来のデスクトップ GIS ソフトを使わずに、巨大な空間データのアップロード、ダッシュボード作成、自然言語での AI 分析、チームでの共有を即座に行える |
| 想定する利用者 | データアナリスト、GIS 専門家、気候・インフラ・エネルギー・不動産・自治体の企画および開発チーム |
| 商用か非商用か | 商用 (無料枠つきの SaaS。Team / Business / Enterprise の階層型プランに加え、SDK やプライベート埋め込み向けの Developer プランは年払いで月額 1,000 ドル程度から) |
| 推定の売上 | 未確認 (非公開企業。これまでに累計約 3,450 万ドル以上のベンチャー資金を調達しており、2025 年 7 月にも 1,500 万ドルの戦略的成長資金を調達) |
| 運営 | 企業 (Felt Inc.、米国サンフランシスコ拠点) |
| 推定の運用費 | 未確認 (大規模空間データのタイル化・配信基盤、AI 推論基盤、Cloudflare CDN およびクラウドインフラの運用費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | MapLibre GL JS (および deck.gl 等の WebGL ベース高速描画) |
| フレームワーク | トップページは Astro (`/_astro/...` スクリプトを確認)。アプリ本体の詳細構成は未確認 |
| 背景の地図とタイル | 自社ホスティングのベクトルタイル、衛星写真、Snowflake / BigQuery / Databricks / PostGIS / S3 等の外部データ接続 |
| 投稿やデータの保存先 | Felt クラウド基盤、および連携した顧客のクラウドデータウェアハウス |
| 配信 | Cloudflare (`server: cloudflare`) |

メモ:

- 2025 年以降は「AI-native GIS」を掲げ、自然言語プロンプトで地図作成や空間クエリを実行する機能 (Felt AI) を強化している。
- 従来の ETL 処理なしにクラウドデータウェアハウスへ直接接続できる点を強みとしている。
