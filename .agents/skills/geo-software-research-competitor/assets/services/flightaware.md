# FlightAware

- URL: https://www.flightaware.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: FlightAware、フライト追跡、ADS-B、航空機、運航状況、PiAware、AeroAPI、OpenLayers、Next.js

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中の航空機のリアルタイム位置、発着状況、遅延予測、航空路を地図上で追跡し、法人向け航空データ API も提供するプラットフォーム |
| 提供する価値 | 地上 ADS-B ネットワーク (PiAware) と航空管制データ・衛星 ADS-B を統合し、正確なフライト追跡や遅延アラート、履歴データを一般利用者と航空業界の双方に届ける |
| 想定する利用者 | 航空機の乗客・送迎者、航空ファン・PiAware 受信機提供者、航空会社・空港運営者、旅行・物流系アプリの開発者 |
| 商用か非商用か | 商用フリーミアム (Web・アプリの基本追跡は広告付きで無料、有料個人プランあり。開発者・法人向け AeroAPI や Firehose は月額 $100〜$1,000+ 等の有料課金プラン) |
| 推定の売上 | 推測: 年数十億円〜百億円規模 (2021年に RTX 傘下の Collins Aerospace が買収した世界大手の商用航空データ事業者だが、買収後の単体売上は非公開) |
| 運営 | 企業 (FlightAware / 2021年より Collins Aerospace [RTX Corporation] 傘下、米国) |
| 推定の運用費 | 推測: 月数千万円規模 (世界数万局の ADS-B 受信機からのリアルタイムストリーム処理、自社カスタムタイル生成、Cloudflare 配信) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | OpenLayers (Web 版。公式技術ブログで OpenLayers 採用と自社カスタムベクトルタイル・Apache Baremaps 等の活用を公開。iOS アプリは MapKit、Android アプリは Google Maps 等) |
| フレームワーク | Next.js + React (`x-powered-by: Next.js` および `/_next/static/chunks/`、`react` を応答ヘッダー・HTML で確認) |
| 背景の地図とタイル | 自社構築のカスタム地図タイル (OpenStreetMap データ等ベース) + 気象レーダー・航空路オーバーレイ |
| 投稿やデータの保存先 | 自社データセンター / クラウド基盤 (ユーザーのアラート設定、PiAware 受信機統計、履歴フライトデータベース) |
| 配信 | Cloudflare (`server: cloudflare` を応答ヘッダーで確認) |

メモ:

- ウェブ版のほか、公式の iOS / Android アプリも提供されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 航空機位置・ADS-B | 世界中のボランティア ADS-B ネットワーク (PiAware)、Aireon 衛星 ADS-B | 公式サイト |
| 管制・スケジュール・気象 | FAA / EUROCONTROL 等の航空管制機関、航空会社、気象機関 | 公式サイト・API ドキュメント |
