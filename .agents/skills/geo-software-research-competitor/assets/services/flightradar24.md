- 探すときの語: Flightradar24、FR24、フライトレーダー、航空機追跡、ADS-B、飛行機、フライト状況、flight tracker、リアルタイム航空機

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中のボランティアが設置した ADS-B 受信機と衛星データから航空機の現在位置をリアルタイムで地図上に表示するフライト追跡サービス |
| 提供する価値 | 民間航空機などのリアルタイム位置・高度・速度・経路・機種情報、過去の航跡再生、空港の離発着状況の可視化と API 提供 |
| 想定する利用者 | 航空ファン、旅行者や出迎え客、航空会社・空港・ロジスティクス企業・メディアなどの法人および開発者 |
| 商用か非商用か | 商用 (フリーミアムモデル。広告付き無料版、Silver/Gold/Business の有料サブスクリプション、従量制 API、法人向けデータ契約) |
| 推定の売上 | 数十億円規模 (スウェーデンの公開登記情報等で年間売上高 4 億 SEK 超が報告されている) |
| 運営 | 企業 (Flightradar24 AB、スウェーデン・ストックホルム拠点、2006 年設立) |
| 推定の運用費 | 未確認 (毎日 20 万便以上・世界最大の ADS-B 受信ネットワークからのストリーム処理とリアルタイム配信、履歴データ保持の基盤を運用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | WebGL (公式情報にて、数万機の航空機アイコンと航跡を滑らかに描画するため WebGL ベースへ移行したことを公表) |
| フレームワーク | 未確認 (トップページが Cloudflare により HTTP 403 を返したため HTML からは未確認) |
| 背景の地図とタイル | ベクトル地図タイル (公式情報にて WebGL とベクトルタイルを採用していることを公表。提供元の詳細は未確認) |
| 投稿やデータの保存先 | Flightradar24 自社基盤 (世界中のボランティア設置 1090 MHz ADS-B 受信機、MLAT、衛星 ADS-B からのデータ集約) |
| 配信 | Cloudflare (`server: cloudflare`, `cf-ray` ヘッダーを確認) |

メモ:

- 航空機所有者や政府等の要請により、一部機体 (軍用機や特定のプライベート機等) の表示制限や匿名化 (LADD 等) を行っている。
- Python / JavaScript (Node.js) 向けの公式 SDK および REST API を提供している。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 航空機位置・航跡 (ADS-B / MLAT / 衛星) | Flightradar24 ボランティア受信機ネットワークおよび衛星 ADS-B パートナー | Flightradar24 公式サイト |
| 配信基盤情報 | Cloudflare | `https://www.flightradar24.com/` の HTTP 応答ヘッダー (2026-11-16 観測) |
