# Flourish

- URL: https://flourish.studio
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Flourish、Canva、データ可視化、ノーコード、コロプレス図、ポイントマップ、スクロールテリング、埋め込み地図

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | スプレッドシートのデータを読み込むだけで、洗練されたインタラクティブな地図やグラフを作成・Web 埋め込みできるノーコード可視化プラットフォーム |
| 提供する価値 | コーディング不要でアニメーション付きのコロプレス図、ポイントマップ、アークマップ、スクロール連動ストーリーなど報道機関品質の可視化を作成し、記事や Canva 資料へ即座に埋め込める |
| 想定する利用者 | 報道機関・データジャーナリスト、企業の広報・マーケティング担当者、アナリスト、Canva を利用するデザイナー |
| 商用か非商用か | 商用フリーミアム (Free プランは公開プロジェクト・Flourish クレジット表示ありで無料。Presenter は Canva Business/Enterprise に同梱、Publisher / Enterprise は個別見積もりの有料プラン) |
| 推定の売上 | 推測: 年十数億円〜数十億円規模 (2022年の Canva による買収以降の企業・報道機関向け主力プラットフォームとしての規模だが、単体売上は非公開) |
| 運営 | 企業 (Kiln Enterprises Ltd として英国で創業、2022年に豪 Canva Pty Ltd が買収し Canva 傘下) |
| 推定の運用費 | 推測: 月数百万円以上 (世界中のメディア埋め込みトラフィックを捌く AWS S3 + CloudFront 配信およびデータ処理基盤) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | テンプレートごとに D3.js / Canvas / WebGL や Mapbox / MapLibre 等を組み合わせた独自埋め込みエンジン (`https://public.flourish.studio/resources/embed.js` を確認) |
| フレームワーク | 未確認 (独自 Web アプリケーション基盤) |
| 背景の地図とタイル | 内蔵の行政境界ベクターテンプレート (GeoJSON/TopoJSON) および Mapbox 等の背景地図タイル |
| 投稿やデータの保存先 | Flourish クラウド基盤 (AWS S3 等。Publisher 以上では HTML エクスポートによるセルフホストも可能) |
| 配信 | Amazon S3 + Amazon CloudFront (`server: AmazonS3`、`via: CloudFront` を応答ヘッダーで確認) |

メモ:

- 専用の独立したモバイルアプリは提供されていない (Web ブラウザ専用、ただし Canva アプリ・エディタ内から直接呼び出し可能)。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 可視化対象データ | ユーザーアップロード (CSV, Excel, Google Sheets, GeoJSON) | 公式サイト |
| 内蔵境界テンプレート | Natural Earth 等の公開行政境界データ | テンプレート選択画面 |
