# Gaia GPS

- URL: https://www.gaiagps.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Gaia GPS、バックカントリー、地形図、オフライン地図、4x4、オフロード、スキー、登山、Outside

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | バックカントリー登山、スキーツアー、4x4 オフロード向けの豊富な地形図レイヤーとオフラインナビゲーションを提供する地図アプリとウェブサービス |
| 提供する価値 | 地形図、土地所有境界、積雪・雪崩・山火事情報など多数の専門レイヤーを重ね合わせ、電波のない荒野でも 3D 地形やオフライン地図で正確に現在地とルートを把握できる |
| 想定する利用者 | 登山者、バックカントリースキーヤー、オーバーランダー (4x4 オフロード)、ハンター、野外調査員 |
| 商用か非商用か | 商用 (基本機能は無料。Gaia GPS Premium は年額 39.99 から 59.90 米ドル前後、Trailforks 等を含む Outside+ バンドルは年額 59.99 米ドル以上) |
| 推定の売上 | 未確認 (親会社 Outside Interactive, Inc. は非公開企業であり、Gaia GPS 単体の売上は公表されていない) |
| 運営 | 企業 (Outside Interactive, Inc.、2021 年に Gaia GPS を買収) |
| 推定の運用費 | 未確認 (多様なサードパーティ地図レイヤーのライセンス費、Mapbox SDK 利用料、オフラインタイル配信とサーバー運用費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 種類 | ウェブ、iOS と Android のアプリ (Android Auto 対応) |
| 描画 | Mapbox Maps SDK (iOS/Android/Android Auto で 3D 地形やベクトルタイル描画に利用と Mapbox 公式事例に記載。`/map/` はログインリダイレクトのため未ログインのウェブでは未確認) |
| フレームワーク | React、Ruby on Rails 関連の参照 (`rails` キーワードをトップページ HTML で確認)、Sentry |
| 背景の地図とタイル | 自社 Gaia Topo (ベクトルタイル)、USGS 地形図、USFS 地図、衛星画像、私有地境界レイヤー、積雪・山火事レイヤーなど多層提供 |
| 投稿やデータの保存先 | 未確認 (ユーザーアカウントに同期するクラウドストレージと推測されるが構成は非公開) |
| 配信 | nginx (`server: nginx` を応答ヘッダーで確認) |

メモ:

- 2021 年に Outside Interactive, Inc. (旧 Pocket Outdoor Media) に買収され、Outside+ サブスクリプションの中核アプリの 1 つとなっている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| ベースマップ・SDK | Mapbox、OpenStreetMap、USGS 等の公的機関データ | Mapbox 公式事例および Gaia GPS 公式サイト |
| 専門レイヤー (積雪・山火事・土地境界等) | 各公的機関および民間データプロバイダー | Gaia GPS 公式サイト |
