## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 北陸・東海・関西エリアを中心に展開するドラッグストア ゲンキーの店舗を県別一覧から検索できる公式店舗検索ページ |
| 提供する価値 | 石川・福井・岐阜・愛知・滋賀の県別エリアからゲンキーの店舗を探し、住所・営業時間・電話番号などの基本情報を確認できる |
| 想定する利用者 | ゲンキーを利用する一般客、北陸・東海エリアで最寄りのディスカウントドラッグストアを探している生活者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (Genky DrugStores株式会社 / ゲンキー株式会社) |
| 推定の運用費 | 推測: 月数千円〜数万円。Apache + PHP による軽量な Web サーバー運用費のみ |
