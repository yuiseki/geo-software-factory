## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のゲオ (GEO) 店舗を都道府県・市区町村や取扱商材 (ゲーム、DVD/CD、スマホ、家電、トレカ等) から探せる公式店舗検索ページ |
| 提供する価値 | 最寄り店舗の営業時間やレンタル・販売・買取・格安 SIM 即日開通などの対応サービスを事前に確認して来店できる |
| 想定する利用者 | ゲームや映像作品のレンタル・購入、スマートフォンや中古品の買取を希望する一般客 |
| 商用か非商用か | 商用 (実店舗への来店およびレンタル・物販・買取送客のために株式会社ゲオが提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。全国の実店舗でのレンタル・販売・リユース買取に貢献する集客基盤 |
| 運営 | 企業 (株式会社ゲオ / 株式会社ゲオホールディングス) |
| 推定の運用費 | 推測: 月数万円〜十数万円。Akamai による CDN/WAF 配信費および店舗検索システムの運用費がかかる (地図 API の有無は HTTP 観測で未確認) |
