## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中に隠された数百万個のコンテナ (キャッシュ) を GPS とヒントを頼りに探し出す世界最大のリアル宝探しゲームおよび位置情報地図プラットフォーム |
| 提供する価値 | 街中から自然の中まで世界各地に隠されたキャッシュの座標・難易度・発見ログを地図上で探し、実際に現地で見つけて記録する体験を提供する |
| 想定する利用者 | アウトドア愛好家、ファミリー層、旅行者、パズル・位置情報ゲーム愛好家 |
| 商用か非商用か | 商用 (基本プレイと初級キャッシュ閲覧は無料。Geocaching Premium は年額約 $30 または月額約 $6 程度で、全キャッシュ種別・オフライン地図・高度な検索フィルタを解放。公式グッズ販売もあり) |
| 推定の売上 | 推測: 年数千万米ドル規模 (従業員約 90〜130 名の非上場企業で、公式決算は非公開だが、全世界の有料会員サブスクリプションと公式ストアにより安定収益を上げている) |
| 運営 | 企業 (Groundspeak, Inc. / 通称 Geocaching HQ、米国ワシントン州シアトル。2000 年創業) |
| 推定の運用費 | 推測: 月数百万円〜数千万円規模 (シアトル本社の開発・運営体制と、世界中の数百万件のキャッシュ座標・ログ・画像データの維持。現地審査はボランティアのレビュアーが担う) |
