# GeoGuessr

- URL: https://www.geoguessr.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: GeoGuessr、ジオゲッサー、地理ゲーム、ストリートビューゲーム、場所当てゲーム、Google Street View、eスポーツ、ブラウザゲーム

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | Google ストリートビューのパノラマ画像の中にランダムで降り立ち、周囲の風景や看板の手がかりから現在地を地図上で推理して当てる地理クイズゲーム |
| 提供する価値 | 世界中の街並みや自然をバーチャルに探索しながら地理知識を競うエンターテインメント体験と、対戦・ランキング・eスポーツ大会の場を提供する |
| 想定する利用者 | 地理や旅行が好きな一般プレイヤー、配信者やコミュニティ大会の参加者、学校の地理教育での利用者 |
| 商用か非商用か | 商用 (基本は有料サブスクリプション制のフリーミアム型ビジネス。2024 年以降は無料プレイの制限を強化し、月額・年額課金が中心) |
| 推定の売上 | 2023 年度の売上は約 2 億 3,569 万スウェーデンクローナ (純利益約 9,306 万 SEK)、一部報道では年間売上約 3.1 億 SEK (約 3,000 万米ドル超) 規模。2025 年の Orkila Capital による出資時の評価額は約 42 億 SEK 規模と報じられている |
| 運営 | 企業 (GeoGuessr AB、スウェーデン・ストックホルム拠点) |
| 推定の運用費 | 未確認 (高利益率を維持しているが、Google Maps API および Street View API の大規模な従量課金と、リアルタイム対戦用サーバーの運用費が主な原価と見られる) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps JavaScript API および Google Street View Service (HTML 内で `streetview` の記述を確認。ピン留め用の地図とパノラマ表示に Google Maps を使用) |
| フレームワーク | Next.js + React (HTML 内で `/_next/static/chunks/` 群を確認) |
| 背景の地図とタイル | Google Maps および Google Street View のパノラマ画像 |
| 投稿やデータの保存先 | 自前のバックエンドサービスおよびデータベース (カスタムマップ、ユーザー成績、ランキングを管理。リアルタイム対戦には WebSockets 等を使用) |
| 配信 | Cloudflare (応答ヘッダーの `server: cloudflare`、`cf-ray` を確認) |
