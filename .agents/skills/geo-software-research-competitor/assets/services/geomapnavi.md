# 地質図Navi (GeomapNavi)

- URL: https://gbank.gsj.jp/geonavi/ (マップ本体: https://gbank.gsj.jp/geonavi/geonavi.php)
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 地質図Navi、GeomapNavi、地質図、産総研、GSJ、シームレス地質図、活断層、火山、地盤、WebGIS

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 産業技術総合研究所 (産総研) 地質調査総合センターが提供する、日本全国の地質図や活断層・火山・ハザード情報を重ねて閲覧できる公式 WebGIS |
| 提供する価値 | 20 万分の 1 日本シームレス地質図や 5 万分の 1 地質図幅、地質断面、ボーリング柱状図などを、地理院地図や衛星写真と重ねて透過比較し、凡例や解説を即座に確認できる |
| 想定する利用者 | 地質・土木・建設の技術者、防災担当者、研究者、教育関係者、地域の地盤や地形に関心のある一般利用者 |
| 商用か非商用か | 非商用 (国立研究開発法人の公的情報提供サービスとして無償公開。利用規約の範囲内で商用・研究での二次利用も可能なデータを多く含む) |
| 推定の売上 | なし (公的機関による無償サービス) |
| 運営 | 公的機関 (国立研究開発法人 産業技術総合研究所 地質調査総合センター / GSJ) |
| 推定の運用費 | 未確認 (公的予算により、産総研内のサーバーおよびタイル配信用 CDN を運用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | OpenLayers 2.14.2 (`OpenLayers-2.14.2.js`)。Google Maps JavaScript API v3 も読み込み |
| フレームワーク | Ext JS 7.0.0 GPL + jQuery 4.0.0 + PHP (`geonavi.php`) |
| 背景の地図とタイル | 産総研 GSJ 配信の各種地質図タイル (ラスタタイル、TileJSON、WMS、WMTS)、国土地理院 (地理院タイル)、Google Maps 等 |
| 投稿やデータの保存先 | なし (ユーザー投稿機能はなく、産総研 GSJ のデータベースからの配信閲覧) |
| 配信 | Apache (`server: Apache`、タイル配信には CDN も併用) |

メモ:

- URL パラメータで表示位置や表示レイヤを直接指定して共有できる。
- シームレス地質図 V2 などのタイルは外部の Leaflet や OpenLayers アプリからも参照できる API として公開されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 地質図・活断層・火山・地質調査データ | 産業技術総合研究所 地質調査総合センター (GSJ) | 地質図Navi ヘルプページおよび産総研公式案内 |
| 使用ライブラリ・サーバー情報 | `geonavi.php` の HTML ソースおよび HTTP 応答ヘッダー | 2026-11-16 の直接観測 |
