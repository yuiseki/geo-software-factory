## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | クラウドファンディングとユーザー寄付で Google Maps API 費用を賄い、無料でマルチプレイ対戦が遊べる地理クイズアプリ |
| 提供する価値 | 有料サブスクリプションが主流となったストリートビュー対戦ゲームを、コミュニティの任意支援（Pay What You Want）と広告のバランスで誰でも遊べるようにしている |
| 想定する利用者 | 友達同士や配信者コミュニティで無料の対戦型 GeoGuessr 系ゲームを遊びたいプレイヤー |
| 商用か非商用か | 商用・コミュニティ支援型（基本無料。寄付・サポーター課金・Twitch 連携および利用量に応じた広告表示で API 費用を回収） |
| 推定の売上 | 推測: 年数百万〜数千万円規模（サポーター寄付と広告収益で高額な Google Maps API 請求を相殺する収支モデル） |
| 運営 | 個人（Eduard But） |
| 推定の運用費 | 推測: 月数十万〜数百万円規模（ユーザーあたりの API コストと寄付比率をシステム側で監視するほど Google Maps / Street View API 費が大きい） |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps JavaScript API / Street View（アプリ本体のゲーム画面で Google Street View と地図を使用） |
| フレームワーク | Vue.js + Vuetify（バンドル `/assets/index-d4d2d03b.js` 内に `vue` および `vuetify` を確認） |
| 背景の地図とタイル | Google Maps Platform（Street View / 2D 地図） |
| 投稿やデータの保存先 | 自前バックエンド（マルチプレイのルーム管理、ユーザーごとの API コスト対寄付比率トラッキング等） |
| 配信 | nginx（応答ヘッダーで `server: nginx` を確認） |

メモ:

- 「Google Maps API の従量課金を個人開発でどう維持するか」という課題に対し、ユーザーごとの利用コストと寄付額の比率を可視化し、一定以上遊ぶと広告が出る仕組みで持続可能な運営を実現している。
