# 銀のさら 店舗検索

- URL: https://www.ginsara.jp/shop_search.html
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、宅配寿司、デリバリー、銀のさら、配達エリア、郵便番号検索、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 宅配寿司「銀のさら」の配達可能エリアと担当店舗を郵便番号や都道府県・市区町村・町丁目から検索できる公式店舗検索ページ |
| 提供する価値 | 配達先の住所や郵便番号を入力・選択することで、その地域に配達可能な銀のさら店舗を即座に特定し、ネット注文へ進める |
| 想定する利用者 | 銀のさらの宅配寿司を注文したい一般客 |
| 商用か非商用か | 商用 (デリバリー注文への送客導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。宅配注文を通じた店舗の売上に直結する集客チャネル |
| 運営 | 企業 (株式会社ライドオンエクスプレス / 株式会社ライドオンエクスプレスホールディングス) |
| 推定の運用費 | 推測: 月数万〜十数万円。Web サーバー (nginx) の運用費程度で、外部の有償地図 API は使用していない |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 埋め込み地図なし (住所・郵便番号からのテキスト検索型 UI) |
| フレームワーク | インライン JavaScript によるクライアントサイド描画 (外部 JS フレームワークの `<script src>` 読み込みは観測されず) |
| 背景の地図とタイル | なし (地図タイルや地図 API の読み込みなし) |
| 投稿やデータの保存先 | HTML 内のインライン `<script>` に全国の都道府県・市区町村・町丁目データ (約 2.85MB の JSON 配列文字列) を直接埋め込み |
| 配信 | nginx (`server: nginx`) |

メモ:

- 観測時点で約 3.59MB の HTML の中に、約 2.85MB の全国住所辞書 JSON がインラインスクリプトとして埋め込まれている
- 銀のさら単体で約 350〜380 店舗以上を展開 (グループ全体で約 695 店舗 / 352 拠点)

データの出どころ (2026-11-17):

- 店舗・配達エリアデータ: 株式会社ライドオンエクスプレス
