# Global Threat Map | Intelligence Platform

- URL: https://globalthreatmap.up.railway.app/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 紛争、地政学、脅威、安全保障、ニュース、リアルタイム

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界の紛争、抗議、災害、テロなどの出来事を、脅威の度合いで分けてリアルタイムに地図へ載せる状況把握のサイト |
| 提供する価値 | 世界の安全保障の出来事を 1 枚の地図で追える |
| 想定する利用者 | 安全保障や地政学の動きを追う人、リスクの担当者 |
| 商用か非商用か | 商用と見られる (企業の宣伝。「Powered by Valyu」。AI 向け検索 API の Valyu の見本で、出来事を見るにはログインが要る) |
| 推定の売上 | 地図そのものの売上は未確認。Valyu の API の利用料への集客と見られる |
| 運営 | 未確認 (企業か、Valyu の API を使った開発者。運営者の表示は見つからなかった) |
| 推定の運用費 | 推測: 月数千〜数万円。Railway のサーバー、Mapbox の地図ロード (月 5 万回まで無料)、出来事を集める検索 API の呼び出し |
