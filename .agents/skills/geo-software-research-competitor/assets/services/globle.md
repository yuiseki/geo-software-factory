# Globle

- URL: https://globle-game.com/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: Globle、Trainwreck Labs、Abe Train、Globe.gl、D3.js、国当てゲーム、3D地球儀、日替わりパズル

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 3D の地球儀上で国名を推測し、正解の国に近づくほど色が濃くなるヒートマップ表現を手がかりに正解の国を当てる日替わりゲーム |
| 提供する価値 | 2D 地図の歪みがない地球儀上で、近接度（距離）という直感的なフィードバックを通じて世界の国々の位置関係を楽しく学べる |
| 想定する利用者 | 日替わり地理パズルの愛好家、地理・世界史を学ぶ学生、教育関係者（教員向け無料アクセスあり） |
| 商用か非商用か | 商用（基本無料・NitroPay による Web 広告および月額約 $5 の「Trainwreck Club」サブスクリプションで広告非表示や対戦機能を提供） |
| 推定の売上 | 推測: 年数千万円〜億円規模（ピーク時デイリー 100 万人超を記録したほか、Trainwreck Labs 全体で 7 桁ドル規模の年間売上との報道あり） |
| 運営 | 個人スタジオ（Trainwreck Labs / Abe Train） |
| 推定の運用費 | 推測: 月数万〜数十万円程度（外部のタイル API を使わず、クライアント側の 3D 地球儀と軽量な国ポリゴンデータで完結するため極めて低コスト） |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Globe.gl（Three.js / WebGL ベース）+ D3.js（バンドル `/assets/index-C4gI8gCr.js` 内に `globe.gl` と `d3` を確認） |
| フレームワーク | Vite ビルドの SPA（`/assets/index-*.js` 構成、Google Sign-In `accounts.google.com/gsi/client` を確認） |
| 背景の地図とタイル | なし（外部地図タイルを使わず、地球儀メッシュ上に国境ポリゴンを描画） |
| 投稿やデータの保存先 | ブラウザ保存 + アカウント同期用バックエンド（Trainwreck Club / 統計同期） |
| 配信 | Cloudflare（応答ヘッダーで `server: cloudflare`、`cf-ray` を確認。Google Analytics `G-WE7RZGKZN5` を掲載） |

メモ:

- 外部の地図タイルサーバーや Google Maps API に一切依存せず、`Globe.gl` + 静的ポリゴンデータだけで構築されているため、100 万人規模のバイラル時にも地図 API 課金で破綻しない設計になっている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 国境ポリゴン・地理データ | 公開地理データ（Natural Earth / TopoJSON 系） | クライアントバンドルおよびゲーム仕様 |
