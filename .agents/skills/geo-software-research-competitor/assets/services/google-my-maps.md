# Google My Maps

- URL: https://www.google.com/maps/d/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Google My Maps、マイマップ、Google マップ、カスタム地図、ピン立て、ルート共有、KML、KMZ、スプレッドシート連携

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | Google アカウント上でピン・ルート・図形を地図に描き込み、共有や共同編集ができる無料のカスタム地図作成サービス |
| 提供する価値 | プログラミングや専門 GIS の知識なしで、スプレッドシートや KML からの一括取り込み、レイヤー分け、複数人での共同編集と限定/一般公開がすぐに行える |
| 想定する利用者 | 旅行計画を立てる一般ユーザー、店舗マップや取材マップを作るブロガー・記者、小規模な現地調査や業務マップを共有したい企業・団体 |
| 商用か非商用か | 非商用・無料提供 (Google LLC が個人・教育・ビジネス向けに完全無料で提供。有料プランや課金は無し) |
| 推定の売上 | 単体の売上はなし (Google エコシステムおよび Google マップの利用促進の一部として無料提供) |
| 運営 | 企業 (Google LLC / Alphabet Inc. 傘下、米国) |
| 推定の運用費 | 推測: 月数百万円以上 (Google マップの基盤タイル配信および Google ドライブと連携した世界規模のユーザーデータ保存を維持) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (非ログイン時の HTTP 観測では Google アカウントのログイン画面 `accounts.google.com` へリダイレクトされたため直接のスクリプトは未観測。一般的には Google Maps 独自の地図エンジンで描画) |
| フレームワーク | 未確認 (同上の理由で未観測) |
| 背景の地図とタイル | Google Maps 自身の地図・衛星・地形タイル |
| 投稿やデータの保存先 | Google ドライブ / Google クラウドインフラ (作成した地図は Google ドライブのファイルとして保存・権限管理される) |
| 配信 | Google フロントエンド (`server: ESF` を応答ヘッダーで確認) |

メモ:

- 専用の独立したモバイルアプリ (Android 版) は過去に提供されていたが終了済み。現在は通常の「Google マップ」アプリ (iOS / Android) の「保存済み」→「マイマップ」から閲覧できるほか、モバイルブラウザで閲覧・簡易編集が可能。
- KML / KMZ / CSV / XLSX / Google スプレッドシートのインポートおよび KML / KMZ でのエクスポートに対応している。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 背景地図・衛星画像 | Google Maps 基盤データ | Google マップ利用規約 |
| 地図上のカスタム地物 | ユーザーの作成・インポートデータ | サービス仕様 |
