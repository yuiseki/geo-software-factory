# 地理院地図 / GSI Maps

- URL: https://maps.gsi.go.jp/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 地理院地図、GSI Maps、国土地理院、地理院タイル、地形図、空中写真、標高、3D 地図、日本

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 国土地理院が整備する地形図、空中写真、標高、地形分類、災害情報などの日本の国土情報を閲覧・計測できる公式ウェブ地図 |
| 提供する価値 | 最新の地形図から過去の空中写真、治水地形分類図、災害時の緊急撮影画像まで、公的機関による高精度な地理空間情報を登録不要・無償で重ね合わせて確認・3D 表示・作図できる |
| 想定する利用者 | 防災・自治体・建設・不動産・教育関係者、登山者、地図・地理愛好家、開発者 |
| 商用か非商用か | 非商用 (国の公的サービスとして完全無料で提供。配信される地理院タイルは国土地理院コンテンツ利用規約のもと出典明示で商用利用も可能) |
| 推定の売上 | なし (公的機関による無償提供) |
| 運営 | 国の機関 (国土交通省 国土地理院) |
| 推定の運用費 | 未確認 (国の予算により AWS CloudFront / S3 等で全国向け地理院タイルとウェブ地図を運用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet (`js.lib/leaflet-1.2.0/leaflet-src.js` および各種プラグインを確認) |
| フレームワーク | jQuery (`jquery-3.6.3.min.js`、`jquery-ui.min.js` を確認) |
| 背景の地図とタイル | 地理院タイル (国土地理院が配信する標準地図、淡色地図、写真、標高タイル等の XYZ タイル) |
| 投稿やデータの保存先 | サーバー側への永続保存機能は未確認 (作図・計測データはブラウザ上での保持およびローカルファイル入出力が中心) |
| 配信 | Amazon S3 + Amazon CloudFront (`server: AmazonS3`、`via: ...cloudfront.net` ヘッダーを確認) |

メモ:

- 地図データの配信基盤である「地理院タイル」は外部の GIS ソフトや他社ウェブサービスからも広く参照されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 地形図・空中写真・標高・土地条件図等 | 国土地理院 (基本測量成果等) | 公式サイトおよび国土地理院コンテンツ利用規約 |
| 一部の災害・自治体関連情報 | 各行政機関・関係機関 | 公式サイトおよびレイヤーごとの出典表示 |
