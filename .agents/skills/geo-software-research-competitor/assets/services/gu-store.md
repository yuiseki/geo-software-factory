## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の GU (ジーユー) 店舗を、現在地・エリア・店舗規模・取り扱い条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 最寄り店舗や大型店・超大型店の位置、営業時間、キッズ・ベビー取り扱い有無、店舗受取り対応などを地図上で素早く確認できる |
| 想定する利用者 | GU の店舗を探している一般客、特定商品の店舗在庫確認やオンライン注文の店舗受取り先を探している利用者 |
| 商用か非商用か | 商用 (GU 実店舗への来店送客およびオンラインストアの店舗受取り導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびオムニチャネル受取り送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社ジーユー) |
| 推定の運用費 | 推測: 月数十万円。Google Maps Platform の利用料に加え、専用サブドメイン (`map.gu-global.com`) の Web 配信・ボット対策基盤の運用費がかかる |
