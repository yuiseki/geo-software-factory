## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のはま寿司店舗をエリア・住所・条件から検索し、店舗情報や予約・テイクアウト導線を確認できる公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の所在地、営業時間、駐車場の有無などを確認でき、来店予約（はまナビ）や持ち帰り注文へスムーズに進める |
| 想定する利用者 | はま寿司への来店を検討している一般客、外出先で近くの回転寿司店を探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客、順番待ち予約、テイクアウト注文への導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびテイクアウト注文に貢献する集客基盤 |
| 運営 | 企業 (株式会社はま寿司) |
| 推定の運用費 | 推測: 月数万〜数十万円。ゼンショーグループ共通とみられる店舗検索基盤の運用・配信費と地図 API 利用料がかかる |
