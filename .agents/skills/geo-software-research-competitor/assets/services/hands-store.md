# 東急ハンズ (現ハンズ) 店舗一覧

- URL: https://info.hands.net/list/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、東急ハンズ、ハンズ、HANDS、生活雑貨、店舗一覧、アクセス、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のハンズ (旧・東急ハンズ) およびハンズ ビー等の店舗を一覧から探し、店舗ごとの営業時間やアクセスを確認できる公式店舗一覧ページ |
| 提供する価値 | 目的の地域や業態の店舗を素早く見つけ、各店舗サイトのフロア案内やアクセス情報、ネットストア連携へ移動できる |
| 想定する利用者 | 生活雑貨、文具、DIY 用品などの購入でハンズの実店舗を訪れたい一般客 |
| 商用か非商用か | 商用 (実店舗への来店送客および公式ネットストアとの連携のために株式会社ハンズが提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびネット取り置き・店舗受取に貢献する集客基盤 |
| 運営 | 企業 (株式会社ハンズ) |
| 推定の運用費 | 推測: 月数万円〜十数万円。Amazon CloudFront による配信費および店舗ごとの Google Maps 利用に伴う地図 API 課金がかかる |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 一覧ページ (`/list/`) は HTML 一覧、個別店舗ページではアクセス欄に地図用クラス (`m-m-shop-access__map--google-map`) と iframe 枠を確認 (2026-11-17 の一次 HTTP 取得で参照先 `/shinjuku/info/map.html` は 404 応答) |
| フレームワーク | 独自フロントエンド JS (`common.min.js`、`zs-module.js`) |
| 背景の地図とタイル | Google Maps (参考の事前調査および個別店舗ページのクラス名 `m-m-shop-access__map--google-map` より。一覧ページ自体は埋め込みなし) |
| 投稿やデータの保存先 | 自社管理の店舗情報基盤 (API 詳細は未確認) |
| 配信 | Amazon CloudFront + Apache (`server: Apache`、`via: ...cloudfront.net (CloudFront)`) |
