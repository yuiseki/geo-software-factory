## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のハードオフグループ各店 (ハードオフ・オフハウス・ホビーオフ等) を検索し、店舗情報や外部地図リンクを確認できる公式店舗検索ページ |
| 提供する価値 | 最寄り店舗の住所、営業時間、取扱業態を確認でき、Google マップの外部リンクから経路案内へすぐ移動できる |
| 想定する利用者 | 楽器、家電、オーディオ、家具、ホビー用品などの中古品購入や店頭買取を希望する一般客 |
| 商用か非商用か | 商用 (実店舗への来店および買取送客のために株式会社ハードオフコーポレーションが提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の買取・販売売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ハードオフコーポレーション) |
| 推定の運用費 | 推測: 月数万円。埋め込み地図 API を使わず Google マップへの外部リンクで構成されているため地図 API 課金は発生せず、Amazon CloudFront による Web 配信費のみ |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 埋め込み地図なし (店舗詳細ページから `https://www.google.com/maps?q=<緯度>,<経度>` への外部リンクで案内する構成) |
| フレームワーク | jQuery (`jquery-3.4.1.min.js`)、独自スクリプト (`/assets/js/shop-0e6e32389f.js`) |
| 背景の地図とタイル | 埋め込み地図なし (外部リンク先として Google マップを利用) |
| 投稿やデータの保存先 | 自社管理の店舗情報基盤 (API 詳細は未確認) |
| 配信 | Amazon CloudFront + nginx (`server: nginx`、`via: ...cloudfront.net (CloudFront)`) |
