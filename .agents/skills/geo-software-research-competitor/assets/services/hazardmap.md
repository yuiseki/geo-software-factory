# 重ねるハザードマップ

- URL: https://disaportal.gsi.go.jp/maps/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 重ねるハザードマップ、ハザードマップポータルサイト、国土地理院、国土交通省、洪水、土砂災害、津波、防災

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本全国の洪水・土砂災害・津波・高潮などの災害リスク情報を一つのウェブ地図上に重ねて閲覧できる国の防災マップ |
| 提供する価値 | 市町村の境界を越えて、指定した場所の複合的な災害リスクや地形・過去の災害伝承碑などの防災情報を、地理院地図上で直感的に重ね合わせて確認できる |
| 想定する利用者 | 住民、防災担当者、不動産・保険関係者、避難計画を立てたい一般利用者 |
| 商用か非商用か | 非商用 (国の防災ポータルとして登録不要・完全無料で提供) |
| 推定の売上 | なし (公的機関による無償提供) |
| 運営 | 国の機関 (国土交通省・国土地理院) |
| 推定の運用費 | 未確認 (国の予算により全国向けハザードタイルと配信 CDN を運用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet (`leaflet-1.9.3/leaflet-src.js` および `Control.MiniMap-gsi.js` 等のプラグインを確認) |
| フレームワーク | jQuery (`jquery-3.6.3.min.js`) + Bootstrap (`bootstrap-3.3.5`) |
| 背景の地図とタイル | 地理院タイル (標準地図、淡色地図等) および各種災害リスク情報の重ね合わせタイル |
| 投稿やデータの保存先 | 投稿機能なし (閲覧中心) |
| 配信 | Varnish / Fastly (`via: 1.1 varnish`、`x-served-by: cache-sin-...` ヘッダーを確認) |

メモ:

- 地理院地図をベースに開発されており、`css/gsimaps.css` や `Control.MiniMap-gsi.js` など共通の資産が使われている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 洪水・土砂災害・津波・高潮等のハザードデータ | 国土交通省、都道府県等の河川管理者および行政機関 | ハザードマップポータルサイトおよび各レイヤー解説 |
| 背景地図データ | 国土地理院 (地理院タイル) | 公式サイトおよび地図の帰属表示 |
