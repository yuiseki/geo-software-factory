## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のハニーズ各店の所在を都道府県や条件から検索し、店舗情報や営業時間を確認できる公式店舗検索ページ |
| 提供する価値 | 最寄りのハニーズ店舗の住所や営業時間、取扱ブランドを確認でき、実店舗への来店やオンラインストアとの併用の導線になる |
| 想定する利用者 | レディースファッションや服飾雑貨の購入で実店舗での試着や買い物を希望する一般客 |
| 商用か非商用か | 商用 (実店舗への来店送客のために株式会社ハニーズが提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。全国の実店舗での衣料品・雑貨販売に貢献する集客基盤 |
| 運営 | 企業 (株式会社ハニーズ / 株式会社ハニーズホールディングス) |
| 推定の運用費 | 推測: 月数万円。埋め込み地図 API を使わず自社 CMS 上の検索ページとして構成されているため、地図 API 課金は発生せず Web サーバーの運用費のみ |
