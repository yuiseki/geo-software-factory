## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 喫茶店チェーン「星乃珈琲店」の全国の店舗を都道府県別に一覧表示し、各店舗の住所・営業時間・地図リンクを確認できる公式店舗情報ページ |
| 提供する価値 | 都道府県ごとの店舗一覧から最寄り店舗の営業時間や電話番号、アクセス情報を確認でき、Google マップのリンクから場所を開ける |
| 想定する利用者 | 星乃珈琲店への来店を予定している一般客、近隣の店舗や営業時間を調べたい利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗情報ページ単体の売上は 0 円。実店舗の飲食売上に貢献する案内ページ |
| 運営 | 企業 (日本レストランシステム株式会社) |
| 推定の運用費 | 推測: 月数万円以下。静的 HTML と Apache サーバーの運用費程度で、有償の地図 API 課金は発生していない |
