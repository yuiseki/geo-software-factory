## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中のホテルやバケーションレンタルを価格・評価・立地で比較し、地図上の料金ピンから直感的に宿泊先を予約できる宿泊特化型予約サイト |
| 提供する価値 | 目的地のエリアやランドマーク周辺の宿泊施設を地図上で比較し、会員限定価格や複数ホテルの横並び比較、One Key リワードを活用して最適な宿を予約できる |
| 想定する利用者 | 出張や観光で宿泊先を探す国内外の旅行者 |
| 商用か非商用か | 商用 (旅行者の利用は無料。宿泊予約の手数料およびパートナー広告収入で運営) |
| 推定の売上 | 親会社 Expedia Group 全体の 2024 年通期売上は 136.9 億ドル (Hotels.com 単体の売上は非開示) |
| 運営 | 企業 (Expedia Group, Inc.、米国) |
| 推定の運用費 | 推測: 月数億円規模 (Expedia Group の共通基盤上で世界中の宿泊在庫・料金検索と地図表示を処理) |
