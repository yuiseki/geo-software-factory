| 項目 | 内容 |
|---|---|
| 一行で | クーポン・コース情報・即時ネット予約に強みを持つ、リクルート運営の大手飲食店検索・予約ポータルサイト |

| 想定する利用者 | 宴会・会食・日常の外食でクーポンやネット予約を活用したい一般消費者、および集客・予約管理を行う飲食店 |
| 商用か非商用か | 商用 (利用者は無料。飲食店からの掲載料、ネット予約送客手数料、広告収入で運営) |
| 推定の売上 | 未確認 (親会社リクルートホールディングスの単体開示なし) |
| 運営 | 企業 (株式会社リクルート) |
| 推定の運用費 | 未確認 (全国の店舗・予約管理システム、Google Maps API 利用料、サーバー基盤の運用) |
