## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 2005年4月に公開され、Craigslist の賃貸・売買物件情報を Google Maps 上に重ねて表示した、インターネット史上初の本格的な Web 地図マッシュアップ（現在は終了） |
| 提供する価値 | 当時テキスト一覧しかなかった Craigslist の物件情報と Google Maps のインタラクティブな地図を結びつけ、街の地図を見ながら価格・写真付きで物件を探せる体験を初めて実現した |
| 想定する利用者 | 米国等で賃貸・住宅物件を探していた一般ユーザー（および初期の Web マッシュアップ技術に注目した開発者） |
| 商用か非商用か | 非商用/個人プロジェクト (Paul Rademacher が個人で開発・公開。後に Google による公式 Google Maps API 公開のきっかけとなった) |
| 推定の売上 | なし (個人開発プロジェクト。現在サービス終了) |
| 運営 | 個人 (Paul Rademacher、2005年4月公開。現在終了) |
| 推定の運用費 | 0円 (現在は終了・停止中。稼働当時は個人サーバーでのスクレイピングおよび HTML/JS 配信程度) |

メモ:

- **現在はサービス終了している。** 2026-11-16 時点のアクセスでも接続拒否 (`WinError 10061`) となり閲覧できない。
- 2005年4月に Paul Rademacher が公開した「世界初の Web マッシュアップ」として知られ、Google Maps API 誕生（2005年6月）の直接の契機となり、本人も後に Google に採用された。
- Craigslist 自身が後に標準で地図表示機能を備えたことや、スクレイピング規制の強化、開発者の別プロジェクトへの移行に伴い役目を終えて終了した。
- iOS / Android の公式アプリは提供されていない。
