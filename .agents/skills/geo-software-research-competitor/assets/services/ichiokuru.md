## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地図タイルを一切読み込まずにスマートフォンの現在地座標を取得し、遭難時などに SMS・メール・LINE 等で共有できる超軽量 Web アプリ |
| 提供する価値 | 山間部や災害時など電波が極めて弱い環境でも数秒で開き、緯度経度・精度・標高などを取得して家族や救助機関へ確実に伝えられる |
| 想定する利用者 | 登山者、アウトドア利用者、災害時の避難者、山岳遭難の当事者や救助関係者 |
| 商用か非商用か | 非商用（完全無料・広告なし・アクセス解析なし。CC BY 4.0 ライセンスで公開され、複製や自前サーバーへの設置も自由） |
| 推定の売上 | 0 円（非営利の社会貢献・防災ツールとして公開） |
| 運営 | 個人（松本圭司。登山用 GPS アプリ「ジオグラフィカ」の開発者） |
| 推定の運用費 | 推測: 月数百円〜数千円程度（HTML と `gps.js` 等の静的ファイルのみで構成され、地図タイル配信やバックエンド DB を持たない） |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 地図描画なし（HTML/テキストのみで座標・精度・Google マップ等の確認用リンクを表示） |
| フレームワーク | 素の HTML + JavaScript（応答 HTML 内に外部フレームワークはなく、`gps.js` のみを読み込む最小構成を確認） |
| 背景の地図とタイル | なし（通信量削減とオフライン・弱電界での確実な起動を優先し、地図タイルを使用しない設計） |
| 投稿やデータの保存先 | なし（サーバーへの位置情報送信・保存やアクセス解析は行わず、ブラウザの Geolocation API で取得した座標を端末上で整形する） |
| 配信 | nginx（応答ヘッダーで `server: nginx` を確認） |

メモ:

- 「地図サービス＝地図タイルを表示する」という前提を外した境界例。緊急時の位置共有という価値の芯に対し、地図を載せないことが最大の強みになっている。
- 日本語のほか英語・韓国語・中国語・タイ語・ドイツ語・スペイン語・フランス語など多言語に対応している。
