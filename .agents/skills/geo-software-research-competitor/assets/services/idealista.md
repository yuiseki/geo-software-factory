## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | スペイン・イタリア・ポルトガルの売買・賃貸物件を網羅し、地図上の手描き範囲検索や不動産評価マップを提供する南欧最大の不動産ポータル |
| 提供する価値 | 視認性の高い独自のグレースケール地図上で指で描いたエリアや複数地域を同時に絞り込め、公的地籍データと連携した建物単位の推定価格情報 (idealista/maps) も参照できる |
| 想定する利用者 | 南欧で住まいや投資物件を探す一般消費者、および物件を掲載する不動産会社・個人売主・貸主 |
| 商用か非商用か | 商用 (閲覧は無料。不動産会社向けの B2B サブスクリプション掲載料、個人売主の有料オプション、住宅ローン仲介、代理店向け CRM・データ販売で収益化) |
| 推定の売上 | 約3億4,600万ユーロ (年間売上高報道値、EBITDA 約1億6,000万ユーロ) |
| 運営 | 企業 (idealista S.A.U.、スペイン・マドリード、Cinven が過半数保有・EQT が少数持分) |
| 推定の運用費 | 推測: 年数十億円規模。南欧3カ国の物件データベース・画像配信、地図・地籍データ処理基盤、DataDome WAF 等の運用 |
