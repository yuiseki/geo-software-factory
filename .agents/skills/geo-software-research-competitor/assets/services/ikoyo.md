# いこーよ

- URL: https://iko-yo.net/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 子連れ、お出かけ、遊び場、施設検索、家族、レジャー、口コミ、いこーよ、iko-yo

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の子ども向けお出かけスポットやイベント、口コミ、クーポンを検索できるファミリー向け情報サイト |
| 提供する価値 | 年齢別やエリア別で子連れに適した遊び場や施設を探し、周辺の天気予報や地図、割引クーポンをまとめて確認できる |
| 想定する利用者 | 0歳から小学生程度の子どもを持つ保護者・ファミリー層、お出かけ施設の集客担当者 |
| 商用か非商用か | 商用 (広告掲載、ディスプレイ広告、タイアップ記事、チケット販売・送客、施設向け集客支援を展開) |
| 推定の売上 | 推測: 年間数億円規模 (運営会社のアクトインディ株式会社は社員数約80〜90名規模で、過去に年商2.6億円超の実績が開示されている) |
| 運営 | アクトインディ株式会社 (actindi Inc.、2003年設立) |
| 推定の運用費 | 推測: 月数十万円から百万円以上 (CloudFront からの大量画像・アセット配信、AWS 上の Rails サーバー群、天気情報や地図埋め込み運用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 施設の天気・地図ページ (`/facilities/4001/weathers`) に `iframe` で Google Maps Embed API (`https://www.google.com/maps/embed/v1/place?key=...&q=36.25269882,136.14706924&zoom=15`) を埋め込み表示している。施設詳細ページからは Google マップ (`maps.google.com/maps?q=...`) への外部リンクも提供する。 |
| フレームワーク | Ruby on Rails (レスポンスヘッダーの `x-request-id`、`x-runtime`、`csrf-param: authenticity_token`、`/packs/` による Webpacker 構成から確認)。 |
| 背景の地図とタイル | Google マップ (Google Maps Embed API の `iframe` 内で読み込み)。 |
| 投稿やデータの保存先 | 自社バックエンド (Rails アプリケーションとデータベース。施設情報、口コミ、お気に入り保存、改善提案の受付を管理)。 |
| 配信 | nginx (`server: nginx/1.30.4`)、AWS ALB (`AWSALBTG` クッキー)、静的アセットや施設写真は Amazon CloudFront (`d2goguvysdoarq.cloudfront.net` 等) から配信。 |

データの出どころ (2026-11-16):

- 施設情報、料金、アクセス、口コミ: いこーよ (アクトインディ株式会社) の掲載情報および施設運営者・利用者からの投稿。
- 埋め込み地図の背景データ: Google マップ (Google Maps Embed API `iframe` による表示)。天気予報の提供元は `otenki.com` の記載あり。
