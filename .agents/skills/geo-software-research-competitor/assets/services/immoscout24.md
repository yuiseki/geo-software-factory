# ImmoScout24

- URL: https://www.immobilienscout24.de
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ImmoScout24、Scout24、ドイツ不動産、賃貸、売買、地図検索、ポリゴン検索、DAX、欧州不動産

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ドイツの賃貸・売買物件を網羅し、地図上のポリゴン範囲検索や相場・街並みデータと合わせて探せるドイツ最大の不動産プラットフォーム |
| 提供する価値 | 地図上で希望の街区を囲んで物件を探せるほか、物件周辺の相場データ・信用情報 (SCHUFA) 連携・入居者向けプレミアム会員特典を組み合わせ、競争の激しいドイツ住宅市場で効率的に探せる |
| 想定する利用者 | ドイツで賃貸や購入物件を探す一般消費者、個人オーナー、およびドイツの不動産仲介会社・デベロッパー |
| 商用か非商用か | 商用 (基本検索は無料。不動産会社向けの B2B サブスクリプション・CRM SaaS、入居・購入希望者向け有料会員 TenantPlus / BuyerPlus、個人掲載課金で運営) |
| 推定の売上 | 約5億6,630万ユーロ (2024年実績、Scout24 SE 連結) |
| 運営 | 企業 (Scout24 SE / Immobilien Scout GmbH、ドイツ・ベルリン/ミュンヘン、DAX 上場) |
| 推定の運用費 | 推測: 年百億円規模。ドイツ全土の物件・査定データベース、SaaS 基盤、CloudFront / AWS WAF の運用 |
