# IQAir Earth

- URL: https://www.iqair.com/earth
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: IQAir、AirVisual、大気汚染、PM2.5、AQI、空気質マップ、環境モニタリング、空気清浄機

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界 10,000 以上の都市の大気汚染 (AQI・PM2.5) と風の流れをリアルタイムで可視化する地球規模の空気質マップ |
| 提供する価値 | 政府の観測局と市民・企業設置の低コストセンサーを統合し、現在および予測の大気汚染レベルと健康への影響を視覚的に把握できる |
| 想定する利用者 | 喘息や呼吸器疾患のある人、都市生活者、環境研究者、学校・自治体、大気質データを利用するアプリ開発者 |
| 商用か非商用か | 商用 (Web マップおよびアプリ AirVisual は無料。AirVisual API は非商用・コミュニティ枠が無料、Startup / Enterprise 向け有料プランあり。本業の空気清浄機・測定器販売と連動) |
| 推定の売上 | 推測: 年 4,000 万〜1 億米ドル以上 (企業情報データベースによる親会社 IQAir 全体の推計。非上場のため非公開で、主軸は空気清浄機・モニター等のハードウェア販売) |
| 運営 | 企業 (IQAir AG、スイス。1963 年創業の同族経営企業) |
| 推定の運用費 | 推測: 月数百万円規模。世界中の数万地点の観測データと気象データのリアルタイム集約、タイル・API 配信を維持している |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (2026-11-16 の HTTP 観測で `429` Vercel Security Checkpoint となり HTML/JS を取得できず。モバイル・Web の地図描画には Mapbox 等が利用される例がある) |
| フレームワーク | 未確認 (Vercel 上でホスティングされていることを応答ヘッダー `server: Vercel` で確認) |
| 背景の地図とタイル | 未確認 |
| 投稿やデータの保存先 | 未確認 (自社の AirVisual センサー網および公的機関データの集約基盤) |
| 配信 | Vercel (`server: Vercel`、`x-vercel-id: hnd1::...` を応答ヘッダーで確認。自動アクセスに対して 429 Security Checkpoint を返却) |

メモ:

- 2026-11-16 の一次 HTTP 観測では Vercel Security Checkpoint により HTTP 429 が返され、内部スクリプトの観測ができなかった。
- ウェブ版のほか iOS / Android アプリ「IQAir AirVisual」を提供している。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 大気質データ (AQI / PM2.5) | 世界各国の公的環境観測局、および IQAir AirVisual センサーネットワーク | 公式サイトおよび API 案内 |
| 気象・風データ | 各国気象機関・数値予報モデル | 公式サイト |
