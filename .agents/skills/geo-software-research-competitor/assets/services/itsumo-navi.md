## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ゼンリンの詳細な日本全国地図と住宅地図データをベースに、住所・施設検索や多様な移動手段のルート案内を提供する地図ポータル・アプリ |
| 提供する価値 | 建物名・テナント名・建物の出入口情報や、戸建ての表札・番地レベルまで分かるゼンリン住宅地図を、PC やスマホで手軽に確認し移動に活かせる |
| 想定する利用者 | 日本国内で詳細な住所・建物・出入口を調べたい一般の人、配達・営業・訪問介護・トラック運転手などの業務利用者 |
| 商用か非商用か | 商用 (ウェブの基本閲覧は無料。アプリ版「ゼンリン地図ナビ」等はスタンダード月額 440 円、住宅地図プラン月額 1,200 円、フル機能月額 1,600 円の有料プランや法人向け API を提供) |
| 推定の売上 | 運営会社の株式会社ゼンリンデータコム全体の売上高は 173 億 1,100 万円 (2026 年 3 月期決算。法人向け・カーナビ事業等を含む全社数値) |
| 運営 | 企業 (株式会社ゼンリンデータコム、株式会社ゼンリンの完全子会社) |
| 推定の運用費 | 未確認 (ゼンリン地図データの維持・ライセンス、ルート計算・住所検索サーバー、CloudFront と AWS WAF による配信基盤の運用費がかかる) |
