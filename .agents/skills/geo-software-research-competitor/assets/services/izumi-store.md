## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 中国・四国・九州地方を中心に展開するイズミ・ゆめタウン・ゆめマート等の店舗を県別一覧から探し、店舗ごとの地図やチラシ・営業時間を確認できる公式店舗検索サイト |
| 提供する価値 | 県別の店舗一覧から目的の店舗を選び、個別店舗ページで Google マップのアクセスマップやトクバイ連携のチラシ・店舗情報を確認できる |
| 想定する利用者 | イズミ・ゆめタウン・ゆめマート等を利用する一般客、西日本エリアで最寄りのスーパーやショッピングモールを探している生活者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社イズミ) |
| 推定の運用費 | 推測: 月数万円。Apache + Drupal の運用費のみで、個別ページの地図は Google マップ iframe 埋め込みのため API 従量課金は発生していない |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | トップ一覧 (`/tenpo`) は地図埋め込みなし。個別店舗ページ (`/tenpo/hiroshima` 等) は Google マップ iframe 埋め込み (`https://www.google.com/maps/embed?pb=...`) |
| フレームワーク | Drupal (`/core/assets/vendor/jquery/jquery.min.js?v=4.0.0`、`/sites/default/files/...`、`/themes/custom/izumi/...`) + Amazon CloudWatch RUM + GTM `GTM-K5682G` |
| 背景の地図とタイル | Google マップ (個別店舗ページの iframe 埋め込み) |
| 投稿やデータの保存先 | Drupal 側で店舗ページ (`/tenpo/<店舗名>`) を生成。チラシはトクバイウィジェット (`widgets.tokubai.co.jp`) を iframe 埋め込み |
| 配信 | Apache (`server: Apache`) |

メモ:

- 店舗検索トップ (`/tenpo`) は都道府県別のアンカーリンクによる店舗一覧ページで、トップ自体には地図が埋め込まれていない
- 個別店舗ページ (`/tenpo/hiroshima`) を観測したところ、Google マップの埋め込み iframe (`www.google.com/maps/embed?pb=...`) とトクバイのチラシウィジェットが埋め込まれていた
