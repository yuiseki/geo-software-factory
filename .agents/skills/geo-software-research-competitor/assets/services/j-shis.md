# J-SHIS 地震ハザードステーション

- URL: https://www.j-shis.bosai.go.jp
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: J-SHIS、地震ハザードステーション、防災科学技術研究所、NIED、地震動予測地図、表層地盤、活断層、OpenLayers、WMS

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本全国の確率論的地震動予測地図や表層地盤の揺れやすさ、活断層分布などを 250m メッシュ単位で閲覧・取得できる地震ハザード情報基盤 |
| 提供する価値 | 今後30年以内に震度6弱以上の揺れに見舞われる確率や地盤増幅率などを、地図表示と Web API / WMS を通じて誰でも確認・活用できる |
| 想定する利用者 | 自治体・企業の防災担当者、建築・不動産関係者、地震・防災研究者、一般の住宅購入検討者 |
| 商用か非商用か | 非商用 (国立研究開発法人防災科学技術研究所が無料で公開。Web API や WMS も公開) |
| 推定の売上 | なし (国の公的研究機関による無償の防災情報基盤) |
| 運営 | 公的研究機関 (国立研究開発法人防災科学技術研究所 / NIED) |
| 推定の運用費 | 推測: 年間数千万円規模 (全国 250m メッシュのハザードデータ・地図タイル・Web API サーバーの維持管理費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | OpenLayers 3 + Google Maps 連携 (`https://www.j-shis.bosai.go.jp/map/` で `ol3gm.js`、`ol3-layerswitcher.js`、`GoogleKey.js` を確認。グラフ描画に `dygraph`、`d3.v3` を併用) |
| フレームワーク | Ext JS 2 (`ext-all.js`) + Prototype.js (`prototype-1.7.3c.js`) (ポータルサイト側は WordPress) |
| 背景の地図とタイル | Google Maps、国土地理院 (地理院タイル)、および J-SHIS 独自の地震ハザード・地盤タイル |
| 投稿やデータの保存先 | 防災科学技術研究所の独自サーバー (Web API / WMS 配信基盤) |
| 配信 | Apache (`server: Apache` を応答ヘッダーで確認) |

メモ:

- ウェブ版のほか、iOS / Android 向けの公式アプリ「J-SHIS」も提供されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 全国地震動予測地図・表層地盤・活断層データ | 地震調査研究推進本部、防災科学技術研究所 | https://www.j-shis.bosai.go.jp/ |
| 背景地図 | 国土地理院 (地理院タイル)、Google Maps | 地図ビューア内のレイヤー切替およびスクリプト構成 |
