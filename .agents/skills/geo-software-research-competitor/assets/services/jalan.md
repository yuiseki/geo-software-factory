## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 国内のホテルや旅館の宿泊予約、日帰りプラン、観光スポット情報、レンタカー予約などを提供する大手旅行予約サイト |
| 提供する価値 | 全国の宿泊施設をエリアや地図、口コミ評価、料金、プラン条件で比較し、リクルートIDやポイント連携を含めて予約できる |
| 想定する利用者 | 国内旅行や出張で宿泊先や観光スポットを探す個人および法人利用者 |
| 商用か非商用か | 商用 (宿泊予約等の送客手数料、広告掲載、各種提携サービスによる収益) |
| 推定の売上 | 未確認 (単体売上は非公開。国内宿泊予約の取扱高は 2025 年度に約 1 兆 5,000 億円と発表されている) |
| 運営 | 企業 (株式会社リクルート) |
| 推定の運用費 | 未確認 (大規模宿泊予約トランザクション基盤、地図・空間検索機能、クチコミや施設情報の保守運用費) |
