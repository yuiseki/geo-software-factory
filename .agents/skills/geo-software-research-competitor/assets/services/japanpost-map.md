## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の郵便局、ゆうちょ銀行 ATM、郵便ポストなどの所在地や営業時間、取扱サービスを検索できる公式拠点マップ |
| 提供する価値 | 郵便や貯金の手続き、荷物発送の条件 (ゆうゆう窓口や駐車場の有無など) に合わせて最寄りの郵便局や ATM を探せる |
| 想定する利用者 | 郵便局やゆうちょ銀行 ATM、ポストを利用したい一般消費者および法人利用者 |
| 商用か非商用か | 商用・インフラサービス (日本郵政グループの窓口案内として無料提供) |
| 推定の売上 | 該当なし (検索サイト単体の課金はなく、郵便・銀行・保険窓口への送客と利便性提供が目的) |
| 運営 | 日本郵便株式会社 (地図システムの基盤には株式会社ゼンリンデータコム等の技術が活用されているとの公開情報あり) |
| 推定の運用費 | 未確認 (全国拠点の店舗検索 ASP/API 利用料および CloudFront 配信費を含むが契約額は非公開) |
