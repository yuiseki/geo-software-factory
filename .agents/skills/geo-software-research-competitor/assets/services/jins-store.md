## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の JINS 店舗をエリアや条件から検索し、営業時間や取扱サービス・アクセスを確認できる公式店舗検索ページ |
| 提供する価値 | 最寄りの JINS 店舗の場所や営業時間、視力測定・受取対応などの条件を調べ、店舗受取や来店計画を立てられる |
| 想定する利用者 | メガネやサングラスの購入・調整・受取のために JINS 実店舗への来店を予定する一般客 |
| 商用か非商用か | 商用 (実店舗への来店送客および公式オンラインショップとのオムニチャネル連携として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗でのメガネ販売およびオンラインショップの店舗受取送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社ジンズ / 株式会社ジンズホールディングス) |
| 推定の運用費 | 推測: 月数万〜数十万円。Akamai による配信・WAF 運用費、店舗検索システム (ONE COMPATH 連携等) および Google Maps 関連の利用費がかかる |
