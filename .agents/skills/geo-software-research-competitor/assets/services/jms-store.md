# ジェームス (jms) 店舗検索

- URL: https://www.jms-car.com/shop/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、カー用品、ジェームス、jms、トヨタモビリティパーツ、ピット作業、車検、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のカー用品店ジェームス (jms) の店舗をエリア一覧や現在地から探し、店舗詳細ページで地図や営業時間を確認できる公式店舗検索サイト |
| 提供する価値 | 近隣のジェームス店舗の位置・営業時間・電話番号・ピット作業メニューを素早く確認し、来店や作業予約につなげられる |
| 想定する利用者 | カー用品の購入やオイル・タイヤ交換、メンテナンスを希望するドライバー・自動車保有者 |
| 商用か非商用か | 商用 (実店舗への来店およびピット作業への送客基盤として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。全国約 88 店舗のカー用品販売およびピットサービスの売上に貢献 |
| 運営 | 企業 (トヨタモビリティパーツ株式会社) |
| 推定の運用費 | 推測: 月数万円〜十数万円。Web サーバーの運用費が中心で、地図は Google Maps の埋め込み iframe のため地図 API 課金が抑えられる構成 |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps 埋め込み (`https://www.google.com/maps/embed?pb=...` の iframe を各店舗詳細ページ `/shop/<area>/<store>/` に表示) |
| フレームワーク | 静的 HTML + JavaScript (`/assets/js/script.js`、現在地検索ページ `/shop/location.html` を併用) |
| 背景の地図とタイル | Google マップ (Google Maps 埋め込み iframe) |
| 投稿やデータの保存先 | 自社 Web サーバー上の店舗ページ (HTML として出力) |
| 配信 | 未確認 (`HTTP/2 200`、レスポンスヘッダー上は `server` 非公開) |

メモ:

- `/shop/` トップやエリア別一覧 (`/shop/kanto/` 等) には動的地図を載せず、個別店舗ページ (`/shop/kanto/21931_tsuchiuraminami/` 等) 内に Google Maps の `iframe` を埋め込む軽量構成になっている

データの出どころ (2026-11-17):

- 店舗データ: トヨタモビリティパーツ株式会社管理の店舗情報
- 背景地図: Google (Google Maps 埋め込み)
