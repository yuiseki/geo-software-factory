# ジョルダン乗換案内

- URL: https://www.jorudan.co.jp/norikae/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ジョルダン、乗換案内、経路検索、青春18きっぷ、ジョルダンライブ、MaaS、モバイルチケット、徒歩ナビ

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本全国の鉄道・飛行機・47都道府県の路線バスを対象とした乗換案内と、駅周辺の地図・徒歩ナビを提供する定番の交通案内サービス |
| 提供する価値 | 1本前後の再検索、定期代・IC運賃計算、ユーザー投稿によるリアルタイム運行情報「ジョルダンライブ!」、および降りた駅からの徒歩案内までを一貫して利用できる |
| 想定する利用者 | 通勤・通学者、旅行者、鉄道・バス利用者、MaaS や法人向け乗換システムを導入する事業者 |
| 商用か非商用か | 商用 (基本機能は無料・広告表示あり。有料の乗換案内 PREMIUM / Plus モードは月額 360 円 / 365日 3,780 円 (税込) 等。法人向けシステムやモバイルチケットも展開) |
| 推定の売上 | 約 28.3 億〜31.1 億円 (ジョルダン株式会社の連結売上高は 2025年9月期が 2,834 百万円、2026年9月期が 3,106 百万円) |
| 運営 | 企業 (ジョルダン株式会社) |
| 推定の運用費 | 推測: 年間数億円〜十数億円規模 (全国の時刻表・バス路線データ整備、サーバー・CDN 運用、モバイルアプリ開発費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (一次観測では CloudFront Function による空レスポンスが返却され、クライアント側 JS は未取得。なおアプリ版の地図・徒歩ナビにはゼンリン等の地図データを活用) |
| フレームワーク | 未確認 |
| 背景の地図とタイル | ゼンリングループ等の地図データ (公式案内より) |
| 投稿やデータの保存先 | ジョルダン自社基盤 (AWS / CloudFront 経由と推測) |
| 配信 | Amazon CloudFront (`server: CloudFront`, `x-cache: FunctionGeneratedResponse from cloudfront` を応答ヘッダーで確認) |

メモ:

- ウェブ版のほか、累計 5,500 万ダウンロードを超える iOS / Android アプリ「乗換案内」を提供している。
- 一次 HTTP 観測時はボット対策等によるものか CloudFront Function から空の 200 レスポンスが返却された。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|

| 地図データ | 株式会社ゼンリン等 | ジョルダン公式アプリ案内 |
