## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のジョイフル店舗を、エリア・設備条件やマップ表示から検索できる公式店舗検索サイト |
| 提供する価値 | リスト表示と「マップ表示」タブを切り替えながら、営業時間や設備条件に合ったジョイフル店舗の位置を地図上で探せる |
| 想定する利用者 | ジョイフルを利用したい一般客、九州・西日本をはじめ全国の幹線道路沿い等で店舗を探すドライバーや利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ジョイフル) |
| 推定の運用費 | 推測: 月数万〜数十万円。Cloudflare + CloudFront の配信費および Google Maps の利用料がかかる |
