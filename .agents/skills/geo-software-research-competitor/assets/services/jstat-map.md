# jSTAT MAP（地図で見る統計）

- URL: https://jstatmap.e-stat.go.jp/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: jSTAT MAP、地図で見る統計、e-Stat、総務省統計局、統計センター、WebGIS、商圏分析、国勢調査、メッシュ統計

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 政府統計 (国勢調査・経済センサス等) の小地域・メッシュデータを地図上に重ねて可視化や商圏分析ができる総務省統計局の WebGIS |
| 提供する価値 | 専門的な GIS ソフトを購入しなくても、ブラウザだけで日本の公的統計データを地図化し、商圏レポートや地域分析を無料で行える |
| 想定する利用者 | 企業・小売業のエリアマーケティング担当者、自治体職員、研究者・学生、コンサルタント |
| 商用か非商用か | 非商用 (総務省統計局が整備し、独立行政法人統計センターが無料で提供。アカウント登録なしで体験版、無料登録で全機能が利用可能) |
| 推定の売上 | なし (国の公的統計ポータル e-Stat の一部として無償提供) |
| 運営 | 公的機関 (整備: 総務省統計局、運用管理: 独立行政法人統計センター) |
| 推定の運用費 | 推測: 年間数千万円〜1億円規模 (公的統計データベースとの連携サーバーおよび WebGIS 基盤の保守・運用費) |
