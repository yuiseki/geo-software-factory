# KakaoMap (カカオマップ)

- URL: https://map.kakao.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: KakaoMap、카카오맵、カカオマップ、韓国地図、3D ベクター地図、ロードビュー、Kakao Mobility、NGII

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | Kakao が韓国国内向けに提供する、3D ベクター地図、ロードビュー (街路写真)、リアルタイムバス・地下鉄案内、ローカル検索を備えた地図サービス |
| 提供する価値 | 360 度回転・傾斜可能な 3D ベクター地図、高精細なロードビューと航空写真、バス到着情報、Kakao T (配車) や周辺人気スポット分析を無料で使える |
| 想定する利用者 | 韓国国内で日常の移動や店舗探しをする一般の人、訪韓旅行者、Kakao Map SDK を組み込む韓国国内のアプリ・ウェブ開発者 |
| 商用か非商用か | 商用 (一般利用は無料。周辺店舗広告・O2O 送客、および配車等の Kakao Mobility サービス基盤として収益化に貢献) |
| 推定の売上 | 未公表 (Kakao Corp. の決算では Platform / Other Platform セグメントに含まれ、KakaoMap 単体の売上は分けて公表されていない) |
| 運営 | 企業 (Kakao Corp.、モビリティ関連は子会社の Kakao Mobility と連携) |
| 推定の運用費 | 未確認 (ロードビュー撮影車両の運用、韓国国土地理情報院データの統合、リアルタイム交通・バス到着データの処理と CDN 配信の運用費がかかる) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | WebGL および HTML5 Canvas による 3D ベクター地図描画 (HTML 内に `canvas_roadview.css` の読み込みを確認) |
| フレームワーク | 未確認 (HTML 内には `info.search.page.next` などの UI 要素がサーバーレンダリングまたは独自 JS で組み込まれている) |
| 背景の地図とタイル | 韓国国土地理情報院 (NGII) の基本地形図、韓国各自治体の公共交通オープンデータ、Kakao 自社撮影の航空写真・ロードビュー |
| 投稿やデータの保存先 | Kakao アカウント (お気に入り場所や店舗レビューの保存) |
| 配信 | Kakao 自社 CDN (`t1.kakaocdn.net` からのアセット配信、応答ヘッダーの `x-kmap-request-id` を確認) |

メモ:

- 2026-11-16 に `https://map.kakao.com/` を確認したところ、`HTTP/2 200` で `x-kmap-request-id` ヘッダーと `t1.kakaocdn.net` からのスタイルシート読み込みを確認した。
- 開発者向けには Kakao Map JavaScript SDK 等を提供しており、韓国の不動産・物流・地域情報サービスで広く使われている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 基本地図・地形データ | 韓国国土地理情報院 (NGII) | KakaoMap 公式情報・報道資料 |
| 公共交通・バス到着情報 | 韓国各自治体および公共データポータル | KakaoMap サービス案内 |
| ロードビュー・航空写真・口コミ | Kakao 自社測量およびユーザー投稿データ | KakaoMap 公式サービス説明 |
