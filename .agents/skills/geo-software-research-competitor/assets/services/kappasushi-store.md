## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のかっぱ寿司店舗を、エリア・キーワード・設備条件から検索できる公式店舗検索サイト |
| 提供する価値 | 駐車場、バリアフリー、多目的トイレ、エレベーターなどの設備条件や営業時間を確認し、来店や予約へ進める |
| 想定する利用者 | かっぱ寿司を利用したい一般客、家族連れや車いす利用者・ドライバーなど |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (カッパ・クリエイト株式会社 / コロワイドグループ) |
| 推定の運用費 | 推測: 月数万円。Apache + CloudFront の運用費および Google Maps API 利用料 |
