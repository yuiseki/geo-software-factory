## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 1995 年から開発が続く個人製の Windows 向け高機能 3D 地形・地図・GPS ビューアおよび風景 CG 作成ソフト |
| 提供する価値 | 国土地理院の数値地図や標高データ、地理院地図を読み込み、3D 鳥瞰図や山座同定付きの展望図（カシバード）、GPS トラックの可視化・編集をオフライン中心で高精度に行える |
| 想定する利用者 | 登山者、山岳写真家、地図・地形愛好家、GIS ユーザー、航空・地形シミュレーション利用者 |
| 商用か非商用か | 非商用ベース（本体は無料のフリーソフト。再配布や商用組み込みは制限されるが、生成した地図・CG 画像の商用利用はクレジット表記で許可。関連書籍やプラグインの形で収益化） |
| 推定の売上 | 推測: 書籍印税や関連開発による年数十万〜数百万円規模（本体は無料配布。実業之日本社などから多数の公式解説本・CD/DVD-ROM 付き書籍が出版されてきた） |
| 運営 | 個人（杉本智彦 / DAN杉本） |
| 推定の運用費 | 推測: 月数千円程度（Web サイトおよびソフト・プラグイン配布サーバーの維持費が中心で、地図計算はユーザーの PC 上で完結する） |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Windows ネイティブ描画（デスクトップアプリ）。公式サイト HTML では地理院地図や動画埋め込みの案内を確認 |
| フレームワーク | デスクトップアプリ（C/C++ 等の Windows ネイティブ実装）。公式サイトは静的 HTML ベース |
| 背景の地図とタイル | 国土地理院の数値地図・基盤地図情報・地理院地図タイル、市販地図データ等（サイト内に `gsi.go.jp` への参照を確認） |
| 投稿やデータの保存先 | ユーザーのローカル PC（地形データ・GPS トラック・ウェイポイント等をローカルファイルで管理） |
| 配信 | Apache（公式サイトの応答ヘッダーで `server: Apache` を確認。Google Analytics・AdSense を掲載） |

メモ:

- 1995 年公開の日本の個人製 GIS・地形可視化ソフトの代表格であり、Web 地図普及以前からデスクトップで高精度な 3D 地形描画を実現してきた。
- iOS/Android 向けには、同じ作者の関連作品や派生ではなく、Web/PC 向けのデスクトップソフトとして独立して提供されている。
