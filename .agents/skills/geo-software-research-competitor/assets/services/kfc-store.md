# ケンタッキーフライドチキン 店舗検索

- URL: https://search.kfc.co.jp/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ストアロケーター、店舗検索、ファストフード、ケンタッキー、KFC、ドライブスルー、ネットオーダー、営業時間、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のケンタッキーフライドチキン店舗を、現在地・エリア・駅名・サービス条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の場所や営業時間、ドライブスルーやネットオーダー対応などの条件を確認し、来店や事前注文につなげられる |
| 想定する利用者 | KFC の店舗を探している一般客、外出先で近くの店舗やドライブスルー対応店を探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客およびネットオーダーへの導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびネットオーダー送客に貢献する集客基盤 |
| 運営 | 企業 (日本ケンタッキー・フライド・チキン株式会社) |
| 推定の運用費 | 推測: 月数十万円。GOGA 店舗検索サービスの利用料と Google Maps Platform の利用料、Google Cloud 側の配信費がかかる |

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps ベース (GOGA 店舗検索サービス。ブラウザ観測で Google Maps (GOGA) を確認) |

メモ:

- 2026-11-16 のブラウザ観測で地図基盤として Google Maps (GOGA) の利用を確認した
- 一次 HTTP 取得 (`https://search.kfc.co.jp/`) ではステータス 200 (タイトル `店舗検索 | ケンタッキーフライドチキン`) が返り、HTML 内に `has_gmaps` / `has_goga` の直接記述は見られず (動的読み込み)、配信ヘッダは `Google Frontend` であった
- 公式スマートフォンアプリとして「KFC公式アプリ」(ケンタッキー公式アプリ) が提供されている

データの出どころ (2026-11-16):

- 店舗データ: 日本ケンタッキー・フライド・チキン株式会社 / GOGA 店舗検索基盤
- 背景地図: Google (Google Maps Platform)
