# 気象庁 キキクル

- URL: https://www.jma.go.jp/bosai/risk/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: キキクル、危険度分布、気象庁、土砂災害、浸水害、洪水、大雨警報、防災マップ、jmatile、Leaflet

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 土砂災害・浸水害・洪水災害の危険度の高まりを地図上でリアルタイムに5段階色分け表示する気象庁の防災情報サービス |
| 提供する価値 | 大雨警報や洪水警報等の発表時に、自分の現在地や周辺のどこで災害の危険が迫っているかをメッシュおよび河川流路単位で直感的に把握できる |
| 想定する利用者 | 一般市民、自治体・防災担当者、報道機関、防災アプリやシステムを開発する事業者 |
| 商用か非商用か | 非商用 (日本の行政機関である気象庁が国の事業として無料で提供) |
| 推定の売上 | なし (国の行政機関による公的防災サービスであり、気象庁の一般会計予算により運営) |
| 運営 | 公的機関 (気象庁) |
| 推定の運用費 | 推測: 年間数千万円〜数億円規模 (全国のアメダス・気象レーダー解析や高負荷に耐える CloudFront / S3 等での配信基盤を維持) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet (気象庁独自の地図バンドル `jmatile.bundle__*.js` 内に `Leaflet` の記述を確認) |
| フレームワーク | jQuery (`jquery-3.4.1.min.js`) + 気象庁独自バンドル (`jmatile.bundle__*.js`) |
| 背景の地図とタイル | 国土地理院の地理院タイル (`maps.gsi.go.jp` を CSP ヘッダーで確認) および気象庁独自の危険度分布タイル (`jmatile`) |
| 投稿やデータの保存先 | 気象庁の観測・解析データ配信基盤 (`www.data.jma.go.jp` / `ds.data.jma.go.jp` を CSP ヘッダーで確認) |
| 配信 | Amazon S3 + Amazon CloudFront (`server: AmazonS3`, `via: 1.1 *.cloudfront.net` を応答ヘッダーで確認) |

メモ:

- 気象庁公式のネイティブアプリは存在しないが、気象庁と連携する民間防災アプリ (Yahoo!防災速報、特務機関NERV防災、PREP 等) でキキクルのプッシュ通知を受け取ることができる。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 危険度分布 (土砂・浸水・洪水) | 気象庁 (解析雨量・降水短時間予報・土壌雨量指数等) | https://www.jma.go.jp/bosai/risk/ |
| 背景地図 | 国土地理院 (地理院タイル) | CSP ヘッダーおよび画面右下の出典表示 |
