# 強震モニタ

- URL: http://www.kmoni.bosai.go.jp/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 強震モニタ、kmoni、防災科学技術研究所、NIED、リアルタイム震度、強震観測網、K-NET、KiK-net、地震、P波

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本全国の強震観測網 (K-NET・KiK-net) が捉えた地面の揺れ (リアルタイム震度や最大加速度など) を毎秒更新の地図で可視化するサービス |
| 提供する価値 | 緊急地震速報の予測円だけでなく、実際に今どこがどれくらい揺れているか、地震波 (P波・S波) がどう伝わっているかをリアルタイムに視覚で確認できる |
| 想定する利用者 | 防災担当者、地震研究者、防災に関心の高い一般市民 |
| 商用か非商用か | 非商用 (国立研究開発法人防災科学技術研究所が公的事業として無料で提供) |
| 推定の売上 | なし (公的研究機関による無償の防災情報公開サービス) |
| 運営 | 公的研究機関 (国立研究開発法人防災科学技術研究所 / NIED) |
| 推定の運用費 | 推測: 年間数千万円以上 (全国千数百箇所の強震観測点のリアルタイムデータ収集・毎秒の画像生成および配信サーバーの運用費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | サーバー生成 PNG 画像の毎秒更新 + 独自 JavaScript (`MapCtrl.js`, `LayerCtrl.js`, `TimeCtrl.js` 等を確認) |
| フレームワーク | jQuery (`jquery-3.7.1.min.js`) + jQuery UI (`jquery-ui-1.12.1`) |
| 背景の地図とタイル | 防災科研独自の日本地図および地域拡大図画像 |
| 投稿やデータの保存先 | 防災科学技術研究所の強震観測データ配信サーバー |
| 配信 | nginx (`server: nginx` を HTTP 応答ヘッダーで確認。なお HTTPS `https://www.kmoni.bosai.go.jp` はタイムアウトし、`http://www.kmoni.bosai.go.jp/` のみ応答) |

メモ:

- ウェブ版のみで、防災科研による公式の iOS / Android アプリは提供されていない (協定を結んだ「特務機関NERV防災」や「TBS NEWS DIG」等の外部アプリ内でレイヤー連携されているほか、非公式のビューワが存在する)。
- 一覧表の指定 URL (`https://www.kmoni.bosai.go.jp`) はタイムアウトしたが、`http://www.kmoni.bosai.go.jp/` では正常に応答することを確認した。
