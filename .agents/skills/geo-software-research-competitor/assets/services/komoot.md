# Komoot

- URL: https://www.komoot.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Komoot、サイクリング、グラベル、ハイキング、ルートプランナー、音声ナビ、OpenStreetMap、MapLibre

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 路面状況やスポーツ種別に応じたルート作成、音声ターンバイターンナビ、コミュニティ推薦スポットを提供するアウトドア向けナビゲーションサービス |
| 提供する価値 | 舗装路・グラベル・シングルトラックなどの路面種別を考慮した最適なルートを簡単に作成でき、オフライン地図と音声案内で迷わず走破・踏破できる |
| 想定する利用者 | ロード・グラベル・MTB サイクリスト、ハイカー、トレイルランナー、自転車旅行者 |
| 商用か非商用か | 商用 (初期 1 地域は無料。買い切りの World Pack は 29.99 ユーロ/米ドル、Komoot Premium は年額 59.99 ユーロ前後または月額 6.99 ユーロ前後) |
| 推定の売上 | 未確認 (2025 年 3 月にイタリアの Bending Spoons が約 3 億ユーロで買収したと報じられた。直近の単体売上は非公開) |
| 運営 | 企業 (komoot GmbH、ドイツ・ポツダム発、2025 年に Bending Spoons 傘下入り) |
| 推定の運用費 | 未確認 (全世界の OSM ベースルーティングエンジン、タイル配信、CloudFront 配信費、買収後は大幅な人員削減を実施と報道) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 種類 | ウェブ、iOS と Android のアプリ |
| 描画 | MapLibre GL (Komoot は MapLibre の Silver Sponsor としてクロスプラットフォームの地図描画に MapLibre を採用) |
| フレームワーク | Express (`x-powered-by: Express`)、React、Vue (`/plan` の HTML で両方を確認) |
| 背景の地図とタイル | OpenStreetMap の道路・トレイル・路面データを基にした自社カスタムルーティングと地図タイル |
| 投稿やデータの保存先 | 未確認 (自社クラウド基盤にルート、ハイライト、写真を保存) |
| 配信 | Amazon CloudFront (`via: CloudFront`、`x-cache: Hit from cloudfront` を応答ヘッダーで確認) |

メモ:

- 2025 年 3 月に Bending Spoons による約 3 億ユーロでの買収が発表され、外部 GPS デバイスへのルート送信機能の有料化など収益化方針の変化が報じられている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 道路・トレイル・路面データ | OpenStreetMap contributors | Komoot 公式サイトおよび MapLibre スポンサー情報 |
| ハイライト・写真・体験談 | Komoot ユーザーコミュニティ投稿 | Komoot 公式サイト |
