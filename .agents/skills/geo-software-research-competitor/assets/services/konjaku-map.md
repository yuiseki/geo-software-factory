# 今昔マップ on the web

- URL: https://ktgis.net/kjmapw/ (マップ画面: https://ktgis.net/kjmapw/kjmapw.html)
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 今昔マップ、古地図、旧版地形図、時系列地図、明治、大正、昭和、土地利用変化、埼玉大学、谷謙二

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 明治期以降の新旧地形図や現代の地図・空中写真を、2画面・4画面で同期比較したり重ね合わせたりできる時系列地形図閲覧サイト |
| 提供する価値 | 日本全国の主要都市や地域の旧版地形図 (4,000 図幅以上) を、特別な GIS ソフトなしでブラウザ上から直感的に見比べて土地の変遷を調べられる |
| 想定する利用者 | 地理・歴史の研究者、学校教育の教員・生徒、地域の歴史や防災 (旧河道や埋立地など) に興味のある一般利用者 |
| 商用か非商用か | 非商用 (埼玉大学教育学部の谷謙二研究室が研究・教育・一般公開目的で無償運営。有料プランや広告収益モデルは確認できず) |
| 推定の売上 | なし (非商用の学術・教育プロジェクト) |
| 運営 | 個人・研究室 (埼玉大学教育学部 人文地理学研究室 谷謙二) |
| 推定の運用費 | 推測: 年数万円程度 (レンタルサーバーでの静的 HTML/JS と大量のラスタタイル画像のホスティング費用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet 1.3.1 (`L.Map.Sync.js` を用いた複数地図の同期制御) |
| フレームワーク | 見つからなかった (素の JavaScript と静的 HTML) |
| 背景の地図とタイル | 国土地理院の旧版地形図を基に生成した自前ラスタタイル (`https://ktgis.net/kjmapw/kjtilemap/`)、地理院タイル (`https://maps.gsi.go.jp/xyz/...`) 等 |
| 投稿やデータの保存先 | なし (ユーザー投稿機能はなく、閲覧専用) |
| 配信 | nginx (`server: nginx`、スクリプト内に `sv53.wadax.ne.jp` の記述あり) |

メモ:

- 2013 年の公開当初は Google Maps API v3 を用いていたが、その後 Leaflet ベースの実装に移行している。
- 配信されている旧版地形図タイルの一部は、QGIS などの外部 GIS ソフトからも参照可能な形式で案内されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 旧版地形図画像データ | 国土地理院 (旧陸地測量部) 発行の地形図をスキャン・幾何補正してタイル化 | 今昔マップ on the web トップページおよび関連論文 |
| 現代の背景地図・空中写真 | 国土地理院 (地理院タイル) | マップ画面および外部スクリプト (`kjmapLeaf.js`) |
