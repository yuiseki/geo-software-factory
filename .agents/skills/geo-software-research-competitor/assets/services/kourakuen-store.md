| 項目 | 内容 |
|---|---|

| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社幸楽苑) |
| 推定の運用費 | 推測: 月数万円。nginx サーバーの運用費および地図 API 利用料 |
