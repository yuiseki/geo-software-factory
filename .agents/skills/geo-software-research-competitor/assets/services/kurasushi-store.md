# くら寿司 店舗検索

- URL: https://shop.kurasushi.co.jp/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ストアロケーター、店舗検索、回転寿司、くら寿司、お持ち帰り、駐車場、予約、営業時間、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のくら寿司店舗を、現在地・エリア・条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の場所や営業時間、駐車場・お持ち帰り対応などの条件を確認し、来店やスマホ予約へ進める |
| 想定する利用者 | くら寿司の店舗を探している一般客、家族連れや車で立ち寄れる回転寿司店を探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客およびお持ち帰り・来店予約への導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびテイクアウト・予約送客に貢献する集客基盤 |
| 運営 | 企業 (くら寿司株式会社) |
| 推定の運用費 | 推測: 月数万〜数十万円。CloudFront の配信費に加え、Google Maps Platform の利用料がかかる |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |

メモ:

- 2026-11-16 のブラウザ観測で地図基盤として Google Maps の利用を確認した
- 一次 HTTP 取得 (`https://shop.kurasushi.co.jp/`) ではステータス 200 (タイトル `店舗検索｜くら寿司｜回転寿司`) が返り、HTML 内に `has_gmaps` 等の直接記述は見られず (動的読み込み)、配信ヘッダは `Apache` / `CloudFront` であった
- 公式スマートフォンアプリとして「くら寿司 公式アプリ」が提供されている
