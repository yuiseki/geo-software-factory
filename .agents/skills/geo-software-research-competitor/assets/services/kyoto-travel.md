# 京都観光Navi

- URL: https://ja.kyoto.travel/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 京都、観光、寺社、イベント、ライトアップ、スポット検索、京都観光Navi、Kyoto travel

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 京都市と京都市観光協会が運営する、京都市内の観光スポットやイベントを案内する公式観光サイト |
| 提供する価値 | 寺社の特別公開や季節のイベント、エリア別の観光スポット、現地へのアクセスと地図をまとめて調べられる |
| 想定する利用者 | 京都を訪れる国内外の観光客、週末の観光やイベント情報を探す旅行者 |
| 商用か非商用か | 非商用 (京都市公式の観光ポータルサイト。有料課金は見当たらない) |
| 推定の売上 | 該当なし (自治体および観光協会の公的事業・広報予算による運営と見られる) |
| 運営 | 京都市・公益社団法人京都市観光協会 (DMO KYOTO) |
| 推定の運用費 | 推測: 月数万円から数十万円規模 (Cloudflare 経由の PHP サーバー運用。Google Maps Embed API は原則無料枠で利用可能) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | スポット詳細ページ (`/tourism/single01.php`) において `iframe` で Google Maps Embed API (`https://www.google.com/maps/embed/v1/place?key=...&q=35.035261,135.70129`) を埋め込み表示している。トップページのエリア案内には `/img/home/areamap.svg` を使用。 |
| フレームワーク | PHP (`PHPSESSID` クッキーおよび `.php` 拡張子から確認)。観光案内ウィジェットとして `@machi-pla/japan_concierge` を CDN (`unpkg.com`) から読み込み。 |
| 背景の地図とタイル | Google マップ (Google Maps Embed API の `iframe` 内で読み込み)。 |
| 投稿やデータの保存先 | サーバー側の PHP アプリケーションおよびデータベース (公開 HTML からは内部 DB 構成は見えない。一般ユーザーの投稿機能は見当たらない)。 |
| 配信 | Cloudflare (`server: cloudflare`、`cf-cache-status: DYNAMIC`)。 |

データの出どころ (2026-11-16):

- 観光スポット、イベント情報、エリアマップ: 【京都市公式】京都観光Navi (京都市・公益社団法人京都市観光協会) の掲載情報。
- 埋め込み地図の背景データ: Google マップ (Google Maps Embed API `iframe` による表示)。
