## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のローソン店舗を、地図上での探索やエリア・設備条件から検索できる公式店舗検索サイト (AreaMarker) |
| 提供する価値 | 地図を動かしながら周辺のローソン店舗を探し、ATM・Loppi・まちかど厨房・マルチコピー機などの取扱サービスを事前に確認できる |
| 想定する利用者 | 近くのローソンや特定のサービス・設備 (ATM、郵便ポスト、チケット発券等) を備えた店舗を探している一般客 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ローソン。店舗検索システムはゼンリンデータコム等の AreaMarker を利用) |
| 推定の運用費 | 推測: 月数十万円以上。AreaMarker (ゼンリンデータコム) の ASP 利用料と S3 + CloudFront 配信費がかかる |
