## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 首都圏・近畿圏を中心に展開するスーパーマーケット「ライフ」の店舗を現在地・エリア・条件から検索し、地図やチラシ情報を確認できる公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の位置、営業時間、駐車場や各種サービス設備、最新チラシ情報を確認でき、日々の買い物やネットスーパー利用の判断材料になる |
| 想定する利用者 | ライフの近隣利用客、引越し先や外出先で最寄りのスーパーマーケットを探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客およびチラシ・ネットスーパー案内への導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗およびネットスーパーの売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ライフコーポレーション) |
| 推定の運用費 | 推測: 月数万〜数十万円。Google Maps Platform の利用料および店舗検索サイトの運用・配信費がかかる |
