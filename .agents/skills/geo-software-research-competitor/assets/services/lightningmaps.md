# LightningMaps.org

- URL: https://www.lightningmaps.org/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: LightningMaps、Blitzortung、雷、落雷、リアルタイム、雷鳴、衝撃波、OpenStreetMap、Leaflet

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中の落雷をリアルタイムに観測し、雷鳴の到達範囲を示す衝撃波アニメーションとともに地図上に表示するサービス |
| 提供する価値 | コミュニティが運営する VLF 電波受信機ネットワークのデータを使い、今どこで落雷が起きているかを数秒の遅延で視覚的に把握できる |
| 想定する利用者 | 雷の接近を知りたい一般利用者、気象愛好家、アウトドア・イベント関係者、観測局のボランティア参加者 |
| 商用か非商用か | 非商用 (無料提供。広告表示およびコミュニティの寄付・ボランティアによる受信機運用で維持されている) |
| 推定の売上 | 推測: 広告および寄付による運営費補填程度と見られるが、金額は未公開 |
| 運営 | コミュニティ・非営利プロジェクト (Blitzortung.org およびコントリビューター) |
| 推定の運用費 | 推測: 月数万円から数十万円規模と見られる (ボランティア受信機からのリアルタイム信号処理と配信サーバーの維持費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet (`/js/leaflet/leaflet.js`、`Leaflet.Terminator.js`、`Leaflet.GoogleMutant.js`、`Leaflet.Geodesic.js` を確認) |
| フレームワーク | jQuery (`jquery.js`) + PHP/8.3.6 (`x-powered-by: PHP/8.3.6` ヘッダーを確認) |
| 背景の地図とタイル | OpenStreetMap および Google Maps (`Leaflet.GoogleMutant.js` による切り替えに対応) |
| 投稿やデータの保存先 | Blitzortung.org のボランティア受信局ネットワークから収集・計算された落雷データをサーバー側で保持・配信 |
| 配信 | nginx (`server: nginx` ヘッダーを確認。インフラ事業者は未確認) |

メモ:

- 以前は Google Maps 主体だったが、API 費用高騰への対応として Leaflet と OpenStreetMap ベースのスタックへ移行した経緯がある。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| リアルタイム落雷位置・時刻データ | Blitzortung.org およびボランティア受信局ネットワーク | 公式サイトのヘッダー・説明およびメタ情報 |
| 背景地図 | OpenStreetMap contributors、Google Maps | 地図のスタイル切り替えおよび帰属表示 |
