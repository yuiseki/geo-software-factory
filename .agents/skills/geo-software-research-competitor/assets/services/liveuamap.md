- 観測した日: 2026-11-16

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ウクライナ・中東・アジアなど世界 30 以上の地域における紛争・抗議活動・災害の速報をリアルタイムで地図上にマッピングする OSINT ニュースサービス |
| 提供する価値 | SNS や報道から収集・位置特定された事件や軍事行動をタイムラインと地図で同時に追跡でき、企業の危機管理向け GeoJSON API も利用できる |
| 想定する利用者 | 報道機関、セキュリティ・危機管理担当者、NGO、OSINT 研究者、一般ニュース利用者 |
| 商用か非商用か | 商用 (Web・アプリは広告付き無料。広告非表示・履歴閲覧の有料サブスクリプション、および法人向け API Pro $150/月〜・Enterprise $1,000/月〜 を提供) |
| 推定の売上 | 推測: 年数千万円〜数億円規模 (一般向け広告・アプリ課金に加え、B2B 向け $150〜$1,000+/月の API 契約を展開しているが、非上場のため非公開) |
| 運営 | 企業 (Liveuamap LLC、米国法人・技術基盤は EU。2014 年に Rodion Rozhkovskiy 氏と Oleksandr Bilchenko 氏が設立) |
| 推定の運用費 | 推測: 月数十万〜数百万円規模 (24 時間体制のニュース・SNS モニタリング・位置特定作業と、高トラフィック対応の Cloudflare・API 基盤) |
