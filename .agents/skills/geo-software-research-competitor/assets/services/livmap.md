# LivMap (リブマップ) - チームで使う共有地図

- URL: https://livmap.co/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 業務用地図、現場、フィールドワーク、位置共有、チーム、自治体、除雪、林業

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | チームで地図を共有し、現在地、写真、地点のメモ、軌跡を記録しながら動く現場の業務のアプリ (紙の地図や GIS のデータを取り込むサービスつき) |
| 提供する価値 | 除雪、林業、漁業、設備の点検、災害対応などの現場で、特殊な地図を持ち運び、みんなの状況をリアルタイムに分かち合える |
| 想定する利用者 | 自治体、中央省庁、設備管理、運輸、農林水産の現場のチーム |
| 商用か非商用か | 商用 (法人と自治体向けの有料のサービス。資料請求と無料トライアル。料金は公開されていない) |
| 推定の売上 | 推測: 年数千万円規模。広島県、秋田県などの自治体と企業に導入 (サイトの表示)。数字は公開されていない |
| 運営 | 企業 (株式会社はんぽさき) |
| 推定の運用費 | 推測: 月数万〜数十万円。アプリと共有のサーバー、地図の取り込みを担う GIS の担当者の人件費 |
