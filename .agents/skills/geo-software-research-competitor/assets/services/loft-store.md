## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のロフト (Loft) 店舗を、エリア・都道府県や店舗一覧から検索し地図上で位置を確認できる公式店舗検索サイト |
| 提供する価値 | 最寄りロフトの住所、営業時間、フロア構成や取り扱いジャンル・イベント情報を確認し、来店の参考やネットストア連携に使える |
| 想定する利用者 | 文具・コスメ・生活雑貨の購入やギフト選びでロフトを訪れたい一般客、出先で近くの店舗を探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客およびロフトネットストア・ロフトアプリ連携の導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗での購買およびオムニチャネル送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社ロフト) |
| 推定の運用費 | 推測: 月数万〜数十万円。Google Maps Platform の利用料と Web サーバー・CDN の配信費がかかる |
