- 概要と収支を確かめた日: 2026-11-17

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のロピアおよびグループ店舗をエリア別一覧から探し、店舗ごとの住所・営業時間・電話番号などを確認できる公式店舗案内ページ |
| 提供する価値 | 都道府県別の店舗一覧と個別店舗ページ（`/shops/<slug>`）により、最寄り店舗の所在地や営業時間、公式アプリの案内をシンプルに確認できる |
| 想定する利用者 | ロピアでの買い物を予定している一般客、近隣のロピア店舗を探している生活者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗案内ページ単体の売上は 0 円。実店舗の小売売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ロピア / OICグループ) |
| 推定の運用費 | 推測: 月数万円。Web サーバー (Apache) の運用費のみで、外部地図 API の従量課金は発生していない |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 地図埋め込みなし (トップ一覧 `/shops/` および個別店舗 `/shops/tonden` の HTTP 観測で地図ライブラリ・地図 iframe ともに未検出) |
| フレームワーク | 静的 HTML / サーバーサイド生成 HTML (主要 JS フレームワーク未検出、Google Tag Manager `GTM-5N58NTBZ` を利用) |
| 背景の地図とタイル | なし (地図未埋め込み) |
| 投稿やデータの保存先 | サーバー側で生成された HTML ページ (`/shops/` および `/shops/<slug>`) |
| 配信 | Apache (`server: Apache`) |

メモ:

- 2026-11-17 の HTTP 観測では、店舗一覧ページおよび個別店舗ページ (`/shops/tonden`) のいずれにも埋め込み地図や地図 JS ライブラリは含まれていなかった
- グループ企業のスーパーバリュー店舗検索 (`https://www.supervalue.jp/shop/`) への外部リンクが一覧に含まれている
