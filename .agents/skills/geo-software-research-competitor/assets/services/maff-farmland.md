# 農地ナビ

- URL: https://map.maff.go.jp
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 農地ナビ、eMAFF農地ナビ、農林水産省、農地台帳、筆ポリゴン、農地転用、耕作放棄地、Mapbox GL JS

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の農業委員会が整備する農地台帳や農地の区画 (筆ポリゴン・農地ピン) を地図上で閲覧できる農林水産省の公式サービス |
| 提供する価値 | 新規就農希望者や農地を借りたい・買いたい人が、全国の農地の所在、面積、権利関係、利用意向などをオンラインの地図上で一括して調査できる |
| 想定する利用者 | 農家・農業法人、新規就農希望者、農業委員会・自治体職員、不動産・調査関係者 |
| 商用か非商用か | 非商用 (農林水産省が「eMAFF農地ナビ」として無料で一般公開) |
| 推定の売上 | なし (国の行政機関による無償の農地情報公開サービス) |
| 運営 | 公的機関 (農林水産省) |
| 推定の運用費 | 推測: 年間数千万円〜数億円規模 (全国数千万筆の農地ポリゴンデータと Mapbox 基盤・API サーバーの維持運用費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Mapbox GL JS + Turf.js (`mapbox-gl-js`、`mapbox-gl-geocoder-js`、`turf-js` の読み込みを HTML で確認) |
| フレームワーク | ASP.NET MVC バンドル + jQuery + Bootstrap (`/bundles/jquery`、`/bundles/bootstrap`、`/bundles/geocontrol` を確認) |
| 背景の地図とタイル | Mapbox 基盤および地理院タイル・衛星写真等 (Mapbox GL JS を利用) |
| 投稿やデータの保存先 | 農林水産省「地理情報共通管理システム (eMAFF 地図)」基盤 (`map-internal.api.maff.go.jp` への参照を確認) |
| 配信 | 未確認 (`x-cache: CONFIG_NOCACHE` ヘッダーを確認) |

メモ:

- 一般利用者向けはウェブ版のみだが、自治体・農業委員会職員の現地調査用としてモバイルアプリ「eMAFF現地確認」が提供されている。

|---|---|---|
