# Mapbox

- URL: https://www.mapbox.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Mapbox、ベクタタイル、Mapbox GL JS、地図 SDK、ジオコーディング、ナビゲーション SDK、自動車、ロケーションプラットフォーム

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ウェブ・モバイル・車載向けに高精度なカスタマイズ可能ベクタ地図、位置検索、ターンバイターンナビゲーション API/SDK を提供する開発者向けプラットフォーム |
| 提供する価値 | WebGL ベースの滑らかな地図描画や自由なスタイル設計、リアルタイム交通を反映したナビゲーション、各種位置情報 API を従量課金で組み込める |
| 想定する利用者 | 地図・配送・配車・不動産・旅行アプリを開発する企業や開発者、自動車メーカー (車載インフォテインメント) |
| 商用か非商用か | 商用 (無料枠あり: Web 地図は月 5 万ロード、モバイル SDK は月 2.5 万 MAU、ジオコーディング等は月 10 万リクエストまで無料。超過分は従量課金、エンタープライズ契約あり) |
| 推定の売上 | 推測: 年 1 億〜1.7 億米ドル規模 (非上場企業のため公式非公開だが、過去の報道で年商 1 億ドル突破、市場調査では約 1.72 億ドル程度と推定) |
| 運営 | 企業 (Mapbox, Inc.、米国) |
| 推定の運用費 | 推測: 月数億円規模。全世界のベクタタイル・航空写真・ナビゲーション API の低遅延配信と、膨大な端末テレメトリ処理基盤を運用している |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Mapbox GL JS (ウェブ向け自社ライブラリ、HTML 内に `Mapbox` / `mapbox` の参照を確認。モバイル向けには Maps SDK / Navigation SDK を提供) |
| フレームワーク | 独自構成 (`static-assets.mapbox.com` からのスクリプト群を確認) |
| 背景の地図とタイル | 自前の Mapbox ベクタタイル、衛星画像、地形データ |
| 投稿やデータの保存先 | Mapbox Studio / Datasets API 等の自社クラウド基盤 |
| 配信 | Cloudflare + Varnish (`server: cloudflare`、`via: 1.1 varnish` を応答ヘッダーで確認) |

メモ:

- 一般消費者向けの単体地図アプリではなく、開発者向けプラットフォームとして iOS / Android ネイティブ SDK（Maps SDK、Navigation SDK）や Flutter / React Native ラッパーを提供している。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| ベースマップ・道路網 | OpenStreetMap (OSM) を基盤とし、自社テレメトリ・衛星画像・機械学習で補強 | Mapbox 公式ドキュメント |
| 交通・プローブデータ | Mapbox SDK を組み込んだ数億台の端末からの匿名テレメトリ | Mapbox 公式サイト |
