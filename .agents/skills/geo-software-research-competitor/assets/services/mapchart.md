# MapChart

- URL: https://www.mapchart.net
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: MapChart、塗り分け地図、白地図、コロプレス図、SVG、歴史地図、国別マップ、都道府県、統計地図

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界・各国・歴史・ファンタジーの白地図テンプレートをクリックして塗り分け、凡例付きの統計地図や図版を手軽に作れるサービス |
| 提供する価値 | GIS ソフトやデータ整形なしで、国・州・都道府県・郡単位の白地図を直感的に色分けし、高品質な PNG / JPEG / SVG 画像として即座に書き出せる |
| 想定する利用者 | ブロガー、SNS 投稿者、学生・教師、歴史やゲーム (HoI4 等) のファン、プレゼン資料用の簡易地図を作りたい一般利用者 |
| 商用か非商用か | 商用フリーミアム (基本機能および画像・SVG 書き出しは広告付きで無料。MapChart Plus は年額約 $49.99 でクラウド保存・カスタムパレット・広告非表示を提供) |
| 推定の売上 | 推測: 年数千万円規模 (Web/アプリの広告収益、MapChart Plus サブスクリプション、モバイルアプリ内課金) |
| 運営 | 個人開発 (Minas Giannekas、ギリシャ) |
| 推定の運用費 | 推測: 月数万円〜数十万円程度 (静的テンプレート配信と MapChart Plus 用の設定データ保存、Cloudflare CDN) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | ブラウザ上の SVG 直接操作 (プリレンダリングされた地域別 SVG パスの塗り分け。なお 2026-11-16 の HTTP 観測時は HTTP 520 エラーのため HTML 本文からスクリプトを直接確認できず) |
| フレームワーク | 未確認 (HTTP 520 エラーにより観測不可) |
| 背景の地図とタイル | タイル地図ではなく、テーマ別のベクター地図テンプレート (SVG) |
| 投稿やデータの保存先 | 無料版はローカル設定ファイル (JSON) 保存、MapChart Plus はクラウド保存 |
| 配信 | Cloudflare (`server: cloudflare` を確認。2026-11-16 のアクセス時はオリジン側で `520: Web server is returning an unknown error` が発生) |
