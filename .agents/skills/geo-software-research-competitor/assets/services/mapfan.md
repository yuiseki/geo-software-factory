# MapFan

- URL: https://mapfan.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: MapFan、マップファン、ジオテクノロジーズ、旧インクリメントP、地図検索、ルート検索、カーナビ、大型車規制、商用地図API

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ジオテクノロジーズが自社整備する最新の日本全国デジタル地図をもとに、住所・施設検索や車・徒歩のルート検索を提供する地図ポータル |
| 提供する価値 | カーナビで培われた最新の道路・施設・大型車規制情報をウェブとアプリで手軽に検索でき、有料プランでは一括ルート作成や業務用印刷、法人向け API/SDK まで展開する |
| 想定する利用者 | ドライバー、営業・配送などの業務利用者、地図アプリや業務システムに国産地図を組み込む開発者・法人 |
| 商用か非商用か | 商用 (Web 版の基本利用は無料・広告表示あり。個人向け有料会員 MapFan プレミアムは月額 300 円 / 年額 3,600 円 (税別) 程度。法人向け MapFan API / SDK・複製利用は有料) |
| 推定の売上 | 非公開 (運営元のジオテクノロジーズ株式会社は非上場のため売上高非公開。従業員数約 583 名規模で、カーナビ地図・法人 API・ポイ活アプリ「トリマ」等を展開) |
| 運営 | 企業 (ジオテクノロジーズ株式会社、旧インクリメント・ピー株式会社) |
| 推定の運用費 | 推測: 年間数億円〜数十億円規模 (日本全国の道路・地図データの継続的な現地調査・整備コストおよび配信インフラ費用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 独自 MapFan 地図エンジン (`https://mapfan.com/map` にて自社製スクリプトを確認) |
| フレームワーク | Express (応答ヘッダーの `x-powered-by: Express` を確認) |
| 背景の地図とタイル | ジオテクノロジーズ自社整備の日本全国地図データ (MapFan 地図タイル) |
| 投稿やデータの保存先 | ジオテクノロジーズ自社サーバー (AWS 基盤と推測) |
| 配信 | Amazon CloudFront (`via: 1.1 *.cloudfront.net` を応答ヘッダーで確認) |
