## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 住所、施設、駅、郵便番号から地図を探し、ルート検索、乗換案内、天気、マップコード、標高、キョリ測を使える老舗の地図サイト |
| 提供する価値 | 地図の検索と周りの便利な機能を、1 つのサイトで無料で使える |
| 想定する利用者 | 地図を探す一般の人 |
| 商用か非商用か | 商用 (Google、Geniee、fluct、Criteo、i-mobile などの広告。アプリは有料のマピオンプラス 250 円 (App Store 2026-11-12)。法人向けのサービスもある) |
| 推定の売上 | 推測: 年数億円規模の広告。はてなブックマーク 1,349 件 (2026-11-12)。サービスごとの売上は公開されていない |
| 運営 | 企業 (ONE COMPATH 株式会社) |
| 推定の運用費 | 推測: 月数百万円以上。地図データの使用料、検索とルートのサーバー、CloudFront の配信、開発と運用の人件費 |
