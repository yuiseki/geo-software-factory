# Mapy.com（旧 Mapy.cz）

- URL: https://mapy.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Mapy.com、Mapy.cz、Seznam.cz、ハイキング地図、登山地図、サイクリング、オフライン地図、チェコ、MapLibre

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | チェコ・スロバキアでの圧倒的な詳細度と、世界中の登山道・サイクリング道・オフライン地図に強みを持つアウトドア対応の総合地図サービス |
| 提供する価値 | 標識付きハイキングコースや等高線・地形表現、活動別の精密な経路計画、オフライン地図ダウンロードを広告の少ない快適な UI で利用できる |
| 想定する利用者 | ハイカー、登山者、サイクリスト、旅行者、ドライバー、チェコおよび欧州の一般利用者、Mapy.com REST API を使う開発者 |
| 商用か非商用か | 商用 (基本機能と 1 地域のオフライン地図は無料。無制限のオフライン地図や PRO ルート作成等を含む Mapy.com Premium が年額約 €18.99、開発者向け API はクレジット消費型で課金) |
| 推定の売上 | 推測: 年数億円〜十数億円規模。チェコ大手ポータル Seznam.cz の主要サービスのひとつで、Premium サブスクリプション・宿泊予約連携・API 課金で収益化しているが単体売上は非公開 |
| 運営 | 企業 (Seznam.cz, a.s.、チェコ) |
| 推定の運用費 | 推測: 月数百万円〜数千万円規模。自前のチェコ・スロバキア詳細地図の継続整備、全世界の OSM タイル・標高・航空写真の配信と API インフラを維持している |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | MapLibre GL JS + WebAssembly (応答 HTML 内に `mapLibRe` の記述および `/js/wasm-boot.2.85.7.js` の読み込みを確認) |
| フレームワーク | Express バックエンド (`x-powered-by: Express` を応答ヘッダーで確認) + 独自フロントエンドバンドル |
| 背景の地図とタイル | 自前ホストの地図タイル・航空写真・地形データ (`geo.seznam.cz` 等の参照を確認) |
| 投稿やデータの保存先 | 未確認 (Seznam アカウント連携や保存ルート、ユーザー投稿写真を扱うが保存先インフラの詳細は非公開) |
| 配信 | nginx (`server: nginx` を応答ヘッダーで確認。`mapy.com` から `mapy.com/en/` へリダイレクト) |

メモ:

- ウェブ版のほか iOS / Android アプリ（および Apple Watch / Wear OS コンパニオンアプリ）が提供されている。
- 旧称 Mapy.cz からグローバル展開に向けて Mapy.com へブランド移行した。
