# MarineTraffic

- URL: https://www.marinetraffic.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: MarineTraffic、マリントラフィック、AIS、船舶追跡、船舶位置情報、海運、港湾、ship tracker、vessel tracking

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地上および衛星の AIS 受信網を用いて世界中の船舶の現在位置や航跡、寄港情報をリアルタイムで可視化する海事情報プラットフォーム |
| 提供する価値 | 世界中の船舶のリアルタイム位置・速度・目的地・ETA の追跡、気象・密度マップの重ね合わせ、サプライチェーンや港湾混雑の可視化と API 提供 |
| 想定する利用者 | 海運会社、港湾管理者、貿易・コモディティ取引企業、ロジスティクス担当者、海事関係者および一般の船舶ファン |
| 商用か非商用か | 商用 (フリーミアムモデル。無料閲覧、個人・ビジネス向け有料サブスクリプション、従量制・契約制 API、エンタープライズ向け海事分析) |
| 推定の売上 | 未確認 (2023 年 2 月に Kpler が買収。Kpler 全体の ARR は 1 億ドル超から 3 億ドル規模へ拡大中とされるが、MarineTraffic 単体は非公開) |
| 運営 | 企業 (Kpler 傘下、2007 年にギリシャ・アテネで設立) |
| 推定の運用費 | 未確認 (世界中の沿岸 AIS 受信局ネットワークおよび衛星 AIS データ調達、数十億点規模の位置データ処理基盤を運用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (トップページが Cloudflare により HTTP 403 を返したため HTML からは未確認。外部資料では Leaflet や Mapbox の利用が言及されている) |
| フレームワーク | 未確認 (HTTP 403 のため HTML から確認できず) |
| 背景の地図とタイル | 未確認 (外部資料では OpenStreetMap を基にした地図タイルや海図・衛星レイヤーの組み合わせが言及されている) |
| 投稿やデータの保存先 | MarineTraffic / Kpler 自社基盤 (地上 AIS 受信局ネットワークおよび衛星 AIS データプロバイダーからの集約) |
| 配信 | Cloudflare (`server: cloudflare`, `cf-ray` ヘッダーを確認) |

メモ:

- 2023 年 2 月にコモディティデータ企業 Kpler が MarineTraffic と FleetMon を同時買収し、その後 FleetMon のコミュニティ網は MarineTraffic へ統合された。
- 気象情報、港湾境界、船舶諸元、過去の航跡や密度マップなど多層的な海事データを統合提供している。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 船舶位置・AIS データ | 陸上 AIS 受信局ネットワーク (ボランティアおよび自社局) と衛星 AIS | MarineTraffic / Kpler 公式情報 |
| 配信基盤情報 | Cloudflare | `https://www.marinetraffic.com/` の HTTP 応答ヘッダー (2026-11-16 観測) |
