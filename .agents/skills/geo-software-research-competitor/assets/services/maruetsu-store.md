# マルエツ 店舗検索 (地図から探す)

- URL: https://www.maruetsu.co.jp/stores/map/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、スーパー、スーパーマーケット、マルエツ、マルエツ プチ、リンコス、U.S.M.H、チラシ、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 首都圏の食品スーパー「マルエツ」「マルエツ プチ」「リンコス」の店舗を、現在地周辺の Google マップ埋め込みから探せる公式ページ |
| 提供する価値 | ブラウザの位置情報許可をもとに現在地周辺のマルエツ店舗を地図上に表示し、最寄り店舗の検索や店舗情報・チラシ確認につなげる |
| 想定する利用者 | マルエツ各店舗への来店を予定している一般客、現在地近くの食品スーパーを探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。マルエツ単体売上高 約 4,092 億円 (2026 年 2 月期) の実店舗送客に貢献 |
| 運営 | 企業 (株式会社マルエツ / ユナイテッド・スーパーマーケット・ホールディングスグループ) |
| 推定の運用費 | 推測: 月数万〜十数万円。Web サーバー (Apache) および Incapsula WAF の運用費がかかるが、地図埋め込みは無料の Google マップ `output=embed` 形式を利用 |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google マップ埋め込み `iframe` (`https://maps.google.co.jp/maps?output=embed&q=%E3%83%9E%E3%83%AB%E3%82%A8%E3%83%84`)。`map.js` で `navigator.geolocation.getCurrentPosition` を呼び出し、取得した緯度経度 (`ll=...`) 付きで `iframe` を動的に差し替える |
| フレームワーク | 独自 JS (`lib.js`、`common.js`、`map.js`) |
| 背景の地図とタイル | Google マップ (`maps.google.co.jp/maps?output=embed`) |
| 投稿やデータの保存先 | Google マップ側の店舗検索結果に依存 (`q=マルエツ` での埋め込み表示) |
| 配信 | Apache + Incapsula WAF (`server: Apache`, `/_Incapsula_Resource`) |

メモ:

- 店舗数は約 307〜311 店舗 (首都圏を中心に展開)
- 地図描画に Google Maps JavaScript API キーは使わず、クラシックな `maps.google.co.jp/maps?output=embed` の `iframe` 埋め込みと Geolocation API を組み合わせている

データの出どころ (2026-11-17):

- 店舗情報: 株式会社マルエツ
- 埋め込み地図・検索結果: Google マップ
