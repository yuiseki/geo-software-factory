## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の丸亀製麺店舗を、現在地・キーワード・条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 近くの丸亀製麺店舗の位置や営業時間、駐車場・お持ち帰り・モバイルオーダー対応などの条件を確認できる |
| 想定する利用者 | 丸亀製麺の店舗を探している一般客、外出先やドライブ中に近くの店舗を探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客およびテイクアウト・モバイルオーダーへの導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびテイクアウト送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社丸亀製麺) |
| 推定の運用費 | 推測: 月数万〜数十万円。Cloudflare 配信費に加え、Google Maps Platform (および Yext 等の店舗検索基盤) の利用料がかかる可能性 |
