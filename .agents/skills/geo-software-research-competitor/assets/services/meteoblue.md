# Meteoblue

- URL: https://www.meteoblue.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Meteoblue、気象予報、マルチモデル、メテオグラム、衛星画像、雨雲レーダー、OpenLayers、Windy

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | スイス発の高解像度マルチモデル気象予報と気象マップ・衛星画像・メテオグラムを提供する気象情報サービス |
| 提供する価値 | 複数の数値予報モデル (NMM、ICON、GFS 等) を機械学習で組み合わせた高精度な局地予報と、風・降水・雲量・日照などのインタラクティブ地図を提供する |
| 想定する利用者 | 一般の天気予報利用者、登山・航空・農業・再生可能エネルギー事業者、気象 API を利用する企業・研究者 |
| 商用か非商用か | 商用 (Web・アプリの基本機能は広告付き無料。広告非表示や高機能版の有料プラン、法人・開発者向けの気象データ API を販売。2024 年 6 月に Windy が過半数株式を取得) |
| 推定の売上 | 推測: 年 320 万〜540 万米ドル規模 (従業員約 30〜50 名の非上場企業として市場調査会社が推計。公式の決算は非公開) |
| 運営 | 企業 (meteoblue AG、スイス・バーゼル。2006 年にバーゼル大学のスピンオフとして設立、2024 年より Windyty, S.E. 傘下) |
| 推定の運用費 | 推測: 月数百万円規模。独自の数値予報モデルの計算基盤、全世界 600 万地点以上のデータ配信、高トラフィックな Web サイト・API サーバーを運用している |

メモ:

- ウェブ版のほか iOS / Android アプリ (Apple Watch 対応含む) を提供している。
- 2024 年 6 月に Windy (Windyty, S.E.) による過半数株式の取得が発表されたが、サービスおよび課金体系はそれぞれ独立して継続している。
