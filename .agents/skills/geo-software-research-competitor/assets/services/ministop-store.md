## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のミニストップ店舗を、エリア・キーワード・設備条件から検索し、店舗詳細で地図を確認できる公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の営業時間やイートイン・ATM・駐車場などの設備条件とあわせて、店舗の位置を地図上で確認できる |
| 想定する利用者 | ミニストップを利用したい一般客、ソフトクリームや店内調理商品・ATM などを目的に店舗を探す利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (ミニストップ株式会社) |
| 推定の運用費 | 推測: 月数万〜数十万円。Web サーバー運用費および Google Maps (iframe 埋め込み) の利用範囲に応じた運用費 |
