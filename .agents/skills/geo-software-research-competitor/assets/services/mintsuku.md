- 探すときの語: 冠水、浸水、大雨、豪雨、アンダーパス、運転、危険な道路

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の「冠水して危なかった道路」を、利用者の投稿で集めて地図にする有志のプロジェクト (約 9,500 件) |
| 提供する価値 | 豪雨のとき、過去に冠水した道やアンダーパスを知って、運転するか外出をやめるかを判断できる |
| 想定する利用者 | 雨の日に車を運転する人 |
| 商用か非商用か | 商用 (AdStir と i-mobile の広告) |
| 推定の売上 | 推測: 月数千〜数万円。表示回数は公開されていない |
| 運営 | 有志 (運営者の会社名は見つからなかった) |
| 推定の運用費 | 推測: 月数千円以下。Cloudflare の配信と、自前の日本のベースマップと冠水の PMTiles |
