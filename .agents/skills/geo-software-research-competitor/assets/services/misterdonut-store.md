## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のミスタードーナツ店舗を、現在地・エリア・駅名・条件から検索してマピオン地図上に表示する公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の場所や営業時間、ミスドネットオーダーや食べ放題・イートイン対応などの条件を素早く確認できる |
| 想定する利用者 | ミスタードーナツの店舗を探している一般客、外出先で手土産やカフェ利用の店舗を探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客およびミスドネットオーダーへの導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびネットオーダー送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社ダスキン) |
| 推定の運用費 | 推測: 月数万〜数十万円。株式会社ワン・コンパス (マピオン) の法人向け店舗検索 ASP 利用料がかかる |
