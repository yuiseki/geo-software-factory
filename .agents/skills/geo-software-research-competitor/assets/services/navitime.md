# NAVITIME（ウェブ総合版）

- URL: https://www.navitime.co.jp
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: NAVITIME、ナビタイム、ナビタイムジャパン、トータルナビ、乗換案内、ルート検索、ドアツードア、時刻表、Mapbox

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 電車・バス・車・徒歩・飛行機などあらゆる移動手段を組み合わせたドア・ツー・ドアの経路探索 (トータルナビ) と地図検索を提供する総合ナビゲーションサービス |
| 提供する価値 | 鉄道の乗換だけでなく、駅からの徒歩やバス接続、遅延・混雑・料金までを考慮した最適な移動ルートを日本全国で一貫して案内できる |
| 想定する利用者 | 通勤・通学者、旅行者・出張者、ドライバー、動態管理や物流システムに組み込む法人 |
| 商用か非商用か | 商用 (基本の乗換案内・地図閲覧は無料・広告表示あり。プレミアムコースは月額 500 円 / 年額 4,500 円 (税込)、ファミリープランやプレミアムプラス、法人向け NAVITIME API を展開) |
| 推定の売上 | 非公開 (株式会社ナビタイムジャパンは非上場のため売上高非公開。従業員数約 430〜450 名規模で BtoC サブスクと BtoB 法人ソリューションを展開) |
| 運営 | 企業 (株式会社ナビタイムジャパン) |
| 推定の運用費 | 推測: 年間数億円〜数十億円規模 (全国の鉄道・バス時刻表・道路ネットワーク・リアルタイム交通情報の整備と高トラフィックな経路探索サーバーの維持費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 自社地図基盤 + Mapbox 関連記述 (`mapbox` の記述を HTML 内で検出。ナビタイム独自の地図データ・経路探索基盤を併用) |
| フレームワーク | Vue.js (`vue.min.js`、`vuejs-datepicker`、`vuejs-paginate` を確認) |
| 背景の地図とタイル | ナビタイムジャパン独自整備地図等 |
| 投稿やデータの保存先 | ナビタイムジャパン独自サーバー |
| 配信 | Apache + Amazon CloudFront (`server: Apache`, `via: 1.1 www.navitime.co.jp, 1.1 *.cloudfront.net` を応答ヘッダーで確認) |

メモ:

- ウェブ版のほか、iOS / Android 向けの総合アプリ「NAVITIME」および用途別アプリ (カーナビタイム、自転車NAVITIME 等) を多数提供している。
