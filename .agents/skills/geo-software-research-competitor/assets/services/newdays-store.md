## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | JR 東日本クロスステーションが運営する駅ナカの NewDays や KIOSK 店舗を、駅名・路線・条件から検索できる公式店舗検索サイト |
| 提供する価値 | 駅構内や改札内外の位置関係、営業時間、セルフレジ・ATM・酒・たばこなどの取扱状況を事前に確認できる |
| 想定する利用者 | 鉄道利用者、通勤・通学者、駅構内でコンビニや売店を探している一般客 |
| 商用か非商用か | 商用 (駅ナカ店舗への来店送客とリテール事業の案内として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社JR東日本クロスステーション) |
| 推定の運用費 | 推測: 月数万〜数十万円。自社 Web サーバー (Apache) の運用費と NAVITIME 法人向け地図 API 利用料がかかる |
