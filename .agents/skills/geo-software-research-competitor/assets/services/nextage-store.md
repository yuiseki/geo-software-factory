# ネクステージ (NEXTAGE) 店舗検索

- URL: https://www.nextage.jp/shop/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、中古車、買取、車検、ネクステージ、NEXTAGE、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のネクステージ中古車販売店・買取店・正規輸入車ディーラーを地域や業態から探し、各店舗ページで地図を確認できる公式店舗検索サイト |
| 提供する価値 | 目的 (買う・売る・車検・整備) や地域から最寄りの店舗を探し、アクセスマップや店舗内の様子、在庫情報、来店予約へスムーズに進める |
| 想定する利用者 | 中古車の購入・買取査定・車検や整備を検討している一般消費者 |
| 商用か非商用か | 商用 (実店舗への来店予約・買取査定・在庫問い合わせへの送客基盤として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。全国約 340〜350 店舗の中古車販売・買取・整備事業の成約に貢献 |
| 運営 | 企業 (株式会社ネクステージ) |
| 推定の運用費 | 推測: 月数万円〜十数万円。Web サーバーおよび静的アセット CDN (`cdn.nextage.jp`) の運用費が中心で、地図は Google Maps 埋め込みのため API 課金が抑えられる構成 |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps 埋め込み (`https://www.google.com/maps/embed?pb=...` の iframe を各店舗詳細ページ `/shop/<id>/` に遅延読み込みで配置。一部店舗ではストリートビュー埋め込みも併用) |
| フレームワーク | jQuery 3.5.1 / jQuery UI (`jquery-3.5.1.min.js`、`jquery-ui-auto.min.js`、`shop.min.js`) |
| 背景の地図とタイル | Google マップ (Google Maps 埋め込み iframe) |
| 投稿やデータの保存先 | 自社店舗データベース (サーバー側生成 HTML として出力) |
| 配信 | 未確認 (`HTTP/2 200`、レスポンスヘッダー上は `server` 非公開。JS/CSS は `cdn.nextage.jp` から配信) |

メモ:

- `/shop/` トップや地方一覧ではリンクと一覧表示を中心とし、個別店舗ページ (`/shop/1144/` 等) で `data-src` を使った遅延読み込み (`lazyload`) により Google Maps およびインドアビューの `iframe` を表示している

データの出どころ (2026-11-17):

- 店舗データ: 株式会社ネクステージ自社管理の店舗情報
- 背景地図: Google (Google Maps 埋め込み)
