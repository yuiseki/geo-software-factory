# OpenSeaMap

- URL: https://openseamap.org
- ソース: https://github.com/OpenSeaMap (各種ツール・ウェブUIを公開)
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: OpenSeaMap、海図、航海図、ブイ、灯台、港湾、水深、OpenStreetMap、OpenLayers

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ブイ・灯台・航路標識・港湾施設・水深などの航海情報を OpenStreetMap 上に重ねて表示する無料のオープンソース海図プロジェクト |
| 提供する価値 | 高価な商用電子海図に頼らず、世界中の港湾や航路標識、クラウドソーシングによる水深情報を自由な海図オーバーレイとして閲覧・利用できる |
| 想定する利用者 | ヨット・プレジャーボートの操縦者、マリンスポーツ愛好家、海洋研究者、OpenStreetMap の海図マッパー |
| 商用か非商用か | 非商用 (OpenStreetMap のサブプロジェクトとしてボランティア開発者チームが運営する非営利プロジェクト。公開タイルはコミュニティ利用向け) |
| 推定の売上 | なし (非商用プロジェクト) |
| 運営 | コミュニティ (Team of OpenSeaMap、国際ボランティア開発者コミュニティ) |
| 推定の運用費 | 推測: 月数万円規模。海図オーバーレイタイルサーバーや水深データ収集基盤をコミュニティおよびパートナーの支援で維持している |
