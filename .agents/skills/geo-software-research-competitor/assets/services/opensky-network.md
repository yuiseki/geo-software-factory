# OpenSky Network

- URL: https://opensky-network.org
- ソース: https://github.com/opensky-network (GPL 等、解析ツールやクライアント群を公開)
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: OpenSky Network、ADS-B、Mode S、航空研究、オープンデータ、フライト追跡、スイス、非営利、REST API

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中のボランティア受信機から集めた生の航空機 ADS-B / Mode S データを学術研究や非営利用途向けに公開する非営利ネットワーク |
| 提供する価値 | 商用フライト追跡サイトでは省かれがちな生の航空管制通信信号や履歴アーカイブを、研究者・教育機関が REST API やデータベース経由で無償利用・再現研究に活用できる |
| 想定する利用者 | 航空交通・通信セキュリティ・気候影響の研究者、大学・教育機関、非営利の航空機データ調査者、ADS-B 受信機を運用するボランティア |
| 商用か非商用か | 非商用・研究向け無料 (研究・教育・非営利・政府機関は原則無料。ただし営利企業の利用や実運用サービスへの REST API 組み込みは事前の書面ライセンス契約が必要) |
| 推定の売上 | 非営利 (公的研究助成金、寄付、商用ライセンス料等で運営。具体的な収支規模は非公開) |
| 運営 | 非営利団体 (OpenSky Network Association、スイス民法第60条に基づく非営利社団法人) |
| 推定の運用費 | 推測: 月数十万円〜数百万円規模 (欧州の研究機関サーバー基盤上で膨大なリアルタイム ADS-B / Mode S ストリームと履歴アーカイブを維持) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet および Google Maps (応答内のバンドル `/static/bundle/main-SC4FRZKY.js` から `leaflet` と `google_maps` の双方を検出) |
| フレームワーク | モダン JavaScript バンドル (`/static/bundle/main-SC4FRZKY.js` を確認) |
| 背景の地図とタイル | OpenStreetMap / Google Maps ベースマップ |
| 投稿やデータの保存先 | OpenSky 自身の研究用データアーカイブ基盤 (履歴クエリ用の分散データベース等) |
| 配信 | 自前サーバー / リバースプロキシ (2026-11-16 の応答ヘッダーは最小限) |

メモ:

- 公式の専用 iOS / Android アプリは提供されていない (REST API を利用したサードパーティ製アプリが存在)。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 航空機 ADS-B / Mode S 信号 | 世界中のボランティア受信機ネットワーク (Raspberry Pi / dump1090 等) | 公式サイト・About |
