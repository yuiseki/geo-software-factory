## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のオリックスレンタカー店舗を都道府県・駅・空港から検索し、店舗情報や地図アクセスを確認して予約できる公式サイト |
| 提供する価値 | 出発予定地の周辺店舗や空港・駅近くの営業所を探し、営業時間・車種・アクセスを確認してそのままオンライン予約できる |
| 想定する利用者 | 旅行・帰省・ビジネス等でレンタカーを利用したい個人および法人顧客 |
| 商用か非商用か | 商用 (自社レンタカー事業への予約送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。運営元であるオリックス自動車株式会社全体の売上高は 3,680 億 7,000 万円 (2025 年 3 月期、オートリース・カーシェア事業を含む) |
| 運営 | 企業 (オリックス自動車株式会社 / オリックス株式会社 100% 子会社) |
| 推定の運用費 | 推測: 月数十万円。Web サーバー運用費に加え、店舗検索・地図連携に用いる NAVITIME Location Cloud (法人向け店舗検索 ASP) の利用料がかかる |
