# Polarsteps

- URL: https://www.polarsteps.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Polarsteps、旅行記録、GPSトラッキング、旅程表、旅ログ、フォトブック、世界地図、Mapbox

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 旅行中の移動ルートをバックグラウンド GPS で自動記録し、写真やメモとともに美しい世界地図上のタイムラインとして残し共有できるトラベルログサービス |
| 提供する価値 | バッテリー消費を抑えつつオフライン環境でも移動軌跡を自動記録でき、旅の思い出を家族や友人とリアルタイム共有したり、ワンクリックで印刷製本の旅行記 (Travel Books) にできる |
| 想定する利用者 | バックパッカー、長期旅行者、海外旅行の移動軌跡と写真を地図上に美しく残したい一般旅行者 |
| 商用か非商用か | 商用 (基本の記録・共有機能は無料。物理フォトブック「Travel Books」の販売、および有料プラン Polarsteps Plus 月額約 €8.99 / 年額約 €29.99 で収益化) |
| 推定の売上 | 約1,000万ドル規模 (経営陣による過去の報道インタビューでのマイルストーン公表値) |
| 運営 | 企業 (Polarsteps B.V.、オランダ・アムステルダム) |
| 推定の運用費 | 推測: 月数百万円規模。2,000万人超の利用者向け GPS ログ・写真ストレージ配信、Mapbox SDK、印刷パートナー (Peecho 等) 連携の運用 |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (トップ LP からは直接観測不可。Mapbox の公式導入事例ではモバイル・Web 向けに Mapbox Maps SDK を採用し、オフラインキャッシュや 3D 地形表示を実現していると報告されている) |
| フレームワーク | Framer (LP スクリプト `events.framer.com/script?v=2` を確認) + `uvicorn` |
| 背景の地図とタイル | 未確認 (LP からは直接のタイル通信先は未確認。公開事例では Mapbox を利用) |
| 投稿やデータの保存先 | Polarsteps 自社基盤 (ユーザーの移動軌跡・写真・ステップデータ) |
| 配信 | `server: uvicorn` (LP 応答ヘッダーを確認) |

メモ:

- `https://www.polarsteps.com` のトップページは Framer 製のマーケティング LP で、アプリ本体とは分離されているため地図ライブラリはトップ HTML から直接観測できなかった。
- ウェブ版のほか iOS / Android アプリも提供されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 旅行ルート・写真・ガイド | ユーザー投稿および Polarsteps 編集コンテンツ | Polarsteps 公式サイト |
| ベースマップ・3D 地形・オフライン地図 | Mapbox (公開導入事例による。直接通信は未確認) | Mapbox 公式ケーススタディ |
