# ポプラ 店舗検索

- URL: https://www.poplar-cvs.co.jp/shop_search/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ストアロケーター、店舗検索、ポプラ、生活彩家、コンビニ、ポプ弁、Google マイマップ、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ポプラおよび生活彩家などの店舗を、地域や Google マイマップ上から探せる公式店舗検索ページ |
| 提供する価値 | 中国地方や首都圏などに展開するポプラグループ店舗の位置や営業情報、ポプ弁・ATM などの取扱状況を確認できる |
| 想定する利用者 | ポプラ・生活彩家の店舗を探している一般客、周辺のコンビニを探している利用者 |
| 商用か非商用か | 商用 (ポプラグループ店舗への来店送客のための公式案内。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ポプラ) |
| 推定の運用費 | 推測: 月数千円〜数万円。Google マイマップ埋め込みと自社 Web サーバー (nginx) の運用費のみ |
