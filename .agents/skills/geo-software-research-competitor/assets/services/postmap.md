# ポストマップ

- URL: https://www.postmap.org/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ポストマップ、postmap、郵便ポスト、取集時刻、株式会社モーフ、Mowof、MapLibre、国土地理院、OpenStreetMap、クラウドソーシング地図

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本全国の郵便ポストの位置、取集時刻、投函口数、写真などをユーザー投稿で共有する老舗の郵便ポスト地図サービス |
| 提供する価値 | 公式には一覧化されていなかった全国の郵便ポストの正確な場所と集荷時間を地図から検索でき、外出先で今すぐ投函できるポストを探せる |
| 想定する利用者 | 郵便物を急いで出したい一般利用者、郵便局・物流関係者、地域のマッピングを楽しむ投稿者（マッパー） |
| 商用か非商用か | 商用・コミュニティ運営（基本無料。Web 版の Google AdSense 等の広告収益と、運営会社の他事業と合わせて維持） |
| 推定の売上 | 推測: 年数十万〜数百万円規模（広告掲載による運営維持が中心で、個人開始後に株式会社モーフが引き継いで長期運用） |
| 運営 | 企業（株式会社モーフ / Mowof, Inc.。2006 年に個人サイトとして開始され、のちに法人へ引き継ぎ） |
| 推定の運用費 | 推測: 月数万円程度（AWS CloudFront 配信と地理院タイル・OSM 等の無償ベースマップ活用により、大規模 POI サイトながらコストを抑制） |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | MapLibre（Web 地図画面では MapLibre を用いたベクトルタイル表示・地図回転に対応。トップ HTML では jQuery 3.7.1 等を確認） |
| フレームワーク | jQuery + 独自サーバーサイド構成（トップ HTML で `/js/jquery.min.js?3.7.1`、`/js/common.js`、`/js/login.js` を確認） |
| 背景の地図とタイル | 国土地理院の地図、OpenStreetMap 等 |
| 投稿やデータの保存先 | 自前データベース + オブジェクトストレージ（全国のポスト位置・取集時刻・投稿写真を蓄積） |
| 配信 | AWS CloudFront + 自前サーバー（応答ヘッダーで `server: RedPostbox`、`via: 1.1 ...cloudfront.net (CloudFront)` を確認。AdSense と Google Analytics を掲載） |

メモ:

- ウェブ版のほか iOS / Android の公式アプリが提供されており、現地からのポスト検索や新規投稿・情報更新ができる。
- 2006 年から続く日本のユーザー投稿型（UGC）テーマ地図の代表例で、Google Maps 課金改定などを経て地理院・OSM・MapLibre へ移行しながら継続している。
