# QBハウス 店舗検索

- URL: https://www.qbhouse.co.jp/search/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、理容、ヘアカット、10分カット、QBハウス、QB HOUSE、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の QBハウス店舗を都道府県や路線・条件から検索し、待ち時間目安や営業時間を調べられる公式店舗検索ページ |
| 提供する価値 | 駅ナカや商業施設内などの最寄り店舗を素早く見つけ、営業時間や現在の混雑状況を確認して立ち寄れる |
| 想定する利用者 | 短時間でのヘアカットを希望し、外出先や通勤経路の近くで QBハウス店舗を探す一般客 |
| 商用か非商用か | 商用 (実店舗への来店送客のために提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。全国の QBハウス店舗でのヘアカット売上を支える集客導線 |
| 運営 | 企業 (キュービーネット株式会社 / キュービーネットホールディングス株式会社) |
| 推定の運用費 | 推測: 月数万円程度。自社 Web サーバーでの PHP サイト運用費のみで、埋め込み地図 API の従量課金は発生しない構成 |
