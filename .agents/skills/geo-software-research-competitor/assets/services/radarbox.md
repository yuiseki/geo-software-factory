# RadarBox（AirNav Radar）

- URL: https://www.radarbox.com

- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: RadarBox、AirNav Radar、AirNav Systems、フライト追跡、ADS-B、AR 航空機、3D コックピット、ATC 音声

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地上 ADS-B 受信機網と衛星 ADS-B・航空管制データを統合し、リアルタイムの航空機追跡と 3D/AR 表示や管制音声を提供するサービス |
| 提供する価値 | 無料でも過去7日間の履歴や現在位置を確認でき、有料プランでは航空図・気象オーバーレイ、KML/GeoJSON エクスポート、ライブ ATC 音声や AR スキャン機能を利用できる |
| 想定する利用者 | 航空ファン・飛行機撮影者 (スポッター)、パイロット、航空関連事業者、リアルタイム航空データ API を求める企業 |
| 商用か非商用か | 商用フリーミアム (基本追跡と7日間履歴は広告付きで無料。Spotter / Pilot / Business の有料サブスクリプションを提供、Pilot は年額約 $34.99〜) |
| 推定の売上 | 推測: 年数億円〜十数億円規模 (個人向けサブスク、ADS-B 受信機ハードウェア販売、B2B データフィードを展開するが売上は非公開) |
| 運営 | 企業 (AirNav Systems LLC、米国) |
| 推定の運用費 | 推測: 月数百万円以上 (グローバルな地上受信機・衛星 ADS-B フィードの統合処理と高頻度配信、Cloudflare インフラ) |

メモ:

- ブランド名を「RadarBox」から「AirNav Radar」へ変更 (`radarbox.com` は `airnavradar.com` にリダイレクトされる)。
