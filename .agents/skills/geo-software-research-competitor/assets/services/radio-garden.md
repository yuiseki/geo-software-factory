# Radio Garden

- URL: https://radio.garden/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: Radio Garden、ラジオガーデン、世界のラジオ、CesiumJS、3D地球儀、衛星画像、ArcGIS、ネットラジオ

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 3D 地球儀をぐるぐる回して緑の点をクリックするだけで、世界中のリアルタイムなローカルラジオ放送を聴けるサービス |
| 提供する価値 | 言語や国境を意識せず「地球上の位置」から直感的に現地の音楽・ニュース・トークをザッピングでき、音響と地理が結びついた体験を提供する |
| 想定する利用者 | 世界中の音楽や文化に触れたいリスナー、語学学習者、作業用 BGM を探すユーザー、ラジオ愛好家 |
| 商用か非商用か | 商用（基本無料。Web/アプリ内の広告表示と、モバイルアプリでの広告非表示買い切り課金 約 $2.99 で収益化） |
| 推定の売上 | 推測: 年数千万円規模（数百万単位の月間アクティブユーザーを持ち、広告およびアプリ内課金で運営されているが非公開） |
| 運営 | 企業（Radio Garden B.V.、オランダ・アムステルダム。2016 年にオランダ音と映像研究所等の展示プロジェクトとして開始後、法人化） |
| 推定の運用費 | 推測: 月数十万〜百万円規模（音声自体は各局のストリーミング URL へ直接接続するが、4 万局超のメタデータ管理・死活監視と大量トラフィックの配信費がかかる） |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | CesiumJS（3D 地球儀の描画コアとして CesiumJS を採用） |
| フレームワーク | React / Preact 系バンドル（`/assets/b/index-BdJBYT27.js` 内に `react` 関連記述を確認） |
| 背景の地図とタイル | ArcGIS 衛星画像タイル等（CesiumJS 上の地球儀テクスチャとして利用） |
| 投稿やデータの保存先 | 自前バックエンド（40,000 局以上のラジオ局座標・ストリーム URL の登録・検索データベース） |
| 配信 | Cloudflare（応答ヘッダーで `server: cloudflare`、`cf-ray` を確認。AdSense スクリプトを掲載） |

メモ:

- ウェブ版のほか iOS（Radio Garden Live）/ Android（Radio Garden）の公式モバイルアプリが提供されており、バックグラウンド再生にも対応している。
- 2016 年の非営利展示プロジェクトから始まり、バイラルヒットを経て個人/少人数スタジオの Radio Garden B.V. として独立・持続可能化した代表例。
