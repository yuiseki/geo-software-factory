# RainViewer

- URL: https://www.rainviewer.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: RainViewer、雨雲レーダー、降水予測、ナウキャスト、気象レーダー、Weather Radar、台風、気象タイル API

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界 120〜150 か国以上の気象レーダー画像を統合し、リアルタイムの雨雲レーダーと降水予測を提供する地図サービス |
| 提供する価値 | 複数の気象機関のレーダーデータを単一の地図上でアニメーション表示し、数分〜数時間先の雨雪の接近や強度を直感的に把握できる |
| 想定する利用者 | 一般の天気予報利用者、アウトドア・通勤通学者、防災担当者、気象レーダータイルを組み込みたい小規模・個人開発者 |
| 商用か非商用か | 商用 (基本機能は無料、有料サブスクリプション Essential / Pro は月額約 $3.99〜$4.99 または年額約 $20〜$22。個人・教育・小規模向けの公開 Weather Maps API も提供) |
| 推定の売上 | 推測: 年数千万円〜数億円規模。iOS / Android アプリは累計 1,000 万ダウンロード以上、アプリ分析では月数万ドル以上の売上が推定されているが、公式の決算は非公開 |
| 運営 | 個人/企業 (Oleksii Schastlyvyi 氏による開発・運営。ウクライナ発) |
| 推定の運用費 | 推測: 月数十万〜数百万円規模。世界各国の気象レーダーデータの継続的な取得・合成・タイル生成と、全世界のモバイルアプリおよび公開 API へのタイル配信を維持している |

メモ:

- ウェブ版のほか iOS / Android アプリを提供している。
- 開発者向けに Weather Maps API (`api.rainviewer.com`) を提供しており、個人・教育・非商用用途では無料で利用できるが、高負荷な商用利用には制限がある。
