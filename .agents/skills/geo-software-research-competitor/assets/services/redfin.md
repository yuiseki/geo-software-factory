# Redfin

- URL: https://www.redfin.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Redfin、Rocket Companies、米国不動産、住宅購入、賃貸、MLS、地図検索、不動産価格推定、学区

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 米国・カナダの売買・賃貸物件を MLS 直結の高頻度更新データと地図検索・価格推定 AI (Redfin Estimate) で探せる大手テクノロジー不動産仲介サイト |
| 提供する価値 | 地図上で学区・通勤時間・価格帯・ポリゴン境界を絞り込みながら、数分おきに更新される MLS の最新物件情報と自動査定額・3D バーチャルツアーを比較し、そのまま低手数料の仲介や住宅ローン相談へ進める |
| 想定する利用者 | 米国・カナダで住宅の購入・売却・賃貸を検討する一般消費者、および自社エージェント・提携エージェント |
| 商用か非商用か | 商用 (検索・地図利用は無料。自社・提携エージェントによる不動産仲介手数料、住宅ローン・タイトル保険等の金融サービス、賃貸・広告掲載料で収益化) |
| 推定の売上 | 約10.4億ドル (2024年実績、Redfin Corporation) |
| 運営 | 企業 (Redfin Corporation、米国ワシントン州シアトル、Rocket Companies 傘下) |
| 推定の運用費 | 推測: 年数百億円規模。米国・カナダ全土の MLS データ統合パイプライン、数千万 MAU 向けの検索・AI 査定基盤、CloudFront / AWS WAF の運用 |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (`https://www.redfin.com` は HTTP 405 Human Verification のため直接観測不可) |
| フレームワーク | 未確認 (HTTP 405 のため HTML/JS の直接観測不可) |
| 背景の地図とタイル | 未確認 (HTTP 405 のため直接のタイル通信先は未確認) |
| 投稿やデータの保存先 | Redfin 自社基盤 (全米 MLS 物件フィード、過去の成約価格、学区・ハザード・相場データ) |
| 配信 | Amazon CloudFront + AWS WAF (`server: CloudFront`、`token.awswaf.com` / `captcha.awswaf.com` による Human Verification・HTTP 405 を確認) |

メモ:

- 2026-11-16 時点の HTTP 観測では AWS WAF のボット検証 (`HTTP 405 Human Verification`) が返却されたため、フロントエンドの地図ライブラリは直接観測できていない。
- ウェブ版のほか iOS / Android アプリも提供されている。
