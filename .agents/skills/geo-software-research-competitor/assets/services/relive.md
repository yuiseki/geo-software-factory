# Relive

- 概要と収支を確かめた日: 2026-11-16

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | サイクリングやランニング、登山の GPS 軌跡と写真を 3D 地形上のフライオーバー動画に変換して共有できるアプリ |
| 提供する価値 | Garmin や Apple Health 等と連携して記録した移動データを、衛星写真と立体地形の上を飛び回るリッチな 3D 動画ストーリーとして数分で自動生成できる |
| 想定する利用者 | サイクリスト、ランナー、ハイカー、スキーヤー、SNS でアクティビティを共有したい一般ユーザー |
| 商用か非商用か | 商用 (基本機能は無料。有料プラン Relive Plus は月額約 $6.99 / 年額約 $38.99 で、HD 動画・BGM・写真最大 100 枚・12 時間超の記録・インタラクティブ 3D 探索等を提供) |
| 推定の売上 | 推測: 年数億〜十数億円規模 (アプリ市場分析で月間数十万ドル規模のサブスクリプション収益が推定されている。非上場のため公式決算は非公開) |
| 運営 | 企業 (Relive B.V.、オランダ。2016 年に Lex Daniels 氏らが創業) |
| 推定の運用費 | 推測: 月数百万円規模 (3D 動画のクラウドレンダリング基盤、Esri 等の衛星画像・地形データの利用料、世界中のユーザー動画ストレージを維持) |
