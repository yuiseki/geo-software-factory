# 三井のリパーク 駐車場検索

- URL: https://www.repark.jp/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、駐車場検索、コインパーキング、時間貸駐車場、三井のリパーク、三井不動産リアルティ、Google Maps、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国約 16,000 カ所の時間貸駐車場「三井のリパーク」を地域・駅・地図から検索し、料金や満空状況を確認できる公式検索サイト |
| 提供する価値 | 目的地周辺のリパーク駐車場の空き状況、時間帯別料金、最大料金、車両サイズ制限を確認し、安心して駐車できる |
| 想定する利用者 | 車での移動中にコインパーキングを探す一般ドライバー、月極駐車場や駐輪場を探す利用者 |
| 商用か非商用か | 商用 (全国のリパーク駐車場への送客・稼働率向上および土地活用オーナー募集のために提供。利用料は無料) |
| 推定の売上 | 推測: 駐車場検索サイト単体の売上は 0 円。運営元である三井不動産リアルティ株式会社全体の連結売上高は 2,105 億 1,600 万円 (2025 年度、リハウス・リパーク事業を含む) |
| 運営 | 企業 (三井不動産リアルティ株式会社 / 三井不動産 100% 子会社) |
| 推定の運用費 | 推測: 月数十万円。Amazon CloudFront + Apache の運用費に加え、事前調査で確認された Google Maps API の利用料がかかる |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (2026-11-17 の `https://www.repark.jp/` および `/app/search/` の `curl` 観測では地図検索結果画面の JS 読み込みまで未到達。事前調査では Google Maps を確認) |
| フレームワーク | jQuery + 独自スクリプト (`/js/map.js` はトップの都道府県マップ選択用 UI スクリプト) |
| 背景の地図とタイル | 未確認 (事前調査では Google Maps を使用していることを確認) |
| 投稿やデータの保存先 | 三井不動産リアルティ自社駐車場基盤 (全国約 16,000 カ所・約 259,000 台の駐車場マスタおよび満空データ) |
| 配信 | Amazon CloudFront + Apache 2.4.69 (`server: Apache/2.4.69 (Amazon Linux)`、`via: ...cloudfront.net (CloudFront)`) |

メモ:

- トップページ (`https://www.repark.jp/`) や `/parking_user/time/` の `/js/map.js` は日本地図イラストのエリア選択 UI 用スクリプトであり、実地図検索は `/app/search/` 側の検索実行後の結果ページに組み込まれている (事前調査で Google Maps を確認)。
