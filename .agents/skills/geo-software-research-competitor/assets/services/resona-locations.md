## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | りそな銀行およびグループ銀行 (埼玉りそな銀行・関西みらい銀行・みなと銀行) の店舗・ATM を地図や条件から検索できる公式案内サイト |
| 提供する価値 | 現在地付近や指定エリアの店舗・ATM を探し、窓口の営業時間、住宅ローン・相続などの相談対応、ATM 稼働時間を確認できる |
| 想定する利用者 | りそなグループの口座保有者、窓口での資産相談や手続き、近くの ATM 利用を希望する一般利用者 |
| 商用か非商用か | 商用 (銀行利用者の利便性向上および店舗窓口・相談予約への送客基盤として提供。利用料は無料) |
| 推定の売上 | 推測: 検索サイト単体の売上は 0 円。個人・法人向け金融サービスの相談予約や顧客接点維持に貢献 |
| 運営 | 企業 (株式会社りそな銀行) |
| 推定の運用費 | 推測: 月数十万円。Google Maps Platform の利用料および Akamai WAF / CDN の配信費がかかる |
