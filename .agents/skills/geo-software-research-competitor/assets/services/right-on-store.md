- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、ジーンズ、カジュアル衣料、ライトオン、Right-on、ワールド、WORLD、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ジーンズ・カジュアル衣料「ライトオン (Right-on)」の実店舗を、ワールド公式オンラインストア上の店舗検索機能から探せる公式ストアロケーター |
| 提供する価値 | ライトオン各店舗の所在地、営業時間、店舗受取やクーポン対象店舗などの条件をワールド EC 基盤上で横断検索できる |
| 想定する利用者 | ジーンズやカジュアルウェアの購入、オンライン注文の店舗受取でライトオン店舗へ来店する一般客 |
| 商用か非商用か | 商用 (実店舗への来店送客およびワールドオンラインストアの店舗受取・在庫連携として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗売上および EC 送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社ライトオン / 株式会社ワールドのオンラインストア基盤上で提供) |
| 推定の運用費 | 推測: 月数十万円。Akamai CDN/WAF を含むワールドオンラインストア基盤の運用費および Google Maps API の利用料がかかる |
