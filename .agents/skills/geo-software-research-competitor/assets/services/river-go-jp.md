# 川の防災情報

- URL: https://www.river.go.jp
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 川の防災情報、国土交通省、河川水位、雨量、ダム放流、河川カメラ、水害、洪水、地理院タイル

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本全国の河川の水位、雨量、ダムの放流状況、河川ライブカメラ映像などをリアルタイムに地図上で確認できる国土交通省のポータル |
| 提供する価値 | 台風や豪雨の際に、身近な河川の現在水位や氾濫危険水位との比較、上流の雨量・ダム放流状況、現地の河川カメラ映像を一元的に把握できる |
| 想定する利用者 | 一般市民、自治体・水防担当者、建設・インフラ関係者、報道機関 |
| 商用か非商用か | 非商用 (国土交通省が公共の防災サービスとして無料で提供) |
| 推定の売上 | なし (国の行政機関による無償の防災情報サービス) |
| 運営 | 公的機関 (国土交通省) |
| 推定の運用費 | 推測: 年間数億円規模 (全国の水位計・雨量計・ダム・河川カメラからのテレメータ収集と Akamai 等の CDN による高負荷対応配信を維持) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (JavaScript バンドルによる WebGIS 実装。CSP ヘッダーで外部タイル・画像接続を確認) |
| フレームワーク | 未確認 |

| 投稿やデータの保存先 | 国土交通省の河川情報基盤および河川カメラ配信サーバー (`cam.river.go.jp` を CSP ヘッダーで確認) |
| 配信 | Akamai 等の CDN 経由 (CSP ヘッダーに `akamaihd.net`、`akamaiapis.net`、`go-mpulse.net` の記述を確認) |

メモ:

- 専用のネイティブアプリ (iOS / Android) はなく、スマートフォンでも利用可能なレスポンシブ Web サービスとして提供されている。

|---|---|---|
