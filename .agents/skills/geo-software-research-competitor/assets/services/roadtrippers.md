## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ドライブ旅行やキャンピングカー旅のルートを作成しながら、道沿いの絶景スポット・奇岩・ダイナー・キャンプ場などの寄り道先を地図上で探せるトリッププランナー |
| 提供する価値 | 出発地と目的地を結ぶルート周辺のユニークな立ち寄りスポットを自動提案し、RV の車高・重量制限を考慮したナビゲーションやオフライン地図と連携できる |
| 想定する利用者 | 北米を中心にドライブ旅行やロードトリップを楽しむ旅行者、RV・キャンピングカー利用者 |
| 商用か非商用か | 商用 (フリーミアム。無料プランは経由地数などに制限あり。有料プランは月額約 $19.99 / 年額約 $59.99 程度のサブスクリプション、および提携アフィリエイト収入で運営) |
| 推定の売上 | 未確認 (非公開企業。推測: 年数百万〜1,000万ドル規模) |
| 運営 | 企業 (TH2Connect, LLC d/b/a Roadpass Digital、TN-RP Holdings, LLC 傘下・米国) |
| 推定の運用費 | 推測: 月数百万円規模。POI データベース (Campendium 等の RV データ含む)、Mapbox のルーティング・ナビゲーション API、Cloudflare / WP Engine の運用 |

メモ:

- トップページ (`https://roadtrippers.com`) は HTTP 200 を返すが、地図プランナー本体や詳細 API のタイル配信先はトップ HTML からは直接観測できなかった。
- ウェブ版のほか iOS / Android アプリ (Apple CarPlay 対応) も提供されている。
