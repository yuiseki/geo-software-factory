# Rome2Rio

- URL: https://www.rome2rio.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Rome2Rio、Omio、経路検索、マルチモーダル、乗り換え案内、国際移動、電車、バス、フェリー、Google Maps

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中のあらゆる都市・地点間の移動手段 (飛行機・鉄道・バス・フェリー・車) を組み合わせて経路・所要時間・概算運賃を地図上で比較できるマルチモーダル経路検索サービス |
| 提供する価値 | 鉄道・長距離バス・航空・フェリーなど国境や事業者をまたぐ複雑な移動ルートを、地図上の路線図とあわせて一括比較し、そのまま予約サイトへ進める |
| 想定する利用者 | 海外旅行者、バックパッカー、複数都市を周遊する移動計画者、公共交通の接続を調べたい旅行者 |
| 商用か非商用か | 商用 (利用者は無料。提携交通機関・OTA への送客アフィリエイト手数料、親会社 Omio 経由のチケット直販手数料、広告・DMO スポンサー収入で運営) |
| 推定の売上 | 未確認 (親会社 Omio グループは非上場のため売上非公開だが、グループ全体の年間チケット取扱高は10億ドル超・EBITDA 黒字化を公表) |
| 運営 | 企業 (Rome2Rio Pty Ltd、オーストラリア発・ドイツ Omio グループ傘下) |
| 推定の運用費 | 推測: 月数百万円〜数千万円規模。世界中の時刻表・運賃・GTFS データの収集・正規化、経路探索エンジン、Google Maps Platform API、Cloudflare の運用 |
