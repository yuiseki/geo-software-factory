# 路線価図・評価倍率表

- URL: https://www.rosenka.nta.go.jp
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 路線価図、評価倍率表、財産評価基準書、国税庁、相続税、贈与税、地価、PDF地図

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 相続税や贈与税における土地評価の基準となる全国の路線価図および評価倍率表を年度別に公開する国税庁の公式サービス |
| 提供する価値 | 毎年7月1日に更新される全国の道路ごとの1平方メートルあたりの評価額 (路線価) を、市区町村・町名索引から正確な公的図面 (PDF) として確認できる |
| 想定する利用者 | 税理士、不動産鑑定士、宅地建物取引業者、相続や土地評価を行う一般市民 |
| 商用か非商用か | 非商用 (国税庁が行政情報として無料で提供) |
| 推定の売上 | なし (国の行政機関による無償の情報公開) |
| 運営 | 公的機関 (国税庁) |
| 推定の運用費 | 推測: 年間数千万円規模 (全国分の静的な HTML・PDF 図面ファイルの生成と、毎年7月の公開時のアクセス集中に耐える CloudFront 配信の維持費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 静的 HTML の一覧と PDF 図面 (インタラクティブなスリッピーマップではなく、地域索引ページから路線価図 PDF を開く形式) |
| フレームワーク | なし (静的 HTML 構成) |
| 背景の地図とタイル | 路線価図 PDF 内の住宅地図・道路図 (インタラクティブタイル配信はなし) |
| 投稿やデータの保存先 | なし (国税庁の静的ファイル配信のみ) |
| 配信 | Apache + Amazon CloudFront (`server: Apache`, `via: 1.1 *.cloudfront.net` を一次観測の応答ヘッダーで確認) |

メモ:

- 専用の iOS / Android アプリは提供されていない。
- 国税庁のホームページに掲載されているのは直近数年分 (約7年分) であり、それ以前の古い路線価図は国立国会図書館デジタルコレクション等で閲覧できる。
