# ラウンドワン 店舗検索・店舗案内

- URL: https://www.round1.co.jp/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: 店舗検索、ラウンドワン、ROUND1、スポッチャ、ボウリング、カラオケ、アミューズメント、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のラウンドワン店舗をエリア別ページから探し、ボウリング・スポッチャ・カラオケ等の営業時間やアクセス地図を確認できる公式サイト |
| 提供する価値 | 都道府県ごとの店舗一覧から各店舗ページへ進み、営業時間、無料シャトルバスの案内、駐車場や周辺の地図をまとめて確認できる |
| 想定する利用者 | ボウリング、スポッチャ、アミューズメント、カラオケなどの利用でラウンドワン店舗への来店を予定している学生・ファミリー・一般客 |
| 商用か非商用か | 商用 (全国のラウンドワン各店舗への来店集客および予約・アプリ誘導のために提供。利用料は無料) |
| 推定の売上 | 推測: 店舗案内単体の売上は 0 円。アミューズメント施設利用料や飲食等の店舗売上に貢献 |
| 運営 | 企業 (株式会社ラウンドワン) |
| 推定の運用費 | 推測: 月数万〜数十万円。nginx Web サーバーでの配信費が中心で、地図は Google マップの無料埋め込み `iframe` を利用しているため地図 API 課金は抑えられている |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps Embed (`iframe` による `https://maps.google.co.jp/maps?output=embed&t=m&hl=ja&...` を各店舗詳細ページに埋め込み) |
| フレームワーク | jQuery + Swiper / Masonry |
| 背景の地図とタイル | Google マップ (Embed iframe) |
| 投稿やデータの保存先 | 自社管理の静的店舗 HTML ページ (`/shop/area01.html`、`/shop/tenpo/<store>.html`) |
| 配信 | nginx (`server: nginx`) |

メモ:

- `/shop/` 自体は一覧ページへの誘導のみで、実際の店舗一覧は `/shop/area01.html` 等、店舗詳細は `/shop/tenpo/hokkaidou-asahikawa.html` 等の静的 HTML として提供されている
- 個別店舗ページ内に `https://maps.google.co.jp/maps?output=embed&...` の `iframe` が埋め込まれていることを確認した

データの出どころ (2026-11-17):

- 店舗データ: 株式会社ラウンドワン自社管理の店舗情報
- 背景地図: Google マップ (iframe 埋め込み)
