## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のロイヤルホスト店舗を、エリア・キーワード・現在地から検索し、店舗詳細ページで地図を確認できる公式店舗検索サイト |
| 提供する価値 | ロイヤルホスト各店の営業時間、住所、駐車場や設備情報とあわせて店舗位置を地図で確認でき、来店計画が立てやすい |
| 想定する利用者 | ロイヤルホストを利用したい一般客、最寄り店舗や設備条件を確認したい利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (ロイヤルフードサービス株式会社) |
| 推定の運用費 | 推測: 月数万〜数十万円。CloudFront 配信および Next.js サーバーの運用費に加え、Google Maps の利用料がかかる |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
