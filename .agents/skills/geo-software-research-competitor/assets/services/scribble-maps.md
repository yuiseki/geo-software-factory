# Scribble Maps

- URL: https://www.scribblemaps.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Scribble Maps、手描き地図、Google Maps、敷地境界、交通量、人口統計、空間解析、地図共有

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | Google マップ等の地図上に手描きや図形描画、敷地境界・交通量・統計データの重ね合わせ、AI による地図作成が行える Web 地図プラットフォーム |
| 提供する価値 | ブラウザだけで直感的に地図へ落書き・注釈・距離面積計測・等時圏/バッファ解析ができ、不動産・都市計画向けの各種主題データをワンクリックで追加して共有できる |
| 想定する利用者 | 不動産・建設・測量関係者、イベント・防災計画担当者、教育関係者、営業エリアマップを作りたいビジネス利用者 |
| 商用か非商用か | 商用フリーミアム (無料プランあり。Pro Basic 月額 $19 / 年払換算月 $14、Business / Enterprise 月額 $100〜 等) |
| 推定の売上 | 推測: 年数億円規模 (2009年創業の独立 SaaS として法人・教育・不動産分野向けに有料サブスクリプションを展開) |
| 運営 | 企業 (Scribble Maps / カナダ拠点、CEO: Jonathan Wagner) |
| 推定の運用費 | 推測: 月数十万円〜数百万円 (Google Maps Platform API の利用料、空間データライセンス、クラウドインフラ) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps JavaScript API ベースのカスタム描画・空間解析エンジン (Google Maps Platform 公式導入事例として公開) |
| フレームワーク | 未確認 (2026-11-16 の観測では `/ja` へリダイレクトされ、クライアントスクリプトの詳細は未抽出) |
| 背景の地図とタイル | Google Maps (地図、衛星写真、3D タイル等) および各種オーバーレイ |
| 投稿やデータの保存先 | Scribble Maps クラウドおよび Google Drive / Google Sheets 連携 |
| 配信 | Cloudflare (`server: cloudflare` を応答ヘッダーで確認) |

メモ:

- 専用の iOS / Android ネイティブアプリは提供されていないが、スマートフォン・タブレットのブラウザ向けに軽量化されたモバイル編集 UI を提供している。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 背景地図・ジオコーディング | Google Maps Platform | Google Cloud 公式事例およびサービス画面 |
| 主題データ (境界・交通量・人口・土壌等) | 各種公的・商用データセット (主に北米等) およびユーザーデータ | トップページの説明 |
