| 項目 | 内容 |
|---|---|
| 一行で | 北海道を中心に展開するセイコーマートの店舗を、地域や設備条件からリスト形式で検索できる公式店舗検索サイト |
| 提供する価値 | 営業時間、ホットシェフや酒・たばこ取扱などの条件で店舗を絞り込み、各店舗の詳細や Google マップへの導線を確認できる |
| 想定する利用者 | セイコーマートの店舗を探している一般客、旅行者、周辺でホットシェフ取扱店を探している利用者 |

| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社セコマ) |
| 推定の運用費 | 推測: 月数千円〜数万円。埋め込み地図 API を使わない PHP ベースの自社サーバー運用費が中心 |
