## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 東京23区の地点ごとに、歩いて行ける飲食店と小売店の多さ、使える路線、主要駅までの時間から利便性のスコアを示す地図 |
| 提供する価値 | 住む場所の候補を、店の集まりと交通の便の数字で比べられる |
| 想定する利用者 | 東京で住む場所を探す人 |
| 商用か非商用か | 非商用 (広告、寄付、有料プランは見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 個人 (KIRIN、X のアカウント) |
| 推定の運用費 | 推測: 0 円。Cloudflare Pages の静的配信で、データはどれも公開されたもの (下の「データの出どころ」) を手元で加工してテキストのファイルにして配る。航空写真は地理院から直接読む |

## 技術 (2026-11-12 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet 1.9.4 |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | 既定は背景の地図のタイルを読まない。道路 (国土地理院 道路中心線)、川 (河川中心線)、駅と線形、区界などを自前のデータから canvas に描くと見られる。「航空写真」を選ぶと地理院の全国最新写真 (`seamlessphoto`) |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | Cloudflare |

メモ:

- 自前のデータをテキストのファイルで読む (`bldg.txt`、`major.txt`、`rgraph.txt`、路線ごとの `t_<key>.txt`。2026-11-12 にページの HTML で確かめた)
- 画面に「パスワード」のボタンがある (用途は未確認)

データの出どころ (画面の最下部の表示、2026-11-12):

| データ | 出どころ |
|---|---|
| 統計 (店の集積) | 経済センサス-活動調査 (2021) |
| 道路 | 国土地理院 道路中心線 |
| 航空写真 | 国土地理院 全国最新写真 (シームレス) |
| 川 | 国土地理院 河川中心線 |
| 道路名、建物名 | © OpenStreetMap contributors |
| 駅、線形 | Mini Tokyo 3D |
| 乗降客数 | 国土数値情報 |
| 町丁目、住所 | 国土交通省 位置参照情報 |
| 区界 | JapanCityGeoJson |

公的なデータ、OSM、OSS のプロジェクト (Mini Tokyo 3D、JapanCityGeoJson) のデータを組み合わせて、店の集まり、路線、主要駅までの時間を出している。各データのライセンス (OSM の ODbL など) と、組み合わせたときの条件は確かめていない
