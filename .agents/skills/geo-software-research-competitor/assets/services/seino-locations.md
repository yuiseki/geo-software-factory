# 西濃運輸 営業所検索

- URL: https://www.seino.co.jp/seino/branch/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 営業所検索、拠点検索、西濃運輸、カンガルー便、支店、営業所止め、路線便、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の西濃運輸の支店・営業所を都道府県や住所・地図から検索できる公式拠点検索サイト |
| 提供する価値 | 路線便やカンガルー便の営業所止め受け取り、持ち込み発送に対応した最寄りの支店・営業所の所在地と連絡先を確認できる |
| 想定する利用者 | 西濃運輸の営業所止めや持ち込み発送を利用する法人・個人顧客、トラックドライバー |
| 商用か非商用か | 商用 (西濃運輸の貨物輸送サービスの拠点案内として提供。利用料は無料) |
| 推定の売上 | 推測: 拠点検索単体の売上は 0 円。貨物輸送・営業所止めサービスの利便性向上に貢献 |
| 運営 | 企業 (西濃運輸株式会社) |
| 推定の運用費 | 推測: 月数万〜数十万円。自社 Web サーバー (nginx) の運用費とゼンリンデータコムの法人向け地図利用料がかかる |
