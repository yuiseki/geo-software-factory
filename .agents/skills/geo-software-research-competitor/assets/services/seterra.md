# Seterra

- URL: https://www.seterra.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Seterra、セテラ、地図クイズ、地理学習、GeoGuessr、白地図、国名クイズ、都道府県クイズ、SVG

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中の国・首都・旗・都市・日本の都道府県などを白地図上のクリックで楽しく覚えられる、400 種類以上の地図クイズサイト |
| 提供する価値 | 多言語対応のインタラクティブな地図クイズと印刷用白地図教材を無料で提供し、学校の地理教育から地理ゲームプレイヤーの学習まで幅広く支える |
| 想定する利用者 | 学生・児童、地理教員、GeoGuessr プレイヤー、地理知識を身につけたい一般利用者 |
| 商用か非商用か | 商用 (Web 版の標準クイズは会員登録不要・無料で利用可能。広告非表示やカスタムクイズ等の拡張機能は GeoGuessr Pro (月額約 $6.99 / 年額換算月 $3.99 程度) に統合) |
| 推定の売上 | 数千万ドル規模 (親会社 GeoGuessr AB 全体として年間数千万ドル規模の売上を計上。Seterra 単体の売上は非公開) |
| 運営 | 企業 (GeoGuessr AB、スウェーデン。Seterra を買収し傘下で運営) |
| 推定の運用費 | 推測: 月数十万円〜数百万円規模 (静的な Next.js アプリと SVG 地図データの CloudFront / S3 配信が中心のため、トラフィックあたりの計算コストは低い) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | SVG + D3.js (HTML 内に `svg` および `d3` の記述を確認。国境や地域パスを SVG で描画してクリック判定を行う構成) |
| フレームワーク | Next.js (`/_next/` のパスを一次観測で検出) |
| 背景の地図とタイル | ベクター白地図 (SVG ベース。タイル地図サーバーには依存しない) |
| 投稿やデータの保存先 | GeoGuessr AB のアカウント・クイズ基盤 |
| 配信 | Amazon S3 + Amazon CloudFront (`server: AmazonS3`, `via: 1.1 *.cloudfront.net` を応答ヘッダーで確認) |
