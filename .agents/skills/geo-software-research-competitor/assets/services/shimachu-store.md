## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 島忠およびホームズ (HOME'S) の店舗を都道府県別に探し、チラシ情報や営業時間を確認できる公式店舗案内サイト |
| 提供する価値 | 都道府県一覧から最寄り店舗のチラシ、営業時間、サービス案内、Google マップへのリンクを素早く確認できる |
| 想定する利用者 | 家具やインテリア、ホームセンター商品の購入で島忠・ホームズへ来店する一般客 |
| 商用か非商用か | 商用 (実店舗への来店送客およびデジタルチラシ閲覧のために提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗売上への送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社島忠 / ニトリホールディングスグループ) |
| 推定の運用費 | 推測: 月数万円。埋め込み地図 API を使わず静的・サーバー生成 HTML で配信しているため運用費は低い |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 埋め込み地図なし (店舗詳細ページ `/shop/tokyo/315.html` 等では `https://goo.gl/maps/...` への外部リンクを掲載) |
