# すかいらーくグループ 店舗検索

- URL: https://store-info.skylark.co.jp/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ストアロケーター、店舗検索、ファミレス、すかいらーく、ガスト、バーミヤン、ジョナサン、しゃぶ葉、営業時間、駐車場、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ガスト・バーミヤン・ジョナサンなどすかいらーくグループの全国店舗を、現在地・エリア・ブランド・設備条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | グループ各ブランドの最寄り店舗の位置、営業時間、駐車場や Wi-Fi などの設備条件を横断して確認でき、来店や宅配・テイクアウトの導線になる |
| 想定する利用者 | すかいらーくグループ各ブランドの利用客、出先で近くのファミリーレストランを探している利用者 |
| 商用か非商用か | 商用 (グループ店舗への来店送客およびテイクアウト・宅配等への導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。グループ実店舗の売上やデリバリー・テイクアウト送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社すかいらーくホールディングス) |
| 推定の運用費 | 推測: 月数十万円。GOGA 店舗検索サービスの利用料と Google Maps Platform の利用料、Google Cloud 側の配信費がかかる |
