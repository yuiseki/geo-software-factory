## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中の観光名所・ビーチ・広場・自然景観などに設置された HD ライブカメラ映像とタイムラプスを配信するライブカメラプラットフォーム |
| 提供する価値 | イタリアやヨーロッパをはじめ世界各地のランドマークの「今」をライブ映像で視聴でき、観光地やホテル等の事業者にはクラウド配信基盤を提供する |
| 想定する利用者 | 旅行検討者・一般視聴者、天気・現地の様子を確認したい人、集客・プロモーションに活用する観光協会やホテル・自治体 |
| 商用か非商用か | 商用 (基本視聴は無料・Google AdSense 等の広告収益モデル。広告非表示等の Go Premium プランや、カメラ設置者向けの有料 Cloud Streaming プランを提供) |
| 推定の売上 | 非公開 (イタリアの非公開企業 VisioRay による運営のため売上高非公開。1億人規模の視聴者を謳い、広告・プレミアム・配信者向け課金で収益化) |
| 運営 | 企業 (VisioRay、イタリア・2005年設立) |
| 推定の運用費 | 推測: 月数百万円以上 (世界中のライブカメラからの常時 HD ストリーミング受信・トランスコード・タイムラプス保存および配信サーバー費用) |
