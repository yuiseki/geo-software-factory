# THE SOUNDING EARTH

- URL: https://musica-terra.com/interactive/the-sounding-earth/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 音楽、世界の音楽、文化圏、地球儀、試聴、音楽史

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地球儀の上の 51 の文化圏に触れると、その土地と時代の音楽 1,806 作品を試聴できるインタラクティブな地図 |
| 提供する価値 | 国境ではなく音楽で分けた地域ごとに、100 年の世界の音楽の流れをたどれる |
| 想定する利用者 | 世界の音楽に関心がある人、音楽の歴史を学ぶ人 |
| 商用か非商用か | 商用 (音楽メディアのサイトの中にあり、Google の広告と i-mobile、logly の広告がある。試聴は Apple Music へつなぐ) |
| 推定の売上 | 推測: サイト全体で月数万〜数十万円の広告。はてなブックマーク 333 件 (2026-11-12)。Apple Music のアフィリエイトの有無は未確認 |
| 運営 | 企業か個人 (Música Terra。運営者の表示は見つからなかった) |
| 推定の運用費 | 推測: 月数千円以下。データは 1.7 MB の JSON 1 本で、試聴の音源とジャケットは Apple の配信元から取るため、配信の費用は小さい |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | three.js |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | 使っていない (4K の地球の画像を three.js の球に貼り、文化圏を塗った画像を重ねる) |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | nginx (静的な配信) |

メモ:

- 地球儀を回して、地域と年代の音楽を聴く作品。地図ライブラリは使っていない
- データは `earth.json` 1 本 (1.7 MB)。文化圏、アルバム (Apple Music の ID つき)、場所、音楽の系譜の線とその出典を持つ
- 試聴の音源は、その場で iTunes Search API の lookup を呼んで `previewUrl` を取り、Web Audio でつないで流す。ジャケットの画像も Apple の配信元から取る

データの出どころ (地図の帰属表示と画面の最下部 500 字、2026-11-12):

- 地図の帰属表示にも画面の最下部にも、データの出典は見えなかった。地図の画面の中に描かれている、別のボタンやページにある、の可能性はある
