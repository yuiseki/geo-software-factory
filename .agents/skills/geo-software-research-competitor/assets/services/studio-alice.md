## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のこども写真館スタジオアリス店舗をエリアや条件から検索し、店舗詳細ページで地図や撮影予約導線を確認できる公式店舗検索ページ |
| 提供する価値 | 自宅近くのスタジオアリス店舗の場所や駐車場・営業時間・取扱衣装サービスを調べ、そのまま撮影予約へ進める |
| 想定する利用者 | お宮参り、七五三、成人式などの記念撮影のために近隣のスタジオアリス店舗を探す家族・保護者 |
| 商用か非商用か | 商用 (実店舗での記念撮影予約および来店送客のために提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。全国のスタジオ店舗での撮影・商品販売売上を支える主要予約導線 |
| 運営 | 企業 (株式会社スタジオアリス) |
| 推定の運用費 | 推測: 月数万円程度。JSTCDN による配信費がかかり、地図表示は店舗詳細の Maps Embed API を中心とした低負荷構成 |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps (店舗詳細 `/shop/1/457/` にて `google.com/maps/embed/v1/place` および `google.com/maps?q=...` へのリンクを確認) |
