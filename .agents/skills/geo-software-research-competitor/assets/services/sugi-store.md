## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のスギ薬局・スギドラッグ・ジャパンなどの店舗を現在地・エリア・調剤対応などの条件から検索し、地図上に表示する公式店舗検索サイト |
| 提供する価値 | 近くの店舗の所在地や営業時間、調剤受付時間、駐車場・キャッシュレス対応などの設備・サービス情報を確認でき、来店や処方箋受付に繋げられる |
| 想定する利用者 | スギ薬局グループの利用客、近くのドラッグストアや処方箋を受け付けている調剤薬局を探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客およびチラシ・調剤サービス案内の導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社スギ薬局) |
| 推定の運用費 | 推測: 月数万〜数十万円。Google Maps Platform の利用料および公式サイトのサーバー運用・CDN 費用がかかる |
