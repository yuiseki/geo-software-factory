## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のすき家店舗を、都道府県・市区町村・条件から検索し、店舗詳細ページで Google マップへのリンクを提供する公式店舗検索サイト |
| 提供する価値 | 近くのすき家店舗の住所・営業時間・ドライブスルーや駐車場の有無を確認し、Google マップ経由で道案内へ進める |
| 想定する利用者 | すき家の店舗を探している一般客、車で立ち寄れる店舗や深夜営業店舗を探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客およびテイクアウト・弁当予約への導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびテイクアウト送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社すき家) |
| 推定の運用費 | 推測: 月数万円程度。埋め込み地図 API を使わず Google マップへの外部リンクのみで構成しているため、地図 API 課金を抑えられる |
