## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 時刻と季節に合わせて、太陽、月、星の下の宇宙から見た地球を描き、デスクトップの壁紙にするアプリ |
| 提供する価値 | 今の昼と夜の境と、最近の衛星画像からの雲を、壁紙として眺められる |
| 想定する利用者 | 宇宙や地球の眺めを好む PC の利用者 (Windows、macOS、Linux) |
| 商用か非商用か | 非商用 (GPLv3 以降の無料のアプリ。広告、寄付は見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 個人か有志 (GitHub の組織 sunlit-earth) |
| 推定の運用費 | 推測: 0 円。紹介のサイトは Cloudflare の静的配信、配布は GitHub Releases。雲の画像の取得は利用者の端末が行う (推測) |
