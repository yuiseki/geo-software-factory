## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のスシロー店舗をエリアや条件から検索し、店舗情報と Google マップへのリンクを案内する公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の住所・営業時間・駐車場の有無などを確認し、Google マップでの位置確認や来店予約へ進める |
| 想定する利用者 | スシローの店舗を探している一般客、家族連れや週末の来店先・お持ち帰り店舗を探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客およびお持ち帰りネット注文等への導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびお持ち帰り注文送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社あきんどスシロー) |
| 推定の運用費 | 推測: 月数万円程度。CloudFront の配信費がかかるが、サイト内埋め込み地図を持たず地図 API 課金を抑えている |
