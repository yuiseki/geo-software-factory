# 食べログ

- URL: https://tabelog.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: 食べログ、tabelog、グルメ、レストラン検索、飲食店マップ、口コミ、予約、地図検索、カカクコム

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ユーザー投稿の口コミ・評点と店舗公式情報をもとに、日本全国の飲食店を検索・地図確認・ネット予約できるグルメサイト |
| 提供する価値 | 駅や現在地周辺の飲食店を地図上で位置確認でき、口コミ点数・写真・予算・空席状況とあわせて店選びから予約まで完結できる |
| 想定する利用者 | 外食先を探す一般消費者・訪日外国人観光客、およびネット予約や集客を行いたい飲食店事業者 |
| 商用か非商用か | 商用 (基本無料、一部プレミアム会員課金あり。飲食店向け有料集客プラン、ネット予約従量課金、広告収入で運営) |
| 推定の売上 | 約 402 億円 (親会社カカクコムの 2026 年 3 月期「食べログ事業」売上収益。2025 年 3 月期は約 335 億円) |
| 運営 | 企業 (株式会社カカクコム、東証プライム上場) |
| 推定の運用費 | 未確認 (全国数十万店舗のデータ・口コミ画像配信、Google Maps API 利用料、Cloudflare CDN の運用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps JavaScript API (`https://tabelog.com/tokyo/A1314/A131401/13136847/dtlmap/` 等の店舗地図ページの HTML 内に `maps.googleapis.com/maps/api/js?v=3&channel=109` の読み込みを確認) |
| フレームワーク | React (検索一覧ページ `https://tabelog.com/tokyo/rstLst/` の HTML 内に React 関連の記述を確認) |
| 背景の地図とタイル | Google Maps (Google Maps JavaScript API による表示) |
| 投稿やデータの保存先 | カカクコム自社基盤 (ユーザー投稿の口コミ・写真、店舗公式情報、予約・空席データ) |
| 配信 | Cloudflare (`server: cloudflare`, `cf-ray` ヘッダーを確認) |

メモ:

- 店舗詳細の地図ページ (`/dtlmap/`) では `maps.googleapis.com/maps/api/js` を読み込んで店舗位置・周辺地図を描画している。
- 配信のフロントには Cloudflare が置かれている。
