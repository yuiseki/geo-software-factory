# Tellus

- URL: https://www.tellusxdp.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Tellus、テルース、衛星データプラットフォーム、JAXA、さくらインターネット、だいち、ASNARO、経済産業省、日本発

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本の政府系衛星データ (JAXA「だいち」等) や商用衛星データをブラウザ・API・クラウド解析環境で手軽に扱える日本発の衛星データプラットフォーム |
| 提供する価値 | 政府のオープン＆フリー衛星データを無料でブラウザ閲覧 (Tellus Traveler / OS) や Python 解析でき、民間衛星データの購入やアルゴリズムのマーケットプレイスも一気通貫で利用できる |
| 想定する利用者 | 日本国内の研究者・学生、衛星データ活用を検証したい企業・スタートアップ、自治体・防災関係者、データサイエンティスト |
| 商用か非商用か | 商用フリーミアム (アカウント登録・政府系オープンデータの閲覧・基本 API・一部解析環境は無料。民間衛星社の高分解能データ購入や高度な計算環境、マーケットプレイスは有料) |
| 推定の売上 | 推測: 年数億円規模 (経済産業省の委託事業や商用衛星データ流通、法人向け環境提供。なお2026年の MBO で設立された株式会社Tellus Global は9億円超の資金調達を実施) |
| 運営 | 企業 (株式会社Tellus。経済産業省事業を端緒にさくらインターネット株式会社から分社化、2026年の MBO により株式会社Tellus Global へ事業承継) |
| 推定の運用費 | 推測: 月数百万円〜数千万円規模 (さくらインターネットのクラウドおよび専用サーバー基盤でのペタバイト級衛星データ保管・配信) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 独自 Web GIS ビューワ (Tellus OS / Tellus Traveler。ポータルサイトでは `/js/index.js` 等を確認。Python 向けには `tellus-traveler` や GeoPandas / Folium / QGIS プラグイン連携を提供) |
| フレームワーク | 未確認 (`tellusxdp.com` トップは独自 JS バンドル `/js/global/global-*.js`, `/js/index.js`) |
| 背景の地図とタイル | 国土地理院タイル / OpenStreetMap 等のベースマップおよび各種衛星データタイル |
| 投稿やデータの保存先 | さくらのクラウド / Tellus クラウド基盤 (JupyterLab 開発環境、データマーケットプレイス) |
| 配信 | nginx + さくらインターネット ELB (`server: nginx`、`via: 1.1 sac-elb` を応答ヘッダーで確認) |

メモ:

- 専用の iOS / Android アプリは提供されていない (Web ブラウザ、JupyterLab、REST API、QGIS プラグイン)。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 政府系衛星・地上データ | JAXA (ALOS/ALOS-2/GCOM 等)、経済産業省 (ASNARO)、気象庁、国土地理院 | Tellus カタログ・公式サイト |
| 商用衛星データ | Maxar、アクセルスペース、パスコ等の民間パートナー | Tellus マーケット・Traveler |
