## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 一般財団法人日本気象協会と株式会社 ALiNK インターネットが共同運営する、市区町村別天気予報・雨雲レーダー・地震・台風情報を提供する気象メディア |
| 提供する価値 | 気象予報士による専門的な解説「日直予報士」や、48 時間先までの無料雨雲レーダー、PM2.5・花粉・熱中症などの生活指数を地図と地域ページで確認できる |
| 想定する利用者 | 一般の天気予報利用者、防災に関心のある市民、アウトドア・通勤通学者 |
| 商用か非商用か | 商用 (Web 版・アプリとも基本無料・広告収益モデル。アプリ内サブスクリプション「tenki.jp ライト」は月額 260 円 (税込) で広告非表示拡大や雨雲接近通知等を提供) |
| 推定の売上 | 約 10 億円規模 (共同運営元の株式会社 ALiNK インターネットの 2026年2月期売上高は 1,015 百万円で、主力の tenki.jp 事業が半期約 3 億円・通期約 6 億円規模を計上。なお日本気象協会全体の売上は 185.3 億円) |
| 運営 | 共同運営 (一般財団法人日本気象協会 + 株式会社 ALiNK インターネット) |
| 推定の運用費 | 推測: 年間数億円規模 (月間数億 PV 規模の高トラフィックを捌く CloudFront / ELB 基盤と気象データ処理・予報士解説制作費) |
