## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 歴史的な写真を見て「撮影された年」と「撮影された場所」の両方を同時に当てる地理・歴史クイズゲーム |
| 提供する価値 | 空間（どこ）だけでなく時間（いつ）の推理を組み合わせることで、風景や服装・車・看板から時代と地域を読み解く独自の知的好奇心を満たす |
| 想定する利用者 | 歴史・写真愛好家、GeoGuessr や日替わりトリビアゲームのプレイヤー、学校・教育現場 |
| 商用か非商用か | 商用（基本無料。iOS アプリ内課金でマルチプレイ・1v1 対戦・カスタムラウンド等を提供） |
| 推定の売上 | 推測: 年数百万〜数千万円規模（日替わりクイズとして人気が高く、App Store でアプリ内課金付きで展開しているが具体額は非公開） |
| 運営 | 法人（iOS App Store 公開名義は TIMEGUESSR LIMITED。Web サイト上には開発者名や About ページを明記していない） |
| 推定の運用費 | 推測: 月数万〜数十万円程度（Google Maps より安価・無料枠の大きい Apple Maps を採用し、写真データの配信と対戦サーバーを維持） |
