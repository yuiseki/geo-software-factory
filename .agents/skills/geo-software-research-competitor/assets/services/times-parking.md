- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、駐車場検索、コインパーキング、時間貸駐車場、タイムズ、Times、タイムズ24、ゼンリンデータコム、いつもNAVI、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の時間貸駐車場「タイムズ」をエリア・駅・施設名から検索し、駐車料金・収容台数・リアルタイム満空情報を地図上で確認できる公式検索サイト |
| 提供する価値 | 目的地の周辺にあるタイムズ駐車場の満車・空車状況、最大料金、車両制限、決済手段を事前に把握し、スムーズに駐車できる |
| 想定する利用者 | 車で外出するドライバー、商業施設や駅周辺の安いコインパーキング・空き駐車場を探す一般利用者 |
| 商用か非商用か | 商用 (自社管理の時間貸駐車場への送客・稼働率向上のために提供。検索利用料は無料) |
| 推定の売上 | 推測: 駐車場検索サイト単体の売上は 0 円。親会社パーク 24 株式会社の連結売上高 4,061 億 6,800 万円 (2025 年 10 月期) の約半分を占める国内駐車場事業の主力集客基盤 |
| 運営 | 企業 (タイムズ 24 株式会社 / パーク 24 グループ) |
| 推定の運用費 | 推測: 月数十万〜百万円規模。駐車場満空情報と連動したサーバー基盤に加え、ゼンリンデータコム「いつもNAVI API v3」の従量課金がかかる |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | ゼンリンデータコム いつもNAVI API v3 (`https://api.its-mo.com/v3/loader?key=...&api=zdcmap.js,control.js,userwidget.js,shape.js` および `/dynamic/js/apps/info/parking/map.js` をエリア詳細ページで確認) |
| フレームワーク | jQuery + jQuery UI + Vue.js (`/common/js/vue.js`) + axios + Seasar/Teeda (`org/seasar/teeda/ajax/js/ajax.js`) |
| 背景の地図とタイル | ゼンリンデータコム (いつもNAVI API v3 / `zdcmap.js` 経由のゼンリン地図タイル) |
| 投稿やデータの保存先 | タイムズ 24 自社駐車場データベース (リアルタイム満空・料金データを API / 動的 JS で連携) |
| 配信 | Apache (`server: Apache`) |

メモ:

- トップページ (`https://times-info.net/`) は都道府県・主要エリアの入口となっており、市区町村・施設別の駐車場一覧ページ (例: `/P13-tokyo/C202/F.../`) に遷移すると `api.its-mo.com/v3/loader` 経由で `zdcmap.js` が読み込まれ、地図上に駐車場ピンと満空状態が描画される。
