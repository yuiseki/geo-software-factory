## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 東急ストアおよびプレッセ等の店舗をエリア・沿線・サービス条件から検索し、店舗ごとの営業時間やチラシ情報を確認できる公式店舗案内サイト |

| 想定する利用者 | 東急ストアを利用する一般客、東急線沿線でスーパーやチラシを探している生活者 |

| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社東急ストア) |
| 推定の運用費 | 推測: 月数万円。Web サーバー (ASP.NET / DotNetNuke 系 CMS) の運用費のみで、外部地図 API の従量課金は発生していない |
