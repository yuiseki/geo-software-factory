# TomTom

- URL: https://www.tomtom.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: TomTom、Orbis Maps、車載ナビ、交通情報、ジオコーディング、ルート検索 API、TomTom GO、Overture Maps

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 車載ナビゲーション向けの地図データ、リアルタイム交通情報、開発者向け位置情報 API/SDK、一般向けナビアプリを提供するオランダの位置情報技術企業 |
| 提供する価値 | 自動車メーカー向けの車載地図・交通情報や、開発者向けの Maps/Routing/Search API、一般ユーザー向けのオフライン対応ナビアプリを一貫して利用できる |
| 想定する利用者 | 自動車メーカー・モビリティ企業、物流・フリート事業者、地図 API を使うアプリ開発者、一般ドライバー (TomTom GO) |
| 商用か非商用か | 商用 (開発者 API はクレジットカード不要の無料枠あり、超過分はリクエスト数に応じた従量課金およびエンタープライズ契約。コンシューマー向けナビアプリはサブスクリプション課金) |
| 推定の売上 | 約 5.55 億ユーロ (2025 年通期のグループ売上実績は €555 million、2024 年は €574 million と公式決算で公表) |
| 運営 | 企業 (TomTom N.V.、オランダ上場企業) |
| 推定の運用費 | 年数億ユーロ規模 (世界中の車載・端末プローブデータの処理、Orbis Maps 基盤の開発、グローバル API インフラおよび R&D 投資を含む) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Web サイト本体はプロモーション・ポータル構成。開発者向けには Maps SDK for Web (MapLibre 互換ベース等) および iOS/Android ネイティブ SDK を提供 |
| フレームワーク | Next.js + React (`x-powered-by: Next.js` 応答ヘッダーおよび `/_next/` 静的チャンクを確認) |
| 背景の地図とタイル | 自前の TomTom Maps / Orbis Maps タイル |
| 投稿やデータの保存先 | 未確認 (一般向けサイト上の保存先インフラ詳細は非公開) |
| 配信 | 未確認 (Next.js サーバーからの応答を確認) |

メモ:

- 開発者・法人向け基盤に加え、一般消費者向けの iOS / Android アプリ（TomTom GO Navigation）が提供されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 地図データ (TomTom Orbis Maps) | TomTom 独自計測車両・自治体データ、Overture Maps Foundation、OpenStreetMap (OSM) 等を統合 | TomTom 公式発表 |
| リアルタイム交通・速度制限 | 数億台のコネクテッドカー・スマートフォン・フリートからの匿名 GPS プローブデータ | TomTom 公式サイト |
