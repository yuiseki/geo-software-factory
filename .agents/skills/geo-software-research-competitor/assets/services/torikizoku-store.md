# 鳥貴族 店舗検索

- URL: https://map.torikizoku.co.jp/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、居酒屋、焼き鳥、鳥貴族、エターナルホスピタリティグループ、営業時間、予約、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の焼き鳥居酒屋「鳥貴族」店舗を、エリア・駅・地図から検索できる公式店舗検索サイト |
| 提供する価値 | 店舗の営業時間、住所、アクセス、予約導線や店舗位置を確認し、来店や席予約へ進める |
| 想定する利用者 | 鳥貴族を利用したい一般客、飲み会や仕事帰りの飲食店を探す人 |
| 商用か非商用か | 商用 (実店舗への来店送客および予約導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社鳥貴族 / エターナルホスピタリティグループ) |
| 推定の運用費 | 推測: 月数万円〜十数万円。株式会社カンリー (Canly) 店舗検索 SaaS の利用料、CloudFront 配信費、および Google Maps API 利用料 |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps (`__NEXT_DATA__` 内に `"mapMapSetting":"google_map"` を確認。事前調査: Google Maps) |
| フレームワーク | Next.js (`x-powered-by: Next.js`、Canly 店舗検索基盤) |
| 背景の地図とタイル | Google マップ |
| 投稿やデータの保存先 | Canly (株式会社カンリーの店舗情報管理 SaaS 基盤) |
| 配信 | Amazon CloudFront (`via: 1.1 ...cloudfront.net (CloudFront)`、`x-cache: Hit from cloudfront`) |

メモ:

- 2026-11-17 の一次 HTTP 取得で、`https://map.torikizoku.co.jp/` は Next.js + CloudFront で配信される Canly ベースの店舗検索サイトであることを確認した
- 同じ Canly 基盤でもフレッシュネスバーガー・リンガーハット・大戸屋が `"mapMapSetting":"leaflet"` であるのに対し、鳥貴族では `"mapMapSetting":"google_map"` (クラスタリング有効) が設定されていることを確認した

データの出どころ (2026-11-17):

- 店舗データ: 株式会社鳥貴族 (Canly 基盤経由)
- 背景地図: Google (`__NEXT_DATA__` の設定および事前調査による)
