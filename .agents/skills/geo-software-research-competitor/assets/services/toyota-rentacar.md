## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のトヨタレンタカー店舗を地図・エリア・駅・空港から検索し、営業時間や貸出車種・予約導線を確認できる公式店舗検索ページ |
| 提供する価値 | 出発地や旅先の駅・空港周辺の店舗位置と営業時間を地図上で素早く見つけ、そのままレンタカー予約へ進める |
| 想定する利用者 | 旅行・出張・引っ越し・ビジネス等でレンタカーを借りたい一般顧客および法人利用者 |
| 商用か非商用か | 商用 (全国のトヨタレンタリース各社店舗への送客・予約基盤として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。地域会社であるトヨタレンタリース各社 (例: トヨタレンタリース大阪 約 388 億円、名古屋 約 341 億円、福岡 約 266 億円) のレンタカー・リース売上を支える公式送客チャネル |
| 運営 | 企業 (トヨタ自動車株式会社 / 全国のトヨタレンタリース各社) |
| 推定の運用費 | 推測: 月数十万〜百万円規模。IIS ベースの予約・店舗基盤運用費に加え、グループ会社トヨタマップマスターの地図 API (`web.map-m.com`) 運用費がかかる |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | トヨタマップマスター Web 地図 API (`https://web.map-m.com/v3.0/proxy/api?appKey=trl_map` および `/js/mapMaster/mapCommon.js`、`mapDisplay.js`、`shopSearchMap.js` を確認) |
| フレームワーク | jQuery 3.7.1 + jQuery UI + Vue.js (一部 UI で利用) |
| 背景の地図とタイル | トヨタマップマスター (TOYOTA MAPMASTER) の地図タイル (事前調査では国土地理院データ併用も確認) |
| 投稿やデータの保存先 | トヨタレンタカー自社店舗・予約基盤 (サジェスト設定 `/search/js/ss_suggest_config.js` 連携) |
| 配信 | Microsoft IIS 10.0 (`Server: Microsoft-IIS/10.0`) |

メモ:

- `/shop/` ページ上で `https://web.map-m.com/v3.0/proxy/api?appKey=trl_map` および `/js/mapMaster/` 配下のスクリプト群が直接読み込まれており、外部地図 SaaS ではなくトヨタグループの地図基盤 (TOYOTA MAPMASTER) を採用していることが確認できる。
