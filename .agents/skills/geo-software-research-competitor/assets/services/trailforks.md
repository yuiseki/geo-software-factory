## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界 90 か国以上・65万〜78万本超のマウンテンバイクおよびアウトドアトレイルの難易度・路面状態・位置を管理する地図プラットフォーム |
| 提供する価値 | 地域のトレイル管理団体と連携した最新のコース閉鎖・コンディション報告や難易度・標高差・人気ヒートマップを確認でき、オフラインでのナビゲーションに使える |
| 想定する利用者 | マウンテンバイカー、トレイルランナー、ハイカー、地域のトレイル整備団体・ショップ |
| 商用か非商用か | 商用 (選んだローカルエリア 1 地域のみ無料。全世界の地図・オフライン・3D 表示等は Trailforks Pro 年額約 $30〜$54、または Gaia GPS 等を含む Outside+ 年額約 $60〜$90 に加入) |
| 推定の売上 | 推測: 年数億円〜十数億円規模 (アプリ調査ではモバイル課金だけで月数十万ドル規模と推計。親会社 Outside Interactive の主要サブスクリプション資産の 1 つ) |
| 運営 | 企業 (Outside Interactive, Inc. / Outside Interactive Canada, Inc.、米国・カナダ。Pinkbike や Gaia GPS 等と同グループ) |
| 推定の運用費 | 推測: 月数百万円規模 (数十万本のトレイル・ヒートマップ・3D 地形タイルの配信、Garmin/Wahoo 連携 API、Cloudflare インフラ維持) |
