## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界のホテル・レストラン・観光スポット・ツアーの口コミと価格比較を地図と連動して探せる世界最大級の旅行プラットフォーム |
| 提供する価値 | 膨大な旅行者の口コミ・評価・写真・価格情報を地図上のピンと連動させて表示し、観光地や宿の位置関係を見ながら計画と予約まで一気通貫で行える |
| 想定する利用者 | 旅行先の宿泊施設・飲食店・アクティビティを探す世界中の旅行者、および集客・予約獲得を行いたいホテル・飲食店・ツアー事業者 |
| 商用か非商用か | 商用 (利用者は無料。ホテルのメタサーチ・クリック課金や広告、傘下 Viator での体験予約手数料、TheFork での飲食店予約・SaaS 収益等で運営) |
| 推定の売上 | 約18.4億ドル (2024年実績)、約18.9億ドル (2025年実績、Tripadvisor, Inc. 連結) |
| 運営 | 企業 (Tripadvisor, Inc.、米国マサチューセッツ州、NASDAQ 上場) |
| 推定の運用費 | 推測: 年数百億円規模。世界中の施設データベース、膨大な口コミ・画像配信、多言語サイト、Mapbox 等の地図基盤と WAF/CDN を大規模運用 |
