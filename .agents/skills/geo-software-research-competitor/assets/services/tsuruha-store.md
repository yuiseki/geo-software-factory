## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ツルハドラッグをはじめとするツルハグループ各社の店舗・調剤薬局を現在地・エリア・条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | グループ横断で最寄り店舗の位置、営業時間、調剤受付や取扱サービスの有無を確認でき、来店や処方箋利用に繋げられる |
| 想定する利用者 | ツルハグループ各ブランドの利用客、近くのドラッグストアや調剤薬局を探している利用者 |
| 商用か非商用か | 商用 (グループ実店舗への来店送客およびチラシ・サービス案内の導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。グループ実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社ツルハホールディングス / 株式会社ツルハ) |
| 推定の運用費 | 推測: 月数万〜数十万円。Google Maps Platform の利用料と Cloudflare を含む店舗検索基盤の運用・配信費がかかる |
