## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のタリーズコーヒー店舗を現在地・エリア・設備条件から検索し、地図上で位置や店舗情報を確認できる公式店舗検索サイト |
| 提供する価値 | 近くの店舗の位置や営業時間、Wi-Fi・電源・喫煙席などの設備条件を事前に確認でき、来店やモバイルオーダーの判断材料になる |
| 想定する利用者 | タリーズコーヒーを探している一般客、外出先で電源や Wi-Fi のあるカフェを探している利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客とモバイルオーダー・デジタルタリーズカード利用促進の導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上やモバイルオーダー送客に貢献する集客基盤 |
| 運営 | 企業 (タリーズコーヒージャパン株式会社) |
| 推定の運用費 | 推測: 月数万〜数十万円。Google Maps Platform の利用料と CloudFront の配信費、店舗情報管理基盤 (Canly 等) の利用料がかかる |
