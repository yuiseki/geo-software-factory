# ユナイテッド・シネマ 劇場案内・アクセスマップ

- URL: https://www.unitedcinemas.jp/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: 劇場検索、映画館、ユナイテッド・シネマ、ローソン・ユナイテッドシネマ、シネプレックス、アクセス、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のローソン・ユナイテッドシネマ / シネプレックス各劇場の上映スケジュールや施設情報、アクセスマップを確認できる公式サイト |
| 提供する価値 | 劇場ごとの個別ページで上映作品やチケット購入に加え、周辺略図の静止画像と Google マップへの直接リンクからアクセス経路を確認できる |
| 想定する利用者 | ユナイテッド・シネマまたはシネプレックスでの映画鑑賞を予定している一般の利用者 |
| 商用か非商用か | 商用 (各劇場への来場集客およびオンラインチケット購入への送客のために提供。利用料は無料) |
| 推定の売上 | 推測: 劇場案内単体の売上は 0 円。映画鑑賞チケット販売および売店売上への送客に貢献 |
| 運営 | 企業 (株式会社ローソン・ユナイテッドシネマ) |
| 推定の運用費 | 推測: 月数万円。静的画像と HTML 中心の軽量な構成で、地図 API 課金も発生しないため運用費は非常に低い |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 埋め込み地図なし (各劇場ページに自社製の静止地図画像 `//img.unitedcinemas.jp/image/map/<theater>_s3.gif` を掲載し、`https://www.google.co.jp/maps/place/...` への外部リンクを設置) |
| フレームワーク | jQuery |
| 背景の地図とタイル | なし (自社作成の GIF 静止地図画像 + Google マップ外部リンク) |
| 投稿やデータの保存先 | 自社管理の劇場 HTML ページ (Shift_JIS エンコーディング、`/<theater>/about-theater.html` 等) |
| 配信 | 未確認 (`HTTP/1.1 200 OK`、`https://www.unitedcinemas.jp/` から `/index.html` へ 301 リダイレクトを確認したが、サーバー製品名は未出力) |

メモ:

- 例として確認した阿久比劇場 (`/agui/about-theater.html`) では、`//img.unitedcinemas.jp/image/map/agui_s3.gif` の周辺イラスト地図を表示し、詳細な地図確認は Google マップへの外部リンク (`https://www.google.co.jp/maps/place/...`) に誘導している
- Google Maps API や埋め込み `iframe` を使わないため、地図 API の利用料金が発生しない構成となっている

データの出どころ (2026-11-17):

- 劇場データ・周辺略図: 株式会社ローソン・ユナイテッドシネマ自社作成・管理
- 外部地図リンク先: Google マップ
