## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 災害、選挙監視、人権侵害、地域課題などの市民からの報告を地図・タイムライン上にリアルタイム集約して可視化するオープンソースのクラウドソーシング基盤 |
| 提供する価値 | SMS・メール・SNS・ウェブ・モバイルアプリなど多様な経路から現場の報告を収集し、検証・分類して地図上に公開できる |
| 想定する利用者 | 人道支援・災害対応団体、選挙監視・NGO、ジャーナリスト、自治体、市民コミュニティ |
| 商用か非商用か | 非商用・商用両対応 (OSS 版のセルフホストは無料。クラウド版は年間予算 25 万ドル未満の草の根非営利団体向け無料枠があり、大企業・国際機関向けの有料 Enterprise プランは $10,000 程度から) |
| 推定の売上 | 推測: 年数億円規模の非営利活動資金・受託収入 (USAID、Omidyar Network、Ford Foundation、Google.org 等の助成金と Enterprise 契約で運営) |
| 運営 | 非営利団体 (Ushahidi, Inc.、ケニア・ナイロビ発祥の非営利テック組織) |
| 推定の運用費 | 推測: 月数百万円規模。オープンソースプラットフォームとクラウドホスティング基盤、iOS/Android 報告アプリの開発・保守を維持している |
