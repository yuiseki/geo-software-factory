# Ventusky

- URL: https://www.ventusky.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Ventusky、InMeteo、天気予報、風、気象マップ、3D 地球儀、WebGL、ICON、ECMWF

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界の風、降水、気温、気圧、波浪など 50 以上の気象レイヤーを 3D 地球儀や平面地図で滑らかに表示する気象可視化サービス |
| 提供する価値 | 複数の気象予報モデルのデータを美しい流線アニメーションと等圧線・色分けで表現し、地球規模の気象システムを一目で理解できる |
| 想定する利用者 | 天気の変化を詳しく追いたい一般利用者、アウトドア・マリンスポーツ愛好家、気象ファン |
| 商用か非商用か | 商用 (ウェブ版の基本機能は無料、アプリおよび高度な機能向けに Premium / Premium+ の年額約 $10 から $20 USD のサブスクリプションを提供) |
| 推定の売上 | 推測: 年数千万円から数億円規模と見られるが、公式の売上数値は未公開 |
| 運営 | 企業 (InMeteo、チェコ) |
| 推定の運用費 | 推測: 月数十万円から数百万円規模。NOAA、DWD、ECMWF 等の大規模気象データを定期処理し、Cloudflare 経由で世界中に配信している |
