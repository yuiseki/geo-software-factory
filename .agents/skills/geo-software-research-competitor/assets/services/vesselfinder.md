# VesselFinder

- URL: https://www.vesselfinder.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: VesselFinder、ベッセルファインダー、AIS、船舶追跡、コンテナ追跡、海運、寄港情報、ship tracker、vessel tracking

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 陸上および衛星の AIS ネットワークを用いて世界中の船舶の現在位置、寄港情報、コンテナ追跡を提供する船舶トラッキングサービス |
| 提供する価値 | 船舶のリアルタイム位置・諸元・航跡の閲覧、衛星 AIS による外洋の船舶追跡、コンテナのトラッキング、クレジット制 REST API |
| 想定する利用者 | 海運・物流・サプライチェーン担当者、港湾関係者、船舶情報を使う開発者、船舶ファン |
| 商用か非商用か | 商用 (フリーミアムモデル。広告付き無料版、Basic 月額約 34 ドル / Satellite 月額約 139 ドル等の有料プラン、クレジット制および定額 API) |
| 推定の売上 | 未確認 (非公開企業であり売上高は公表されていない。Web/アプリ課金、B2B API、広告が収益源) |
| 運営 | 企業 (VesselFinder、民間の海事情報サービス企業) |
| 推定の運用費 | 未確認 (世界中の沿岸 AIS 受信局からのデータ収集、衛星 AIS データの調達、Web サーバーおよび地図配信基盤の運用) |

メモ:

- クレジット消費型の REST API (`Vessels`, `PortCalls`, `ExpectedArrivals`, `MasterData`, `Distance` 等) およびライブデータ配信を提供し、OpenAPI 3.1 仕様を公開している。
- 陸上 AIS のみの Basic プラン (年額約 179 ドル) と、外洋もカバーする衛星 AIS 対応の Satellite プラン (年額約 1,399 ドル) の価格体系を公開している。

| データ | 出どころ | どこに書いてあるか |
|---|---|---|

| 配信サーバーおよびスクリプト構成 | Apache、`static.vesselfinder.net` (`vfmap`) | `https://www.vesselfinder.com/` の HTTP 応答ヘッダーおよび HTML (2026-11-16 観測) |
