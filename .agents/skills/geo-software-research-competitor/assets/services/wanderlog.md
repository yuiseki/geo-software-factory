# Wanderlog

- URL: https://wanderlog.com
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Wanderlog、Travelchime、旅程管理、しおり、旅行計画、ルート最適化、共同編集、地図プランナー

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 旅行のスケジュール・行きたい場所・予約情報・予算を仲間と共同編集しながら、地図上のピンとルートで整理できる旅程プランナー |
| 提供する価値 | Google Docs のようなリアルタイム共同編集と地図表示を一体化し、行きたい場所の登録から効率的な巡回順の自動最適化、Gmail からの予約自動取り込みまでを1画面で行える |
| 想定する利用者 | 友人や家族とのグループ旅行を計画する人、ロードトリップや複数都市の観光ルートを効率よく組みたい旅行者 |
| 商用か非商用か | 商用 (フリーミアム。基本の旅程作成・地図表示・共同編集は無料。Wanderlog Pro は年額約 $39.99〜$49.99 程度で、オフライン利用・ルート最適化・Gmail 自動連携等を提供) |
| 推定の売上 | 未確認 (非公開企業。推測: 年数億円規模、サブスクリプションと予約アフィリエイトで運営) |
| 運営 | 企業 (Travelchime Inc.、米国カリフォルニア州サンフランシスコ) |
| 推定の運用費 | 推測: 月数百万円規模。Google Maps API 等の検索・ルート計算費用、リアルタイム共同編集バックエンド、画像・添付ファイルストレージ |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (トップ HTML からは直接観測不可。公開情報では Google Maps API をスポット検索・ジオコーディング・ピン表示・ルート線描画に利用している) |
| フレームワーク | React + Express (`x-powered-by: Express` および `tech_hits` の `react` を確認) |
| 背景の地図とタイル | 未確認 (トップ HTML からは直接のタイル通信先は未確認。公開情報では Google Maps API を利用) |
| 投稿やデータの保存先 | Travelchime 自社基盤 (旅程データ、チェックリスト、費用精算、添付ファイル) |
| 配信 | nginx/1.24.0 (Ubuntu) + Express (`server: nginx/1.24.0 (Ubuntu)` を確認) |

メモ:

- トップページ (`https://wanderlog.com`) は HTTP 200 を返すが、地図を含むアプリ本体の描画スクリプトはログイン・旅程画面側で読み込まれるため直接観測はできていない。
- ウェブ版・Chrome 拡張機能のほか iOS / Android アプリも提供されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 施設・スポット情報・地図 | Google Maps Platform / Google Places 等 | 公開技術・サービス紹介情報 |
| 旅程・メモ・費用データ | ユーザー自身の入力および Gmail 連携取り込み | Wanderlog 公式サイト |
