# Watch Duty

- URL: https://www.watchduty.org/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Watch Duty、山火事、災害マップ、避難指示、防災アプリ、501(c)(3)、Mapbox、消防無線

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 訓練を受けたボランティアや元消防士らが無線・衛星・公的発表を人力で精査し、山火事や洪水の延焼範囲・避難情報を即時配信する非営利防災マップ |
| 提供する価値 | AI や自動集計のみに頼らず人が裏取りした正確な火災境界・消火航空機の位置・避難指示・停電情報を広告なしで受け取れる |
| 想定する利用者 | 米国等の山火事・洪水リスク地域の住民、消防・救急の現場関係者 (First Responders)、自治体 |
| 商用か非商用か | 非商用 (米国 501(c)(3) 非営利団体 Sherwood Forestry Service が運営。基本機能は完全無料・広告なし。任意のサポーター会員年額 $25 あり) |
| 推定の売上 | 推測: 年数百万米ドル規模の寄付・助成金・サポーター会費 (大規模山火事のたびに寄付や会員が急増する非営利モデル。正確な年次決算は非公開) |
| 運営 | 非営利団体 (Watch Duty / 法人名 Sherwood Forestry Service、米国 501(c)(3)) |
| 推定の運用費 | 推測: 月数万〜十数万米ドル規模 (専任エンジニア・防災スタッフの人件費と、災害時のアクセス急増に耐える Mapbox・Cloudflare 等のインフラ費用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Mapbox GL JS (2026-11-16 のトップページは Webflow 製紹介サイトだが、Mapbox 公式事例で `app.watchduty.org` は当初 MapLibre GL から大規模災害時の負荷対応のため Mapbox GL JS + Capacitor へ移行したことが公表されている) |
| フレームワーク | React + Capacitor (紹介ページは Webflow、アプリ本体は React + Capacitor と推測) |
| 背景の地図とタイル | Mapbox のベクター・衛星地図、NASA VIIRS/MODIS ホットスポット、気象レーダー (Wet Dog Weather)、消火航空機航跡等 |
| 投稿やデータの保存先 | 自社の災害インテリジェンス基盤 (訓練済みボランティアが消防無線を聴取・検証して登録) |
| 配信 | Cloudflare (`server: cloudflare`、`cf-ray` ヘッダーを確認) |

メモ:

- ウェブ版 (`app.watchduty.org`) のほか iOS / Android アプリを無料提供している。
- MapLibre GL から Mapbox GL JS へ移行した事例として、高トラフィック災害アプリのアーキテクチャ面でもよく参照される。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 山火事境界・避難情報 | CAL FIRE、NIFC、地方消防局の無線通信と現地リポーターによる検証 | 公式サイトおよびアプリ内説明 |
| 衛星熱異常・気象 | NASA (VIIRS/MODIS)、NOAA、Wet Dog Weather | 公式サイト |
