## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 大型家具から日用雑貨まで数百万点以上のホームグッズを扱い、注文時の住所検証によって配送精度を高めている米国大手の家具・インテリア専門 EC サイト |
| 提供する価値 | 部屋番号の抜けや郵便番号・番地の入力ミスをチェックアウト時にリアルタイムで検知・補正することで、大型家具の再配達や配送遅延を防ぎスムーズに商品を受け取れる |
| 想定する利用者 | オンラインで家具・インテリア・生活雑貨を購入する一般消費者 |
| 商用か非商用か | 商用 (EC での家具・ホームグッズの販売により収益化) |
| 推定の売上 | Wayfair Inc. 全体の 2024 年通期純売上は 119 億ドル (約 118.5 億ドル) |
| 運営 | 企業 (Wayfair Inc.、米国上場企業) |
| 推定の運用費 | 推測: 月数億円規模 (大規模 EC カタログ、物流ネットワーク、Cloudflare 配信およびチェックアウト時の Address Validation API 利用料) |

メモ:

- 2026-11-16 時点の HTTP 一次観測では `HTTP 429` (`Server: cloudflare`) が返却されたため、フロントエンドの直接観測はできていない。
- Google Maps Platform の公式導入事例として、大型家具の誤配送・再配達コストを減らすため、パートナーの Eviden と共に **Google Maps Platform Address Validation API** をチェックアウトフローへ組み込み、**配送精度を 10% 向上**させたことが公開されている。
- ウェブ版のほか、iOS / Android 向けの公式モバイルアプリを提供している（2024年第4四半期時点で全配達注文の 64.5% がモバイル経由）。
