# Waze

- URL: https://www.waze.com/ (Live Map: https://www.waze.com/live-map)
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Waze、ウェイズ、カーナビ、リアルタイム交通情報、渋滞情報、取締り情報、クラウドソーシング、ドライブ、ルート案内、navigation

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ドライバー同士がリアルタイムの渋滞・事故・警察の取締り情報を共有し合いながら最適ルートを案内するソーシャル・カーナビゲーションサービス |
| 提供する価値 | 他の利用者の走行速度や投稿に基づく即時の渋滞回避ルート案内、危険箇所や速度取締りの事前警告、コミュニティによる迅速な地図更新 |
| 想定する利用者 | 日常的に自動車を運転するドライバー、通勤・配送ドライバー、地域の地図編集に参加するボランティアマッパー |
| 商用か非商用か | 商用 (基本無料で利用でき、ルート沿いの店舗ピンや停止中バナーなどの位置連動型広告で収益化) |
| 推定の売上 | 未確認 (2013 年に Google が約 9.66 億ドルで買収。現在は Google Geo 部門に統合されており、Waze 単体の売上は非公開) |
| 運営 | 企業 (Waze Mobile、2013 年より Google 傘下、現在は Google Geo 組織の一部) |
| 推定の運用費 | 未確認 (Google Cloud Platform 上で稼働し、Memorystore for Redis Cluster や Vertex AI 等を用いた大規模リアルタイム基盤を運用) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 未確認 (Live Map の HTML からは具体的な地図描画ライブラリ名を特定できず。モバイルアプリではベクトル形式で経路や地図を描画) |
| フレームワーク | Next.js (Live Map の HTML 内に `next` の出力を確認) |
| 背景の地図とタイル | 自社整備およびコミュニティ編集による独自の道路グラフ・1km 四方単位の地図タイル (Waze Map Editor 経由で更新) |
| 投稿やデータの保存先 | Waze 独自のバックエンド (Google Cloud Platform 上のクラウドインフラおよび分散キャッシュ) |
| 配信 | Google Frontend (`server: Google Frontend`, `via: 1.1 google`) |

メモ:

- 2006 年にイスラエルで創業され、2013 年 6 月に Google が買収。2022 年後半に Google Maps 等と同じ Google Geo 組織に統合された。
- 地図データはボランティアのコミュニティ編集者 (Waze Map Editor) によって継続的に更新されている。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 道路地図・POI・渋滞情報・インシデント | Waze コミュニティ編集者およびドライバーからのクラウドソーシングデータ | Waze 公式サイト・ヘルプドキュメント |
| Live Map 配信元 | Google Frontend | `https://www.waze.com/live-map` の HTTP 応答ヘッダーおよび HTML (2026-11-16 観測) |
