# ウェザーニュース

- URL: https://weathernews.jp
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ウェザーニュース、ウェザーニューズ、雨雲レーダー、台風、地震、天気予報、ウェザーリポート、MapLibre GL JS、Nuxt

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 独自の気象観測網とユーザー投稿「ウェザーリポート」を組み合わせ、ピンポイント天気予報や 60 時間先までの雨雲レーダーなどを提供する総合気象情報サービス |
| 提供する価値 | 気象庁データに加えて全国約 13,000 箇所の独自観測網と利用者からのリアルタイム天気報告を統合し、高精細な雨雲レーダーやゲリラ豪雨・落雷・台風マップを確認できる |
| 想定する利用者 | 一般の天気予報利用者、アウトドア・レジャー愛好家、防災担当者、海運・航空・物流等の法人 |
| 商用か非商用か | 商用 (基本機能は無料・広告表示あり。有料会員プランは月額 330〜360 円程度、上位のウェザーニュース Pro は月額 680 円程度。海運・航空等の法人向け BtoB 事業も展開) |
| 推定の売上 | 約 245 億円 (株式会社ウェザーニューズの 2026年5月期連結売上高は 244 億 7,900 万円。個人向けサブスク・広告に加え、海運・航空・陸上等の法人向け売上が過半を占める) |
| 運営 | 企業 (株式会社ウェザーニューズ) |
| 推定の運用費 | 推測: 年間数十億円〜百億円超 (独自気象観測網・予報センター・24時間ライブ配信・クラウド基盤の維持費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | MapLibre GL JS (雨雲レーダーページ `https://weathernews.jp/onebox/radar/` にて `maplibre.*.css` の読み込みと `maplibre` 記述を確認) |
| フレームワーク | Nuxt / Vue.js + React (トップページで `vue.min.2.0.js`、雨雲レーダーページで `_nuxt/` および `React` 関連記述を確認) |
| 背景の地図とタイル | 自社配信タイル等 (MapLibre GL JS 上で気象レーダー・地図タイルを描画) |
| 投稿やデータの保存先 | ウェザーニューズ独自基盤 (ウェザーリポート・観測データ) |
| 配信 | Amazon S3 + Amazon CloudFront (`server: AmazonS3`, `via: 1.1 *.cloudfront.net` を応答ヘッダーで確認) |
