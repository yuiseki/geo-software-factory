## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地球上を 3m × 3m のマス目に分割し、それぞれに固有の 3 つの単語の組み合わせを割り当てて場所を伝えられるようにする位置情報サービス |
| 提供する価値 | 番地のない場所や複雑な住所のエリアでも、覚えやすく口頭でも伝えやすい 3 つの単語だけで 3m 四方の正確な位置を共有・入力できる |
| 想定する利用者 | 位置を正確に伝えたい一般利用者、救急・救助機関、配送・物流事業者、音声入力で目的地を指定したい自動車メーカー |
| 商用か非商用か | 商用 (一般利用者・慈善団体・救急機関向けは無料だが、B2B の API 利用料・what3words Pro サブスクリプション・自動車や物流企業向けのライセンス契約で収益を得る) |
| 推定の売上 | 2024 年度の売上高は約 210 万英ポンド、税引前損失は約 1,060 万英ポンド (英国 Companies House への提出決算に基づく報道。2023 年度は売上約 110 万英ポンド、損失約 1,640 万から 1,750 万英ポンド) |
| 運営 | 企業 (What3words Limited、英国ロンドン拠点) |
| 推定の運用費 | 未確認 (決算では 2024 年度に人員削減やマーケティング費圧縮を進めても年間 1,000 万英ポンド超の赤字が出ており、人件費や AWS 等のクラウド基盤費が主な支出と見られる) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps JavaScript API (HTML 内で `maps.googleapis.com` の読み込みを確認) |
| フレームワーク | Next.js + React (HTML 内で `/map/assets/_next/static/` のチャンク群を確認) |
| 背景の地図とタイル | Google Maps (ウェブの地図画面で Google Maps を利用。車載や企業向け SDK は座標変換のみを行い他の地図基盤にも重ねられる) |
| 投稿やデータの保存先 | 自前のプロプライエタリな変換アルゴリズムと AWS クラウド基盤 (3 ワード変換の仕組みは非公開) |
| 配信 | Amazon CloudFront (応答ヘッダーの `server: CloudFront`、`via: ...cloudfront.net` を確認。User-Agent なしのリクエストには 403 を返す設定) |

メモ:

- オフライン環境でも変換可能な SDK を自動車メーカーや救急機関向けに提供している。
- 3 ワードへの変換アルゴリズム自体はオープンソースではなく非公開である。
