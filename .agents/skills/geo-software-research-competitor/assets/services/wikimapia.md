# Wikimapia

- URL: https://wikimapia.org/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Wikimapia、WikiMapia、地理百科事典、クラウドソーシング、ポリゴン、建物タグ、Google Maps、マッシュアップ、POI

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 衛星写真や地図上にユーザーが建物・街区・地理的特徴のポリゴンを描き、説明やカテゴリをWiki形式で共同編集できる地理オンライン百科事典 |
| 提供する価値 | 世界中の建物や施設、地形などの領域をポリゴンで囲み、多言語の説明文やカテゴリ、写真、歴史情報をコミュニティで蓄積・閲覧できる |
| 想定する利用者 | 地域の地理や建物の詳細を知りたい閲覧者、地元の場所や施設情報を地図上に記録・共有したいボランティア編集者 |
| 商用か非商用か | 商用 (利用は無料。Google AdSense や独自の Wikimapia Ads などの広告収入で運営) |
| 推定の売上 | 未確認 (非公開。2010年代以降のトラフィック低下と Google Maps API 料金上昇により維持費捻出に苦戦していると報じられている) |
| 運営 | 企業/個人創設 (Alexandre Koriakine および Evgeniy Saveliev、2006年5月創設。Wikipedia / Wikimedia Foundation とは無関係) |
| 推定の運用費 | 推測: 月数十万〜数百万円規模。全世界の膨大なポリゴン・POI データベースと Web サーバーの維持、および Google Maps API 利用料が掛かる |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps (`https://wikimapia.org/` の HTTP 200 応答 HTML 内に Google Maps の読み込みを確認) |
| フレームワーク | 未確認 (独自 Web フロントエンド) |
| 背景の地図とタイル | Google Maps (衛星写真・地図タイル。過去にコストや規約面の課題も指摘されている) |
| 投稿やデータの保存先 | Wikimapia 自社サーバー (ユーザーが投稿した数千万件規模のポリゴン境界・説明文・カテゴリデータ) |
| 配信 | `Server: nginx` (`https://wikimapia.org/` の応答ヘッダーを確認) |

メモ:

- 2006年5月にロシア人開発者2名によって公開された、初期の代表的な地図マッシュアップ・地理クラウドソーシングサービス。
- FAQ にも明記されている通り、名称に「Wiki」とあるが Wikipedia / Wikimedia Foundation とは一切関係がない独立プロジェクト。
- 公式のネイティブモバイルアプリはなく、主に Web ブラウザ向けとして提供されている（過去にサードパーティ製アプリが存在）。近年はメンテナンスやコミュニティ活動が停滞傾向にある。
