# Windy

- URL: https://www.windy.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: Windy、Windyty、風向、風速、天気予報、気象レーダー、台風、気象マップ、ECMWF、MapLibre

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界の風向・風速・雨雲レーダー・波浪・気温などの気象予報をリアルタイムのアニメーション地図で可視化するサービス |
| 提供する価値 | ECMWF や GFS、ICON などの複数の数値予報モデルを切り替えながら、風や気圧配置の動きを滑らかなパーティクル表現で直感的に把握できる |
| 想定する利用者 | パイロット、セーラー、サーファー、パラグライダー愛好家、防災担当者、一般の天気予報利用者 |
| 商用か非商用か | 商用 (基本機能は無料、Windy Premium は月額約 $2.99 または年額 $24.99 から $29.99 程度。寄付および開発者・法人向け Windy API の有料プランを提供) |
| 推定の売上 | 推測: 年数億円以上。世界中で利用される気象プラットフォームで有料会員・寄付・B2B API を展開し、スイスの気象企業 meteoblue の過半数株式を取得する規模だが、売上数値は未公開 |
| 運営 | 企業 (Windyty, S.E.、チェコ) |
| 推定の運用費 | 推測: 月数百万円以上。複数の全球・領域数値予報モデルや衛星・レーダーデータを高頻度で処理し、全世界へタイルと API を高速配信している |

| フレームワーク | 未確認 (`index.js` による独自バンドル) |

| 投稿やデータの保存先 | 未確認 (観測点やウェブカメラ、ユーザー設定を扱うが保存先インフラの詳細は非公開) |
