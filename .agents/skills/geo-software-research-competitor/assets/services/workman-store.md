## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のワークマン、WORKMAN Plus、#ワークマン女子などの店舗を、エリアや業態から検索し店舗情報を案内する公式店舗検索ページ |
| 提供する価値 | 最寄り店舗の住所、営業時間、業態ブランド (Pro / Plus / Colors 等) を確認でき、Google マップの外部リンクから経路案内へ遷移できる |
| 想定する利用者 | 作業服・安全靴を探している職人や作業員、アウトドア・カジュアルウェアを購入したい一般客 |
| 商用か非商用か | 商用 (フランチャイズを含む実店舗への来店送客および公式オンラインストアの店舗取り置き導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の来店・購買および店舗受け取り送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社ワークマン) |
| 推定の運用費 | 推測: 月数万円。埋め込み地図 API を使わず Google マップへの外部リンクで案内しているため地図 API 課金は抑えられ、WordPress + CloudFront の配信費が中心 |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | 埋め込み地図なし (ブラウザ観測で Google マップへの外部リンクによる案内を確認) |
| フレームワーク | WordPress (`workman_v1` テーマ) + jQuery 1.11.3 |
| 背景の地図とタイル | 埋め込み地図なし (外部リンク先として Google マップを利用) |
| 投稿やデータの保存先 | WordPress / 自社管理の店舗データ |
| 配信 | nginx + Amazon CloudFront (`server: nginx`、`via: ...cloudfront.net`) |

メモ:

- 2026-11-16 のブラウザ観測で、ページ内にインタラクティブな埋め込み地図を持たず、Google マップへの外部リンクで店舗位置を案内する形式であることを確認した
- 一次 HTTP 取得 (`https://www.workman.co.jp/store`) ではステータス 200、配信ヘッダは `server: nginx` および CloudFront 経由 (`x-amz-cf-id`) であり、HTML は WordPress テーマ構成 (`wp-content/themes/workman_v1/`) であった
- 公式スマートフォンアプリとして「ワークマン公式アプリ」が提供されている

データの出どころ (2026-11-16):

- 店舗データ: 株式会社ワークマン自社管理の店舗情報
- 背景地図: 埋め込みなし (Google マップへの外部リンク)
