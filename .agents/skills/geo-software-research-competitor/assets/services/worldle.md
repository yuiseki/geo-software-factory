- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: Worldle、Antoine Teuf、Teuteuf Games、国シルエット、国当てゲーム、Wordle風、Natural Earth、地図タイルなし

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 国のシルエット（輪郭図）だけを見て国名を当て、距離と方角のヒントから 6 回以内に正解を導く日替わり地理パズルゲーム |
| 提供する価値 | 地図タイルやストリートビューを使わず、純粋な国の形・位置関係・方角の知識だけで毎日数分で遊べるシンプルな地理ゲーム体験を提供する |
| 想定する利用者 | Wordle などの日替わりパズル愛好家、地理好き、学生・教育関係者 |
| 商用か非商用か | 商用（基本無料・Web/アプリ広告およびプレミアム会員・サブスクリプションで収益化） |
| 推定の売上 | 推測: 年数千万円以上（世界的な日替わりパズルブームで定着し、Web 広告と iOS/Android アプリ課金・アーカイブ機能を展開） |
| 運営 | 個人発→スタジオ運営（2022 年 1 月に Antoine Teuf が個人開発し、その後 Teuteuf Games が運営を引き継ぎ） |
| 推定の運用費 | 推測: 月数万〜数十万円程度（地図タイル配信を行わず静的アセットと軽量 API/アカウント同期が中心のため低コスト） |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | SVG / 静的シルエット画像（背景地図タイルは使用せず、国・地域の輪郭図を描画） |
| フレームワーク | React（応答 HTML 内の `/static/js/main.c4f9dc4e.js` 構成および関連スクリプトを確認） |
| 背景の地図とタイル | なし（国別の静的シルエットおよび距離・方位計算ロジックのみで構成） |
| 投稿やデータの保存先 | ブラウザの LocalStorage（プレイ履歴）および Teuteuf Games アカウント同期用バックエンド |
| 配信 | Cloudflare（応答ヘッダーで `server: cloudflare`、`cf-ray` を確認） |

メモ:

- ウェブ版のほか iOS / Android の公式アプリ（Teuteuf Games）が配信されている。
- 背景地図タイルを持たず「国のシルエットと方角・距離だけ」に絞ったことで、サーバー負荷・API 課金を抑えつつ世界規模のバイラル成長を実現した境界例。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 国・地域の輪郭・座標データ | Natural Earth 等の公開地理データ | 公開解説・クレジット情報 |
