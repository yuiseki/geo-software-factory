# 薬王堂 店舗・チラシを探す

- URL: https://www.yakuodo.co.jp/shop/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、ドラッグストア、薬王堂、YAKUODO、東北、チラシ、営業時間、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 東北 6 県を中心に展開するドラッグストア薬王堂の店舗を県別・条件別で検索し、各店舗の地図や営業時間・チラシ情報を確認できる公式店舗検索サイト |
| 提供する価値 | 青森・岩手・宮城・秋田・山形・福島などの地域から店舗を探し、個別店舗ページで Google マップの位置情報や営業時間を確認できる |
| 想定する利用者 | 薬王堂を利用する一般客、東北エリアで最寄りのドラッグストアやチラシを探している生活者 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上に貢献する集客基盤 |
| 運営 | 企業 (株式会社薬王堂) |
| 推定の運用費 | 推測: 月数万円。nginx + WordPress の運用費のみで、個別ページの地図は Google マップ iframe 埋め込みのため API 従量課金は発生していない |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | トップ (`/shop/`) および一覧 (`/shop/result/?p=aomori`) は地図埋め込みなし。個別店舗ページ (`/shop/563/` 等) は Google マップ iframe 埋め込み (`https://maps.google.co.jp/maps?q=...&ll=...&output=embed...`) |
| フレームワーク | WordPress (`/wp-content/themes/service/...`、Contact Form 7、Swiper) + jQuery 3.7.1 (GA4 / GTM) |
| 背景の地図とタイル | Google マップ (個別店舗ページの iframe 埋め込み) |
| 投稿やデータの保存先 | WordPress 側で店舗検索結果 (`/shop/result/?p=...`) および個別店舗ページ (`/shop/<ID>/`) を生成 |
| 配信 | nginx (`server: nginx`) |

メモ:

- 2026-11-17 の HTTP 観測では、店舗検索トップ (`/shop/`) は都道府県リンクによる検索入口となっており、個別店舗ページ (`/shop/563/`) に遷移すると `maps.google.co.jp/maps?...&output=embed` の iframe が埋め込まれていることを確認した
