- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ストアロケーター、店舗検索、家電量販店、ヤマダデンキ、LABI、テックランド、WEBチラシ、営業時間、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のヤマダデンキ（LABI・テックランド・家電住まいる館など）の店舗をエリア・条件から検索し、地図や WEB チラシを確認できる公式店舗検索サイト |
| 提供する価値 | 最寄り店舗の位置、営業時間、駐車場や取扱サービス、店舗ごとの WEB チラシを素早く確認でき、来店前の下調べに役立つ |
| 想定する利用者 | ヤマダデンキでの家電・日用品購入を検討している一般客、近隣店舗のチラシやアクセスを調べたい利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客および WEB チラシ閲覧の導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびヤマダウェブコムとの連携に貢献する集客基盤 |
| 運営 | 企業 (株式会社ヤマダデンキ) |
| 推定の運用費 | 推測: 月数万〜数十万円。Google Maps Platform の利用料および公式サイトのサーバー運用費がかかる |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps (2026-11-16 のブラウザ観測で確認) |

| 配信 | nginx (`server: nginx`) |
