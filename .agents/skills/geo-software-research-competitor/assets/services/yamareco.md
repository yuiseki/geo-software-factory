# ヤマレコ (Yamareco)

- URL: https://www.yamareco.com/
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ヤマレコ、Yamareco、登山、山行記録、登山計画、オフライン地図、GPS、国土地理院、みんなの足跡

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 登山やハイキングの山行記録、登山計画の作成、オフライン GPS 地図、コミュニティを提供する日本の登山プラットフォーム |
| 提供する価値 | 過去の豊富な山行記録や「みんなの足跡」から最新のルート状況を確認でき、電波の届かない山中でもオフライン地図で現在地を把握して遭難を防げる |
| 想定する利用者 | 登山者、ハイカー、山岳会や家族 (見守り機能) |
| 商用か非商用か | 商用 (基本無料、広告表示あり。有料のプレミアムプランは月額 780 円または年額 4,900 円、スーパープレミアム年額 10,500 円、ウルトラプレミアム年額 21,000 円) |
| 推定の売上 | 未確認 (非上場企業のため売上は非公開。スマホアプリは累計 140 万ダウンロード超で、有料会員と広告収入が主な収益源と見られる) |
| 運営 | 企業 (株式会社ヤマレコ、長野県松本市) |
| 推定の運用費 | 未確認 (山行記録と大容量写真の保存、地図タイル配信、アプリとウェブの開発および運用人件費) |

## 技術 (2026-11-16 の観測)

| 項目 | 観測したもの |
|---|---|
| 種類 | ウェブ、iOS と Android のアプリ |
| 描画 | Leaflet (`showroute_rec2.php` で確認。アプリ版はネイティブのオフライン地図描画および 3D マップ機能を提供) |
| フレームワーク | PHP 8.3.33 (`x-powered-by: PHP/8.3.33`)、jQuery |
| 背景の地図とタイル | 国土地理院の地形図、OpenStreetMap、およびユーザー GPS ログを集計した独自レイヤー「みんなの足跡」 |
| 投稿やデータの保存先 | 自社サーバーと推測されるが、具体的なデータベースやストレージ構成は未確認 |
| 配信 | Cloudflare 経由 (`server: cloudflare`、`cf-ray` ヘッダーを確認)。アプリは App Store、Google Play |

メモ:

- 2005 年に代表の的場一峰氏が個人で開始し、後に法人化した。
- 国土地理院と「ビッグデータを活用した地形図の修正のための協力協定」を締結し、ユーザーの GPS ログを地形図の更新に活用している。

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 地形図・標高データ | 国土地理院 | ヤマレコ公式サイトおよび国土地理院との協力協定発表 |
| 一部の背景地図 | OpenStreetMap contributors | ヤマレコの地図画面および公式案内 |
| みんなの足跡・山行記録 | ヤマレコユーザーの投稿と GPS ログ | ヤマレコ公式サイト |
