## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のヤマト運輸営業所・取扱店・PUDO ステーションを現在地や住所・駅名から検索できる公式拠点検索サイト |
| 提供する価値 | 荷物の発送・受け取りが可能な最寄りの営業所やコンビニ取扱店、宅配ロッカーの位置と受付締切時間を確認できる |
| 想定する利用者 | 宅急便を発送・受け取りしたい個人・法人、再配達や営業所止めを利用する顧客 |
| 商用か非商用か | 商用 (ヤマト運輸の宅配・物流サービスの利便性向上と受付拠点案内として提供。利用料は無料) |
| 推定の売上 | 推測: 拠点検索単体の売上は 0 円。宅配便の発送受付・受取誘導により本業の物流売上に貢献 |
| 運営 | 企業 (ヤマト運輸株式会社) |
| 推定の運用費 | 推測: 月数十万円規模。CloudFront / S3 での配信費と GeoTechnologies (MapFan 系) の法人向け地図利用料がかかる |
