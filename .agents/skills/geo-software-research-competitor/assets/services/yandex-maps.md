## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ロシアおよび CIS 諸国を中心に詳細な地図・リアルタイム渋滞情報・経路案内・店舗情報を提供する総合地図サービス |
| 提供する価値 | ロシア語圏や周辺地域における高精度な建物形状・番地・屋内フロア図・公共交通リアルタイム位置・渋滞予測・ストリートパノラマを無料で利用できる |
| 想定する利用者 | 一般のドライバーや公共交通利用者、旅行者、周辺店舗を探す利用者、Yandex MapKit SDK を組み込むアプリ開発者 |
| 商用か非商用か | 商用 (一般利用・一般公開アプリでの規定条件内の利用は無料。非公開・有料アプリやデータ保存等を伴う商用利用は MapKit SDK の MAU/DAU 課金や API 契約が必要。広告・店舗掲載による収益化も実施) |
| 推定の売上 | 推測: 年数百億円以上。ロシア最大手 IT 企業グループの主力サービス群の一角で、検索・広告・配車・配送・B2B MapKit API を支える基盤だが、地図単体の売上は非公開 |
| 運営 | 企業 (Yandex LLC 等 Yandex グループ) |
| 推定の運用費 | 推測: 月数千万円以上。計測車両によるパノラマ撮影、衛星・航空写真処理、膨大な車両プローブデータと全世界向けタイル配信を維持している |
