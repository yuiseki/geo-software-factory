# ヤオコー チラシ・店舗情報

- URL: https://www.yaoko-net.com/store/
- 観測した日: 2026-11-17
- 概要と収支を確かめた日: 2026-11-17
- 探すときの語: ストアロケーター、店舗検索、スーパー、スーパーマーケット、ヤオコー、YAOKO、チラシ、埼玉県、関東、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 埼玉県を中心に展開する食品スーパー「ヤオコー」の店舗を都県別一覧から検索し、各店舗のチラシやアクセスマップを確認できる公式店舗情報サイト |
| 提供する価値 | 都県ごとの店舗一覧から最寄り店舗の営業時間・駐車場・デジタルチラシを確認でき、店舗詳細ページの Google マップ埋め込みから場所を把握できる |
| 想定する利用者 | ヤオコー各店舗への来店を予定している一般客、近隣店舗の特売チラシを確認したい買い物客 |
| 商用か非商用か | 商用 (実店舗への来店送客として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗情報サイト単体の売上は 0 円。ヤオコー単体売上高 約 3,213 億円 (中間期実績等、グループ連結約 4,524 億円) の実店舗送客に貢献 |
| 運営 | 企業 (株式会社ヤオコー / ブルーゾーンホールディングスグループ) |
| 推定の運用費 | 推測: 月数万円。Apache + CloudFront の Web 運用費が中心で、Google Maps Embed API (`v1/place`) は無料枠内で利用可能 |

## 技術 (2026-11-17 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | トップ (`/store/`) には埋め込み地図なし。個別店舗ページ (`/store/store01/235.html` 等) 内に Google Maps Embed API (`https://www.google.com/maps/embed/v1/place?key=...&zoom=17&q=...`) の `iframe` を埋め込み |
| フレームワーク | 独自 JS (`lib.js`、`main.js`、`top.js`、`store_chirashi_2016.js`)、サイト内検索に Google カスタム検索 |
| 背景の地図とタイル | Google Maps (`maps/embed/v1/place`) |
| 投稿やデータの保存先 | ヤオコー管理の静的 HTML 店舗ページ (`/store/store01/...`) |
| 配信 | Apache + Amazon CloudFront (`server: Apache`, `via: CloudFront`) |

メモ:

- ヤオコー単体で約 206 店舗、グループ計で約 276 店舗以上を展開している
- 店舗一覧トップは地域別リンク中心で、詳細ページに Google Maps Embed API と Google マップ検索への外部リンクを配置している

データの出どころ (2026-11-17):

- 店舗・チラシデータ: 株式会社ヤオコー
- 埋め込み地図: Google Maps Platform (Maps Embed API)
