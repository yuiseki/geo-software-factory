## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 飲食店から地域サービスまでローカルビジネスの口コミ・評価と位置情報を地図上で検索・比較できる米国発のローカル情報プラットフォーム |
| 提供する価値 | 地図の移動・ズーム範囲に応じた店舗の高速な近接検索、ユーザー投稿の口コミ・写真・混雑状況の確認、予約・見積もり依頼を一体で提供する |
| 想定する利用者 | 飲食店や地域の店舗・サービスを探す一般消費者、およびローカル広告や予約機能で集客したい中小事業者 |
| 商用か非商用か | 商用 (一般利用者は無料。ローカル広告・クリック課金・店舗向け SaaS ツール・提携予約手数料で運営) |
| 推定の売上 | 約 14 億 6,000 万米ドル (Yelp Inc. 2025 年通期売上高。2024 年は 14 億 1,000 万米ドル) |
| 運営 | 企業 (Yelp Inc.、米 NYSE 上場) |
| 推定の運用費 | 未確認 (世界中の店舗データと大量の口コミ画像、Geohash や Elasticsearch を用いた地理空間検索基盤、Varnish 等の CDN 運用) |

| 配信 | Varnish (`server: Varnish`, `via: 1.1 varnish` ヘッダーを確認。HTTP 403) |

メモ:

- 2026-11-16 時点の `curl -sL` による確認では `HTTP/2 403` (`server: Varnish`) が返却されたため、フロントエンドの地図描画ライブラリの直接観測はできていない。
- 位置情報検索のバックエンド構成としては、地図のバウンディングボックスや半径に応じた高速な店舗絞り込みのために Geohash や Elasticsearch (BKD ツリー) 等の地理空間インデックスを活用していることが技術解説等で知られている。
