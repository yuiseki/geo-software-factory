## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のワイモバイルショップおよび取扱店をエリア・キーワード・現在地から検索し、かんたん来店予約ができる公式店舗検索ページ |
| 提供する価値 | 近隣のワイモバイル店舗やソフトバンクショップとの併設店の営業時間・取扱手続きを確認し、スムーズに来店予約へ進める |
| 想定する利用者 | ワイモバイルの新規契約、乗り換え (MNP)、機種変更、料金相談などで対面サポートを希望する利用者 |
| 商用か非商用か | 商用 (実店舗への来店送客と事前予約促進のために提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗での回線契約・端末販売に貢献する集客基盤 |
| 運営 | 企業 (ソフトバンク株式会社 / ワイモバイル) |
| 推定の運用費 | 推測: 月数十万円。Amazon CloudFront・Apache サーバーによる配信費、PHP ベースの店舗検索 API 運用費、および地図表示基盤の運用費がかかる |
