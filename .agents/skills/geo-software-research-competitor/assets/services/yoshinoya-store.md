## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の吉野家店舗を、現在地・都道府県・キーワード・設備条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 近くの吉野家店舗の位置や営業時間、駐車場・ドライブスルー・テイクアウト予約対応などを素早く確認できる |
| 想定する利用者 | 吉野家の店舗を探している一般客、外出先で近くの牛丼店やドライブスルー店舗を探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客およびテイクアウト予約への導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびテイクアウト送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社吉野家) |
| 推定の運用費 | 推測: 月数万〜数十万円。NAVITIME Location Cloud の法人向け利用料とサーバー運用費がかかる |
