# ゼッテリア（旧ロッテリア） 店舗検索

- URL: https://maps.zetteria.jp/shop
- 観測した日: 2026-11-16
- 概要と収支を確かめた日: 2026-11-16
- 探すときの語: ストアロケーター、店舗検索、ハンバーガー、ファストフード、ゼッテリア、ロッテリア、営業時間、モバイルオーダー、store locator

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のゼッテリア店舗を、現在地・エリア・条件から検索して地図上に表示する公式店舗検索サイト |
| 提供する価値 | 近くのゼッテリア店舗の位置や営業時間、イートイン・テイクアウト等の条件を確認して来店や注文につなげられる |
| 想定する利用者 | ゼッテリア（旧ロッテリア）の店舗を探している一般客、外出先で近くのハンバーガー店を探している利用者 |
| 商用か非商用か | 商用 (店舗への来店送客およびモバイルオーダーへの導線として提供。利用料は無料) |
| 推定の売上 | 推測: 店舗検索単体の売上は 0 円。実店舗の売上およびモバイルオーダー送客に貢献する集客基盤 |
| 運営 | 企業 (株式会社バーガー・ワン、旧株式会社ロッテリア・ゼンショーグループ) |
| 推定の運用費 | 推測: 月数万円程度。Web サーバーの運用費に加え、Google Maps Platform の利用料がかかる |
