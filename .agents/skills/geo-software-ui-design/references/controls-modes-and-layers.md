# 操作モード・コントロール・レイヤーの UI

地図アプリに検索、レイヤー切替、計測、作図などの機能が増えると、地図上の UI が肥大化して「今どの状態にいるか分からない」「地図が見えない」状態に陥りやすい。

## 操作モードの明確化

閲覧以外のモード (距離/面積の計測、ピンやポリゴンの作図・編集、範囲選択) を持つ場合は、モード中であることを画面全体で明確に示す。

- **既定は閲覧 (Inspect) モード**: ページを開いた直後はパン・ズームと地物のクリック選択ができる安全な状態にしておく。いきなりクリックでピンが打たれる状態にしない。
- **モード中のバナーと終了導線**: 計測や作図に入ったら、画面上部またはツールバーの近くに現在のモード名 (例: 「距離を計測中: 地図をクリックして点を追加」) と、「完了」「キャンセル」ボタンを常に表示する。`Escape` キーでも安全にキャンセルして閲覧モードへ戻れるようにする。
- **カーソルと視覚フィードバック**: PC ではモードに応じてカーソル (`crosshair`、`grab` など) を切り替え、作図中の仮の線やスナップ先を点線やハイライトで示す。

## レイヤー切替と凡例の肥大化防止

レイヤー数や凡例項目が増えたときに、地図の隅へそのまま並べると地図領域が埋まる。

- **初期状態は閉じる**: レイヤー一覧と凡例は 1 つのボタン (またはコンパクトなタブ) にまとめ、必要なときだけ開く引き出し式 (ドロワー/ポップオーバー) にする。常時表示が必要な凡例でも、現在画面に表示されているレイヤーの凡例だけを出す。
- **ベースマップと主題レイヤーの分離**: 背景地図 (標準・航空写真・ダーク) の切替と、上に載せる主題データ (施設・境界・ヒートマップ) の表示切替はグループを分けて見せる。
- **読み込み中と空状態の表示**: タイルや外部レイヤーの取得中は小さなスピナーまたはインジケータを該当レイヤー行の横に出し、地図全体の操作を止めない。

## ベースマップに負けない UI コントラスト

地図の背景色は白系の地図、濃色のダークマップ、情報密度の高い航空写真へと動的に変わる。通常の Web ページと同じ半透明背景や薄い文字色を使うと、航空写真の上で UI が読めなくなる。

- **不透明または高不透明度の面**: 地図の上に浮かせるカード、検索バー、コントロールボタンは、背景色に対して十分なコントラストを確保する (不透明な面、または薄い枠線と影を組み合わせた面にする)。
- **地図上のオーバーレイに大面積ブラーを使わない**: `backdrop-filter: blur()` を広いパネルや常時動く要素に使うと、地図のパン・ズーム時に描画負荷でフレーム落ちが起きやすい。
- **ベースマップ切替への追従**: ユーザーが背景地図をライトからダークや航空写真に切り替えた場合でも、UI パネルや文字・アイコンの視認性が崩れないよう、UI のテーマと地図上のオーバーレイ境界 (枠線・影) を保つ。
- **文字とアイコンの扱い**: ボタン内の文字は折り返さず (`whitespace-nowrap`)、狭い領域でも見出しやボタンが潰れないようにする。アイコンのみのコントロールにはホバーツールチップと `aria-label` を付け、無効状態のボタンは隠すのではなく無効化 (`disabled`) して理由を添える。
