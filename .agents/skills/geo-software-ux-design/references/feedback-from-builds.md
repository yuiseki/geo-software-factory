# 作ったものへの指摘から

地図アプリを企画から公開まで通したとき、本人から受けた画面と操作への指摘を一般化したもの。指摘されなくても満たす既定として、設計と実装に当てる。プロダクト概要の要件や、昼に本人が決めたことと食い違うときだけ要件に従い、外した既定と理由を「夜に決めたこと」に書く。各項の「場面」は、その既定が当てはまる条件である。

## 部品と導線

- 新しい部品を作る前に、既存の部品を使い回す。複数ページのナビゲーションが要る場合は、共通のヘッダーを使い、現在地 (パンくず) とアカウントの操作を揃える。映像を常時眺める画面のように、導線が不要な場面ではヘッダーを省く。
- URL は、最初の版の対象が 1 つでも、増やせる形にする (`/osaka/` でなく `/japan/kansai/osaka/`)。対象を足すたびに URL を変えると、共有したリンクと端末に入れた画面が壊れる。
- 同じ見た目の部品は、どのページでも同じ所へ行く。サイト名を押したときの行き先がページによって違うと混乱する。
- アカウントのメニューに足せるなら、そこに自分のページへの導線を入れる (認証の SDK のメニューは項目を足せることが多い)。
- 見出しが折り返しても、ボタンが潰れないようにする (ボタンは縮めない、文字は折り返さない)。

## 地図

- 地図を開く操作からは地図を表示する。地図のカードを押して一覧が出ると戸惑う。最初に開く画面は、地図が主役か、一覧や映像が主役かに合わせて決める。
- 現在地はライブラリ標準のコントロールを使う。状態が色で出るなど、作り直すより良いことが多い。
- 初めの表示範囲は場面で変える。使っている最中は現在地と対象、振り返るときは対象だけ。
- 小さな地図のカードは操作を無効にし、収める範囲に余白を取る。
- 状態は色と記号の両方で出す (解除済みは緑のマーカーと ✅)。一覧では記号を行の先頭に置き、縦に揃える。
- 記号や表記は、本人がすでに使っているもの (前の道具での記録、メモの印) を引き継ぐ。新しい記号を発明すると、本人の記録と画面の対応が取れなくなる。
- 振り返る場面 (終わった旅、過去の記録) では、済んだものを先に並べる。絞り込み (済んだものだけ) は、一覧と地図の両方に同じように効かせる。片方だけに効くと、一覧と地図で見えるものが食い違う。

## 書けない人への見せ方

- 書き込めない人 (ログインしていない人) には、操作を隠さず無効にして見せる。何ができるサービスかが伝わる。
- 書けない人に意味の無い絞り込みは無効にし、既定を「全部見える」側にする。既定で空のページを見せない。
- 一時的に閉じている機能 (準備中のログインなど) は、無効にしたうえで理由を出す。無効にしたボタンの標準のツールチップは、環境によってカーソルの印に隠れて読めないので、ホバーで出す自前の吹き出しにし、ボタンの横 (画面の内側) に出す。タッチの端末ではホバーが残らないように、ホバーを持つ端末だけに当てる。
- 計画中のものなど、本人にだけ見せるものは、画面で隠すだけでなくサーバーの読み出しで除く。

## 常時表示の画面

場面: 操作せずに眺め続ける画面 (壁紙、サイネージ、監視の画面、映像を流し続ける画面)。

- 主役 (映像、地図) に面積を使う。導線が要らないならヘッダーを置かない。主役から読める情報 (映像に映る名前、地図で分かる位置) を、別の行で繰り返さない。座標の数値は、使う人がそれを読むときだけ出す。
- 地図を、映像や再生の操作 (プレーヤーのボタン) の上に重ねない。領域を分け、映像の縦横比を保つ。埋め込みの映像は、縦横比が合わないと上下や左右に黒い帯が出るので、画面の大きさを変えて実物で確かめる。映像や地図の提供元が求める操作、表示、帰属を隠さない。
- 複数の画面を自動で切り替えるときは、一斉に切り替えず、時機をずらす。各画面に、次の切り替えまでの進み具合を出す。間隔は実際に眺めて決める。
- 再生できない映像が混ざるときは、プレーヤーが出す失敗のイベントで、その画面だけ次へ進める。失敗した映像はしばらく候補から外し、続けて失敗したときの再試行に上限を置く。通信や認証のように全体に効く失敗と、ブラウザの自動再生の制限は、別の原因として扱う。イベントで分からない失敗もあるので、そのときに出す代わりの表示も決める。

## 位置を示す地図

場面: 何か (カメラ、施設、写真) が世界や国のどこにあるかを、小さな地図で示すとき。

- 縮尺を 2 つに分ける。広域の小さな地図 (地球儀や国の全体) では所在の国や地域を塗り、詳しい地図では行政区画を塗って対象に印を立てる。小さな国や島も見えるように、塗りか印の大きさに下限を置く。2 つの地図は重ねず並べる。
- 複数の部分からなる面 (離島を含む都道府県、飛び地、日付変更線をまたぐ国) は、全体の外接矩形に合わせると、見せたい部分が小さくなる。対象を含む部分に合わせて表示範囲を決め、面の全体は地図に残す。含む部分を特定できないとき (簡略化した形など) は、対象を中心に決まった縮尺で見せる。区画の全体を見せたい画面では、全体を収める。
- 小さな地図の帰属表示は、読めることと、占める面積の両方を確かめる。畳めるコントロールがあっても、初めの表示と操作できることを実際の版で確かめる。畳んでよい条件は geo-software-legal-check の [attribution](../../geo-software-legal-check/references/attribution.md) に従う。

## 狭い場所の文字

場面: 地図の脇の見出し、カードの名前のように、幅が限られた場所に名前を出すとき。

- 1 行に収め、入りきらない末尾を省略記号で切る。折り返すと、隣の地図の領域が押される。
- 名前に添え書き (「境界未特定」のような注記) を足して折り返すくらいなら、添え書きを別の表し方 (記号、色、ホバーの吹き出し) にする。省略で失われる情報が要るときは、全文を別の手段 (吹き出し、詳細の画面) で読めるようにする。

出典: 一部は、ライブカメラの映像を地図とともに流し続ける作例 ([livecam-wallpaper](../../../../examples/livecam-wallpaper/README.md)) で、本人が画面を見ながら指摘したことを一般化した。
