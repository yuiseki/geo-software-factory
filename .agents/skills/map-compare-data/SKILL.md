# map-compare-data

地図プロダクトの「表示するデータ」を、どの出どころから得るかを決める。地物の種類 (施設、建物、境界、住所、統計など) ごとに、足切り、軸ごとの評価の順に比べ、混ぜたときのライセンスの条件と出典表示の文面までをまとめて出す。比較の軸は [criteria](references/criteria.md) にあり、各出どころの事実は下の表の reference にある。ベースマップ (背景の地図) の供給元は map-compare-infra で選ぶ。

|---|---|---|

| [sources/openstreetmap](references/sources/openstreetmap.md) | 候補に入れるとき | OpenStreetMap のデータ (タイルではなく地物) |
| [sources/overture-maps](references/sources/overture-maps.md) | 候補に入れるとき | Overture Maps |
| [sources/ksj](references/sources/ksj.md) | 国内が対象のとき | 国土数値情報 |
| [sources/fgd](references/sources/fgd.md) | 国内で正確な基盤の図形が要るとき | 基盤地図情報 |
| [sources/estat](references/sources/estat.md) | 統計や境界が要るとき | e-Stat の統計と境界 |

## 入力

比較の前に、次の要件をそろえる。プロダクト概要があればそこから読み、無ければ依頼から読み取る。

- 地図に載せるデータ: 地物の種類ごとに (例: 避難所、学校、建物の形、町丁目の境界、人口)
- 対象地域: 1 つの自治体、都道府県、国内全体、全球
- 利用形態: 商用か、公共案件か。データやタイルとして再配布するか
- 自社のデータと混ぜるか: 同じ種類の地物を突き合わせる、補い合う、重複を消すか
- 鮮度: どれだけ新しいデータが要るか。安全に関わる情報 (避難場所など) を含むか
- 結合の予定: 統計、住所、自社の台帳と結びつけるか

地図に載せるデータと利用形態が分からないまま比較に入らない。足切りがこの 2 つで決まるので、分からなければ先に聞く。聞くときは選択肢で答えられる形にし、1 回に聞く数を絞る。要件が全体に曖昧なら、比較の前にプロダクトの価値から聞き直す (map-product-grilling に当たる手順)。

## 進め方

1. [criteria](references/criteria.md) を読み、要るデータを地物の種類ごとに分け、「要件から軸の重みを決める」の表で足切りの条件と重くする軸を決める。
2. 地物の種類ごとに、下の「最初の当たり」から候補を集め、`sources/` の reference を開く。
3. 足切りの条件で候補を外す。使う版の利用条件を、データの項目と版ごとに確かめる (同じ項目でも古い版だけ非商用のことがある)。外した候補と理由を残す。
4. 残った候補を評価の軸で比べる。値は各 reference から写し、「未確認」とあるものは未確認のまま書く。網羅性や精度が結論を左右するなら、対象地域のデータを実際に取って見比べることを勧める。
5. 選んだ出どころを並べ、[license-mixing](references/license-mixing.md) で混ぜたときの条件を確かめる。OSM や ODbL のテーマと自社のデータを同じ種類の地物で混ぜるなら、共有義務が及ぶ範囲を書く。
6. 利用条件、版、配布の URL は、答える前に公式のページで確かめ直す。reference の確認日 (2026-11-10 など) から変わっていれば新しい値を使い、変わったことを書く。
7. 「出力」の形で答える。公開の前の法令と権利の確認 (測量法、帰属表示、ODbL) は map-legal-check に回す。

## 最初の当たり

候補を集めるときの出発点。どれも足切りと評価の軸で確かめてから推奨する。

- 全国の行政区域、鉄道、学校、医療機関、浸水想定区域: 国土数値情報 (項目と版ごとに条件を確かめる)
- 避難場所、避難所: 自治体のデータ、国土地理院の指定緊急避難場所データ。国土数値情報の避難施設は古く、非商用
- 建物の形、道路縁、町字界、標高: 基盤地図情報 (測量法の承認の要否を確かめる)
- 人口、世帯、事業所の主題図: e-Stat の統計と境界 (KEY_CODE で結合)
- 住所の正規化と代表点: アドレス・ベース・レジストリ (座標参照系の混在に注意)
- 特定の自治体の施設一覧: その自治体のオープンデータ、自治体標準オープンデータセット
- 全球の道路、建物、POI: OSM (ODbL)。POI を ODbL なしで使いたいなら Overture の places
- 名所や施設の代表点と写真: Wikidata の座標 (CC0) と画像 (Commons、ファイルごとのライセンス)。路線や店など座標の無い項目は OSM で補う
- チェーン店の店舗 (コンビニ、飲食チェーンなど): OSM と Overture の places をブランドの Wikidata ID (`brand:wikidata`、`brand.wikidata`) で絞り、AllThePlaces と並べる。どれも網羅率の公表がないので、会社が公表する店舗数と合計を突き合わせる
- 国内の POI を検索 API で引きたい: map-compare-infra の `search/`

## 出力

答えは次の順に並べる。

1. 推奨: 地物の種類ごとの出どころと、その理由を 1〜2 文ずつ。
2. 足切りで外した候補と理由。
3. 比較表: 地物の種類ごとに、行に評価の軸、列に候補。各セルに値と reference の根拠。
4. 混ぜたときの条件: 共有義務が及ぶ範囲、再配布できないもの、加工の表示。
5. 出典表示の文面: 地図に表示する出典を、出どころごとに並べた形で。
6. 確かめた日と版: 使う版 (年度、リリース ID) と、利用条件を確かめた日。
7. 未確認のこと: 結論を左右するのに確かめられなかったこと。網羅性や精度を見比べる手順を添える。

## 注意

- 利用条件は項目と版ごとに違う。「国土数値情報は CC BY」のように出どころ単位でまとめて書かない。
- 公式見解の無いライセンスの組み合わせ (ODbL と CC BY や PDL を 1 つのデータベースにするなど) は、推測と明記し、断定しない。
- 安全に関わる情報 (避難場所など) は、時点と出どころを地図の上で見せることを勧める。
- 店舗や施設の件数を地域ごとに数えるときは、出どころごとに数えて並べ、食い違いの大きさを答えに書く。正解の数が手に入らないなら、どの出どころの数で描いたかを地図に書く。
- 規約やライセンスの解釈は、条文から読んだものと推測を分けて書く。法的な判断を断定しない。
