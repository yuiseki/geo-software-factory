# map-compare-data

地図プロダクトの「表示するデータ」を、どの出どころから得るかを決める。

後で書く。

| reference | 読むとき | 中身 |
|---|---|---|
| [criteria](references/criteria.md) | 比較を始める前に、いつも | 比較の軸 (後で書く) |
| [sources/openstreetmap](references/sources/openstreetmap.md) | 候補に入れるとき | OpenStreetMap のデータ (タイルではなく地物) |
| [sources/overture-maps](references/sources/overture-maps.md) | 候補に入れるとき | Overture Maps |
| [sources/ksj](references/sources/ksj.md) | 国内が対象のとき | 国土数値情報 |
| [sources/fgd](references/sources/fgd.md) | 国内で正確な基盤の図形が要るとき | 基盤地図情報 |
| [sources/estat](references/sources/estat.md) | 統計や境界が要るとき | e-Stat の統計と境界 |
| [sources/abr](references/sources/abr.md) | 住所の正規化や位置参照が要るとき | アドレス・ベース・レジストリ |
| [sources/municipal-open-data](references/sources/municipal-open-data.md) | 自治体のデータが要るとき | 自治体のオープンデータと G空間情報センター |
| [license-mixing](references/license-mixing.md) | 複数のデータを混ぜるとき | ライセンスを混ぜたときの条件 |

後で書く:

- 入力 (要件のうち、このスキルの判断を左右するもの)
- 進め方
- 出力の形
- 注意
