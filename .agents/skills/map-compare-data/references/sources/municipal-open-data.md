対象: 自治体標準オープンデータセット、各自治体のカタログ、G空間情報センター、BODIK

## 概要

自治体のオープンデータは、公共施設、避難場所、AED、公衆トイレ、文化財、子育て施設などの一覧を、各自治体が CSV などで公開しているものである。デジタル庁の自治体標準オープンデータセットが項目と様式の標準を示し、施設系の多くの一覧に緯度と経度の項目がある。公開先は自治体自身のカタログ、BODIK のような共同カタログ、G空間情報センターなどに分かれる。ライセンス、更新、品質は自治体とデータセットごとにばらばらなので、全国をまとめて使うには集める手間と正規化が要る。

## 形式と取得方法

- 配布形式 (Shapefile、GeoJSON、GeoParquet、PMTiles、CSV など): BODIK のカタログのリソース形式は CSV (8,830)、XLSX (5,352)、PDF (3,112)、XLS (2,974) が多く、GeoJSON は 473。東京都のカタログは CSV (6,243)、XLS (1,314)、XLSX (1,176)、PDF (544) が多く、GeoJSON は 35。G空間情報センターは ZIP (10,415)、PDF (7,476)、GeoJSON (3,904)、SHP (2,519)、CSV (1,843) が多い (いずれも 2026-11-10 に CKAN API のファセットで数えた値)。施設の一覧は緯度経度の列を持つ CSV が中心で、PDF や Excel だけのものもある。自治体標準オープンデータセットの定義書は Excel で、文字コード (UTF-8 など) をメタデータに書く項目がある。
- 取得方法 (一括ダウンロード、API、範囲を絞った取得): 各カタログのページからダウンロードする。BODIK、東京都、G空間情報センターのカタログは CKAN API (`/api/3/action/package_search` など) で検索と一覧が取れる (2026-11-10 に応答を確認)。BODIK は自治体標準オープンデータセットなどの API や位置情報を使う Location API も提供している。G空間情報センターの多くのデータは登録なしでダウンロードできるが、一部 (法務省登記所備付地図の XML など) はユーザー登録が要り、有料のデータもある。出典: https://www.bodik.jp/ 、 https://front.geospatial.jp/faq/
- 座標参照系: 自治体標準オープンデータセットの定義書には座標参照系を示す項目の注記があるが、緯度経度の測地系 (JGD2011 など) を統一して定める記載は見つけられなかった。CSV の緯度経度は世界測地系の 10 進度が多いと考えられる (推測)。Shapefile は平面直角座標系のものもあり、データごとに確かめる必要がある (推測)。

## ライセンスと出典表示

- ライセンス: データセットごとに違う。オープンデータ基本指針 (2017-05-30 決定、2024-07-05 改正) と公共データ利用規約のページでは、PDL 1.0 は国と地方公共団体などのサイトやオープンデータに使え、これまで政府標準利用規約や CC BY 4.0 を使っていたものにも PDL 1.0 を使うよう案内している。PDL 1.0 は CC BY 4.0 と互換。実際のカタログでは CC BY 4.0 が多く、BODIK では cc-by-40-intl が 13,903 件、PDL 1.0 が 297 件、CC BY 2.1 JP などもある。東京都はほぼ全件が CC BY 4.0 (9,675 件、ほかに CC BY-NC-ND 4.0 が 1 件)。G空間情報センターは「独自利用規約」(ol) が 5,886 件で最も多く、CC BY、政府標準利用規約、ライセンス未指定 (2,131 件)、非商用 (cc-nc 109 件) などが混ざる (件数は 2026-11-10 に CKAN API で数えた値)。出典: https://www.digital.go.jp/resources/open_data 、 https://www.digital.go.jp/resources/open_data/public_data_license_v1.0
- 出典表示の書き方 (公式の例): 東京都: 「【ライセンスされている著作物のタイトル】、東京都・【その他の著作権者】、クリエイティブ・コモンズ・ライセンス 表示4.0国際」。G空間情報センターの FAQ: CC BY のデータで出典者の指定がなければ「□□作成の〇〇」を使用しています (□□は出典者名、〇〇はデータセット名かリソース名)。PDL 1.0: 提供者、ページの URL、PDL 1.0 へのリンクを示す。出典: https://portal.data.metro.tokyo.lg.jp/terms/ 、 https://front.geospatial.jp/faq/ 、 https://www.digital.go.jp/resources/open_data/public_data_license_v1.0
- 加工したときの表示: 東京都は「この【作品・アプリ・データベース等】は、以下の著作物を改変して利用しています。」を加え、東京都や都内区市町村が作ったように見せることを禁じる。PDL 1.0 も加工したことと加工者を書くよう求める。出典: https://portal.data.metro.tokyo.lg.jp/terms/ 、 https://www.digital.go.jp/resources/open_data/public_data_license_v1.0
- 商用利用、再配布、加工したものの再配布: CC BY 4.0 と PDL 1.0 のデータは出典表示で商用利用と再配布ができる。東京都の規約は「商用利用も可能です。」と明記する。G空間情報センターの FAQ は、CC BY のデータは出典を明記すれば商用を含めて許諾なしで使えるとする。独自利用規約、非商用、ライセンス未指定のデータは個別の規約を読む必要があり、未指定のものは使える条件がわからない (推測)。出典: https://portal.data.metro.tokyo.lg.jp/terms/ 、 https://front.geospatial.jp/faq/
- 他のデータと混ぜたとき (ODbL、CC BY、PDL、政府標準利用規約など) の条件: 公式の説明は見当たらない。複数の自治体の CC BY 4.0 と PDL 1.0 のデータを 1 つのレイヤーにまとめる場合、自治体ごとに出典を並べて書く必要があると考えられる (推測)。CC BY 4.0 のデータを OpenStreetMap (ODbL) に取り込むことの可否は、本ファイルでは確かめていない。

## 品質の限界

- 公開している自治体としていない自治体があり、全国をそろえて表示すると空白の地域ができる (推測)。
- 同じ種類の一覧でも、自治体ごとに列名、文字コード、緯度経度の有無が違うことがある。自治体標準オープンデータセットは揃えるための標準だが、従っていないデータもある (推測)。
- 位置は住所からのジオコーディングで付けたものなど、付け方がまちまちで精度がわからない (推測)。
- G空間情報センターの「最終更新日」はデータ自体の更新とは限らず、データの取得時期は概要や付帯資料、提供元で確かめる必要がある。出典: https://front.geospatial.jp/faq/
- G空間情報センターは格納と配信の場で、データの不備には回答しないとしている (登記所備付地図についての FAQ)。品質の問い合わせ先はデータの提供者になる。出典: https://front.geospatial.jp/faq/
- 文化財などは、存在自体を公表できないものがあり、可能なものだけ公開するよう標準の定義書に注記がある。網羅性は保証されない。出典: 定義書 A

## 地図プロダクトでの使いどころ

- 特定の自治体の地図 (防災マップ、子育て施設マップ、AED マップ、公共施設案内など) で、その自治体が公式に出している最新の施設一覧を載せるとき。
- 指定緊急避難場所など、自治体が指定するもので、国のデータより新しい情報が要るとき。
- 自治体標準オープンデータセットに従ったデータなら、同じ処理で複数の自治体のデータを読めるとき。

## 向いていない場面

- 全国を同じ質でそろえたい場面。国土数値情報や国土地理院のデータ、民間の POI のほうが向く。
- 自動で定期的に取り込みたいが、自治体ごとに形式や URL が変わる場面。集める処理の保守が重くなる (推測)。
- ライセンス未指定や独自規約のデータを、確かめずに商用で使う場面。
