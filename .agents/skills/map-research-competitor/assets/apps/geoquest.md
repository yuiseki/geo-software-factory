# ジオクエ-写真を撮ってポイントに！ポイ活アプリ

- URL: https://apps.apple.com/jp/app/id6475946493
- 観測した日: 2026-11-12
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 提示された条件の場所や物を撮って位置と一緒に投稿すると、ポイントがもらえるポイ活のアプリ |
| 提供する価値 | 移動のついでに写真を撮るだけでポイントが貯まる。運営にとっては、投稿の写真が自社の地図を新しくする材料になる (サイトに「あなたの写真が最新の地図に！」) |
| 想定する利用者 | ポイ活をする人、街歩きや旅行をする人 |
| 商用か非商用か | 商用 (ポイントの支払いと引き換えに、地図を新しくする写真を集める仕組み。サイトに i-mobile の広告) |
| 推定の売上 | 未確認 (集めた写真は自社の地図の事業に使われると見られる) |
| 運営 | 企業 (ジオテクノロジーズ株式会社。トリマと同じ会社) |
| 推定の運用費 | 推測: 月数百万円以上 (投稿者へのポイントと、写真の審査) |
