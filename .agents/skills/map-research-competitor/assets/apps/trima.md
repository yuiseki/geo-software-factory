# トリマ-歩数・移動でポイント！散歩やウォーキングでお金を稼ぐ

- 観測した日: 2026-11-12
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 移動の距離と歩数に応じてマイルが貯まり、電子マネーやポイントに交換できるポイ活のアプリ |
| 提供する価値 | ふだんの移動と散歩が小さなお金になり、移動の軌跡と滞在した場所も振り返れる |
| 想定する利用者 | ポイ活をする人、よく歩く人 |
| 商用か非商用か | 商用 (アプリは無料。広告と、移動のデータの活用で賄うと見られる (推測)) |
| 推定の売上 | 推測: 年数十億円規模。App Store の評価 37 万件、Google Play 500 万ダウンロード以上。売上は公開されていない |
| 運営 | 企業 (ジオテクノロジーズ株式会社。地図のデータの会社) |
| 推定の運用費 | 推測: 月数千万円以上 (利用者へのポイントの還元が大きな原価になる)。位置の記録を集めて保存する仕組み |
