# V2X2MAP - live receiver and map for ITS-G5 / V2X

- URL: https://v2x2map.com/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | クルマや信号機が 5.9 GHz で送る ITS-G5 (V2X) の電波を、20 ドルの ESP32-C5 の受信機で拾って地図に示す iPhone と Android のアプリ |
| 提供する価値 | 周りのクルマや信号機が何を送っているかを、クラウドを使わずスマートフォンで見られる |
| 想定する利用者 | V2X や無線に関心がある技術者、愛好家 (主に欧州) |
| 商用か非商用か | 商用 (有料のアプリ: iOS 版は 1.99 USD、日本の App Store では 300 円、2026-11-12) |
| 推定の売上 | 推測: 月数万円以下。専用の受信機が要る狭い分野のアプリ |
| 運営 | 個人 (App Store の販売元は個人名。Imprint のページがある) |
| 推定の運用費 | 推測: 月 0〜数百円とストアの登録料 (Apple は年 99 USD)。解読は端末の中で行い、サーバーを持たない |
