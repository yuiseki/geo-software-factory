## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 緊急地震速報、豪雨予報、避難情報などをプッシュ通知で知らせ、現在地と登録した地域の災害情報と避難場所、災害マップを見るアプリ |
| 提供する価値 | 現在地と最大 3 地点の災害情報をいち早く受け取り、旅行中や離れた家族の地域にも備えられる |
| 想定する利用者 | すべての住民、旅行者、離れて暮らす家族を持つ人 |
| 商用か非商用か | 非商用と見られる (無料。アプリ内課金は無い。LINEヤフーの社会貢献と自社のサービスへの集客の面がある (推測)) |
| 推定の売上 | なし (アプリそのものの売上は見えない) |
| 運営 | 企業 (LINEヤフー株式会社) |
| 推定の運用費 | 推測: 月数百万円以上。災害のときに数百万台へ同時に通知を送る仕組みと、災害マップへの投稿の受け付け |
