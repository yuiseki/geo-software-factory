# adsb.lol, unfiltered flight tracking

- URL: https://www.adsb.lol/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中の有志の受信機が集めた航空機の ADS-B の信号を、絞り込まずに地図と API と毎日のアーカイブで公開するネットワーク |
| 提供する価値 | 大手の追跡サイトが有料化や表示の制限をした機体も含めて、生のデータを誰でも無料で使える |
| 想定する利用者 | 航空機の追跡を趣味にする人、受信機を置いて信号を寄せる人、航空データを使う開発者や研究者 |
| 商用か非商用か | 商用 (寄付。運営者の GitHub Sponsors へのリンクがある)。広告と有料プランは見えなかった |
| 推定の売上 | 推測: 月数万〜数十万円の寄付。根拠は GitHub Sponsors のみで、金額は公開されていない |
| 運営 | 個人 (サイトの下に「made with <3 by katia」、2023 年から) |
| 推定の運用費 | 推測: 月数万〜十数万円。同時に約 1.3 万機、WAN 約 130 Mbps の常時の受信と配信、5,610 GB のアーカイブを Kubernetes で持つ (画面の表示、2026-11-12) |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | OpenLayers |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | 見つからなかった |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | Istio (Kubernetes) の後ろ |

- 航空機の位置を ADS-B で集めて表示する。OpenLayers で描いており、tar1090 の系統と見られる (推測)
