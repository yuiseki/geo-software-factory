# 浸水センサ表示システム（国土交通省）

- URL: https://c-sensor.river.go.jp/map/index?x=15028131.25709&y=4478521.57355&z=5.23368&r=0
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 浸水、冠水、洪水、浸水センサ、水害、IoT センサ、国土交通省

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 国土交通省が自治体や企業と置いた浸水センサの状態を、地図で示す実証実験のシステム |
| 提供する価値 | 堤防の越水や地域の浸水を、現地のセンサから速やかにつかめる |
| 想定する利用者 | 河川と防災の担当者、自治体、浸水の状況を知りたい住民 |
| 商用か非商用か | 非商用 (国の実証実験。二次利用は認めていないと明記) |
| 推定の売上 | なし (非商用) |
| 運営 | 公的機関 (国土交通省。令和6年度は 162 自治体と 45 企業等と実証実験、ページの説明) |
| 推定の運用費 | 未確認。センサの機器と通信、CloudFront と nginx のサーバーを国の予算で持つ。地図の配信だけなら月数万円規模 (推測) |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | OpenLayers |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | 地理院タイル、自前のタイル (サイトと同じドメイン) |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | CloudFront 経由 (nginx/1.14.1) |
