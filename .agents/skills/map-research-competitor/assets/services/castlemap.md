- 観測した日: 2026-11-11

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | シドニー周辺 (ニューカッスルからウロンゴンまで) の、建物の間取りや区画を載せた独自の地図タイルと地図 |
| 提供する価値 | 不動産や建築の仕事で使える区画と住所の地図を、自分のサイトに埋め込める |
| 想定する利用者 | グラニーフラットの施工業者、設計事務所、不動産のサイト |
| 商用か非商用か | 商用と見られる (タイルの外部サイトでの利用とセルフホストを案内している。料金は見えなかった) |
| 推定の売上 | 未確認。料金表は見えなかった。推測: 個人の受託や利用料で月数万円以下 |
| 運営 | 個人 (About に Daniel Lyons への連絡先) |
| 推定の運用費 | 推測: 月数千円。Ubuntu の Apache で自前のタイルを配る VPS 1 台 |
