## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | Organic Maps から分かれた、コミュニティ主導で非営利の、オフラインの地図とナビのアプリ |
| 提供する価値 | 透明性、プライバシー、非営利を約束したうえで、オフラインの地図とナビを無料で使える |
| 想定する利用者 | 旅行者、ハイカー、プライバシーを気にする人、運営の透明性を重視する人 |
| 商用か非商用か | 商用 (寄付。Open Collective の表示で年約 23,300 (通貨は応答で GBP、2026-11-12)。広告とアプリ内課金は無い) |
| 推定の売上 | Open Collective の表示: 年の収入 約 23,300 GBP、残高 約 22,500 GBP (2026-11-12) |
| 運営 | 団体 (コミュニティ。App Store の販売元は個人名) |
| 推定の運用費 | 推測: 月数万〜数十万円。地図を作って配るサーバー。Open Collective で支出が公開されている |

## 技術 (2026-11-12 の観測)

| 項目 | 観測したもの |
|---|---|
| 種類 | iOS と Android のアプリ |
| 描画 | 自前の C++ の地図エンジン (Organic Maps から分かれた) |
| フレームワーク | C++ (共通) |
| 背景の地図とタイル | OSM から作った自前のオフラインの地図 |
| 投稿やデータの保存先 | 端末の中 |
| 配信 | App Store、Google Play |
