# 賃貸を地図で探す - 家賃相場が一目でわかる物件検索 | Comfy

- URL: https://comfy.maison/
- 観測した日: 2026-11-12
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 賃貸、部屋探し、物件検索、家賃相場、不動産、通勤時間、住む場所

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国約 110 万件の賃貸物件を、家賃、間取り、行き先の駅までの所要時間などで絞り込みながら、件数と家賃の相場を地図とグラフで見る物件検索 |
| 提供する価値 | エリアを決めていなくても、条件を変えるたびに地図の上の件数と相場がすぐ変わり、自分に合う場所と物件を探せる |
| 想定する利用者 | 賃貸の部屋を探す人、とくに住む地域がまだ決まっていない人 |
| 商用か非商用か | 商用 (アフィリエイトで提携した物件の掲載と、問い合わせの取次ぎ) |
| 推定の売上 | 推測: 月数十万〜数百万円。物件の問い合わせや成約ごとのアフィリエイトの報酬。売上は公開されていない |
| 運営 | 企業 (株式会社cocowa) |
| 推定の運用費 | 推測: 月数万〜十数万円。Vercel の配信、Cloud Run の検索の API、110 万件の物件を 1 日 1 回以上更新する処理、自前の PMTiles (e-Stat の境界、鉄道) |

## 技術 (2026-11-12 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | MapLibre GL JS |
| フレームワーク | Next.js、React |
| 背景の地図とタイル | OpenStreetMap Japan のタイル、自前のタイル (サイトと同じドメイン) |
| 投稿やデータの保存先 | 物件の検索の API (Google Cloud Run、`*.a.run.app`) |
