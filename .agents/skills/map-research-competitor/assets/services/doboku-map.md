## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本の大規模な土木事業 150 件 (鉄道、道路、ダム・河川、港湾・空港) を地図に置き、事業費、工期、進捗率、遅れと増額、最近のニュースを一覧と統計で見せる地図 |
| 提供する価値 | 各地の大きな工事が、いくらかかり、どこまで進み、遅れや増額があるかを、公表資料と報道へのリンクつきで 1 画面で見渡せる |
| 想定する利用者 | インフラや公共事業に関心のある人、鉄道や道路の工事を追う人 |
| 商用か非商用か | 非商用と見られる (広告、寄付、有料プランは見えなかった。運営の会社へのリンクも画面には無い) |
| 推定の売上 | なし (非商用と見られる) |
| 運営 | 企業と見られる (株式会社Hiden、京都市。地図のドメイン h1den.com が同社のサイト。地図の画面の表記は「BUILT BY @hiden830」(X のアカウント) だけ) |
| 推定の運用費 | 推測: 月数百円以下。Amazon S3 と CloudFront の静的配信で、背景は無料の地理院タイル。案件のデータは 1 つの JSON (約 360 KB)。データの調べ直しにかかる人の時間は含めていない |

メモ:

- 案件の JSON は 150 件で、1 件ごとに事業者、事業費、工期、状況の要約、進捗率 (公表されている案件だけ)、ニュース、出典、YouTube の動画、路線や区間の線 (75 件) を持つ。出典は合計 360 件、ニュースは 268 件、動画は 47 件
- 画面の上の集計は、総事業費 40.6 兆円、実進捗の公表 31 件、計画段階 28 件、遅れ 16 件、増額 35 件 (2026-11-12)
- 画面の「DB SYNC」は 09-04、ニュースの最新は 2026-09 だった。JSON の最終更新 (Last-Modified) は 2026-10-30 (2026-11-12)
- 全案件の一覧のページ (`/p/index.html`) がある
- ルートの線は概略で、破線は未着工か計画段階 (画面の最下部)
- 通信は Google Analytics だけで、広告の通信は無かった
- はてなブックマーク 5 件 (2026-11-12)

データの出どころ:

| データ | 出どころ | どこに書いてあるか |
|---|---|---|
| 背景の地図 | 国土地理院 (地理院タイル、淡色地図) | 地図の帰属表示、画面の最下部 (「MAP: 国土地理院タイル」) |
| 案件の事業費、工期、進捗 | 各事業者、国土交通省などの公表資料と報道。案件ごとの出典は国土交通省と各地方整備局、水資源機構、都道府県と市、鉄道会社、防衛省などのページ | 画面の最下部 (「SOURCE: 各事業者・国土交通省等の公表資料および報道」)、各案件の出典のリンク |
| ニュース | 報道とブログ (`kurukura.jp`、乗りものニュース、日本経済新聞、`news.railway-pressnet.com`、マイナビニュース、時事通信など) と、事業者の発表 | 各案件のニュースのリンク、LIVE FEED |
| 動画 | YouTube | 各案件の動画のリンク |
| ルートの線 | 未確認 (概略表示とだけ書かれている。自作と見られる) | 画面の最下部 |

案件の情報は、公表資料と報道を読んでまとめたものと見られるが、まとめ方は書かれていない。進捗率は工事全体の実進捗が公表されている案件だけ、事業費は概算で公表時点のもの (全案件の一覧のページ、2026-11-12)
