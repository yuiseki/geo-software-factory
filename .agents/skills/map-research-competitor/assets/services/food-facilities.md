# 🍽️ Japan Food Facilities - 地図

- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の自治体と厚生労働省の食品営業許可のオープンデータを集めた約 138 万施設を、業種で絞って見る地図 |
| 提供する価値 | ばらばらの自治体のオープンデータを、全国で 1 つの形にまとめて使える |
| 想定する利用者 | 飲食や食品の業界を調べる人、出店の候補地を探す人、オープンデータを使う開発者 |
| 商用か非商用か | 非商用と見られる (広告、寄付、有料プランは見えなかった。データとコードを GitHub で公開) |
| 推定の売上 | なし (非商用と見られる) |
| 運営 | 団体か個人 (GitHub の組織 gl20percentclub。運営者の表示は見つからなかった) |
| 推定の運用費 | 推測: 月 0〜数百円。GitHub Pages の静的配信と地理院タイル |
