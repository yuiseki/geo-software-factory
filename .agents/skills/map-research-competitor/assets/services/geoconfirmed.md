- URL: https://geoconfirmed.org/map/iran
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 紛争、OSINT、位置特定、ジオロケーション、検証、戦争

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界の紛争の映像や写真の撮影地点を、有志が特定して確かめ、地図に載せる OSINT のプロジェクト |
| 提供する価値 | 紛争の現場の映像がいつどこのものかを、検証された地点で追える |
| 想定する利用者 | 記者、研究者、紛争を追う OSINT の愛好家 |
| 商用か非商用か | 非商用と見られる (ボランティアのプロジェクト。地図のページに広告、有料プランは見えなかった。寄付は未確認) |
| 推定の売上 | なし (非商用と見られる。寄付の有無は未確認) |
| 運営 | 団体 (有志のボランティア) |
| 推定の運用費 | 推測: 月数千〜数万円。Cloudflare の後ろのサーバーと自前のタイル、ログインの仕組み |
