# GeoLens: Open-Source Geospatial Data Catalog & Map Builder

- URL: https://getgeolens.com/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: データカタログ、GIS、OGC API、セルフホスト、PostGIS、地図作成

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 自分のサーバーに置く、地理空間データのカタログと地図作成のオープンソースのアプリ |
| 提供する価値 | チームの空間データを探して、見て、地図にして、OGC API で QGIS や ArcGIS Pro に渡せる。データは PostGIS と開いた形式に残る |
| 想定する利用者 | 地理空間データを持つ組織の GIS の担当者 |
| 商用か非商用か | 非商用 (Apache-2.0 の OSS。有料プランや寄付は見えなかった) |
| 推定の売上 | なし (非商用。サイトは OSS の紹介) |
| 運営 | 団体 (GeoLens contributors。GitHub の組織 geolens-io) |
| 推定の運用費 | 推測: 月数千円。紹介のサイトとデモ。利用者は自分のサーバーで動かす (メモリ 8 GB が要る) |
