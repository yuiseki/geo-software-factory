## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 人工衛星、航空機、船、公開のカメラの実際のデータを、写実的な 3D の地球儀に重ねて追う、ブラウザで動くオープンソースの状況把握のツール |
| 提供する価値 | 公開されたデータだけで、スパイ衛星の画面のように世界の動きを 1 つの地球儀で見られる |
| 想定する利用者 | OSINT や地理空間の情報に関心がある人、開発者、AI エージェントを使う人 |
| 商用か非商用か | 商用と見られる (コードは MIT で無料。ホストした版の順番待ちを募っており、運営は企業) |
| 推定の売上 | 未確認 (ホストした版の料金は公開されていない)。GitHub のスター 6.3 万以上、YouTube で 2,500 万回以上の視聴とサイトに表示 |
| 運営 | 企業 (Halfpixel, Inc.。作者は Bilawal Sidhu) |
| 推定の運用費 | 推測: 紹介のサイトは月 0〜数千円 (Cloudflare)。利用者が自分で動かす場合は、写実的な 3D の地図 (Google の Photorealistic 3D Tiles なら月 1,000 件を超えると 1,000 件あたり 6 USD) とデータの API の費用が利用者側にかかる |
