# ゴミ箱マップ | 街中のゴミ箱情報をシェアしよう！

- URL: https://gomibako-map.com/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: ゴミ箱、ごみ箱、くずかご、投稿、共有、街歩き

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 街中のゴミ箱の場所を、利用者が登録して共有する地図 |
| 提供する価値 | 外出先でゴミ箱を探し回らずに済み、ポイ捨てを減らす |
| 想定する利用者 | 観光や出張で街を歩く人 |
| 商用か非商用か | 商用 (Google AdSense の広告、不用品回収の予約などへの誘導) |
| 推定の売上 | 推測: 月数千円以下。はてなブックマーク 2 件 (2026-11-12) で、広告の収入は表示回数に比例するため |
| 運営 | 個人と見られる (運営者の会社名は見つからなかった。2022 年から) |
| 推定の運用費 | 推測: 月 1,000〜3,000 円。nginx のサーバー 1 台 (WordPress と見られる) と、OSM 財団の公開タイル (費用はかからないが利用方針の条件がある) |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet |
| フレームワーク | WordPress |
| 背景の地図とタイル | OSM 財団の公開タイル、Mapbox の API への通信 (用途は未確認) |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | nginx (配信先の事業者は不明) |

読み込んだタイルとスタイルの URL (一部):

- `https://a.tile.osm.org/{z}/{x}/{y}.png`
- `https://b.tile.osm.org/{z}/{x}/{y}.png`
- `https://c.tile.osm.org/{z}/{x}/{y}.png`
