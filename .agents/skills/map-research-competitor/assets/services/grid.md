## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国の基幹送電網を路線図のように描き、電気の流れ (潮流) を光で示す模式図の地図 |
| 提供する価値 | 見えない電力の流れと送電網のつながりを、時刻ごとに路線図の感覚で眺められる |
| 想定する利用者 | 電力やインフラに関心がある人、エネルギーを学ぶ人 |
| 商用か非商用か | 非商用と見られる (広告、寄付、有料プランは見えなかった。地図のデザインの活動の作品) |
| 推定の売上 | なし (非商用と見られる。デザインの仕事への宣伝の面はありうる) |
| 運営 | 個人と見られる (chizutodesign。X と note のアカウント) |
| 推定の運用費 | 推測: 月 0〜数百円。Cloudflare の静的配信。潮流は OCCTO などの公開資料から作る |
