# 地理院ルートビルダー｜峠名がわかる自転車ルート作成（GPX無料）

- URL: https://wheelwhirlpool.com/route/
- 観測した日: 2026-11-12
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 自転車、サイクリング、ルート作成、峠、GPX、獲得標高、勾配

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地理院の地図の上で自転車のルートを作り、通る峠の名前、距離、獲得標高、勾配を見て GPX と FIT で保存するツール |
| 提供する価値 | 峠の名前が分かるルートを無料で作れ、ルートを自動で作る「峠ガチャ」で行き先も選べる |
| 想定する利用者 | ロードバイク、グラベル、トレイルのサイクリスト |
| 商用か非商用か | 商用 (ルートに合わせて自転車の用品を勧める欄がある。アフィリエイトと見られる (推測)。運営者のブログもある) |
| 推定の売上 | 推測: 月数千円以下。はてなブックマーク 5 件 (2026-11-12) |
| 運営 | 個人と見られる (やくものガレージ) |
| 推定の運用費 | 推測: 月 1,000〜3,000 円。nginx のサーバー、地理院タイル、BRouter の経路探索。OSM の公開の Overpass API (overpass-api.de) への通信があった。月 1 回 OSM のデータをサイトに取り込むと説明 |

## 技術 (2026-11-12 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet |
| フレームワーク | 見つからなかった |

読み込んだタイルとスタイルの URL (一部):

- `https://cyberjapandata.gsi.go.jp/xyz/dem5a_png/{z}/{x}/{y}.png`
- `https://cyberjapandata.gsi.go.jp/xyz/experimental_anno/{z}/{x}/{y}.geojson`
- `https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png`

メモ:

- 経路探索は BRouter。OSM の公開の Overpass API (`overpass-api.de`) への通信があった
- 峠や水場の名前は、地理院の注記 (`experimental_anno`) と OSM から取っている
