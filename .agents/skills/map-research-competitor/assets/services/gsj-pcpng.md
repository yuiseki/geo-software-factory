## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 複数の点群のデータから点群 PNG タイルを作り、統合したタイルセットとして公開する実例のページ |
| 提供する価値 | 大量の点群を、地理院タイルと同じタイルの分け方で、必要な範囲と解像度だけ受け取って使える |
| 想定する利用者 | 点群をウェブで扱う開発者、測量や地質の研究者 |
| 商用か非商用か | 非商用 (研究機関の公開) |
| 推定の売上 | なし (非商用) |
| 運営 | 公的機関 (産業技術総合研究所 地質調査総合センター、tiles.gsj.jp) |
| 推定の運用費 | 推測: 月数千〜数万円。S3 と CloudFront の配信で、費用は点群タイルの量と転送量に比例する |
