# どこでも北海道マップ

- URL: https://kishobosai.github.io/-Map/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 北海道や都府県の形を、地図の上でドラッグして世界の別の場所に重ね、メルカトル図法での大きさを比べる地図 |
| 提供する価値 | 高緯度ほど大きく描かれるメルカトル図法の歪みを、身近な北海道の形で実感できる |
| 想定する利用者 | 地理を学ぶ生徒と教員、地図の図法に関心がある人 |
| 商用か非商用か | 非商用 (広告、寄付は見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 個人と見られる (GitHub のアカウント kishobosai) |
| 推定の運用費 | 推測: 0 円。GitHub Pages の静的配信と、OSM 財団の公開タイル (費用はかからないが利用方針の条件がある) |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet |
| フレームワーク | 見つからなかった |
