## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 出かけた先で、いま開いている本屋、近くの大きな本屋、本屋のイベントを探す全国の新刊書店と古本屋の地図 |
| 提供する価値 | 全国約 8,600 軒の本屋から、今から行ける店をすぐに見つけられる |
| 想定する利用者 | 旅先や外出先で本屋に寄りたい人、本屋めぐりが好きな人 |
| 商用か非商用か | 非商用と見られる (広告、寄付、有料プランは見えなかった) |
| 推定の売上 | なし (非商用と見られる) |
| 運営 | 個人 (AI と一緒に作っているとサイトで説明) |
| 推定の運用費 | 推測: 月数千円以下。店のデータ (転送 627 KB) の静的配信、OpenFreeMap のタイル、Supabase (無料か月 25 USD)。店とイベントの情報を AI で集める API の費用が加わる |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | MapLibre GL JS 5.6.0 |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | OpenFreeMap |
| 投稿やデータの保存先 | Supabase |
| 配信 | Cloudflare |

読み込んだタイルとスタイルの URL (一部):

- `https://tiles.openfreemap.org/planet/20261101_080013_pt/{z}/{x}/{y}.pbf`

メモ:

- 全国の本屋を探す地図。画面に「この範囲 8673 軒」と出た。店とイベントの情報は AI で集めており、確かめきれていないところがあるとサイトで説明している
- 店のデータは `/real/index.json` 1 本 (展開して 2.2 MB、転送 627 KB)、イベントは `/real/events.json`。MapLibre GL JS 5.6.0 を cdnjs から読む
- Supabase の `data_edits_live` を開くたびに呼んでいた。利用者からの修正の受け付けに使っていると見られる (推測)
