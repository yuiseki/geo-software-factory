- URL: https://jvmap.live/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: ライブハウス、ライブ会場、コンサートホール、アリーナ、音楽、会場検索

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国のライブハウス、ホール、アリーナ、ジャズの店など約 2,400 の音楽の会場を、エリアとキャパシティで探す地図 |
| 提供する価値 | 出演や公演の会場を、住所、電話、公式サイトまで地図からすぐに探せる |
| 想定する利用者 | バンドマン、イベンター、音楽ファン |
| 商用か非商用か | 商用 (Google AdSense の広告と、Stripe で払う有料の機能 (特定商取引法の表記あり。品目は未確認)) |
| 推定の売上 | 推測: 月数千〜数万円。はてなブックマーク 7 件 (2026-11-12) で、表示回数は大きくないと見られる |
| 運営 | 企業 (株式会社takepoint、東京都渋谷区) |
| 推定の運用費 | 推測: 月 0〜数千円。Vercel の配信と CARTO のベースマップ (商用の利用は CARTO との契約が要る場合がある) |
