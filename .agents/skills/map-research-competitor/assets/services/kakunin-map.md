## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地図の中心や現在地を基準に、周りの約 250 m メッシュの高低差を色で示し、洪水の浸水想定区域と避難場所を重ねる防災の地形アプリ |
| 提供する価値 | 自分のいる場所が周りより低いか、どちらが高いかをひと目で確かめ、近くの避難場所を距離の順に探せる |
| 想定する利用者 | 防災に備えたい住民、水害が心配な土地に住む人 |
| 商用か非商用か | 非商用と見られる (無料、アカウント不要、広告を表示しないとストアの説明に明記) |
| 推定の売上 | なし (アプリそのものの売上は無い。会社の技術の紹介の面がある) |
| 運営 | 企業 (ウェーブオン株式会社) |
| 推定の運用費 | 推測: 月数千円とストアの登録料 (Apple は年 99 USD)。標高、浸水想定 (国土数値情報)、避難場所 (国土地理院) は公開データ。位置を自社のサーバーに保存しないと説明 |
