- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 郵便番号や気になるテーマから、自分に関係する国会議員と、その発言、投票、政治とお金の記録を調べるサイト |
| 提供する価値 | 広告も政党の資金も受けずに、考えの近い議員と代表者の活動を多面的に知れる |
| 想定する利用者 | 有権者、とくに政治に詳しくない人 |
| 商用か非商用か | 商用 (寄付。月額サポーター: 月 500 円から、特別応援 月 3,000 円。広告と政党や企業の資金は受け取らないと明記) |
| 推定の売上 | 運営者の公表: 両マップ合計で 2026 年 9 月の応援金 501,974 円、8 月 643,666 円。継続サポーター 208 名で毎月約 196,400 円 (2026-10-01 集計、サイトの運営収支のページ) |
| 運営 | 個人 (個人運営の非公式のサイトと明記) |
| 推定の運用費 | 運営者の公表: 2026 年 9 月は約 875,000 円 (Anthropic API 240,000 円、Claude Code の追加利用 312,000 円、Codex 110,000 円、AI の月額基本料 約 122,000 円、サイトとデータベース 約 13,000 円、弁護士 30,000 円など)。自己負担は約 373,000 円。選挙が近づくとアクセスは 10 倍以上になる |
