# 避難施設のご案内

- URL: https://www.kokuminhogo-map.go.jp/kokuminhogo/map
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 避難施設、シェルター、ミサイル、地下、国民保護、避難場所

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 弾道ミサイルが飛んできたときなどの緊急一時避難施設 (堅ろうな建物、地下施設) を、地図と一覧で探す国のサイト |
| 提供する価値 | 近くの避難できる頑丈な建物や地下を、24 時間使えるかまで含めて探せる |
| 想定する利用者 | 住民、旅行者、自治体の担当者 |
| 商用か非商用か | 非商用 (国の行政サービス) |
| 推定の売上 | なし (非商用) |
| 運営 | 公的機関 (内閣官房 国民保護ポータルサイト) |
| 推定の運用費 | 未確認。ゼンリンデータコムの地図 API の契約と、S3 と CloudFront の配信を国の予算で持つ。地図 API の料金は個別の契約で公開されていない |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | ゼンリンデータコムの地図 API |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | 見つからなかった |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | Amazon S3 + CloudFront |
