# くまっぷ - クマ目撃・痕跡情報を共有するマップアプリ

- URL: https://kumap-xenon.web.app/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: クマ、熊、目撃情報、痕跡、投稿、共有、自治体

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | クマの目撃、痕跡、被害を誰でも登録なしで投稿し、地図で共有する仕組み (API とテナント申請もある) |
| 提供する価値 | クマの出没を地域の人どうしでリアルタイムに知らせ合え、自治体などは自分のテナントとして使える |
| 想定する利用者 | クマの出る地域の住民、自治体 |
| 商用か非商用か | 商用と見られる (テナント申請と API の仕様を公開。料金は見えなかった。閲覧と投稿は無料) |
| 推定の売上 | 未確認。テナントの料金は公開されていない |
| 運営 | 企業 (株式会社Xenon) |
| 推定の運用費 | 推測: 月数千円。Firebase Hosting、Supabase (無料か月 25 USD)、OSM 財団の公開タイル (費用はかからないが利用方針の条件がある) |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | OSM 財団の公開タイル |
| 投稿やデータの保存先 | Supabase |
| 配信 | 不明 (応答ヘッダーに手がかりが無い) |

読み込んだタイルとスタイルの URL (一部):

- `https://a.tile.openstreetmap.org/{z}/{x}/{y}.png`
- `https://b.tile.openstreetmap.org/{z}/{x}/{y}.png`
- `https://c.tile.openstreetmap.org/{z}/{x}/{y}.png`
