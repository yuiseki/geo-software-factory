## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 東京の駅から終電で帰れる範囲が、時刻が進むにつれて消えていく様子を同心円で示す地図 |
| 提供する価値 | 終電を「時間」でとらえ、何時までにどの路線で帰れるかが直感で分かる |
| 想定する利用者 | 東京で夜遅くまで出かける人、終電を気にする人 |
| 商用か非商用か | 非商用と見られる (広告、寄付、有料プランは見えなかった。地図のデザインの活動の作品) |
| 推定の売上 | なし (非商用と見られる) |
| 運営 | 個人と見られる (chizutodesign) |
| 推定の運用費 | 推測: 0 円。Cloudflare Pages の静的配信。時刻表は公共交通オープンデータセンターのデータ |
