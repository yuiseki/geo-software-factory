# ラズリマップ｜図面から、測る手間を消す

- URL: https://lazurimap.com/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 地番、筆界、登記所備付地図、測量、地積測量図、土地家屋調査士、SIMA、DXF

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 法務省の登記所備付地図 (筆界) を航空写真に重ね、地積測量図の PDF から座標を読んで重ね、SIMA、DXF、JWW で書き出す測量の業務の地図 |
| 提供する価値 | 図面から測る手間を省き、相続税の土地評価や分割の作業まで地図の上で続けられる |
| 想定する利用者 | 測量の業者、土地家屋調査士、税理士 |
| 商用か非商用か | 商用と見られる (運営は株式会社。地積測量図の読み取りにはアカウントが要る。料金は見えなかった) |
| 推定の売上 | 未確認。料金のページは見つからなかった (2026-11-12) |
| 運営 | 企業 (株式会社ラズリ、東京都渋谷区) |
| 推定の運用費 | 推測: 月数千〜数万円。Fly.io のサーバー、地理院タイルと自前の筆界のタイル、PDF を読み取る処理 |
