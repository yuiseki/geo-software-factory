# MapComplete

- URL: https://mapcomplete.org/
- 観測した日: 2026-11-12
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: OpenStreetMap、OSM の編集、テーマ地図、ベンチ、自転車、カフェ、貢献

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | カフェ、自転車、ベンチなどテーマごとの地図で OpenStreetMap を見せ、そのまま情報を足して OSM へ返せるウェブのプラットフォーム |
| 提供する価値 | OSM の編集の知識が無くても、テーマの地図で質問に答えるだけで OSM をよくできる |
| 想定する利用者 | OSM に貢献したい一般の人、特定のテーマの地図が欲しい団体 |
| 商用か非商用か | 非商用と見られる (広告、有料プランは見えなかった。寄付と助成は未確認) |
| 推定の売上 | なし (非商用と見られる) |
| 運営 | 個人 (作者 Pieter Vander Vennet。GitHub の旧リポジトリは 2025-02 に保存のみになった) |
| 推定の運用費 | 推測: 月数千〜数万円。Caddy のサーバーと PMTiles、編集は利用者のアカウントで OSM の API へ直接送る |

## 技術 (2026-11-12 の観測)

| 項目 | 観測したもの |
|---|---|
| 種類 | ウェブ |
| 描画 | MapLibre GL JS |
| フレームワーク | Svelte |
| 背景の地図とタイル | Protomaps (PMTiles) |
| 投稿やデータの保存先 | OpenStreetMap (利用者のアカウントで直接編集) |
| 配信 | Caddy (配信先の事業者は不明) |
