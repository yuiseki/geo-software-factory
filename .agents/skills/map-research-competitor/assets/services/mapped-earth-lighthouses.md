## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界の海図に載る約 9.6 万の航路標識の灯りを、夜の地球儀の上で、海図に書かれた周期どおりに光らせて見せる地図 |
| 提供する価値 | 灯台やブイの光り方の違いを、世界の海岸で眺めて比べられる |
| 想定する利用者 | 灯台や海に関心がある人、地図の表現が好きな人 |
| 商用か非商用か | 商用 (作者の仕事の見本。報道機関、研究、企業からの地図と映像の受託とコンサルティングを募る。広告と寄付は見えなかった) |
| 推定の売上 | 地図そのものの売上は無い。受託の売上は未確認 |
| 運営 | 個人 (Aaron J. Becker) |
| 推定の運用費 | 推測: 月 0〜数千円。Cloudflare の配信。灯りのデータは OpenSeaMap / OSM、米国の NGA と NOAA と USCG、各国の灯台表から作る |
