## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 市区町村の中の行政区画 (町や字) だけで描いたシンプルな地図を、市区町村ごとに作って公開するサイト (2017 年から制作、全部の完成は 2030 年ごろの見込み) |
| 提供する価値 | 住所の区画の形と並びを、余計なものの無い白地図で確かめられる |
| 想定する利用者 | 地域の区画を知りたい人、資料を作る人、地図の愛好家 |
| 商用か非商用か | 商用 (Google の広告と、閲覧を続けるための広告の視聴の要求。公式グッズ、商標登録) |
| 推定の売上 | 推測: 月数万円。広告の視聴を求めるほど広告に頼っている |
| 運営 | 個人と見られる (運営者の会社名は見つからなかった) |
| 推定の運用費 | 推測: 月 1,000〜3,000 円。LiteSpeed のレンタルサーバー。地図は手作業で作っており、主な費用は作る人の時間 |
