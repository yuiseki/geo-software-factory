# Mobility Maps: Making Public Transport Infrastructure Transparent

- URL: https://mobility.dbvis.de/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ドイツのすべての住宅について、公共交通の駅までの歩く距離と接続の質を分析して示した研究のページと地図 |
| 提供する価値 | どの家が公共交通に恵まれ、どこが取り残されているかを、全国で透明にする |
| 想定する利用者 | 交通計画と都市計画の担当者、研究者 |
| 商用か非商用か | 非商用 (大学の研究の公開) |
| 推定の売上 | なし (非商用) |
| 運営 | 大学 (コンスタンツ大学 データ分析と可視化グループ DBVIS) |
| 推定の運用費 | 推測: 月数千円。大学の nginx のサーバーで、分析の結果を MapLibre と deck.gl で描く |
