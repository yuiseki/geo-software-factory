# 名字マップ

- URL: https://www.dmuchgis.com/myojimap/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 苗字、名字、姓、分布、都道府県、ルーツ

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 電話帳と住宅地図の表札の名前約 4,000 万件を都道府県ごとに集計し、名字の分布を地図にしたもの |
| 提供する価値 | 自分や知り合いの名字がどこに多いかを、人数と特化係数の 2 つの見方で比べられる |
| 想定する利用者 | 名字のルーツに関心がある人、地理や社会を学ぶ人 |
| 商用か非商用か | 非商用 (大学の研究の公開。広告、寄付は見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 大学 (立命館大学。協力 アクトン・ウインズ株式会社) |
| 推定の運用費 | 推測: 月数千円。S3 と CloudFront の静的配信、MIERUNE のタイル (料金は MIERUNE との契約による)。はてなブックマーク 1,063 件 (2026-11-12) で、話題になると転送とタイルの利用が増える |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Leaflet 1.6.0 |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | MIERUNE |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | Amazon S3 + CloudFront |
