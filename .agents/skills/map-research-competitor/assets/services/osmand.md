- URL: https://osmand.net/map/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | OpenStreetMap を使うオフラインの地図とナビのアプリ OsmAnd の、ウェブ版の地図とルート計画 |
| 提供する価値 | ネットにつながらなくても使える地図とナビ、GPX のトラックの解析をウェブでも使える |
| 想定する利用者 | 登山、自転車、旅行でオフラインの地図とナビが要る人 |
| 商用か非商用か | 商用 (アプリの有料プラン Maps+ と Pro。年額の購読と買い切り、FastSpring で販売) |
| 推定の売上 | 推測: 年数億円規模。世界で使われるアプリの購読。数字は公開されていない |
| 運営 | 企業 (OsmAnd B.V.、オランダ) |
| 推定の運用費 | 推測: 月数十万円以上。全球の地図データの更新と、オフライン用の地図とタイルの配信、ナビのサーバー |
