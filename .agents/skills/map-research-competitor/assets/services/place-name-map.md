## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地名や建物名のキーワードを入れると、指定した中心と範囲の中で、その名前を含む建物、駅、バス停、町名、路線、道路を探して地図と一覧に出すツール |
| 提供する価値 | 「〇〇」を名前に含む建物がどこにどれだけあるかを、半径を決めて地図で拾える |
| 想定する利用者 | 地名や建物の名前に興味がある人、地図好き |
| 商用か非商用か | 非商用 (広告、寄付、有料プランは見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 個人 (GitHub の個人アカウント tokyo26-sudo。デイリーポータルZ の記事「AIで地図アプリをたくさん作った」の作者) |
| 推定の運用費 | 推測: 0 円。GitHub Pages の静的配信と CARTO のベースマップ (商用でなければ無料の範囲)。「エリアデータ取得」で OSM のデータを取ると見られる (取得先は観測していない) |
