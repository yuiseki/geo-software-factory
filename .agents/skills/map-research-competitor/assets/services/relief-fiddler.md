- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | マウスのドラッグで標高の色分けを自在に変えながら、日本と世界の地形を探る地図のデモ |
| 提供する価値 | 見たい標高の幅に色を合わせて、ふつうの段彩では見えない地形の細部を浮かび上がらせられる |
| 想定する利用者 | 地形や地質に関心がある人、地図の表現を研究する人 |
| 商用か非商用か | 非商用と見られる (企業のラボのデモ。広告、寄付、有料プランは見えなかった) |
| 推定の売上 | なし (地図そのものの売上は無い。運営する企業の技術の紹介の面がある) |
| 運営 | 企業 (mite-shiru.co.jp の会社のラボ。会社名は確かめていない。作者の GitHub は geoign) |
| 推定の運用費 | 推測: 月 0〜数百円。nginx の静的配信。標高は産総研のシームレス標高タイルと Mapterhorn、背景は地理院タイルで、費用はかからない |

## 技術 (2026-11-12 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | MapLibre GL JS |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | 地理院タイル、産総研のシームレス標高タイル |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | nginx (配信先の事業者は不明) |

- `https://tiles.gsj.jp/tiles/elev2/mixed/{z}/{x}/{y}.webp`
