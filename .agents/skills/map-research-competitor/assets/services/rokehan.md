# どこでもロケハン

- URL: https://tools.oyasumi-gamedev.com/rokehan/
- 観測した日: 2026-11-12
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: ロケハン、マンガの背景、背景素材、3D 街並み、線画、トーン、イラスト

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界のどこでも、実在の街を OpenStreetMap の地図と標高から 3D にし、マンガの背景の線画とトーンで描いて書き出すブラウザのツール |
| 提供する価値 | ロケハンに行けない場所でも、実在の街の背景を、光、季節、人や車まで決めてマンガの絵として手に入れられる |
| 想定する利用者 | マンガ家、イラストレーター、背景を描く人 |
| 商用か非商用か | 非商用と見られる (無料、登録不要。広告と寄付は見えなかった。作者のゲームとマンガの活動の一部) |
| 推定の売上 | なし (非商用と見られる) |
| 運営 | 個人 (MIYADAIKU、おやすみゲーム開発部) |
| 推定の運用費 | 推測: 月数百〜数千円。nginx のサーバーで静的に配り、街のデータは OpenFreeMap、標高は地理院と AWS の Terrain Tiles で、費用はかからない。3D の計算は利用者のブラウザで行う |
