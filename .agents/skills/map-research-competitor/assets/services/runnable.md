# 全国のトレランコースと大会コース｜Runnable

- URL: https://runnable.jp/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: トレイルランニング、トレラン、コース、山、ランニング、大会

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 全国約 1,691 のトレイルランニングのコースと大会コースを、走ってよい区間、予想タイム、補給、エスケープの道まで 1 枚の地図に載せたサービス |
| 提供する価値 | コース選びから当日の補給、下山後の風呂まで、トレランの計画が無料、登録なしで 1 か所で済む。一度開いたコースは電波の無い山でも見られる |
| 想定する利用者 | トレイルランナー、山を走る大会に出る人 |
| 商用か非商用か | 商用 (寄付。Ko-fi の「応援」)。広告と有料プランは見えなかった |
| 推定の売上 | 推測: 月数千円以下の寄付 |
| 運営 | 個人と見られる (Ko-fi のアカウント。会社名は見つからなかった) |
| 推定の運用費 | 推測: 月 0〜数千円。Vercel の配信、地理院タイル、OSM から作った区間データ |
