## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 東京23区の地点ごとに、歩いて行ける飲食店と小売店の多さ、使える路線、主要駅までの時間から利便性のスコアを示す地図 |
| 提供する価値 | 住む場所の候補を、店の集まりと交通の便の数字で比べられる |
| 想定する利用者 | 東京で住む場所を探す人 |
| 商用か非商用か | 非商用 (広告、寄付、有料プランは見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 個人 (KIRIN、X のアカウント) |
| 推定の運用費 | 推測: 0 円。Cloudflare Pages の静的配信。統計は経済センサス、道路は国土地理院のデータ |
