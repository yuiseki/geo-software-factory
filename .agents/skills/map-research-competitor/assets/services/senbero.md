## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 東京都内の立ち飲み、大衆酒場、居酒屋を、予算の目安つきで Google マップから探すせんべろの地図 |
| 提供する価値 | 安く気軽に一杯できる店を、実際に訪ねた記事とあわせて地図で探せる |
| 想定する利用者 | 東京で安く飲みたい人、一人飲みや昼飲みをする人 |

| 推定の売上 | 推測: サイト全体で月数万〜数十万円の広告。はてなブックマーク 596 件 (2026-11-12) |
| 運営 | 個人 (せんべろnet の運営者。自分で巡った店の体験をもとにしたブログ) |
| 推定の運用費 | 推測: 月 1,000〜3,000 円。nginx のサーバー 1 台 (WordPress と見られる)。地図は Google マップで、自分の API キーで Maps JavaScript API を使っているなら月 1 万ロードを超えた分が 1,000 回あたり 7 USD。マイマップの埋め込みなら費用はかからない (どちらかは未確認) |
