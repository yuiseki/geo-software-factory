# showhand - 全晒しAI不動産周辺マップ

- URL: https://showhand.jp/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 不動産、物件の周辺、住環境、マンション、施設、AI

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 物件の周りの、価値を上げる施設と下げる施設を AI で洗い出して地図に示す不動産の周辺マップ |
| 提供する価値 | レインズの物件情報に無い周辺の環境を、買う前に漏れなく確かめられる |
| 想定する利用者 | マンションや戸建ての購入を考える人、不動産の仲介の担当者 |
| 商用か非商用か | 商用 (会員登録とログインがある。不動産の仲介サービスの PR 広告を載せている) |
| 推定の売上 | 推測: 月数万円以下。PR の成果報酬と見られる。登録会員の数と有料の機能は未確認 |
| 運営 | 企業 (Mokkatsumei K.K.、画面の著作権表示) |
| 推定の運用費 | 推測: 月数千〜数万円。Vercel の配信、周辺の施設を集めて AI で判定する処理 |
