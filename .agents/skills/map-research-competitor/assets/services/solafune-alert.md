# SNS災害情報集約マップAI

- URL: https://alert.solafune.com/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 地震などの災害のとき、気象庁、環境省、自治体の発表と報道、SNS を集めて、被害や通行障害、停電を地図に載せる AI のサービス |
| 提供する価値 | ばらばらに出る災害の情報を、出どころを示しながら 1 枚の地図で把握できる |
| 想定する利用者 | 被災地の住民、支援に入る人、報道や行政の担当者 |
| 商用か非商用か | 商用と見られる (企業の宣伝。無料。衛星データの AI を扱う企業の取り組みで、広告や有料プランは見えなかった) |
| 推定の売上 | 地図そのものの売上は無い。運営する企業の事業への集客と信頼づくりと見られる |
| 運営 | 企業 (株式会社 Solafune と見られる。ドメインから。ページに運営者の表示は見つからなかった) |
| 推定の運用費 | 推測: 月数万円。S3 と CloudFront の配信、地理院タイル、報道と SNS を集めて AI で読む処理の API の費用 |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | MapLibre GL JS |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | 地理院タイル |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | Amazon S3 + CloudFront |
