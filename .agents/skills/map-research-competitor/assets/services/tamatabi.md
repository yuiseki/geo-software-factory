## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 世界中のライブカメラ、定点カメラ、お天気カメラを 1 枚の地図に集め、クリックひとつで今の映像を見るサービス |
| 提供する価値 | 富士山や京都、星空やオーロラ、水族館まで、世界の今の景色を登録なし無料で旅するように眺められる |
| 想定する利用者 | 旅行や景色が好きな人、作業中に世界の景色を流したい人 |
| 商用か非商用か | 商用 (寄付。「コーヒーをおごる」で Stripe の寄付。広告は見えなかった) |
| 推定の売上 | 推測: 月数千〜数万円の寄付。はてなブックマーク 455 件 (2026-11-12)。寄付の額は公開されていない |
| 運営 | 個人と見られる (運営者の会社名は見つからなかった) |
| 推定の運用費 | 推測: 月数千円。カメラの一覧 (8.7 MB) の配信と、配信中かを数分おきに確かめる処理。映像は YouTube の埋め込み、背景は OpenFreeMap で費用はかからない |

- `https://tiles.openfreemap.org/styles/dark`

メモ:

- 世界のライブカメラを地図で見るサービス。カメラは YouTube の埋め込み
- カメラのデータは `/api/livecams` 1 本 (展開して 8.7 MB、転送 1.3 MB)。配信中かを確かめた時刻 (`checkedAt`) が数分前になっていた
- MapLibre GL JS 4.7.1 と OpenFreeMap の dark スタイルのほか、d3-geo と topojson で Natural Earth の陸地 (`land-50m.json`) を点で描いている
