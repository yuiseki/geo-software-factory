# TokyoMap（東京都地図情報サイト）

- URL: https://tokyomap.metro.tokyo.lg.jp/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 東京都、防災、暑さ対策、子育て、行政の地図、東京

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 東京都が持つ防災、暑さ対策、子育てなどの地図を 1 つに集め、地点やルートの検索と重ねて見る都の地図サイト |
| 提供する価値 | 目的地の周りの危険や暑さ、施設を、都の公式の情報でまとめて確かめられる |
| 想定する利用者 | 都民、東京を訪れる人、区市町村の職員 |
| 商用か非商用か | 非商用 (都の行政サービス) |
| 推定の売上 | なし (非商用) |
| 運営 | 公的機関 (東京都デジタルサービス局と一般財団法人 GovTech 東京) |
| 推定の運用費 | 推測: 月数十万〜数百万円。Google Maps JavaScript API の地図ロードは月 1 万回を超えると 1,000 回あたり 7 USD (10 万回を超えると 5.6 USD) で、はてなブックマーク 281 件の注目を受ける行政のサイトでは月数十万ロードはありうる。S3 と CloudFront の配信。開発と運用の委託費は別 |

## 技術 (2026-11-11 の観測)

| 項目 | 観測したもの |
|---|---|
| 描画 | Google Maps JavaScript API |
| フレームワーク | 見つからなかった |
| 背景の地図とタイル | Google Maps Platform |
| 投稿やデータの保存先 | 見えなかった |
| 配信 | Amazon S3 + CloudFront |
