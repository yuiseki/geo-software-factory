## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 日本各地の YouTube のライブカメラと定期更新の画像を、地図から探してその場で見るサービス |
| 提供する価値 | 目的地を決めずに、各地の今の天気や街、山、海、鉄道の景色を眺めて寄り道できる |
| 想定する利用者 | 天気や景色を見たい人、旅の下見をする人、作業用に景色を流したい人 |
| 商用か非商用か | 商用 (Google の広告。ウェブカメラの販売、レンタル、設置への誘導) |
| 推定の売上 | 推測: 月数万〜数十万円。広告は表示回数に比例し、はてなブックマーク 477 件 (2026-11-12) と話題になった。カメラ関連の仲介の収入は未確認 |
| 運営 | 企業 (株式会社ついのて、サイトの説明) |
| 推定の運用費 | 推測: 月数千円。Cloudflare の配信と地理院タイル。映像は YouTube の埋め込みなので配信の費用はかからない。配信中かの確認に YouTube Data API の割り当てを使うと見られる (推測) |
