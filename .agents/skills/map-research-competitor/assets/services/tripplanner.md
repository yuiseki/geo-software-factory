## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 雪崩の危険度と注意すべき雪崩の種類を選ぶと、雪崩が起きやすい斜面を地理院の地図に色分けする山行計画の地図 |
| 提供する価値 | 雪山に入る前に、ルートのどこが危ないかを地形と結びつけて想像できる。GPX のルートも読み込める |
| 想定する利用者 | 冬の山に入る登山者、山スキーやスノーボードをする人 |
| 商用か非商用か | 商用 (寄付。運営する NPO が寄付とサポーターを募り、ショップもある) |
| 推定の売上 | 推測: 団体全体で年数百万円規模の寄付と会費。地図そのものは無料。NPO の事業報告で確かめられる (未確認) |
| 運営 | 団体 (特定非営利活動法人 日本雪崩ネットワーク) |
| 推定の運用費 | 推測: 月数千円。Cloudflare の後ろの配信、地理院タイル、斜面を色分けした自前のデータ |
