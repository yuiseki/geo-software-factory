# USOMAP - 架空世界地図ジェネレーター｜無料の地図メーカー

- URL: https://amix-design.com/asoboad/tools/d-usomap/
- 観測した日: 2026-11-11
- 概要と収支を確かめた日: 2026-11-12
- 探すときの語: 架空の地図、ファンタジー地図、地図生成、世界観、TRPG、創作

## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | シードひとつで大陸、川、都市、国境、地名まで生成する架空の世界地図のメーカー |
| 提供する価値 | 物語やゲームの舞台の、筋の通った架空の世界地図を、登録なし無料で作って PNG、SVG、GeoJSON で書き出せる |
| 想定する利用者 | 小説やゲーム、TRPG の世界を作る人、イラストを描く人 |
| 商用か非商用か | 商用と見られる (企業の宣伝。無料、登録なし。デザイン事務所のサイト内の無料ツールで、広告と寄付は見えなかった) |
| 推定の売上 | 地図そのものの売上は無い。本業のデザインの受注への集客と見られる |
| 運営 | 企業 (デザイン事務所 AMIX) |
| 推定の運用費 | 推測: 月 0〜数千円。生成はブラウザの中で行い (データを外に送らないと明記)、Cloudflare の静的配信 |
