## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | ブラウザの AI エージェントが WebMCP を通じて Google マップを操作する様子を見せるデモ |
| 提供する価値 | AI エージェントがウェブの地図を道具として使う形を試せる |
| 想定する利用者 | WebMCP や AI エージェントを試す開発者 |
| 商用か非商用か | 非商用 (技術のデモ。広告、寄付は見えなかった) |
| 推定の売上 | なし (非商用) |
| 運営 | 個人と見られる (Cloudflare Pages の既定のドメイン。運営者の表示は見つからなかった) |
| 推定の運用費 | 推測: 月 0 円。Cloudflare Pages の静的配信と、Google Maps JavaScript API の無料枠 (月 1 万ロード) の範囲 |
