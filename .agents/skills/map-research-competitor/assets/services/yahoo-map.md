## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 見やすい地図、ナビ、乗換、テーマ別の地図 (ラーメン、EV 充電など)、混雑予報を提供する LINEヤフーの地図アプリとサイト |
| 提供する価値 | 文字やアイコンが大きく、地下鉄の出口や屋内の地図まで分かり、街歩きで迷わない |
| 想定する利用者 | 日本の一般の人 |
| 商用か非商用か | 商用 (アプリは無料。Yahoo! の広告 (サイトで yads への通信があった)) |
| 推定の売上 | 未公表 (LINEヤフーの地図の事業の売上は分けて公表されていない) |
| 運営 | 企業 (LINEヤフー株式会社) |
| 推定の運用費 | 未確認。ウェブ版は Mapbox GL JS と Mapbox の Standard スタイルと地形を読んでいた。Mapbox は地図ロードの数で課金される |
