## どんなサービスか

| 項目 | 内容 |
|---|---|
| 一行で | 電波の届かない山の中でも現在地が分かる地図と、登山の記録、山の情報、コミュニティを提供する登山のアプリとサイト |
| 提供する価値 | 遭難や道迷いを防ぎ、登山の記録を簡単に残して、ほかの人の最新のルートの状況を参考にできる |
| 想定する利用者 | 登山者、ハイカー |
| 商用か非商用か | 商用 (有料の YAMAP プレミアム、オンラインストア、アウトドア保険、ふるさと納税。学生は無料使い放題のキャンペーン) |
| 推定の売上 | 推測: 年数十億円規模。国内で最大級の登山アプリ (サイトの表示は App Ape の調べ)。売上は未確認 |
| 運営 | 企業 (株式会社ヤマップ、福岡市) |
| 推定の運用費 | 推測: 月数百万円以上。アプリと地図の配信、活動日記の保存、開発と運用の人件費 |
