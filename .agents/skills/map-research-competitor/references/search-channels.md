# 似たサービスを探す経路

経路ごとに見つかるものが違う。1 つの経路で見つからなくても、他の経路で探してから「見つからなかった」と書く。探した経路、検索語、日付は、プロダクト概要の「似たサービスと違い」に残す。

## 経路と得手不得手

| 経路 | 見つけやすいもの | 見落としやすいもの | 使い方 |
|---|---|---|---|
| 本人に聞く | 本人が前に見たもの、同じ関心の人の間で話題になったもの | 本人が知らないもの | SKILL.md の手順 1。最初に聞く |
| ウェブ検索 | 企業や団体の公式のサービス、報道されたアプリ、名簿や電話帳 | 個人や小さなチームが最近作ったサービス。サービス名を指定しても出ないことがある | 日本語と英語の両方で、対象 + 範囲 + 「地図」「マップ」で引く |
| はてなブックマークの検索 | 公開されてすぐ話題になった個人のサービス。ブックマーク数で注目の度合いも分かる | ブックマークされなかったもの、日本語圏の外のもの | `https://b.hatena.ne.jp/q/<検索語>?target=all&sort=recent`。既定では 3 users 以上、直近 5 年が対象 |
| GitHub の検索 | ソースを公開しているもの。技術の構成まで読める | ソースを公開していないもの (大半) | `gh search repos "<検索語>"`。日本語の語と英語の語の両方で |
| アプリのストア | ネイティブアプリとして出ているもの。既存のアプリの新しい機能 (例: ナビのアプリの中の地図) は、運営者のプレスリリースで知ることが多い | ウェブだけのもの | App Store は `https://itunes.apple.com/search?term=<検索語>&country=jp&entity=software` (販売元、価格、評価の数、初出と更新の日が JSON で返る)。Google Play は `https://play.google.com/store/search?q=<検索語>&c=apps&hl=ja` で、出てきたパッケージ名の詳細のページからダウンロード数を読む |

次の経路は、2026-11-11 時点で試していない (未確認): X や Bluesky の投稿の検索、note、Zenn、Qiita、Product Hunt、公開された uMap や Google マイマップ。新しいサービスは公開の告知が投稿でされることが多いので、使える環境なら試す価値がある (推測)。

## 試した記録: 「全国の本屋だけに注目した地図」(2026-11-11)

「今からほんや」(https://imahon.jp/) を知らないまま、全国の本屋の地図を思いついた場合を想定して、各経路で探した。

| 経路 | 検索語 | 今からほんや | ほかに見つかったもの |
|---|---|---|---|
| ウェブ検索 (このエージェントの検索の道具) | 「全国 本屋 地図 探す サービス」 | 出ない | マピオン電話帳の全国の書店一覧、全国古書籍商組合連合会の「日本の古本屋」と地図から探す古本屋の一覧 |
| ウェブ検索 | 「本屋 マップ 全国 書店 検索 地図アプリ 2026」 | 出ない | 本コレ (出版業界 8 社が出資する会社のアプリ)、丸善ジュンク堂書店のアプリ、カーリル (図書館) |
| ウェブ検索 | 「"今からほんや"」(名前の完全一致) | 出ない | 名前の一部の「ほんや」に当たる別の店や絵本 |
| はてなブックマークの検索 | 「本屋 地図」(新着順) | 1 件目に出た (「今からほんや｜出かけた先で、本屋を探す地図」、99 users) | 「Readsの地図をつくりました」 |
| GitHub の検索 | 「本屋 地図」「bookstore map japan」 | 出ない | なし |

ウェブ検索だけで探していたら、今からほんやを見落とし、本コレとマピオンだけを比べていた。逆に、はてなブックマークだけでは、本コレのような業界のアプリは出なかった。経路を重ねる理由はこの 2 つである。
