# プロダクト概要: 台東区 浸水時避難場所マップ

## 一行で

水害のおそれがあるときの住民の「どの避難場所が浸水区域外で、今から一番近いか分からない」という困りごとを、避難場所と浸水想定区域の重ね合わせと最寄り検索で解く。

## 利用者と場面

- 利用者: 台東区周辺の住民・滞在者
- 場面: 豪雨や水害の警報が出たときに、安全な避難場所を探して向かう
- 端末: スマートフォンとパソコンのブラウザ

## 提供する価値

1. 最重要: 避難場所の正確な位置と、浸水想定区域の内か外かが正しく分かる
2. 重要: 現在地（指定座標）から最も近い安全な避難場所と距離をすぐ調べられる
3. 副次的: バリアフリー対応や名前で絞り込める

## 地図の役割

主役。現在地を自動で取得しなくてよいが、指定座標からの最寄り検索を提供する。

## 表示するデータ

- 避難場所 12 件: `data/shelters.csv`。列は `id, name, ward, x, y, capacity, wheelchair`。座標は平面直角座標系 第 IX 系 (JGD2011)、単位はメートル。評価用に作ったデータで、ライセンスは CC0
- 浸水想定区域: `data/hazard_zones.geojson`。WGS84 (EPSG:4326) のポリゴン GeoJSON。評価用に作ったデータで、ライセンスは CC0
- 書き込むもの: なし

## 機能

| 優先度 | 機能 | この機能が届ける価値 |
|---|---|---|
| Must | 避難場所 12 件と浸水想定区域を地図に表示する | 避難場所と浸水区域の位置関係が分かる |
| Must | 浸水想定区域外の避難場所だけを残す (`safe_only=true`) | 浸水時に使える安全な場所だけを選べる |
| Must | 指定座標からの最寄り避難場所と距離 (`distance_m`) を返す | 一番近い避難場所をすぐ決められる |
| Must | 名前 (`q`) とバリアフリー (`wheelchair=true`) で絞り込む | 条件に合う避難場所を見つけられる |
| Must | 不正な入力や過大な入力で落ちず `400` を返し、HTML を安全に扱う | 誤操作や異常入力でも壊れない |
| Must | 出典を画面に表示する | データの出どころが分かる |

## 完成の条件

- 大枠: 次の約束を守るアプリが、リポジトリの `start.sh` で起動すること
  - `sh start.sh` で、0.0.0.0 の 8787 番で待ち受ける。起動に要るものは、このリポジトリとコンテナの中にあるもの (Python 3.12、pyproj) だけにする
  - `GET /` が地図の画面を返し、画面に出典として「避難場所データ: 評価用 (CC0)」の文字列をそのまま表示する
  - `GET /api/shelters` が GeoJSON FeatureCollection (経度、緯度の順、WGS84) を返す。各 Feature の `properties` に `id`, `name`, `ward`, `capacity` (整数), `wheelchair` (真偽値), `in_hazard` (真偽値) を入れる
  - `GET /api/shelters` は `q` (名称の部分一致)、`wheelchair=true`、`safe_only=true` (浸水想定区域ポリゴンの外にあるものだけ) のクエリを受け付ける。組み合わせて使えて、該当が 0 件なら空の FeatureCollection を状態 200 で返す
  - `GET /api/nearest?lon=<経度>&lat=<緯度>` が JSON (`{"shelter": <Feature>, "distance_m": <メートル数値>}`) を返す。`safe_only=true` や `wheelchair=true` も受け付け、条件に合う避難場所が無ければ `404` を返す
  - 不正な座標 (`lon` が -180..180 外、`lat` が -90..90 外、数値でない)、過大な `q` (例: 500 文字超)、未知のパラメータ異常に対して `500` で落ちず `400` を返す
- 評価のシナリオの置き場所: 評価者のコンテナの中。本数: 5。実装者には見せない
- 判定: 機械で判定する
- 本人と決めた閾値と見た目の基準: シナリオの中
- 代役で評価するもの / 本物で評価するもの: 外部のサービスは使わない

## 判断の方針

- 費用: 無料のものだけ
- 優先順位: Must を確実に。空間判定・距離計算・入力検証の正確さを優先する
- 迷ったときの既定: 外部のサービスに頼らない。背景の地図は無くてよい。公開の OpenStreetMap のサーバー (tile.openstreetmap.org、nominatim.openstreetmap.org、overpass-api.de) は使わない
- 公開の範囲: 手元だけ。デプロイしない
