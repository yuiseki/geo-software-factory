# プロダクト概要: ライブカメラで世界を眺める

## 一行で

自宅でゆっくり過ごす人が、世界のどこかと繋がっている感覚を得られるよう、ライブカメラの映像を自動で巡り、地球上のおおまかな位置と詳細な位置を地図で示す。

## 利用者と場面

- 利用者: 最初は本人。いずれ不特定多数が使えるようにしたい。
- 場面: 家でゆっくり過ごしているとき、スクリーンセーバーや BGM のように眺める。
- 端末: パソコンの画面と、テレビや大きなディスプレイ。スマートフォンやタブレットにも需要があるかもしれない。
- 今のやり方: 未確認。

## 提供する価値

1. 最重要: 部屋に引きこもっていても、世界のどこかと繋がっているという感覚を得られること。街の雰囲気や場所ごとの時間から、その場所の今を感じる。
2. 重要・副次的: 落ち着いて眺めること、知らない場所との出会い、旅をしている気分の順位は、作ってみてから判断する。

## 地図の役割

ライブ映像の右側に、地球と詳細地図を縦に並べ、その場所を地球全体の中に位置づける。小さな地球でおおまかな位置を示し、詳細な位置も示す。四つの映像を同時に表示し、それぞれの映像に地球と地図を付ける。地球では所在国を塗り、詳細地図では該当する行政区画を Natural Earth の admin-1 のポリゴンで示し、カメラの位置にピンを立てる。現在地の利用は未定。

- 書き込むもの: 未定。将来はカメラの生存状態や発見したカメラを管理したい。

## 機能

| 優先度 | 機能 | この機能が届ける価値 |
|---|---|---|
| Must | 公開ライブカメラの映像をランダムに再生し、数分ごとに次の場所へ自動で切り替える | 操作せず、各地の今を眺め続ける |
| Must | 映像ごとに、小さな地球でおおまかな位置と地図で詳細な位置を示す | 映っている場所と世界との位置関係を感じる |
| Must | 四つの映像を同時に表示する | 複数の場所を一度に眺める |
| Should / Could 未定 | Lo-Fi 系の BGM を、場所の切り替えに関係なく流し続ける | 映像を眺めながら過ごす |
| Should / Could 未定 | カメラを約 1 日に 1 回生存チェックし、再生できないものを一時的に外して再確認する。失敗が続けば削除する | 再生できない映像を減らす |
| Should / Could 未定 | 再生時のエラーを受け取り、再生対象の管理に役立てる | 再生できない映像への対応 |
| Should / Could 未定 | AI エージェントが約 1 週間に 1 回、新しいライブカメラを探して追加する | 新しい場所との出会いを増やす |

後から取り組む機能の優先順位は、最初の版を使ってから決める。
